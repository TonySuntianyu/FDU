# Lab7 知识点详解

## 1. 并查集（Union-Find / Disjoint Set Union, DSU）

### 1.1 基本概念

并查集是一种树型的数据结构，用于处理一些**不交集的合并及查询问题**。它支持两种主要操作：
- **Find（查找）**：确定某个元素属于哪个子集
- **Union（合并）**：将两个子集合并成一个集合

### 1.2 核心思想

并查集通过维护一个**父节点数组**来表示集合关系：
- 每个元素都有一个父节点
- 如果元素的父节点是它自己，那么它就是该集合的**根节点**
- 属于同一个集合的元素，它们的根节点相同

### 1.3 基本实现

#### 1.3.1 初始化

```cpp
class UnionFind {
private:
    vector<int> parent;  // 父节点数组
    vector<int> rank;    // 秩数组（用于优化）

public:
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++) {
            parent[i] = i;  // 初始时每个节点都是自己的父节点
        }
    }
};
```

#### 1.3.2 Find 操作（查找根节点）

**朴素实现**：
```cpp
int find(int x) {
    if (parent[x] != x) {
        return find(parent[x]);  // 递归向上查找
    }
    return x;
}
```

**路径压缩优化**：
```cpp
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);  // 路径压缩：直接指向根节点
    }
    return parent[x];
}
```

**路径压缩的作用**：将查找路径上的所有节点直接连接到根节点，减少后续查找的时间复杂度。

#### 1.3.3 Union 操作（合并集合）

**朴素实现**：
```cpp
void unite(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
        parent[rootX] = rootY;  // 简单合并
    }
}
```

**按秩合并优化**：
```cpp
void unite(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    
    if (rootX == rootY) return;  // 已在同一集合
    
    // 按秩合并：将秩小的树合并到秩大的树下
    if (rank[rootX] < rank[rootY]) {
        parent[rootX] = rootY;
    } else if (rank[rootX] > rank[rootY]) {
        parent[rootY] = rootX;
    } else {
        parent[rootY] = rootX;
        rank[rootX]++;  // 秩相同时，合并后秩加1
    }
}
```

**按秩合并的作用**：保持树的平衡，避免树退化成链，提高查找效率。

### 1.4 时间复杂度

- **朴素实现**：O(n) 最坏情况
- **仅路径压缩**：O(log n) 平均情况
- **路径压缩 + 按秩合并**：O(α(n))，其中 α 是阿克曼函数的反函数，在可预见的范围内几乎为常数

### 1.5 应用场景

1. **连通性问题**：判断图中两点是否连通
2. **等价关系**：判断元素是否属于同一等价类
3. **约束满足问题**：如Lab7题目1，判断约束条件是否冲突
4. **最小生成树**：Kruskal算法中判断边是否形成环

### 1.6 Lab7题目1中的应用

在程序分析问题中：
- **相等约束（e=1）**：使用 `unite(x, y)` 将变量合并到同一集合
- **不等约束（e=0）**：使用 `same(x, y)` 检查两个变量是否在同一集合
  - 如果在同一集合，说明通过相等约束可以推出 x = y，与不等约束冲突
  - 如果不在同一集合，说明约束可以满足

**算法流程**：
1. 先处理所有相等约束，建立并查集
2. 再检查所有不等约束，看是否与已建立的相等关系冲突

## 2. 最小生成树（Minimum Spanning Tree, MST）

### 2.1 基本概念

**生成树**：一个连通无向图的生成树是包含图中所有顶点的极小连通子图，有 n-1 条边。

**最小生成树**：所有生成树中，边权总和最小的那棵树。

### 2.2 应用场景

- 网络设计：用最少的成本连接所有节点
- 电路设计：用最少的导线连接所有元件
- 聚类分析：将数据点分组

### 2.3 Kruskal 算法

#### 2.3.1 算法思想

Kruskal算法采用**贪心策略**：
1. 将所有边按权重从小到大排序
2. 依次考虑每条边
3. 如果加入这条边不会形成环，则加入MST
4. 重复步骤2-3，直到有 n-1 条边

#### 2.3.2 算法步骤

```
1. 初始化并查集，每个顶点自成一个集合
2. 将所有边按权重排序
3. 遍历排序后的边：
   a. 如果边的两个端点不在同一集合（不形成环）
   b. 则加入MST，并合并这两个集合
   c. MST边数加1
4. 当MST边数达到 n-1 时，算法结束
```

#### 2.3.3 代码实现

```cpp
// 边的结构
struct Edge {
    int u, v;
    long long w;
    bool operator<(const Edge& other) const {
        return w < other.w;
    }
};

// Kruskal算法主流程
long long kruskal(int n, vector<Edge>& edges) {
    // 1. 排序
    sort(edges.begin(), edges.end());
    
    // 2. 初始化并查集
    UnionFind uf(n);
    
    // 3. 贪心选择边
    long long mstWeight = 0;
    int edgeCount = 0;
    
    for (const Edge& e : edges) {
        if (!uf.same(e.u, e.v)) {  // 不形成环
            uf.unite(e.u, e.v);
            mstWeight += e.w;
            edgeCount++;
            if (edgeCount == n - 1) break;  // 已找到MST
        }
    }
    
    return mstWeight;
}
```

#### 2.3.4 为什么不会形成环？

- 如果边 (u, v) 的两个端点已经在同一集合中，说明 u 和 v 已经通过其他路径连通
- 加入这条边会形成环，所以不加入
- 如果两个端点不在同一集合，加入后不会形成环，可以安全加入

### 2.4 时间复杂度

- **排序**：O(m log m)，其中 m 是边数
- **并查集操作**：O(m α(n))，其中 n 是顶点数
- **总时间复杂度**：O(m log m)，主要由排序决定

### 2.5 算法正确性证明（贪心选择性质）

**关键引理**：设 S 是某个最小生成树的一部分，e 是连接 S 和 V-S 的最小权重边，则 e 一定属于某个最小生成树。

**证明思路**：
- 假设存在最小生成树 T 不包含 e
- 在 T 中，从 S 到 V-S 一定存在另一条边 e'
- 用 e 替换 e' 得到 T'，由于 w(e) ≤ w(e')，所以 w(T') ≤ w(T)
- 因此 e 属于某个最小生成树

### 2.6 其他MST算法

#### 2.6.1 Prim算法

**思想**：从任意顶点开始，每次选择连接已选顶点和未选顶点的最小权重边。

**时间复杂度**：
- 朴素实现：O(n²)
- 使用优先队列：O(m log n)

**适用场景**：稠密图（边数接近 n²）

#### 2.6.2 Kruskal vs Prim

| 特性 | Kruskal | Prim |
|------|---------|------|
| 思想 | 按边排序，贪心选择 | 从点出发，逐步扩展 |
| 数据结构 | 并查集 | 优先队列 |
| 时间复杂度 | O(m log m) | O(m log n) |
| 适用场景 | 稀疏图 | 稠密图 |
| 实现难度 | 较简单 | 中等 |

### 2.7 Lab7题目2中的实现细节

1. **边权范围**：0 ≤ w ≤ 10⁹，使用 `long long` 存储边权和
2. **数据规模**：n ≤ 2×10⁵, m ≤ 5×10⁵，需要高效的排序和并查集
3. **优化**：使用路径压缩和按秩合并的并查集，提前退出（当边数达到 n-1）

## 4. 常见问题与注意事项

### 4.1 并查集常见问题

**Q1: 为什么需要路径压缩？**
- 避免树退化成链，提高查找效率

**Q2: 为什么需要按秩合并？**
- 保持树的高度较小，进一步优化性能

**Q3: 如何处理大范围的节点编号？**
- 使用 `unordered_map` 进行离散化（如Lab7题目1）

### 4.2 最小生成树常见问题

**Q1: 如果图不连通怎么办？**
- Kruskal算法会生成最小生成森林（每个连通分量一棵树）
- 需要检查最终边数是否为 n-1

**Q2: 如何处理重边和自环？**
- 重边：保留权重最小的
- 自环：在Kruskal中会自动跳过（因为 same(u, u) 为 true）

**Q3: 如何输出MST的边？**
- 在加入边时记录即可
