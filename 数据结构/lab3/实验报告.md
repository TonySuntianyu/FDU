## 题目一：矩阵乘法

### 问题分析
给定两个矩阵A(n×p)和B(p×m)，计算它们的乘积C = A × B，并对结果进行模运算。

### 设计思路

#### 1. 数据结构选择
- 使用`vector<vector<long long>>`存储矩阵
- 选择`long long`类型避免整数溢出
- 利用vector的自动初始化特性

#### 2. 算法实现
```cpp
// 核心算法：三重循环计算矩阵乘法
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        for (int k = 0; k < p; k++) {
            C[i][j] = (C[i][j] + (A[i][k] * B[k][j]) % MOD) % MOD;
        }
    }
}
```

#### 3. 模运算处理
- 常量定义：`const int MOD = 1e9 + 7`
- 中间结果取模避免溢出
- 最终输出确保非负数：`(C[i][j] + MOD) % MOD`

#### 4. 时间复杂度
- 时间复杂度：O(n×p×m)
- 空间复杂度：O(n×m + n×p + p×m)

### 关键优化点
1. **防止溢出**：在累加过程中及时取模
2. **负数处理**：确保最终结果非负
3. **内存管理**：使用vector自动管理内存

## 题目二：子串数量（KMP算法）

### 问题分析
使用KMP算法计算字符串B在字符串A中的出现次数，支持重叠匹配。

### 设计思路

#### 1. KMP算法原理
KMP算法通过预处理模式串，构建next数组，避免重复比较已匹配的部分。

#### 2. next数组构建
```cpp
vector<int> buildNext(const string& pattern) {
    int m = pattern.length();
    vector<int> next(m, 0);
    int j = 0;
    
    for (int i = 1; i < m; i++) {
        // 不匹配时回退
        while (j > 0 && pattern[i] != pattern[j]) {
            j = next[j - 1];
        }
        // 匹配时前进
        if (pattern[i] == pattern[j]) {
            j++;
        }
        next[i] = j;
    }
    return next;
}
```

#### 3. 模式匹配过程
```cpp
int kmpSearch(const string& text, const string& pattern) {
    vector<int> next = buildNext(pattern);
    int count = 0, j = 0;
    
    for (int i = 0; i < text.length(); i++) {
        while (j > 0 && text[i] != pattern[j]) {
            j = next[j - 1];
        }
        if (text[i] == pattern[j]) {
            j++;
        }
        if (j == pattern.length()) {
            count++;
            j = next[j - 1]; // 支持重叠匹配
        }
    }
    return count;
}
```

#### 4. 算法特点
- **时间复杂度**：O(n + m)
- **空间复杂度**：O(m)
- **优势**：避免重复比较，支持重叠匹配

### 关键设计决策
1. **重叠匹配**：完全匹配后回退到next[j-1]位置
2. **边界处理**：处理空字符串和长度不匹配的情况
3. **模块化设计**：将next数组构建和匹配分离

## 题目三：编程作业（代码雷同检测）

### 问题分析
检测代码片段在完整代码中的出现次数，通过变量替换标准化后使用KMP算法。

### 设计思路

#### 1. 问题归约
将代码雷同检测问题转换为字符串匹配问题：
- 变量标准化：将变量按出现顺序映射为a,b,c...
- 非变量标准化：将非变量符号按出现顺序映射为A,B,C...

#### 2. 代码标准化算法
```cpp
string normalizeCode(const string& code) {
    map<char, char> varMap;      // 变量映射表
    map<char, char> nonVarMap;   // 非变量符号映射表
    char nextVar = 'a';
    char nextNonVar = 'A';
    
    string result = "";
    for (char c : code) {
        if (c >= 'a' && c <= 'z') {
            // 变量处理
            if (varMap.find(c) == varMap.end()) {
                varMap[c] = nextVar++;
            }
            result += varMap[c];
        } else if (c >= 'A' && c <= 'Z') {
            // 非变量符号处理
            if (nonVarMap.find(c) == nonVarMap.end()) {
                nonVarMap[c] = nextNonVar++;
            }
            result += nonVarMap[c];
        } else {
            result += c;
        }
    }
    return result;
}
```

#### 3. 算法流程
1. **输入处理**：读取完整代码S和代码片段T
2. **标准化**：将S和T都进行标准化处理
3. **KMP匹配**：使用KMP算法计算标准化后的T在标准化后的S中的出现次数
4. **输出结果**：返回匹配次数

#### 4. 归约的正确性
- **变量替换**：不同变量名映射为相同符号，保持结构一致
- **非变量保持**：关键字、运算符等保持原有映射关系
- **结构保持**：代码的整体结构在标准化后保持不变

### 关键设计决策
1. **映射策略**：分别处理变量和非变量符号
2. **算法复用**：直接使用题目二的KMP算法
3. **边界处理**：处理空字符串和长度不匹配的情况
