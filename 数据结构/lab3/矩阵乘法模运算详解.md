# 矩阵乘法中模运算详解

## 1. 模运算的基本概念

### 1.1 数学定义

模运算（Modular Arithmetic）是数论中的一个重要概念。对于整数a、b和正整数m，我们定义：

```
a ≡ b (mod m) 当且仅当 m | (a - b)
```

即a和b在模m意义下同余，当且仅当m能整除(a-b)。

### 1.2 基本性质

模运算具有以下重要性质：

1. **加法性质**：`(a + b) mod m = ((a mod m) + (b mod m)) mod m`
2. **乘法性质**：`(a × b) mod m = ((a mod m) × (b mod m)) mod m`
3. **幂运算性质**：`(a^n) mod m = ((a mod m)^n) mod m`

## 2. 矩阵乘法中模运算的必要性

### 2.1 防止整数溢出

在矩阵乘法中，每个结果元素的计算公式为：

```
C[i][j] = Σ(A[i][k] × B[k][j]) for k = 0 to p-1
```

**问题**：当矩阵元素很大时，累加过程可能导致整数溢出。

**示例**：
```cpp
// 假设矩阵元素范围为 -10^9 到 10^9
// 对于 500×500 的矩阵，累加结果可能达到 500 × 10^9 × 10^9 = 5×10^20
// 这超出了 long long 的表示范围（约 9×10^18）
```

### 2.2 保持结果在合理范围内

通过模运算，我们可以将结果限制在 [0, MOD-1] 范围内，避免溢出问题。

## 3. 模运算在矩阵乘法中的实现

### 3.1 基本实现

```cpp
const int MOD = 1e9 + 7;  // 10^9 + 7

// 错误的实现方式
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        long long sum = 0;
        for (int k = 0; k < p; k++) {
            sum += A[i][k] * B[k][j];  // 可能溢出
        }
        C[i][j] = sum % MOD;  // 只在最后取模
    }
}
```

**问题**：在累加过程中可能发生溢出，导致错误结果。

### 3.2 正确的实现方式

```cpp
const int MOD = 1e9 + 7;

for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        long long sum = 0;
        for (int k = 0; k < p; k++) {
            // 方法1：每次累加后立即取模
            sum = (sum + (A[i][k] * B[k][j]) % MOD) % MOD;
        }
        C[i][j] = sum;
    }
}
```

### 3.3 更安全的实现方式

```cpp
const int MOD = 1e9 + 7;

for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        long long sum = 0;
        for (int k = 0; k < p; k++) {
            // 方法2：分步取模，更加安全
            long long product = (A[i][k] % MOD) * (B[k][j] % MOD);
            product %= MOD;
            sum = (sum + product) % MOD;
        }
        C[i][j] = sum;
    }
}
```

## 4. 负数处理

### 4.1 问题描述

在模运算中，负数取模的结果可能为负数，但通常我们希望结果在 [0, MOD-1] 范围内。

### 4.2 负数取模的规则

在C++中，负数取模的结果取决于编译器的实现：
- 有些编译器返回负数
- 有些编译器返回正数

**示例**：
```cpp
int a = -5;
int b = 3;
int result = a % b;  // 结果可能是 -2 或 1
```

### 4.3 确保非负结果

```cpp
// 确保模运算结果为非负数
int safeMod(long long x, int mod) {
    return ((x % mod) + mod) % mod;
}

// 在矩阵乘法中的应用
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        long long sum = 0;
        for (int k = 0; k < p; k++) {
            sum = (sum + (A[i][k] * B[k][j]) % MOD) % MOD;
        }
        C[i][j] = (sum + MOD) % MOD;  // 确保非负
    }
}
```

## 5. 为什么选择 MOD = 10^9 + 7

### 5.1 质数性质

10^9 + 7 = 1,000,000,007 是一个质数，具有以下优势：

1. **模逆元存在**：在模质数意义下，每个非零元素都有模逆元
2. **运算性质良好**：质数模运算具有更好的数学性质
3. **避免特殊值**：质数模运算不容易产生特殊值

### 5.2 数值范围合适

- **表示范围**：10^9 + 7 在 int 范围内（2^31 - 1 ≈ 2.1×10^9）
- **运算安全**：两个 10^9 的数相乘不会超过 long long 范围
- **常见选择**：在竞赛编程中广泛使用

### 5.3 其他常见模数

```cpp
const int MOD1 = 1e9 + 7;   // 1,000,000,007 (最常用)
const int MOD2 = 1e9 + 9;   // 1,000,000,009 (另一个质数)
const int MOD3 = 998244353; // 另一个常用的质数模数
```

## 6. 模运算的数学意义

### 6.1 同余关系

模运算建立了同余关系，使得在模意义下：
- 不同的数可能相等
- 运算结果在有限范围内
- 保持了运算的代数结构

### 6.2 矩阵乘法的模运算性质

对于矩阵A、B和模数m：

```
(A × B) mod m = ((A mod m) × (B mod m)) mod m
```

这意味着我们可以对矩阵元素先取模，再进行乘法运算。

## 8. 代码实现细节

### 8.1 完整的矩阵乘法实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MOD = 1e9 + 7;

int main() {
    int n, p, m;
    cin >> n >> p >> m;
    
    // 读取矩阵A
    vector<vector<long long>> A(n, vector<long long>(p));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < p; j++) {
            cin >> A[i][j];
        }
    }
    
    // 读取矩阵B
    vector<vector<long long>> B(p, vector<long long>(m));
    for (int i = 0; i < p; i++) {
        for (int j = 0; j < m; j++) {
            cin >> B[i][j];
        }
    }
    
    // 矩阵乘法 with 模运算
    vector<vector<long long>> C(n, vector<long long>(m, 0));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            for (int k = 0; k < p; k++) {
                // 关键：每次累加后立即取模
                C[i][j] = (C[i][j] + (A[i][k] * B[k][j]) % MOD) % MOD;
            }
        }
    }
    
    // 输出结果，确保非负数
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << (C[i][j] + MOD) % MOD;
            if (j < m - 1) cout << " ";
        }
        cout << endl;
    }
    
    return 0;
}
```

### 8.2 关键点总结

1. **数据类型选择**：使用 `long long` 避免中间计算溢出
2. **取模时机**：每次累加后立即取模
3. **负数处理**：最终结果使用 `(x + MOD) % MOD` 确保非负
4. **模数选择**：使用质数模数 10^9 + 7

## 9. 总结

矩阵乘法中的模运算是一个重要的技术，它：

1. **防止溢出**：避免大数运算导致的整数溢出
2. **保持精度**：在有限范围内保持运算的准确性
3. **提高效率**：减少大数运算的开销
4. **扩展应用**：为后续的数学运算提供基础

通过合理使用模运算，我们可以在保证计算正确性的同时，处理更大规模的矩阵运算问题。
