## 1. 卡特兰数简介

卡特兰数（Catalan Numbers）是组合数学中一个重要的数列，以比利时数学家欧仁·查理·卡特兰（Eugène Charles Catalan）的名字命名。卡特兰数在计算机科学、组合数学、几何学等领域有广泛的应用。

### 历史背景
- 卡特兰数最早由瑞士数学家莱昂哈德·欧拉（Leonhard Euler）在18世纪研究多边形三角剖分时发现
- 19世纪，比利时数学家卡特兰在研究括号匹配问题时重新发现了这个数列
- 20世纪以来，卡特兰数在计算机科学中得到了广泛应用

## 2. 卡特兰数的定义

卡特兰数序列的前几项为：
```
C₀ = 1
C₁ = 1
C₂ = 2
C₃ = 5
C₄ = 14
C₅ = 42
C₆ = 132
C₇ = 429
C₈ = 1430
...
```

### 通项公式
卡特兰数的通项公式为：
```
Cₙ = (1/(n+1)) × C(2n,n) = (2n)! / ((n+1)! × n!)
```

其中 C(2n,n) 表示从 2n 个元素中选择 n 个元素的组合数。

### 递推关系
卡特兰数满足以下递推关系：
```
C₀ = 1
Cₙ = Σ(i=0 to n-1) Cᵢ × Cₙ₋₁₋ᵢ  (n ≥ 1)
```

## 3. 卡特兰数的递推关系

### 递推公式的推导

考虑第 n 个卡特兰数 Cₙ 的计算。我们可以通过以下方式理解：

**思路：** 将问题分解为子问题，利用动态规划的思想。

**具体推导：**

对于 n ≥ 1，考虑如何计算 Cₙ：

1. **分解问题**：将 n 个元素的问题分解为两个子问题
2. **选择分割点**：选择第 i 个位置作为分割点（0 ≤ i ≤ n-1）
3. **递归计算**：左边有 i 个元素，右边有 n-1-i 个元素

**递推关系建立：**
```
Cₙ = C₀ × Cₙ₋₁ + C₁ × Cₙ₋₂ + C₂ × Cₙ₋₃ + ... + Cₙ₋₁ × C₀
```

**数学表达：**
```
Cₙ = Σ(i=0 to n-1) Cᵢ × Cₙ₋₁₋ᵢ
```

### 递推关系的验证

让我们验证前几项：

**C₀ = 1**（定义）

**C₁ = Σ(i=0 to 0) Cᵢ × C₀₋ᵢ = C₀ × C₀ = 1 × 1 = 1** ✓

**C₂ = Σ(i=0 to 1) Cᵢ × C₁₋ᵢ = C₀ × C₁ + C₁ × C₀ = 1 × 1 + 1 × 1 = 2** ✓

**C₃ = Σ(i=0 to 2) Cᵢ × C₂₋ᵢ = C₀ × C₂ + C₁ × C₁ + C₂ × C₀ = 1 × 2 + 1 × 1 + 2 × 1 = 5** ✓

## 4. 卡特兰数的通项公式推导

### 方法一：生成函数法

**步骤1：定义生成函数**
设卡特兰数的生成函数为：
```
G(x) = C₀ + C₁x + C₂x² + C₃x³ + ...
```

**步骤2：利用递推关系**
根据递推关系 Cₙ = Σ(i=0 to n-1) Cᵢ × Cₙ₋₁₋ᵢ，我们有：
```
G(x) = 1 + x × G(x)²
```

**步骤3：解二次方程**
```
G(x) = 1 + x × G(x)²
x × G(x)² - G(x) + 1 = 0
```

使用二次公式：
```
G(x) = (1 ± √(1 - 4x)) / (2x)
```

**步骤4：选择正确的根**
由于 G(0) = C₀ = 1，我们选择负号：
```
G(x) = (1 - √(1 - 4x)) / (2x)
```

**步骤5：展开平方根**
使用二项式定理展开 √(1 - 4x)：
```
√(1 - 4x) = 1 - 2x - 2x² - 4x³ - ...
```

**步骤6：计算系数**
```
G(x) = (1 - (1 - 2x - 2x² - 4x³ - ...)) / (2x)
     = (2x + 2x² + 4x³ + ...) / (2x)
     = 1 + x + 2x² + 5x³ + ...
```

因此：
```
Cₙ = (1/(n+1)) × C(2n,n)
```

### 方法二：组合计数法

**问题：** 计算从 (0,0) 到 (n,n) 的不越过对角线 y=x 的路径数。

**分析：**
1. **总路径数**：从 (0,0) 到 (n,n) 的路径总数为 C(2n,n)
2. **无效路径**：越过对角线的路径数
3. **有效路径**：总路径数 - 无效路径数

**计算无效路径：**
对于每条越过对角线的路径，存在一个"反射"路径，其数量等于 C(2n,n+1)。

**卡特兰数公式：**
```
Cₙ = C(2n,n) - C(2n,n+1) = (1/(n+1)) × C(2n,n)
```

## 5. 卡特兰数的应用

### 5.1 二叉树计数

**问题：** n 个节点的不同二叉树结构有多少种？

**解答：** Cₙ

**解释：** 
- 根节点固定，左子树有 i 个节点，右子树有 n-1-i 个节点
- 左子树有 Cᵢ 种结构，右子树有 Cₙ₋₁₋ᵢ 种结构
- 总数为 Σ(i=0 to n-1) Cᵢ × Cₙ₋₁₋ᵢ = Cₙ

### 5.2 括号匹配

**问题：** n 对括号有多少种正确的匹配方式？

**解答：** Cₙ

**解释：**
- 第一个括号必须是左括号
- 第 k 个左括号必须与某个右括号匹配
- 匹配后，左边有 k-1 对括号，右边有 n-k 对括号
- 总数为 Σ(k=1 to n) Cₖ₋₁ × Cₙ₋ₖ = Cₙ

### 5.3 多边形三角剖分

**问题：** 将 n+2 边形分割成三角形有多少种方法？

**解答：** Cₙ

**解释：**
- 选择一条边作为基准
- 选择第 k 个顶点与基准边形成三角形
- 左边是 k+1 边形，右边是 n-k+2 边形
- 总数为 Σ(k=1 to n) Cₖ₋₁ × Cₙ₋ₖ = Cₙ

### 5.4 路径计数

**问题：** 从 (0,0) 到 (n,n) 不越过对角线 y=x 的路径数？

**解答：** Cₙ

### 5.5 栈操作序列

**问题：** 1,2,...,n 通过栈有多少种不同的输出序列？

**解答：** Cₙ

**解释：**
- 每个数字要么入栈，要么出栈
- 入栈对应左括号，出栈对应右括号
- 转化为括号匹配问题

## 6. 卡特兰数的性质

### 6.1 基本性质

1. **单调性**：Cₙ 随 n 单调递增
2. **增长率**：Cₙ ≈ 4ⁿ / (√π × n^(3/2))
3. **奇偶性**：Cₙ 的奇偶性取决于 n

### 6.2 渐近性质

**斯特林公式近似：**
```
Cₙ ≈ 4ⁿ / (√π × n^(3/2)) × (1 - 9/(8n) + 145/(128n²) - ...)
```

**对数增长率：**
```
lim(n→∞) (ln Cₙ) / n = ln 4 ≈ 1.386
```

### 6.3 数论性质

1. **整除性**：Cₙ 总是整数
2. **模运算**：Cₙ mod p 的性质（p 为素数）
3. **因子分解**：Cₙ 的质因子分解

## 7. 卡特兰数的计算

### 7.1 递归计算

```python
def catalan_recursive(n):
    if n <= 1:
        return 1
    result = 0
    for i in range(n):
        result += catalan_recursive(i) * catalan_recursive(n-1-i)
    return result
```

**时间复杂度：** O(4ⁿ)
**空间复杂度：** O(n)

### 7.2 动态规划

```python
def catalan_dp(n):
    if n <= 1:
        return 1
    
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    
    for i in range(2, n + 1):
        for j in range(i):
            dp[i] += dp[j] * dp[i-1-j]
    
    return dp[n]
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

### 7.3 通项公式计算

```python
def catalan_formula(n):
    from math import factorial
    return factorial(2*n) // (factorial(n+1) * factorial(n))
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

### 7.4 优化计算

```python
def catalan_optimized(n):
    if n <= 1:
        return 1
    
    result = 1
    for i in range(n):
        result = result * (2*n - i) // (i + 1)
    
    return result // (n + 1)
```

**时间复杂度：** O(n)
**空间复杂度：** O(1)

## 9. 卡特兰数的变种

### 9.1 广义卡特兰数

**定义：**
```
Cₙ^(k) = (1/(kn+1)) × C((k+1)n, n)
```

**性质：**
- Cₙ^(1) = Cₙ（标准卡特兰数）
- Cₙ^(2) = Cₙ（三叉树计数）

### 9.2 加权卡特兰数

**定义：**
```
Cₙ(w) = Σ(i=0 to n-1) wᵢ × Cᵢ × Cₙ₋₁₋ᵢ
```

**应用：**
- 带权二叉树计数
- 带权路径计数

### 9.3 多变量卡特兰数

**定义：**
```
Cₙ(x,y) = Σ(i=0 to n-1) Cᵢ(x,y) × Cₙ₋₁₋ᵢ(x,y)
```

**应用：**
- 多色二叉树
- 多约束路径问题
