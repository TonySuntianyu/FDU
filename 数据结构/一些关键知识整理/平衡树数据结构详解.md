## 平衡树的基本概念

### 什么是平衡树？

平衡树（Balanced Tree）是一种**自平衡的二叉搜索树**，通过特定的平衡策略来保持树的高度尽可能低，从而保证各种操作的时间复杂度为O(log n)。

### 为什么需要平衡树？

#### 问题：普通二叉搜索树的退化

普通二叉搜索树（BST）在插入有序数据时会出现退化：

```
插入序列：1, 2, 3, 4, 5, 6, 7

普通BST（退化）：
    1
     \
      2
       \
        3
         \
          4
           \
            5
             \
              6
               \
                7

高度：7，查找时间复杂度：O(n) ❌
```

#### 解决方案：平衡树

平衡树通过旋转操作保持平衡：

```
AVL树（平衡）：
        4
       / \
      2   6
     / \ / \
    1  3 5  7

高度：3，查找时间复杂度：O(log n) ✅
```

### 平衡树的特点

| 特点 | 描述 | 优势 |
|------|------|------|
| **自平衡** | 插入/删除后自动调整 | 避免退化 |
| **高度平衡** | 树的高度保持在O(log n) | 保证性能 |
| **动态调整** | 通过旋转操作调整结构 | 适应动态数据 |
| **有序性** | 保持二叉搜索树的性质 | 支持有序操作 |

### 平衡树的分类

#### 按平衡策略分类

1. **严格平衡树**
   - AVL树：任意节点左右子树高度差≤1
   - 优点：最平衡，查找性能最优
   - 缺点：插入/删除可能需要多次旋转

2. **近似平衡树**
   - 红黑树：最长路径不超过最短路径的2倍
   - 优点：插入/删除操作更少
   - 缺点：查找性能略低于AVL树

3. **多路平衡树**
   - B树：每个节点可以有多个子节点
   - B+树：B树的变种，所有数据在叶子节点
   - 优点：适合磁盘存储，减少I/O次数

### 平衡树的基本操作

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| **查找** | O(log n) | 在平衡树中查找元素 |
| **插入** | O(log n) | 插入元素并保持平衡 |
| **删除** | O(log n) | 删除元素并保持平衡 |
| **旋转** | O(1) | 调整树结构的操作 |

## AVL树

### 什么是AVL树？

AVL树（Adelson-Velsky and Landis Tree）是一种**严格平衡的二叉搜索树**，由G.M. Adelson-Velsky和E.M. Landis在1962年发明。

### AVL树的性质

1. **二叉搜索树性质**：左子树所有节点值 < 根节点值 < 右子树所有节点值
2. **平衡性质**：任意节点的左右子树高度差（平衡因子）的绝对值不超过1
3. **平衡因子**：BF(node) = height(left) - height(right)，取值范围：{-1, 0, 1}

### AVL树的平衡因子

```
平衡因子计算示例：

        5 (BF = 1-2 = -1)
       / \
      3   7 (BF = 0-1 = -1)
     /   / \
    2   6   8 (BF = 0-0 = 0)
```

### AVL树的旋转操作

#### 1. 左旋转（Left Rotation）

**场景**：右子树过高（BF < -1）

```
旋转前：
    A (BF = -2)
     \
      B (BF = -1)
       \
        C

旋转后：
      B (BF = 0)
     / \
    A   C
```

**代码实现**：
```cpp
Node* leftRotate(Node* x) {
    Node* y = x->right;
    Node* T2 = y->left;
    
    // 执行旋转
    y->left = x;
    x->right = T2;
    
    // 更新高度
    x->height = max(height(x->left), height(x->right)) + 1;
    y->height = max(height(y->left), height(y->right)) + 1;
    
    return y;  // 返回新的根节点
}
```

#### 2. 右旋转（Right Rotation）

**场景**：左子树过高（BF > 1）

```
旋转前：
        A (BF = 2)
       /
      B (BF = 1)
     /
    C

旋转后：
      B (BF = 0)
     / \
    C   A
```

**代码实现**：
```cpp
Node* rightRotate(Node* y) {
    Node* x = y->left;
    Node* T2 = x->right;
    
    // 执行旋转
    x->right = y;
    y->left = T2;
    
    // 更新高度
    y->height = max(height(y->left), height(y->right)) + 1;
    x->height = max(height(x->left), height(x->right)) + 1;
    
    return x;  // 返回新的根节点
}
```

#### 3. 左右旋转（Left-Right Rotation）

**场景**：左子树的右子树过高（BF > 1 且左子节点BF < 0）

```
步骤1：先对左子节点左旋转
步骤2：再对根节点右旋转

旋转前：
        A (BF = 2)
       /
      B (BF = -1)
       \
        C

步骤1：左旋转B
        A (BF = 2)
       /
      C
     /
    B

步骤2：右旋转A
        C (BF = 0)
       / \
      B   A
```

#### 4. 右左旋转（Right-Left Rotation）

**场景**：右子树的左子树过高（BF < -1 且右子节点BF > 0）

```
步骤1：先对右子节点右旋转
步骤2：再对根节点左旋转
```

### AVL树的插入操作

#### 插入算法步骤

1. **标准BST插入**：按照BST规则插入新节点
2. **更新高度**：更新从插入点到根节点路径上所有节点的高度
3. **计算平衡因子**：计算当前节点的平衡因子
4. **检查不平衡**：如果平衡因子不在{-1, 0, 1}范围内，执行旋转
5. **选择旋转类型**：根据不平衡类型选择相应的旋转

#### 插入示例

```
插入序列：10, 20, 30, 40, 50, 25

步骤1：插入10
    10 (BF = 0)

步骤2：插入20
    10 (BF = -1)
      \
      20 (BF = 0)

步骤3：插入30（不平衡，需要左旋转）
    10 (BF = -2)  →  20 (BF = 0)
      \            / \
      20 (BF = -1) 10 30 (BF = 0)
        \
        30 (BF = 0)

步骤4：插入40
        20 (BF = -1)
       / \
     10  30 (BF = -1)
          \
          40 (BF = 0)

步骤5：插入50（不平衡，需要左旋转）
        20 (BF = -2)  →      30 (BF = 0)
       / \                  / \
     10  30 (BF = -2)      20  40 (BF = -1)
          \                /     \
          40 (BF = -1)   10     50 (BF = 0)
            \
            50 (BF = 0)

步骤6：插入25
          30 (BF = 0)
         / \
       20  40 (BF = -1)
      / \    \
    10  25   50
```

### AVL树的删除操作

#### 删除算法步骤

1. **标准BST删除**：按照BST规则删除节点
2. **更新高度**：更新从删除点到根节点路径上所有节点的高度
3. **检查平衡**：检查每个节点的平衡因子
4. **执行旋转**：如果发现不平衡，执行相应的旋转操作

#### 删除的三种情况

1. **删除叶子节点**：直接删除
2. **删除有一个子节点的节点**：用子节点替换
3. **删除有两个子节点的节点**：用中序后继替换，然后删除后继

### AVL树的完整实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// AVL树节点
struct AVLNode {
    int key;
    AVLNode* left;
    AVLNode* right;
    int height;
    
    AVLNode(int k) : key(k), left(nullptr), right(nullptr), height(1) {}
};

// 获取节点高度
int height(AVLNode* node) {
    if (node == nullptr) return 0;
    return node->height;
}

// 获取平衡因子
int getBalance(AVLNode* node) {
    if (node == nullptr) return 0;
    return height(node->left) - height(node->right);
}

// 右旋转
AVLNode* rightRotate(AVLNode* y) {
    AVLNode* x = y->left;
    AVLNode* T2 = x->right;
    
    x->right = y;
    y->left = T2;
    
    y->height = max(height(y->left), height(y->right)) + 1;
    x->height = max(height(x->left), height(x->right)) + 1;
    
    return x;
}

// 左旋转
AVLNode* leftRotate(AVLNode* x) {
    AVLNode* y = x->right;
    AVLNode* T2 = y->left;
    
    y->left = x;
    x->right = T2;
    
    x->height = max(height(x->left), height(x->right)) + 1;
    y->height = max(height(y->left), height(y->right)) + 1;
    
    return y;
}

// 插入节点
AVLNode* insert(AVLNode* node, int key) {
    // 1. 标准BST插入
    if (node == nullptr)
        return new AVLNode(key);
    
    if (key < node->key)
        node->left = insert(node->left, key);
    else if (key > node->key)
        node->right = insert(node->right, key);
    else
        return node;  // 不允许重复键
    
    // 2. 更新高度
    node->height = 1 + max(height(node->left), height(node->right));
    
    // 3. 获取平衡因子
    int balance = getBalance(node);
    
    // 4. 如果不平衡，执行旋转
    // 左左情况
    if (balance > 1 && key < node->left->key)
        return rightRotate(node);
    
    // 右右情况
    if (balance < -1 && key > node->right->key)
        return leftRotate(node);
    
    // 左右情况
    if (balance > 1 && key > node->left->key) {
        node->left = leftRotate(node->left);
        return rightRotate(node);
    }
    
    // 右左情况
    if (balance < -1 && key < node->right->key) {
        node->right = rightRotate(node->right);
        return leftRotate(node);
    }
    
    return node;
}

// 查找最小值节点
AVLNode* minValueNode(AVLNode* node) {
    AVLNode* current = node;
    while (current->left != nullptr)
        current = current->left;
    return current;
}

// 删除节点
AVLNode* deleteNode(AVLNode* root, int key) {
    // 1. 标准BST删除
    if (root == nullptr)
        return root;
    
    if (key < root->key)
        root->left = deleteNode(root->left, key);
    else if (key > root->key)
        root->right = deleteNode(root->right, key);
    else {
        // 节点只有一个子节点或没有子节点
        if (root->left == nullptr || root->right == nullptr) {
            AVLNode* temp = root->left ? root->left : root->right;
            
            if (temp == nullptr) {
                temp = root;
                root = nullptr;
            } else {
                *root = *temp;
            }
            delete temp;
        } else {
            // 节点有两个子节点
            AVLNode* temp = minValueNode(root->right);
            root->key = temp->key;
            root->right = deleteNode(root->right, temp->key);
        }
    }
    
    if (root == nullptr)
        return root;
    
    // 2. 更新高度
    root->height = 1 + max(height(root->left), height(root->right));
    
    // 3. 获取平衡因子
    int balance = getBalance(root);
    
    // 4. 如果不平衡，执行旋转
    // 左左情况
    if (balance > 1 && getBalance(root->left) >= 0)
        return rightRotate(root);
    
    // 左右情况
    if (balance > 1 && getBalance(root->left) < 0) {
        root->left = leftRotate(root->left);
        return rightRotate(root);
    }
    
    // 右右情况
    if (balance < -1 && getBalance(root->right) <= 0)
        return leftRotate(root);
    
    // 右左情况
    if (balance < -1 && getBalance(root->right) > 0) {
        root->right = rightRotate(root->right);
        return leftRotate(root);
    }
    
    return root;
}

// 中序遍历
void inOrder(AVLNode* root) {
    if (root != nullptr) {
        inOrder(root->left);
        cout << root->key << " ";
        inOrder(root->right);
    }
}

// 测试
int main() {
    AVLNode* root = nullptr;
    
    root = insert(root, 10);
    root = insert(root, 20);
    root = insert(root, 30);
    root = insert(root, 40);
    root = insert(root, 50);
    root = insert(root, 25);
    
    cout << "中序遍历: ";
    inOrder(root);
    cout << endl;
    
    return 0;
}
```

### AVL树的优缺点

#### 优点
- ✅ **严格平衡**：保证树的高度为O(log n)
- ✅ **查找性能最优**：在所有平衡树中查找性能最好
- ✅ **时间复杂度稳定**：所有操作都是O(log n)

#### 缺点
- ❌ **旋转操作频繁**：插入/删除可能需要多次旋转
- ❌ **维护成本高**：需要频繁更新高度和平衡因子
- ❌ **实现复杂**：需要处理四种旋转情况

## 红黑树

### 什么是红黑树？

红黑树（Red-Black Tree）是一种**自平衡的二叉搜索树**，由Rudolf Bayer在1972年发明。它通过颜色标记和旋转操作来保持平衡。

### 红黑树的性质

红黑树必须满足以下**五个性质**：

1. **颜色性质**：每个节点要么是红色，要么是黑色
2. **根节点性质**：根节点必须是黑色
3. **叶子节点性质**：所有叶子节点（NIL节点）都是黑色
4. **红色节点性质**：如果一个节点是红色，那么它的两个子节点都是黑色（不能有两个连续的红色节点）
5. **路径性质**：从任意节点到其每个叶子节点的所有路径上，黑色节点的数量相同（称为"黑高"）

### 红黑树的平衡原理

红黑树通过以下方式保持平衡：

- **最长路径**：红黑交替，最长路径 = 2 × 黑高
- **最短路径**：全黑，最短路径 = 黑高
- **平衡比**：最长路径 ≤ 2 × 最短路径

```
红黑树示例（●=黑色，○=红色）：

        ●10
       /  \
      ○5   ●15
     / \   / \
    ●3 ●7 ●12 ●20

黑高 = 2
最长路径：10(黑) → 5(红) → 3(黑) = 2个黑节点
最短路径：10(黑) → 15(黑) = 2个黑节点
```

### 红黑树的旋转操作

红黑树的旋转操作与AVL树相同，包括：
- **左旋转**：处理右子树过高的情况
- **右旋转**：处理左子树过高的情况

### 红黑树的插入操作

#### 插入算法步骤

1. **标准BST插入**：按照BST规则插入新节点，**新节点初始为红色**
2. **检查父节点颜色**：
   - 如果父节点是黑色，直接完成
   - 如果父节点是红色，需要修复（违反性质4）
3. **修复红黑树性质**：根据叔父节点的颜色进行不同的处理

#### 插入修复的三种情况

##### 情况1：叔父节点是红色

**操作**：重新着色

```
插入前：
        ●G
       /  \
      ○P   ○U  (叔父节点是红色)
     /
    ○N  (新插入的节点)

操作：将P和U变为黑色，G变为红色
        ○G
       /  \
      ●P   ●U
     /
    ○N
```

##### 情况2：叔父节点是黑色，且新节点是父节点的右子节点

**操作**：先左旋转父节点，转换为情况3

```
插入前：
        ●G
       /
      ○P
       \
        ○N

操作：左旋转P
        ●G
       /
      ○N
     /
    ○P

现在转换为情况3
```

##### 情况3：叔父节点是黑色，且新节点是父节点的左子节点

**操作**：右旋转祖父节点，并重新着色

```
插入前：
        ●G
       /
      ○P
     /
    ○N

操作：右旋转G，P变黑，G变红
        ●P
       /  \
      ○N   ○G
```

#### 插入示例

```
插入序列：10, 20, 30, 15, 25

步骤1：插入10（根节点，必须是黑色）
    ●10

步骤2：插入20（父节点是黑色，直接完成）
    ●10
      \
       ○20

步骤3：插入30（父节点是红色，叔父节点不存在（视为黑色），情况3）
    ●10          →    ●20
      \              /  \
       ○20         ○10  ○30
         \
          ○30

步骤4：插入15（父节点是黑色，直接完成）
        ●20
       /  \
      ○10  ○30
     /
    ○15

步骤5：插入25（父节点是红色，叔父节点是红色，情况1）
        ●20          →    ○20
       /  \               /  \
      ○10  ○30          ●10  ●30
     /     \            /     \
    ○15    ○25        ○15    ○25
```

### 红黑树的删除操作

#### 删除算法步骤

1. **标准BST删除**：按照BST规则删除节点
2. **如果删除的是红色节点**：直接删除，不影响黑高
3. **如果删除的是黑色节点**：需要修复，因为会影响黑高
4. **修复红黑树性质**：根据兄弟节点的颜色和子节点情况进行不同的处理

#### 删除修复的四种情况

删除修复比插入修复更复杂，需要考虑兄弟节点的颜色和子节点情况。

### 红黑树的完整实现

```cpp
#include <iostream>
using namespace std;

enum Color { RED, BLACK };

struct RBNode {
    int key;
    Color color;
    RBNode* left;
    RBNode* right;
    RBNode* parent;
    
    RBNode(int k) : key(k), color(RED), left(nullptr), 
                    right(nullptr), parent(nullptr) {}
};

class RedBlackTree {
private:
    RBNode* root;
    RBNode* nil;  // 哨兵节点（NIL）
    
    // 左旋转
    void leftRotate(RBNode* x) {
        RBNode* y = x->right;
        x->right = y->left;
        
        if (y->left != nil)
            y->left->parent = x;
        
        y->parent = x->parent;
        
        if (x->parent == nil)
            root = y;
        else if (x == x->parent->left)
            x->parent->left = y;
        else
            x->parent->right = y;
        
        y->left = x;
        x->parent = y;
    }
    
    // 右旋转
    void rightRotate(RBNode* y) {
        RBNode* x = y->left;
        y->left = x->right;
        
        if (x->right != nil)
            x->right->parent = y;
        
        x->parent = y->parent;
        
        if (y->parent == nil)
            root = x;
        else if (y == y->parent->left)
            y->parent->left = x;
        else
            y->parent->right = x;
        
        x->right = y;
        y->parent = x;
    }
    
    // 插入修复
    void insertFixup(RBNode* z) {
        while (z->parent->color == RED) {
            if (z->parent == z->parent->parent->left) {
                RBNode* y = z->parent->parent->right;  // 叔父节点
                
                // 情况1：叔父节点是红色
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                } else {
                    // 情况2：叔父节点是黑色，且z是右子节点
                    if (z == z->parent->right) {
                        z = z->parent;
                        leftRotate(z);
                    }
                    // 情况3：叔父节点是黑色，且z是左子节点
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    rightRotate(z->parent->parent);
                }
            } else {
                // 对称情况
                RBNode* y = z->parent->parent->left;
                
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                } else {
                    if (z == z->parent->left) {
                        z = z->parent;
                        rightRotate(z);
                    }
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    leftRotate(z->parent->parent);
                }
            }
        }
        root->color = BLACK;
    }
    
public:
    RedBlackTree() {
        nil = new RBNode(0);
        nil->color = BLACK;
        root = nil;
    }
    
    // 插入
    void insert(int key) {
        RBNode* z = new RBNode(key);
        RBNode* y = nil;
        RBNode* x = root;
        
        // 标准BST插入
        while (x != nil) {
            y = x;
            if (z->key < x->key)
                x = x->left;
            else
                x = x->right;
        }
        
        z->parent = y;
        if (y == nil)
            root = z;
        else if (z->key < y->key)
            y->left = z;
        else
            y->right = z;
        
        z->left = nil;
        z->right = nil;
        z->color = RED;
        
        insertFixup(z);
    }
    
    // 中序遍历
    void inOrder(RBNode* node) {
        if (node != nil) {
            inOrder(node->left);
            cout << node->key << "(" << (node->color == RED ? "R" : "B") << ") ";
            inOrder(node->right);
        }
    }
    
    void print() {
        inOrder(root);
        cout << endl;
    }
};

int main() {
    RedBlackTree tree;
    
    tree.insert(10);
    tree.insert(20);
    tree.insert(30);
    tree.insert(15);
    tree.insert(25);
    
    tree.print();
    
    return 0;
}
```

### 红黑树的优缺点

#### 优点
- ✅ **插入/删除效率高**：旋转操作比AVL树少
- ✅ **实现相对简单**：比AVL树更容易实现
- ✅ **广泛应用**：C++ STL的map和set使用红黑树

#### 缺点
- ❌ **查找性能略低**：不如AVL树严格平衡
- ❌ **高度可能更高**：最长路径是最短路径的2倍

## B树

### 什么是B树？

B树（B-Tree）是一种**多路平衡搜索树**，由Rudolf Bayer和Edward M. McCreight在1972年发明。B树特别适合用于**磁盘存储系统**，因为它可以减少磁盘I/O次数。

### B树的性质

对于**m阶B树**（m ≥ 3），必须满足以下性质：

1. **节点关键字数量**：
   - 根节点：至少1个关键字，最多m-1个关键字
   - 非根节点：至少⌈m/2⌉-1个关键字，最多m-1个关键字

2. **节点子节点数量**：
   - 根节点：至少2个子节点（如果非空）
   - 非根节点：至少⌈m/2⌉个子节点，最多m个子节点

3. **关键字有序性**：每个节点内的关键字按升序排列

4. **子树性质**：对于节点中的关键字kᵢ，其左子树的所有关键字都小于kᵢ，右子树的所有关键字都大于kᵢ

5. **平衡性**：所有叶子节点在同一层

### B树的结构

#### 3阶B树示例

```
3阶B树（每个节点最多2个关键字，3个子节点）：

        [50]
       /  |  \
    [20,30] [60,70] [80,90]
    / | \   / | \   / | \
  叶子 叶子 叶子 叶子 叶子 叶子
```

#### 节点结构

```
B树节点结构：

┌─────────────────────────┐
│ P0 | K1 | P1 | K2 | P2 │
└─────────────────────────┘

其中：
- Ki：关键字（按升序排列）
- Pi：指向子节点的指针
- 关键字数量 = 指针数量 - 1
```

### B树的查找操作

#### 查找算法

1. **从根节点开始**
2. **在当前节点中查找关键字**：
   - 如果找到，返回
   - 如果未找到，确定关键字所在的子树
3. **递归查找子树**

#### 查找示例

```
在3阶B树中查找35：

        [50]
       /  |  \
    [20,30] [60,70] [80,90]

步骤1：在根节点[50]中查找35，35 < 50，进入左子树
步骤2：在节点[20,30]中查找35，30 < 35，进入右子树
步骤3：在叶子节点中找到35（如果存在）
```

### B树的插入操作

#### 插入算法步骤

1. **查找插入位置**：找到应该插入的叶子节点
2. **插入关键字**：如果节点未满，直接插入
3. **节点分裂**：如果节点已满（关键字数 = m-1），需要分裂：
   - 将节点分为两部分
   - 中间关键字提升到父节点
   - 如果父节点也满了，继续向上分裂

#### 插入示例（3阶B树）

```
插入序列：10, 20, 30, 40, 50, 60, 70

步骤1：插入10, 20
    [10, 20]

步骤2：插入30（节点已满，需要分裂）
    [10, 20, 30]  →  分裂为：
        [20]
       /    \
    [10]    [30]

步骤3：插入40
        [20]
       /    \
    [10]    [30, 40]

步骤4：插入50（节点已满，需要分裂）
        [20]
       /    \
    [10]    [30, 40, 50]  →  分裂为：
        [20, 40]
       /   |   \
    [10]  [30]  [50]

步骤5：插入60, 70
        [20, 40]
       /   |   \
    [10]  [30]  [50, 60, 70]

步骤6：插入80（节点已满，需要分裂，并向上传播）
        [20, 40]
       /   |   \
    [10]  [30]  [50, 60, 70, 80]  →  分裂为：
        [20, 40, 60]
       /   |   |   \
    [10]  [30] [50] [70, 80]

根节点也满了，继续分裂：
            [40]
           /    \
        [20]    [60]
       /    \   /    \
    [10]  [30] [50]  [70, 80]
```

### B树的删除操作

#### 删除算法步骤

删除操作比插入更复杂，需要考虑多种情况：

1. **删除叶子节点的关键字**：
   - 如果删除后关键字数 ≥ ⌈m/2⌉-1，直接删除
   - 如果删除后关键字数 < ⌈m/2⌉-1，需要合并或借用

2. **删除内部节点的关键字**：
   - 用前驱或后继替换
   - 然后删除前驱或后继（转换为删除叶子节点）

3. **节点合并**：如果节点关键字数不足，需要与兄弟节点合并

### B树的完整实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MIN_DEGREE = 3;  // B树的最小度数（阶数 = 2 * MIN_DEGREE - 1）

struct BTreeNode {
    bool isLeaf;
    vector<int> keys;
    vector<BTreeNode*> children;
    int n;  // 当前关键字数量
    
    BTreeNode(bool leaf) : isLeaf(leaf), n(0) {
        keys.resize(2 * MIN_DEGREE - 1);
        children.resize(2 * MIN_DEGREE);
    }
};

class BTree {
private:
    BTreeNode* root;
    
    // 分裂子节点
    void splitChild(BTreeNode* parent, int index) {
        BTreeNode* fullChild = parent->children[index];
        BTreeNode* newChild = new BTreeNode(fullChild->isLeaf);
        
        // 新节点获取后半部分关键字
        newChild->n = MIN_DEGREE - 1;
        for (int i = 0; i < MIN_DEGREE - 1; i++)
            newChild->keys[i] = fullChild->keys[i + MIN_DEGREE];
        
        // 如果不是叶子节点，复制子节点指针
        if (!fullChild->isLeaf) {
            for (int i = 0; i < MIN_DEGREE; i++)
                newChild->children[i] = fullChild->children[i + MIN_DEGREE];
        }
        
        fullChild->n = MIN_DEGREE - 1;
        
        // 将中间关键字提升到父节点
        for (int i = parent->n; i > index; i--)
            parent->keys[i] = parent->keys[i - 1];
        for (int i = parent->n + 1; i > index + 1; i--)
            parent->children[i] = parent->children[i - 1];
        
        parent->keys[index] = fullChild->keys[MIN_DEGREE - 1];
        parent->children[index + 1] = newChild;
        parent->n++;
    }
    
    // 在非满节点中插入
    void insertNonFull(BTreeNode* node, int key) {
        int i = node->n - 1;
        
        if (node->isLeaf) {
            // 叶子节点，直接插入
            while (i >= 0 && key < node->keys[i]) {
                node->keys[i + 1] = node->keys[i];
                i--;
            }
            node->keys[i + 1] = key;
            node->n++;
        } else {
            // 内部节点，找到应该插入的子树
            while (i >= 0 && key < node->keys[i])
                i--;
            i++;
            
            // 如果子树已满，先分裂
            if (node->children[i]->n == 2 * MIN_DEGREE - 1) {
                splitChild(node, i);
                if (key > node->keys[i])
                    i++;
            }
            insertNonFull(node->children[i], key);
        }
    }
    
    // 查找关键字
    bool search(BTreeNode* node, int key) {
        int i = 0;
        while (i < node->n && key > node->keys[i])
            i++;
        
        if (i < node->n && key == node->keys[i])
            return true;
        
        if (node->isLeaf)
            return false;
        
        return search(node->children[i], key);
    }
    
    // 打印B树
    void print(BTreeNode* node, int level) {
        if (node != nullptr) {
            for (int i = 0; i < level; i++)
                cout << "  ";
            cout << "[";
            for (int i = 0; i < node->n; i++) {
                cout << node->keys[i];
                if (i < node->n - 1) cout << ", ";
            }
            cout << "]" << endl;
            
            if (!node->isLeaf) {
                for (int i = 0; i <= node->n; i++)
                    print(node->children[i], level + 1);
            }
        }
    }
    
public:
    BTree() : root(nullptr) {}
    
    void insert(int key) {
        if (root == nullptr) {
            root = new BTreeNode(true);
            root->keys[0] = key;
            root->n = 1;
        } else {
            // 如果根节点已满，需要分裂
            if (root->n == 2 * MIN_DEGREE - 1) {
                BTreeNode* newRoot = new BTreeNode(false);
                newRoot->children[0] = root;
                splitChild(newRoot, 0);
                
                int i = 0;
                if (key > newRoot->keys[0])
                    i++;
                insertNonFull(newRoot->children[i], key);
                root = newRoot;
            } else {
                insertNonFull(root, key);
            }
        }
    }
    
    bool search(int key) {
        if (root == nullptr)
            return false;
        return search(root, key);
    }
    
    void print() {
        print(root, 0);
    }
};

int main() {
    BTree tree;
    
    tree.insert(10);
    tree.insert(20);
    tree.insert(30);
    tree.insert(40);
    tree.insert(50);
    tree.insert(60);
    tree.insert(70);
    
    tree.print();
    
    cout << "查找30: " << (tree.search(30) ? "找到" : "未找到") << endl;
    
    return 0;
}
```

### B树的应用

#### 主要应用场景

1. **数据库索引**：MySQL的InnoDB存储引擎使用B树
2. **文件系统**：许多文件系统使用B树来组织文件
3. **磁盘存储**：减少磁盘I/O次数，提高查询效率

#### 为什么B树适合磁盘存储？

- **节点大小**：B树节点大小通常等于磁盘页大小（如4KB）
- **减少I/O**：一次磁盘读取可以获取多个关键字
- **树高较低**：m阶B树的高度为O(logₘ n)，比二叉树低得多

## B+树

### 什么是B+树？

B+树（B+ Tree）是**B树的变种**，由Douglas Comer在1979年提出。B+树在B树的基础上进行了优化，特别适合用于**数据库索引**。

### B+树与B树的主要区别

| 特性 | B树 | B+树 |
|------|-----|------|
| **数据存储** | 关键字和数据都在内部节点和叶子节点 | 数据只在叶子节点，内部节点只存储关键字 |
| **叶子节点** | 叶子节点不连接 | 叶子节点通过指针连接成链表 |
| **查找** | 可能在内部节点找到数据 | 必须到叶子节点才能找到数据 |
| **范围查询** | 需要回溯 | 通过叶子节点链表顺序访问 |

### B+树的性质

对于**m阶B+树**：

1. **内部节点**：
   - 只存储关键字（不存储数据）
   - 关键字数量：⌈m/2⌉-1 到 m-1
   - 子节点数量：⌈m/2⌉ 到 m

2. **叶子节点**：
   - 存储关键字和数据
   - 关键字数量：⌈m/2⌉ 到 m
   - 通过指针连接成有序链表

3. **其他性质**：与B树相同（有序性、平衡性等）

### B+树的结构

#### 3阶B+树示例

```
3阶B+树：

内部节点层：
        [20, 50]
       /    |    \
叶子节点层：
    [10,20] → [30,40,50] → [60,70]
     ↓         ↓            ↓
    数据      数据         数据
```

### B+树的查找操作

#### 查找算法

1. **从根节点开始**
2. **在内部节点中查找**：找到关键字所在的子树
3. **到达叶子节点**：在叶子节点中查找关键字和数据
4. **范围查询**：通过叶子节点的链表指针顺序访问

#### 查找示例

```
在B+树中查找35：

        [20, 50]
       /    |    \
    [10,20] → [30,40,50] → [60,70]

步骤1：在根节点[20,50]中查找，20 < 35 < 50，进入中间子树
步骤2：在叶子节点[30,40,50]中找到35（如果存在）
```

### B+树的插入操作

#### 插入算法步骤

1. **查找插入位置**：找到应该插入的叶子节点
2. **插入关键字和数据**：如果节点未满，直接插入
3. **节点分裂**：如果节点已满，需要分裂：
   - 将节点分为两部分
   - 中间关键字复制（不是移动）到父节点
   - 如果父节点也满了，继续向上分裂

#### 插入示例（3阶B+树）

```
插入序列：10, 20, 30, 40, 50

步骤1：插入10, 20
    [10, 20] (叶子节点)

步骤2：插入30（节点已满，需要分裂）
    [10, 20, 30]  →  分裂为：
        [20] (内部节点)
       /    \
    [10,20] → [30] (叶子节点，用指针连接)

步骤3：插入40
        [20]
       /    \
    [10,20] → [30, 40]

步骤4：插入50（节点已满，需要分裂）
        [20]
       /    \
    [10,20] → [30, 40, 50]  →  分裂为：
        [20, 40]
       /    |    \
    [10,20] → [30,40] → [50]
```

### B+树的删除操作

#### 删除算法步骤

1. **查找删除位置**：找到包含关键字的叶子节点
2. **删除关键字和数据**：如果删除后关键字数 ≥ ⌈m/2⌉，直接删除
3. **节点合并或借用**：如果删除后关键字数 < ⌈m/2⌉，需要与兄弟节点合并或借用

### B+树的完整实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MIN_DEGREE = 3;

struct BPlusNode {
    bool isLeaf;
    vector<int> keys;
    vector<void*> values;  // 数据指针
    vector<BPlusNode*> children;
    BPlusNode* next;  // 叶子节点的链表指针
    int n;
    
    BPlusNode(bool leaf) : isLeaf(leaf), n(0), next(nullptr) {
        keys.resize(2 * MIN_DEGREE - 1);
        if (leaf) {
            values.resize(2 * MIN_DEGREE - 1);
        } else {
            children.resize(2 * MIN_DEGREE);
        }
    }
};

class BPlusTree {
private:
    BPlusNode* root;
    
    // 查找关键字
    BPlusNode* searchNode(BPlusNode* node, int key) {
        if (node == nullptr) return nullptr;
        
        int i = 0;
        while (i < node->n && key > node->keys[i])
            i++;
        
        if (node->isLeaf) {
            if (i < node->n && node->keys[i] == key)
                return node;
            return nullptr;
        }
        
        return searchNode(node->children[i], key);
    }
    
public:
    BPlusTree() : root(nullptr) {}
    
    void* search(int key) {
        BPlusNode* node = searchNode(root, key);
        if (node == nullptr) return nullptr;
        
        for (int i = 0; i < node->n; i++) {
            if (node->keys[i] == key)
                return node->values[i];
        }
        return nullptr;
    }
    
    // 范围查询（简化版）
    vector<void*> rangeSearch(int start, int end) {
        vector<void*> results;
        // 实现范围查询逻辑
        return results;
    }
};

int main() {
    BPlusTree tree;
    // 测试代码
    return 0;
}
```

### B+树的优缺点

#### 优点
- ✅ **范围查询高效**：通过叶子节点链表顺序访问
- ✅ **内部节点更小**：只存储关键字，可以存储更多关键字
- ✅ **数据集中存储**：所有数据在叶子节点，便于管理
- ✅ **适合数据库**：MySQL的InnoDB使用B+树作为索引

#### 缺点
- ❌ **实现复杂**：比B树更复杂
- ❌ **内部节点查找**：必须到叶子节点才能找到数据

### B+树的应用

#### 主要应用场景

1. **数据库索引**：
   - MySQL的InnoDB存储引擎
   - PostgreSQL的B+树索引
   - Oracle数据库索引

2. **文件系统**：
   - NTFS文件系统
   - ReiserFS文件系统

3. **搜索引擎**：倒排索引的存储结构

## 2-3树

### 什么是2-3树？

2-3树是一种**多路平衡搜索树**，是B树的一种特殊情况（3阶B树）。2-3树中的每个节点可以有2个或3个子节点。

### 2-3树的性质

1. **节点类型**：
   - **2-节点**：包含1个关键字和2个子节点
   - **3-节点**：包含2个关键字和3个子节点

2. **平衡性**：所有叶子节点在同一层

3. **有序性**：保持搜索树的有序性质

### 2-3树的结构

```
2-3树示例：

         [20, 50]
        /    |    \
    [10]   [30,40]  [60,70]
    2-节点   3-节点   3-节点
```

### 2-3树的插入操作

#### 插入算法

1. **查找插入位置**：找到应该插入的叶子节点
2. **插入关键字**：
   - 如果是2-节点，转换为3-节点
   - 如果是3-节点，需要分裂

#### 插入示例

```
插入序列：10, 20, 30

步骤1：插入10
    [10] (2-节点)

步骤2：插入20
    [10, 20] (3-节点)

步骤3：插入30（3-节点已满，需要分裂）
    [10, 20, 30]  →  分裂为：
        [20]
       /    \
    [10]    [30]
```

### 2-3树与红黑树的关系

**重要发现**：2-3树可以转换为红黑树！

- **2-节点** → 黑色节点
- **3-节点** → 一个黑色节点带一个红色子节点

```
2-3树：
        [20, 50]
       /    |    \
    [10]   [30]  [60,70]

转换为红黑树：
        ●20
       /    \
      ●10   ●50
            /  \
          ○30  ○60
                 \
                 ●70
```

## 伸展树（Splay Tree）

### 什么是伸展树？

伸展树（Splay Tree）是一种**自调整的二叉搜索树**，由Daniel Sleator和Robert Tarjan在1985年发明。伸展树通过"伸展"操作将最近访问的节点移动到根节点。

### 伸展树的特点

1. **自调整**：访问节点后将其移动到根节点
2. **局部性原理**：最近访问的节点很可能再次被访问
3. **平摊时间复杂度**：虽然单次操作可能是O(n)，但平摊时间复杂度是O(log n)

### 伸展操作（Splaying）

#### 三种旋转情况

1. **Zig（单旋转）**：父节点是根节点
2. **Zig-Zig（双旋转）**：节点和父节点都是左子节点或都是右子节点
3. **Zig-Zag（双旋转）**：节点是左子节点，父节点是右子节点（或相反）

#### 伸展示例

```
查找节点X后的伸展操作：

原始树：
        A
       /
      B
     /
    X

Zig-Zig旋转：
    X
     \
      B
       \
        A
```

### 伸展树的优缺点

#### 优点
- ✅ **简单实现**：不需要存储额外信息（如颜色、高度）
- ✅ **局部性好**：适合访问模式有局部性的场景
- ✅ **平摊性能好**：平摊时间复杂度O(log n)

#### 缺点
- ❌ **最坏情况**：单次操作可能是O(n)
- ❌ **不适合并发**：不适合多线程环境

### 选择建议

#### 何时选择AVL树？
- ✅ 查找操作非常频繁
- ✅ 插入和删除操作相对较少
- ✅ 需要保证最严格的平衡
- ✅ 内存操作，不需要考虑磁盘I/O

**应用示例**：游戏引擎中的空间索引、实时系统

#### 何时选择红黑树？
- ✅ 需要平衡的查找、插入、删除性能
- ✅ 通用场景，没有特殊要求
- ✅ 标准库实现（如C++ STL）
- ✅ 内存操作

**应用示例**：C++ STL的map、set、multimap、multiset

#### 何时选择B树？
- ✅ 数据存储在磁盘上
- ✅ 需要减少磁盘I/O次数
- ✅ 节点大小可以匹配磁盘页大小
- ✅ 不需要范围查询

**应用示例**：文件系统索引、某些数据库存储引擎

#### 何时选择B+树？
- ✅ 数据库索引
- ✅ 需要高效的范围查询
- ✅ 数据存储在磁盘上
- ✅ 内部节点可以存储更多关键字

**应用示例**：MySQL InnoDB、PostgreSQL、Oracle数据库索引

#### 何时选择伸展树？
- ✅ 访问模式有明显的局部性
- ✅ 最近访问的数据很可能再次被访问
- ✅ 实现简单，不需要额外存储
- ✅ 单线程环境

**应用示例**：缓存系统、某些编译器实现

## 算法复杂度分析

### 时间复杂度分析

#### AVL树

| 操作 | 平均情况 | 最坏情况 | 说明 |
|------|---------|---------|------|
| **查找** | O(log n) | O(log n) | 严格平衡，高度为log₂(n+1) |
| **插入** | O(log n) | O(log n) | 需要查找位置 + 最多2次旋转 |
| **删除** | O(log n) | O(log n) | 需要查找位置 + 可能多次旋转 |
| **旋转** | O(1) | O(1) | 单次旋转是常数时间 |

**推导过程**：
- AVL树的高度h满足：N(h) = N(h-1) + N(h-2) + 1（类似斐波那契数列）
- 因此 h ≈ 1.44 × log₂(n+2) - 0.328
- 所有操作最多需要h次比较，因此时间复杂度为O(log n)

#### 红黑树

| 操作 | 平均情况 | 最坏情况 | 说明 |
|------|---------|---------|------|
| **查找** | O(log n) | 2×O(log n) | 最长路径是最短路径的2倍 |
| **插入** | O(log n) | O(log n) | 最多2次旋转 |
| **删除** | O(log n) | O(log n) | 删除修复最多3次旋转 |
| **旋转** | O(1) | O(1) | 单次旋转是常数时间 |

**推导过程**：
- 红黑树的黑高至少为h/2（h为树高）
- 从根到叶子的路径上至少有2^(h/2) - 1个节点
- 因此 h ≤ 2×log₂(n+1)
- 所有操作的时间复杂度为O(log n)

#### B树

| 操作 | 平均情况 | 最坏情况 | 说明 |
|------|---------|---------|------|
| **查找** | O(logₘ n) | O(logₘ n) | m为阶数，树高为logₘ n |
| **插入** | O(logₘ n) | O(logₘ n) | 可能需要向上分裂 |
| **删除** | O(logₘ n) | O(logₘ n) | 可能需要合并或借用 |
| **分裂** | O(m) | O(m) | 分裂一个节点需要O(m)时间 |

**推导过程**：
- m阶B树的高度h满足：n ≥ 2×⌈m/2⌉^(h-1) - 1
- 因此 h ≤ logₘ/₂((n+1)/2) + 1
- 对于m=3（2-3树），h ≈ log₂ n
- 对于m=100，h ≈ log₁₀₀ n，树高大大降低

#### B+树

| 操作 | 平均情况 | 最坏情况 | 说明 |
|------|---------|---------|------|
| **查找** | O(logₘ n) | O(logₘ n) | 必须到叶子节点 |
| **插入** | O(logₘ n) | O(logₘ n) | 与B树类似 |
| **删除** | O(logₘ n) | O(logₘ n) | 与B树类似 |
| **范围查询** | O(logₘ n + k) | O(logₘ n + k) | k为结果数量 |

**说明**：
- 查找操作与B树相同
- 范围查询通过叶子节点链表，时间复杂度为O(logₘ n)（查找起始位置）+ O(k)（遍历k个结果）

#### 伸展树

| 操作 | 平均情况 | 最坏情况 | 平摊情况 | 说明 |
|------|---------|---------|---------|------|
| **查找** | O(log n) | O(n) | O(log n) | 可能退化为链表 |
| **插入** | O(log n) | O(n) | O(log n) | 插入后伸展 |
| **删除** | O(log n) | O(n) | O(log n) | 删除后伸展 |
| **伸展** | O(log n) | O(n) | O(log n) | 平摊分析 |

**平摊分析**：
- 使用势能方法（Potential Method）
- 定义势能为树的不平衡度
- 证明m次操作的平摊成本为O(m log n)
- 因此单次操作的平摊成本为O(log n)

### 空间复杂度分析

| 数据结构 | 空间复杂度 | 说明 |

## 完整实现示例

### 完整的AVL树实现

```cpp
#include <iostream>
#include <algorithm>
#include <queue>
using namespace std;

// AVL树节点
struct AVLNode {
    int key;
    AVLNode* left;
    AVLNode* right;
    int height;
    
    AVLNode(int k) : key(k), left(nullptr), right(nullptr), height(1) {}
};

class AVLTree {
private:
    AVLNode* root;
    
    // 获取节点高度
    int height(AVLNode* node) {
        if (node == nullptr) return 0;
        return node->height;
    }
    
    // 获取平衡因子
    int getBalance(AVLNode* node) {
        if (node == nullptr) return 0;
        return height(node->left) - height(node->right);
    }
    
    // 右旋转
    AVLNode* rightRotate(AVLNode* y) {
        AVLNode* x = y->left;
        AVLNode* T2 = x->right;
        
        x->right = y;
        y->left = T2;
        
        y->height = max(height(y->left), height(y->right)) + 1;
        x->height = max(height(x->left), height(x->right)) + 1;
        
        return x;
    }
    
    // 左旋转
    AVLNode* leftRotate(AVLNode* x) {
        AVLNode* y = x->right;
        AVLNode* T2 = y->left;
        
        y->left = x;
        x->right = T2;
        
        x->height = max(height(x->left), height(x->right)) + 1;
        y->height = max(height(y->left), height(y->right)) + 1;
        
        return y;
    }
    
    // 插入节点（递归）
    AVLNode* insert(AVLNode* node, int key) {
        if (node == nullptr)
            return new AVLNode(key);
        
        if (key < node->key)
            node->left = insert(node->left, key);
        else if (key > node->key)
            node->right = insert(node->right, key);
        else
            return node;  // 不允许重复键
        
        node->height = 1 + max(height(node->left), height(node->right));
        
        int balance = getBalance(node);
        
        // 左左情况
        if (balance > 1 && key < node->left->key)
            return rightRotate(node);
        
        // 右右情况
        if (balance < -1 && key > node->right->key)
            return leftRotate(node);
        
        // 左右情况
        if (balance > 1 && key > node->left->key) {
            node->left = leftRotate(node->left);
            return rightRotate(node);
        }
        
        // 右左情况
        if (balance < -1 && key < node->right->key) {
            node->right = rightRotate(node->right);
            return leftRotate(node);
        }
        
        return node;
    }
    
    // 查找最小值节点
    AVLNode* minValueNode(AVLNode* node) {
        AVLNode* current = node;
        while (current->left != nullptr)
            current = current->left;
        return current;
    }
    
    // 删除节点（递归）
    AVLNode* deleteNode(AVLNode* root, int key) {
        if (root == nullptr)
            return root;
        
        if (key < root->key)
            root->left = deleteNode(root->left, key);
        else if (key > root->key)
            root->right = deleteNode(root->right, key);
        else {
            if (root->left == nullptr || root->right == nullptr) {
                AVLNode* temp = root->left ? root->left : root->right;
                
                if (temp == nullptr) {
                    temp = root;
                    root = nullptr;
                } else {
                    *root = *temp;
                }
                delete temp;
            } else {
                AVLNode* temp = minValueNode(root->right);
                root->key = temp->key;
                root->right = deleteNode(root->right, temp->key);
            }
        }
        
        if (root == nullptr)
            return root;
        
        root->height = 1 + max(height(root->left), height(root->right));
        
        int balance = getBalance(root);
        
        // 左左情况
        if (balance > 1 && getBalance(root->left) >= 0)
            return rightRotate(root);
        
        // 左右情况
        if (balance > 1 && getBalance(root->left) < 0) {
            root->left = leftRotate(root->left);
            return rightRotate(root);
        }
        
        // 右右情况
        if (balance < -1 && getBalance(root->right) <= 0)
            return leftRotate(root);
        
        // 右左情况
        if (balance < -1 && getBalance(root->right) > 0) {
            root->right = rightRotate(root->right);
            return leftRotate(root);
        }
        
        return root;
    }
    
    // 查找节点
    bool search(AVLNode* node, int key) {
        if (node == nullptr)
            return false;
        
        if (key == node->key)
            return true;
        else if (key < node->key)
            return search(node->left, key);
        else
            return search(node->right, key);
    }
    
    // 中序遍历
    void inOrder(AVLNode* node) {
        if (node != nullptr) {
            inOrder(node->left);
            cout << node->key << " ";
            inOrder(node->right);
        }
    }
    
    // 层序遍历（用于可视化）
    void levelOrder(AVLNode* root) {
        if (root == nullptr) return;
        
        queue<AVLNode*> q;
        q.push(root);
        
        while (!q.empty()) {
            AVLNode* node = q.front();
            q.pop();
            
            cout << node->key << "(" << getBalance(node) << ") ";
            
            if (node->left != nullptr)
                q.push(node->left);
            if (node->right != nullptr)
                q.push(node->right);
        }
    }
    
public:
    AVLTree() : root(nullptr) {}
    
    void insert(int key) {
        root = insert(root, key);
    }
    
    void remove(int key) {
        root = deleteNode(root, key);
    }
    
    bool search(int key) {
        return search(root, key);
    }
    
    void printInOrder() {
        cout << "中序遍历: ";
        inOrder(root);
        cout << endl;
    }
    
    void printLevelOrder() {
        cout << "层序遍历: ";
        levelOrder(root);
        cout << endl;
    }
};
```

```cpp
#include <iostream>
#include <queue>
using namespace std;

enum Color { RED, BLACK };

struct RBNode {
    int key;
    Color color;
    RBNode* left;
    RBNode* right;
    RBNode* parent;
    
    RBNode(int k) : key(k), color(RED), left(nullptr), 
                    right(nullptr), parent(nullptr) {}
};

class RedBlackTree {
private:
    RBNode* root;
    RBNode* nil;  // 哨兵节点
    
    void leftRotate(RBNode* x) {
        RBNode* y = x->right;
        x->right = y->left;
        
        if (y->left != nil)
            y->left->parent = x;
        
        y->parent = x->parent;
        
        if (x->parent == nil)
            root = y;
        else if (x == x->parent->left)
            x->parent->left = y;
        else
            x->parent->right = y;
        
        y->left = x;
        x->parent = y;
    }
    
    void rightRotate(RBNode* y) {
        RBNode* x = y->left;
        y->left = x->right;
        
        if (x->right != nil)
            x->right->parent = y;
        
        x->parent = y->parent;
        
        if (y->parent == nil)
            root = x;
        else if (y == y->parent->left)
            y->parent->left = x;
        else
            y->parent->right = x;
        
        x->right = y;
        y->parent = x;
    }
    
    void insertFixup(RBNode* z) {
        while (z->parent->color == RED) {
            if (z->parent == z->parent->parent->left) {
                RBNode* y = z->parent->parent->right;
                
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                } else {
                    if (z == z->parent->right) {
                        z = z->parent;
                        leftRotate(z);
                    }
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    rightRotate(z->parent->parent);
                }
            } else {
                RBNode* y = z->parent->parent->left;
                
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                } else {
                    if (z == z->parent->left) {
                        z = z->parent;
                        rightRotate(z);
                    }
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    leftRotate(z->parent->parent);
                }
            }
        }
        root->color = BLACK;
    }
    
    void transplant(RBNode* u, RBNode* v) {
        if (u->parent == nil)
            root = v;
        else if (u == u->parent->left)
            u->parent->left = v;
        else
            u->parent->right = v;
        v->parent = u->parent;
    }
    
    RBNode* minimum(RBNode* node) {
        while (node->left != nil)
            node = node->left;
        return node;
    }
    
    void deleteFixup(RBNode* x) {
        while (x != root && x->color == BLACK) {
            if (x == x->parent->left) {
                RBNode* w = x->parent->right;
                
                if (w->color == RED) {
                    w->color = BLACK;
                    x->parent->color = RED;
                    leftRotate(x->parent);
                    w = x->parent->right;
                }
                
                if (w->left->color == BLACK && w->right->color == BLACK) {
                    w->color = RED;
                    x = x->parent;
                } else {
                    if (w->right->color == BLACK) {
                        w->left->color = BLACK;
                        w->color = RED;
                        rightRotate(w);
                        w = x->parent->right;
                    }
                    w->color = x->parent->color;
                    x->parent->color = BLACK;
                    w->right->color = BLACK;
                    leftRotate(x->parent);
                    x = root;
                }
            } else {
                RBNode* w = x->parent->left;
                
                if (w->color == RED) {
                    w->color = BLACK;
                    x->parent->color = RED;
                    rightRotate(x->parent);
                    w = x->parent->left;
                }
                
                if (w->right->color == BLACK && w->left->color == BLACK) {
                    w->color = RED;
                    x = x->parent;
                } else {
                    if (w->left->color == BLACK) {
                        w->right->color = BLACK;
                        w->color = RED;
                        leftRotate(w);
                        w = x->parent->left;
                    }
                    w->color = x->parent->color;
                    x->parent->color = BLACK;
                    w->left->color = BLACK;
                    rightRotate(x->parent);
                    x = root;
                }
            }
        }
        x->color = BLACK;
    }
    
    void inOrder(RBNode* node) {
        if (node != nil) {
            inOrder(node->left);
            cout << node->key << "(" << (node->color == RED ? "R" : "B") << ") ";
            inOrder(node->right);
        }
    }
    
public:
    RedBlackTree() {
        nil = new RBNode(0);
        nil->color = BLACK;
        root = nil;
    }
    
    void insert(int key) {
        RBNode* z = new RBNode(key);
        RBNode* y = nil;
        RBNode* x = root;
        
        while (x != nil) {
            y = x;
            if (z->key < x->key)
                x = x->left;
            else
                x = x->right;
        }
        
        z->parent = y;
        if (y == nil)
            root = z;
        else if (z->key < y->key)
            y->left = z;
        else
            y->right = z;
        
        z->left = nil;
        z->right = nil;
        z->color = RED;
        
        insertFixup(z);
    }
    
    void remove(int key) {
        RBNode* z = root;
        while (z != nil) {
            if (key == z->key)
                break;
            else if (key < z->key)
                z = z->left;
            else
                z = z->right;
        }
        
        if (z == nil) return;
        
        RBNode* y = z;
        Color yOriginalColor = y->color;
        RBNode* x;
        
        if (z->left == nil) {
            x = z->right;
            transplant(z, z->right);
        } else if (z->right == nil) {
            x = z->left;
            transplant(z, z->left);
        } else {
            y = minimum(z->right);
            yOriginalColor = y->color;
            x = y->right;
            
            if (y->parent == z)
                x->parent = y;
            else {
                transplant(y, y->right);
                y->right = z->right;
                y->right->parent = y;
            }
            
            transplant(z, y);
            y->left = z->left;
            y->left->parent = y;
            y->color = z->color;
        }
        
        delete z;
        
        if (yOriginalColor == BLACK)
            deleteFixup(x);
    }
    
    bool search(int key) {
        RBNode* x = root;
        while (x != nil) {
            if (key == x->key)
                return true;
            else if (key < x->key)
                x = x->left;
            else
                x = x->right;
        }
        return false;
    }
    
    void print() {
        cout << "中序遍历: ";
        inOrder(root);
        cout << endl;
    }
};
```

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

const int MIN_DEGREE = 3;
const int MAX_KEYS = 2 * MIN_DEGREE - 1;
const int MIN_KEYS = MIN_DEGREE - 1;

struct BTreeNode {
    bool isLeaf;
    vector<int> keys;
    vector<BTreeNode*> children;
    int n;
    
    BTreeNode(bool leaf) : isLeaf(leaf), n(0) {
        keys.resize(MAX_KEYS);
        children.resize(MAX_KEYS + 1, nullptr);
    }
};

class BTree {
private:
    BTreeNode* root;
    
    void splitChild(BTreeNode* parent, int index) {
        BTreeNode* fullChild = parent->children[index];
        BTreeNode* newChild = new BTreeNode(fullChild->isLeaf);
        
        newChild->n = MIN_KEYS;
        for (int i = 0; i < MIN_KEYS; i++)
            newChild->keys[i] = fullChild->keys[i + MIN_DEGREE];
        
        if (!fullChild->isLeaf) {
            for (int i = 0; i < MIN_DEGREE; i++)
                newChild->children[i] = fullChild->children[i + MIN_DEGREE];
        }
        
        fullChild->n = MIN_KEYS;
        
        for (int i = parent->n; i > index; i--)
            parent->keys[i] = parent->keys[i - 1];
        for (int i = parent->n + 1; i > index + 1; i--)
            parent->children[i] = parent->children[i - 1];
        
        parent->keys[index] = fullChild->keys[MIN_KEYS];
        parent->children[index + 1] = newChild;
        parent->n++;
    }
    
    void insertNonFull(BTreeNode* node, int key) {
        int i = node->n - 1;
        
        if (node->isLeaf) {
            while (i >= 0 && key < node->keys[i]) {
                node->keys[i + 1] = node->keys[i];
                i--;
            }
            node->keys[i + 1] = key;
            node->n++;
        } else {
            while (i >= 0 && key < node->keys[i])
                i--;
            i++;
            
            if (node->children[i]->n == MAX_KEYS) {
                splitChild(node, i);
                if (key > node->keys[i])
                    i++;
            }
            insertNonFull(node->children[i], key);
        }
    }
    
    bool search(BTreeNode* node, int key) {
        int i = 0;
        while (i < node->n && key > node->keys[i])
            i++;
        
        if (i < node->n && key == node->keys[i])
            return true;
        
        if (node->isLeaf)
            return false;
        
        return search(node->children[i], key);
    }
    
    void print(BTreeNode* node, int level) {
        if (node != nullptr) {
            for (int i = 0; i < level; i++)
                cout << "  ";
            cout << "[";
            for (int i = 0; i < node->n; i++) {
                cout << node->keys[i];
                if (i < node->n - 1) cout << ", ";
            }
            cout << "]" << endl;
            
            if (!node->isLeaf) {
                for (int i = 0; i <= node->n; i++)
                    print(node->children[i], level + 1);
            }
        }
    }
    
public:
    BTree() : root(nullptr) {}
    
    void insert(int key) {
        if (root == nullptr) {
            root = new BTreeNode(true);
            root->keys[0] = key;
            root->n = 1;
        } else {
            if (root->n == MAX_KEYS) {
                BTreeNode* newRoot = new BTreeNode(false);
                newRoot->children[0] = root;
                splitChild(newRoot, 0);
                
                int i = 0;
                if (key > newRoot->keys[0])
                    i++;
                insertNonFull(newRoot->children[i], key);
                root = newRoot;
            } else {
                insertNonFull(root, key);
            }
        }
    }
    
    bool search(int key) {
        if (root == nullptr)
            return false;
        return search(root, key);
    }
    
    void print() {
        print(root, 0);
    }
};
```

## 总结

### 核心要点回顾

1. **AVL树**：最严格平衡，查找性能最优，适合查找频繁的场景
2. **红黑树**：平衡的插入/删除性能，广泛应用，C++ STL使用
3. **B树**：多路平衡，适合磁盘存储，减少I/O次数
4. **B+树**：B树变种，适合数据库索引，支持高效范围查询
5. **2-3树**：3阶B树，教学用途，帮助理解多路平衡树
6. **伸展树**：自调整树，适合局部访问模式，实现简单

### 选择指南

- **内存操作，查找频繁** → AVL树
- **内存操作，通用场景** → 红黑树
- **磁盘存储，减少I/O** → B树或B+树
- **数据库索引** → B+树
- **局部访问模式** → 伸展树
- **学习理解** → 2-3树

### 学习建议

1. **理解原理**：掌握各种平衡树的基本原理和性质
2. **动手实现**：尝试实现至少一种平衡树（建议从AVL树或红黑树开始）
3. **对比分析**：理解不同平衡树的优缺点和适用场景
4. **实际应用**：了解在实际系统中的应用（如数据库、文件系统等）
