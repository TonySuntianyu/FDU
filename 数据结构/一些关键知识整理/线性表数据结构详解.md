## 线性表的基本概念

### 什么是线性表？

线性表（Linear List）是一种**线性数据结构**，由n（n≥0）个数据元素组成的有限序列。线性表具有以下特点：

1. **线性结构**：数据元素之间存在一对一的关系
2. **有限性**：线性表中的元素个数是有限的
3. **有序性**：元素之间存在先后顺序关系
4. **同质性**：所有元素具有相同的数据类型

### 线性表的特点

| 特点 | 描述 | 示例 |
|------|------|------|
| **线性结构** | 除第一个元素外，每个元素有且仅有一个前驱 | 1→2→3→4→5 |
| **有限性** | 元素个数有限，可以为空 | 空表：[] |
| **有序性** | 元素按位置有序排列 | 位置1的元素在位置2的元素之前 |
| **同质性** | 所有元素类型相同 | 都是整数、都是字符串等 |

### 线性表的基本操作

#### 基本操作列表

| 操作名称 | 功能描述 | 输入 | 输出 |
|----------|----------|------|------|
| **InitList** | 初始化线性表 | 无 | 空线性表 |
| **DestroyList** | 销毁线性表 | 线性表 | 无 |
| **ClearList** | 清空线性表 | 线性表 | 空线性表 |
| **ListEmpty** | 判断是否为空 | 线性表 | 布尔值 |
| **ListLength** | 获取长度 | 线性表 | 整数 |
| **GetElem** | 获取元素 | 线性表，位置 | 元素值 |
| **LocateElem** | 查找元素 | 线性表，元素值 | 位置 |
| **PriorElem** | 获取前驱 | 线性表，元素值 | 前驱元素 |
| **NextElem** | 获取后继 | 线性表，元素值 | 后继元素 |
| **ListInsert** | 插入元素 | 线性表，位置，元素 | 更新后的线性表 |
| **ListDelete** | 删除元素 | 线性表，位置 | 被删除的元素 |

## 线性表的抽象数据类型

### ADT定义

```cpp
ADT LinearList {
    数据对象：D = {a1, a2, ..., an}
    数据关系：R = {<ai-1, ai> | ai-1, ai ∈ D, i = 2, 3, ..., n}
    
    基本操作：
    InitList(&L)           // 初始化
    DestroyList(&L)        // 销毁
    ClearList(&L)          // 清空
    ListEmpty(L)           // 判空
    ListLength(L)          // 求长度
    GetElem(L, i, &e)      // 获取元素
    LocateElem(L, e)       // 查找元素
    PriorElem(L, cur_e, &pre_e)  // 前驱
    NextElem(L, cur_e, &next_e)  // 后继
    ListInsert(&L, i, e)   // 插入
    ListDelete(&L, i, &e)  // 删除
} ADT LinearList
```

### 操作说明

#### 1. 初始化操作
```cpp
void InitList(LinearList &L);
```
- **功能**：构造一个空的线性表
- **前置条件**：无
- **后置条件**：L为空表

#### 2. 销毁操作
```cpp
void DestroyList(LinearList &L);
```
- **功能**：销毁线性表L
- **前置条件**：L已存在
- **后置条件**：L被销毁

#### 3. 插入操作
```cpp
bool ListInsert(LinearList &L, int i, ElemType e);
```
- **功能**：在线性表L的第i个位置插入元素e
- **前置条件**：1 ≤ i ≤ ListLength(L) + 1
- **后置条件**：L的长度增加1，e成为第i个元素

#### 4. 删除操作
```cpp
bool ListDelete(LinearList &L, int i, ElemType &e);
```
- **功能**：删除线性表L的第i个元素
- **前置条件**：1 ≤ i ≤ ListLength(L)
- **后置条件**：L的长度减少1，e为被删除的元素

## 顺序表（数组实现）

### 顺序表的定义

顺序表是用**数组**实现的线性表，数据元素在内存中连续存储。

### 顺序表的特点

#### 优点
1. **随机访问**：可以通过下标直接访问任意元素，时间复杂度O(1)
2. **内存连续**：数据在内存中连续存储，缓存性能好
3. **实现简单**：逻辑简单，易于理解和实现

#### 缺点
1. **插入删除效率低**：需要移动大量元素，时间复杂度O(n)
2. **空间固定**：数组大小固定，可能浪费空间或空间不足
3. **内存分配**：需要预先分配足够的内存空间

### 顺序表实现

```cpp
#include <iostream>
#include <cstring>
using namespace std;

template<typename T>
class ArrayList {
private:
    T* data;           // 数据数组
    int capacity;      // 容量
    int length;        // 当前长度
    
public:
    // 构造函数
    ArrayList(int cap = 100) : capacity(cap), length(0) {
        data = new T[capacity];
    }
    
    // 析构函数
    ~ArrayList() {
        delete[] data;
    }
    
    // 拷贝构造函数
    ArrayList(const ArrayList& other) {
        capacity = other.capacity;
        length = other.length;
        data = new T[capacity];
        for (int i = 0; i < length; i++) {
            data[i] = other.data[i];
        }
    }
    
    // 赋值操作符
    ArrayList& operator=(const ArrayList& other) {
        if (this != &other) {
            delete[] data;
            capacity = other.capacity;
            length = other.length;
            data = new T[capacity];
            for (int i = 0; i < length; i++) {
                data[i] = other.data[i];
            }
        }
        return *this;
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return length == 0;
    }
    
    // 获取长度
    int getLength() const {
        return length;
    }
    
    // 获取容量
    int getCapacity() const {
        return capacity;
    }
    
    // 获取元素
    T get(int index) const {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        return data[index];
    }
    
    // 设置元素
    void set(int index, const T& value) {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        data[index] = value;
    }
    
    // 查找元素
    int find(const T& value) const {
        for (int i = 0; i < length; i++) {
            if (data[i] == value) {
                return i;
            }
        }
        return -1;  // 未找到
    }
    
    // 插入元素
    bool insert(int index, const T& value) {
        if (index < 0 || index > length) {
            return false;  // 索引无效
        }
        
        if (length >= capacity) {
            expand();  // 扩容
        }
        
        // 移动元素
        for (int i = length; i > index; i--) {
            data[i] = data[i - 1];
        }
        
        data[index] = value;
        length++;
        return true;
    }
    
    // 删除元素
    bool remove(int index) {
        if (index < 0 || index >= length) {
            return false;  // 索引无效
        }
        
        // 移动元素
        for (int i = index; i < length - 1; i++) {
            data[i] = data[i + 1];
        }
        
        length--;
        return true;
    }
    
    // 添加元素到末尾
    void append(const T& value) {
        insert(length, value);
    }
    
    // 清空
    void clear() {
        length = 0;
    }
    
    // 扩容
    void expand() {
        int newCapacity = capacity * 2;
        T* newData = new T[newCapacity];
        
        for (int i = 0; i < length; i++) {
            newData[i] = newData[i];
        }
        
        delete[] data;
        data = newData;
        capacity = newCapacity;
    }
    
    // 打印
    void print() const {
        cout << "[";
        for (int i = 0; i < length; i++) {
            cout << data[i];
            if (i < length - 1) cout << ", ";
        }
        cout << "]" << endl;
    }
};
```

## 链表（链式实现）

### 链表的定义

链表是用**指针**实现的线性表，数据元素在内存中可以不连续存储。

### 链表的特点

#### 优点
1. **动态分配**：可以根据需要动态分配内存
2. **插入删除效率高**：只需要修改指针，时间复杂度O(1)
3. **空间利用率高**：按需分配，不浪费空间

#### 缺点
1. **不支持随机访问**：必须从头开始遍历，时间复杂度O(n)
2. **内存开销大**：每个节点需要额外的指针空间
3. **缓存性能差**：数据在内存中不连续

### 单链表实现

```cpp
#include <iostream>
using namespace std;

template<typename T>
class LinkedList {
private:
    struct Node {
        T data;
        Node* next;
        
        Node(const T& value) : data(value), next(nullptr) {}
    };
    
    Node* head;  // 头节点
    int length;  // 长度
    
public:
    // 构造函数
    LinkedList() : head(nullptr), length(0) {}
    
    // 析构函数
    ~LinkedList() {
        clear();
    }
    
    // 拷贝构造函数
    LinkedList(const LinkedList& other) {
        head = nullptr;
        length = 0;
        Node* current = other.head;
        while (current != nullptr) {
            append(current->data);
            current = current->next;
        }
    }
    
    // 赋值操作符
    LinkedList& operator=(const LinkedList& other) {
        if (this != &other) {
            clear();
            Node* current = other.head;
            while (current != nullptr) {
                append(current->data);
                current = current->next;
            }
        }
        return *this;
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return head == nullptr;
    }
    
    // 获取长度
    int getLength() const {
        return length;
    }
    
    // 获取元素
    T get(int index) const {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        Node* current = head;
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        return current->data;
    }
    
    // 设置元素
    void set(int index, const T& value) {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        Node* current = head;
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        current->data = value;
    }
    
    // 查找元素
    int find(const T& value) const {
        Node* current = head;
        int index = 0;
        
        while (current != nullptr) {
            if (current->data == value) {
                return index;
            }
            current = current->next;
            index++;
        }
        return -1;  // 未找到
    }
    
    // 插入元素
    bool insert(int index, const T& value) {
        if (index < 0 || index > length) {
            return false;  // 索引无效
        }
        
        Node* newNode = new Node(value);
        
        if (index == 0) {
            // 在头部插入
            newNode->next = head;
            head = newNode;
        } else {
            // 在其他位置插入
            Node* current = head;
            for (int i = 0; i < index - 1; i++) {
                current = current->next;
            }
            newNode->next = current->next;
            current->next = newNode;
        }
        
        length++;
        return true;
    }
    
    // 删除元素
    bool remove(int index) {
        if (index < 0 || index >= length) {
            return false;  // 索引无效
        }
        
        Node* toDelete;
        
        if (index == 0) {
            // 删除头节点
            toDelete = head;
            head = head->next;
        } else {
            // 删除其他节点
            Node* current = head;
            for (int i = 0; i < index - 1; i++) {
                current = current->next;
            }
            toDelete = current->next;
            current->next = toDelete->next;
        }
        
        delete toDelete;
        length--;
        return true;
    }
    
    // 添加元素到末尾
    void append(const T& value) {
        insert(length, value);
    }
    
    // 清空
    void clear() {
        while (head != nullptr) {
            Node* toDelete = head;
            head = head->next;
            delete toDelete;
        }
        length = 0;
    }
    
    // 打印
    void print() const {
        cout << "[";
        Node* current = head;
        while (current != nullptr) {
            cout << current->data;
            if (current->next != nullptr) cout << ", ";
            current = current->next;
        }
        cout << "]" << endl;
    }
};
```

### 双向链表实现

```cpp
template<typename T>
class DoublyLinkedList {
private:
    struct Node {
        T data;
        Node* prev;
        Node* next;
        
        Node(const T& value) : data(value), prev(nullptr), next(nullptr) {}
    };
    
    Node* head;  // 头节点
    Node* tail;  // 尾节点
    int length;  // 长度
    
public:
    // 构造函数
    DoublyLinkedList() : head(nullptr), tail(nullptr), length(0) {}
    
    // 析构函数
    ~DoublyLinkedList() {
        clear();
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return head == nullptr;
    }
    
    // 获取长度
    int getLength() const {
        return length;
    }
    
    // 在头部插入
    void insertHead(const T& value) {
        Node* newNode = new Node(value);
        
        if (head == nullptr) {
            head = tail = newNode;
        } else {
            newNode->next = head;
            head->prev = newNode;
            head = newNode;
        }
        
        length++;
    }
    
    // 在尾部插入
    void insertTail(const T& value) {
        Node* newNode = new Node(value);
        
        if (tail == nullptr) {
            head = tail = newNode;
        } else {
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }
        
        length++;
    }
    
    // 删除头部
    bool removeHead() {
        if (head == nullptr) {
            return false;
        }
        
        Node* toDelete = head;
        head = head->next;
        
        if (head != nullptr) {
            head->prev = nullptr;
        } else {
            tail = nullptr;
        }
        
        delete toDelete;
        length--;
        return true;
    }
    
    // 删除尾部
    bool removeTail() {
        if (tail == nullptr) {
            return false;
        }
        
        Node* toDelete = tail;
        tail = tail->prev;
        
        if (tail != nullptr) {
            tail->next = nullptr;
        } else {
            head = nullptr;
        }
        
        delete toDelete;
        length--;
        return true;
    }
    
    // 清空
    void clear() {
        while (head != nullptr) {
            Node* toDelete = head;
            head = head->next;
            delete toDelete;
        }
        tail = nullptr;
        length = 0;
    }
    
    // 打印
    void print() const {
        cout << "[";
        Node* current = head;
        while (current != nullptr) {
            cout << current->data;
            if (current->next != nullptr) cout << ", ";
            current = current->next;
        }
        cout << "]" << endl;
    }
};
```

## 线性表的应用

### 1. 数据存储

**应用场景**：
- 数组：存储固定大小的数据集合
- 列表：存储动态大小的数据集合
- 缓存：存储临时数据

**示例**：
```cpp
// 学生成绩管理
ArrayList<int> scores;
scores.append(85);
scores.append(92);
scores.append(78);
```

### 2. 算法实现

**应用场景**：
- 排序算法：冒泡排序、快速排序
- 查找算法：顺序查找、二分查找
- 动态规划：状态存储

**示例**：
```cpp
// 动态规划 - 斐波那契数列
ArrayList<int> fib;
fib.append(0);
fib.append(1);
for (int i = 2; i < 10; i++) {
    fib.append(fib.get(i-1) + fib.get(i-2));
}
```

### 3. 数据结构基础

**应用场景**：
- 栈：后进先出（LIFO）
- 队列：先进先出（FIFO）
- 字符串：字符序列

**示例**：
```cpp
// 栈的实现
class Stack {
private:
    ArrayList<int> data;
public:
    void push(int value) {
        data.append(value);
    }
    
    int pop() {
        int value = data.get(data.getLength() - 1);
        data.remove(data.getLength() - 1);
        return value;
    }
};
```

## 算法复杂度分析

### 时间复杂度对比

| 操作 | 顺序表 | 单链表 | 双向链表 |
|------|--------|--------|----------|
| **访问元素** | O(1) | O(n) | O(n) |
| **查找元素** | O(n) | O(n) | O(n) |
| **插入元素** | O(n) | O(1)* | O(1)* |
| **删除元素** | O(n) | O(1)* | O(1)* |
| **头部插入** | O(n) | O(1) | O(1) |
| **尾部插入** | O(1) | O(n) | O(1) |

*注：O(1)表示在已知位置插入/删除，O(n)表示需要先找到位置*

### 空间复杂度对比

| 存储方式 | 空间复杂度 | 说明 |
|----------|------------|------|
| **顺序表** | O(n) | 连续存储，无额外指针 |
| **单链表** | O(n) | 每个节点一个指针 |
| **双向链表** | O(n) | 每个节点两个指针 |

### 性能特点总结

#### 顺序表适合的场景
1. **频繁访问**：需要随机访问元素
2. **内存效率**：对内存使用要求严格
3. **缓存友好**：数据连续存储，缓存性能好

#### 链表适合的场景
1. **频繁插入删除**：在已知位置插入删除
2. **动态大小**：数据大小经常变化
3. **内存分散**：内存分配不连续

## 完整实现示例

### 通用线性表接口

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 线性表接口
template<typename T>
class LinearList {
public:
    virtual ~LinearList() {}
    virtual bool isEmpty() const = 0;
    virtual int getLength() const = 0;
    virtual T get(int index) const = 0;
    virtual void set(int index, const T& value) = 0;
    virtual int find(const T& value) const = 0;
    virtual bool insert(int index, const T& value) = 0;
    virtual bool remove(int index) = 0;
    virtual void clear() = 0;
    virtual void print() const = 0;
};

// 顺序表实现
template<typename T>
class ArrayList : public LinearList<T> {
private:
    T* data;
    int capacity;
    int length;
    
public:
    ArrayList(int cap = 100) : capacity(cap), length(0) {
        data = new T[capacity];
    }
    
    ~ArrayList() {
        delete[] data;
    }
    
    bool isEmpty() const override {
        return length == 0;
    }
    
    int getLength() const override {
        return length;
    }
    
    T get(int index) const override {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        return data[index];
    }
    
    void set(int index, const T& value) override {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        data[index] = value;
    }
    
    int find(const T& value) const override {
        for (int i = 0; i < length; i++) {
            if (data[i] == value) {
                return i;
            }
        }
        return -1;
    }
    
    bool insert(int index, const T& value) override {
        if (index < 0 || index > length) {
            return false;
        }
        
        if (length >= capacity) {
            expand();
        }
        
        for (int i = length; i > index; i--) {
            data[i] = data[i - 1];
        }
        
        data[index] = value;
        length++;
        return true;
    }
    
    bool remove(int index) override {
        if (index < 0 || index >= length) {
            return false;
        }
        
        for (int i = index; i < length - 1; i++) {
            data[i] = data[i + 1];
        }
        
        length--;
        return true;
    }
    
    void clear() override {
        length = 0;
    }
    
    void print() const override {
        cout << "[";
        for (int i = 0; i < length; i++) {
            cout << data[i];
            if (i < length - 1) cout << ", ";
        }
        cout << "]" << endl;
    }
    
private:
    void expand() {
        int newCapacity = capacity * 2;
        T* newData = new T[newCapacity];
        
        for (int i = 0; i < length; i++) {
            newData[i] = data[i];
        }
        
        delete[] data;
        data = newData;
        capacity = newCapacity;
    }
};

// 使用示例
int main() {
    // 创建顺序表
    ArrayList<int> list;
    
    // 添加元素
    list.insert(0, 10);
    list.insert(1, 20);
    list.insert(2, 30);
    
    cout << "初始列表: ";
    list.print();
    
    // 插入元素
    list.insert(1, 15);
```

## 线性表的变种

线性表的变种是在基本线性表基础上，通过改变存储结构或增加特殊功能而形成的数据结构。这些变种在特定场景下具有独特的优势。

### 1. 循环链表（Circular Linked List）

#### 1.1 基本概念

循环链表是一种特殊的链表，其中最后一个节点的指针指向第一个节点，形成一个环状结构。

**特点**：
- 没有真正的"头"和"尾"
- 可以从任意节点开始遍历整个链表
- 适合需要循环访问的场景

#### 1.2 循环单链表实现

```cpp
template<typename T>
class CircularLinkedList {
private:
    struct Node {
        T data;
        Node* next;
        Node(const T& value) : data(value), next(nullptr) {}
    };
    
    Node* head;
    int length;
    
public:
    CircularLinkedList() : head(nullptr), length(0) {}
    
    ~CircularLinkedList() {
        clear();
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return head == nullptr;
    }
    
    // 获取长度
    int size() const {
        return length;
    }
    
    // 在头部插入
    void insertHead(const T& value) {
        Node* newNode = new Node(value);
        
        if (head == nullptr) {
            head = newNode;
            head->next = head;
        } else {
            newNode->next = head;
            // 找到尾节点
            Node* tail = head;
            while (tail->next != head) {
                tail = tail->next;
            }
            tail->next = newNode;
            head = newNode;
        }
        
        length++;
    }
    
    // 在尾部插入
    void insertTail(const T& value) {
        Node* newNode = new Node(value);
        
        if (head == nullptr) {
            head = newNode;
            head->next = head;
        } else {
            Node* tail = head;
            while (tail->next != head) {
                tail = tail->next;
            }
            tail->next = newNode;
            newNode->next = head;
        }
        
        length++;
    }
    
    // 在指定位置插入
    void insert(int index, const T& value) {
        if (index < 0 || index > length) {
            throw out_of_range("索引越界");
        }
        
        if (index == 0) {
            insertHead(value);
            return;
        }
        
        if (index == length) {
            insertTail(value);
            return;
        }
        
        Node* newNode = new Node(value);
        Node* current = head;
        
        for (int i = 0; i < index - 1; i++) {
            current = current->next;
        }
        
        newNode->next = current->next;
        current->next = newNode;
        length++;
    }
    
    // 删除指定位置的元素
    T remove(int index) {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        if (length == 1) {
            T value = head->data;
            delete head;
            head = nullptr;
            length = 0;
            return value;
        }
        
        Node* toDelete;
        T value;
        
        if (index == 0) {
            toDelete = head;
            value = head->data;
            
            // 找到尾节点
            Node* tail = head;
            while (tail->next != head) {
                tail = tail->next;
            }
            
            head = head->next;
            tail->next = head;
        } else {
            Node* current = head;
            for (int i = 0; i < index - 1; i++) {
                current = current->next;
            }
            
            toDelete = current->next;
            value = toDelete->data;
            current->next = toDelete->next;
        }
        
        delete toDelete;
        length--;
        return value;
    }
    
    // 查找元素
    int find(const T& value) const {
        if (head == nullptr) return -1;
        
        Node* current = head;
        int index = 0;
        
        do {
            if (current->data == value) {
                return index;
            }
            current = current->next;
            index++;
        } while (current != head);
        
        return -1;
    }
    
    // 获取指定位置的元素
    T get(int index) const {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        Node* current = head;
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        
        return current->data;
    }
    
    // 清空链表
    void clear() {
        if (head == nullptr) return;
        
        Node* current = head->next;
        while (current != head) {
            Node* toDelete = current;
            current = current->next;
            delete toDelete;
        }
        delete head;
        head = nullptr;
        length = 0;
    }
    
    // 打印链表
    void print() const {
        if (head == nullptr) {
            cout << "[]" << endl;
            return;
        }
        
        cout << "[";
        Node* current = head;
        do {
            cout << current->data;
            if (current->next != head) cout << " -> ";
            current = current->next;
        } while (current != head);
        cout << "]" << endl;
    }
    
    // 从指定位置开始打印
    void printFrom(int startIndex) const {
        if (head == nullptr || startIndex < 0 || startIndex >= length) {
            cout << "[]" << endl;
            return;
        }
        
        Node* current = head;
        for (int i = 0; i < startIndex; i++) {
            current = current->next;
        }
        
        cout << "[";
        Node* start = current;
        do {
            cout << current->data;
            if (current->next != start) cout << " -> ";
            current = current->next;
        } while (current != start);
        cout << "]" << endl;
    }
};
```

#### 1.4 循环链表的应用

**约瑟夫问题**：
```cpp
class JosephusProblem {
private:
    CircularLinkedList<int> circle;
    
public:
    // 解决约瑟夫问题
    int solve(int n, int k) {
        // 创建包含n个人的循环链表
        for (int i = 1; i <= n; i++) {
            circle.insertTail(i);
        }
        
        int current = 0;
        while (circle.size() > 1) {
            // 数到第k个人
            current = (current + k - 1) % circle.size();
            circle.remove(current);
        }
        
        return circle.get(0);
    }
};
```

### 2. 静态链表（Static Linked List）

#### 2.1 基本概念

静态链表是用数组实现的链表，通过游标（索引）模拟指针，适用于不支持指针的语言或需要固定内存分配的场景。

**特点**：
- 用数组存储节点
- 用游标模拟指针
- 需要预先分配固定大小的数组
- 适用于不支持指针的语言

#### 2.2 静态链表实现

```cpp
template<typename T>
class StaticLinkedList {
private:
    struct Node {
        T data;
        int next;
        bool used;  // 标记节点是否被使用
        
        Node() : next(-1), used(false) {}
    };
    
    Node* nodes;
    int capacity;
    int length;
    int freeHead;
    int dataHead;
    
public:
    StaticLinkedList(int cap = 100) : capacity(cap), length(0), freeHead(0), dataHead(-1) {
        nodes = new Node[capacity];
        
        // 初始化空闲链表
        for (int i = 0; i < capacity - 1; i++) {
            nodes[i].next = i + 1;
            nodes[i].used = false;
        }
        nodes[capacity - 1].next = -1;
        nodes[capacity - 1].used = false;
    }
    
    ~StaticLinkedList() {
        delete[] nodes;
    }
    
    // 分配节点
    int allocateNode() {
        if (freeHead == -1) {
            return -1;  // 空间不足
        }
        
        int index = freeHead;
        freeHead = nodes[freeHead].next;
        nodes[index].used = true;
        return index;
    }
    
    // 释放节点
    void freeNode(int index) {
        if (index < 0 || index >= capacity) {
            return;
        }
        
        nodes[index].next = freeHead;
        nodes[index].used = false;
        freeHead = index;
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return dataHead == -1;
    }
    
    // 获取长度
    int size() const {
        return length;
    }
    
    // 在头部插入
    void insertHead(const T& value) {
        int newNodeIndex = allocateNode();
        if (newNodeIndex == -1) {
            throw runtime_error("空间不足");
        }
        
        nodes[newNodeIndex].data = value;
        nodes[newNodeIndex].next = dataHead;
        dataHead = newNodeIndex;
        length++;
    }
    
    // 在尾部插入
    void insertTail(const T& value) {
        int newNodeIndex = allocateNode();
        if (newNodeIndex == -1) {
            throw runtime_error("空间不足");
        }
        
        nodes[newNodeIndex].data = value;
        nodes[newNodeIndex].next = -1;
        
        if (dataHead == -1) {
            dataHead = newNodeIndex;
        } else {
            int current = dataHead;
            while (nodes[current].next != -1) {
                current = nodes[current].next;
            }
            nodes[current].next = newNodeIndex;
        }
        
        length++;
    }
    
    // 删除头部
    T removeHead() {
        if (dataHead == -1) {
            throw runtime_error("链表为空");
        }
        
        int toDelete = dataHead;
        T value = nodes[toDelete].data;
        dataHead = nodes[toDelete].next;
        
        freeNode(toDelete);
        length--;
        return value;
    }
    
    // 查找元素
    int find(const T& value) const {
        int current = dataHead;
        int index = 0;
        
        while (current != -1) {
            if (nodes[current].data == value) {
                return index;
            }
            current = nodes[current].next;
            index++;
        }
        
        return -1;
    }
    
    // 获取指定位置的元素
    T get(int index) const {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        int current = dataHead;
        for (int i = 0; i < index; i++) {
            current = nodes[current].next;
        }
        
        return nodes[current].data;
    }
    
    // 清空链表
    void clear() {
        int current = dataHead;
        while (current != -1) {
            int next = nodes[current].next;
            freeNode(current);
            current = next;
        }
        dataHead = -1;
        length = 0;
    }
    
    // 打印链表
    void print() const {
        cout << "[";
        int current = dataHead;
        while (current != -1) {
            cout << nodes[current].data;
            if (nodes[current].next != -1) cout << " -> ";
            current = nodes[current].next;
        }
        cout << "]" << endl;
    }
    
    // 打印存储结构
    void printStorage() const {
        cout << "存储结构:" << endl;
        cout << "索引\t数据\t下一节点\t使用状态" << endl;
        for (int i = 0; i < capacity; i++) {
            cout << i << "\t" << nodes[i].data << "\t" << nodes[i].next << "\t\t" 
                 << (nodes[i].used ? "已使用" : "空闲") << endl;
        }
        cout << "数据头: " << dataHead << endl;
        cout << "空闲头: " << freeHead << endl;
    }
};
```

### 3. 双向链表（Doubly Linked List）

#### 3.1 基本概念

双向链表是每个节点都有两个指针的链表，一个指向前驱节点，一个指向后继节点。

**特点**：
- 每个节点有两个指针
- 可以双向遍历
- 插入删除操作更复杂
- 占用更多内存空间

#### 3.2 双向链表实现

```cpp
template<typename T>
class DoublyLinkedList {
private:
    struct Node {
        T data;
        Node* prev;
        Node* next;
        Node(const T& value) : data(value), prev(nullptr), next(nullptr) {}
    };
    
    Node* head;
    Node* tail;
    int length;
    
public:
    DoublyLinkedList() : head(nullptr), tail(nullptr), length(0) {}
    
    ~DoublyLinkedList() {
        clear();
    }
    
    // 拷贝构造函数
    DoublyLinkedList(const DoublyLinkedList& other) {
        head = nullptr;
        tail = nullptr;
        length = 0;
        
        Node* current = other.head;
        while (current != nullptr) {
            insertTail(current->data);
            current = current->next;
        }
    }
    
    // 赋值操作符
    DoublyLinkedList& operator=(const DoublyLinkedList& other) {
        if (this != &other) {
            clear();
            
            Node* current = other.head;
            while (current != nullptr) {
                insertTail(current->data);
                current = current->next;
            }
        }
        return *this;
    }
    
    bool isEmpty() const {
        return head == nullptr;
    }
    
    int size() const {
        return length;
    }
    
    // 在头部插入
    void insertHead(const T& value) {
        Node* newNode = new Node(value);
        
        if (head == nullptr) {
            head = tail = newNode;
        } else {
            newNode->next = head;
            head->prev = newNode;
            head = newNode;
        }
        
        length++;
    }
    
    // 在尾部插入
    void insertTail(const T& value) {
        Node* newNode = new Node(value);
        
        if (tail == nullptr) {
            head = tail = newNode;
        } else {
            tail->next = newNode;
            newNode->prev = tail;
            tail = newNode;
        }
        
        length++;
    }
    
    // 在指定位置插入
    void insert(int index, const T& value) {
        if (index < 0 || index > length) {
            throw out_of_range("索引越界");
        }
        
        if (index == 0) {
            insertHead(value);
            return;
        }
        
        if (index == length) {
            insertTail(value);
            return;
        }
        
        Node* newNode = new Node(value);
        Node* current = head;
        
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        
        newNode->prev = current->prev;
        newNode->next = current;
        current->prev->next = newNode;
        current->prev = newNode;
        
        length++;
    }
    
    // 删除头部
    T removeHead() {
        if (head == nullptr) {
            throw runtime_error("链表为空");
        }
        
        Node* toDelete = head;
        T value = head->data;
        
        if (head == tail) {
            head = tail = nullptr;
        } else {
            head = head->next;
            head->prev = nullptr;
        }
        
        delete toDelete;
        length--;
        return value;
    }
    
    // 删除尾部
    T removeTail() {
        if (tail == nullptr) {
            throw runtime_error("链表为空");
        }
        
        Node* toDelete = tail;
        T value = tail->data;
        
        if (head == tail) {
            head = tail = nullptr;
        } else {
            tail = tail->prev;
            tail->next = nullptr;
        }
        
        delete toDelete;
        length--;
        return value;
    }
    
    // 删除指定位置的元素
    T remove(int index) {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        if (index == 0) {
            return removeHead();
        }
        
        if (index == length - 1) {
            return removeTail();
        }
        
        Node* current = head;
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        
        T value = current->data;
        current->prev->next = current->next;
        current->next->prev = current->prev;
        
        delete current;
        length--;
        return value;
    }
    
    // 查找元素
    int find(const T& value) const {
        Node* current = head;
        int index = 0;
        
        while (current != nullptr) {
            if (current->data == value) {
                return index;
            }
            current = current->next;
            index++;
        }
        
        return -1;
    }
    
    // 获取指定位置的元素
    T get(int index) const {
        if (index < 0 || index >= length) {
            throw out_of_range("索引越界");
        }
        
        Node* current = head;
        for (int i = 0; i < index; i++) {
            current = current->next;
        }
        
        return current->data;
    }
    
    // 清空链表
    void clear() {
        while (head != nullptr) {
            Node* toDelete = head;
            head = head->next;
            delete toDelete;
        }
        tail = nullptr;
        length = 0;
    }
    
    // 正向打印
    void print() const {
        cout << "[";
        Node* current = head;
        while (current != nullptr) {
            cout << current->data;
            if (current->next != nullptr) cout << " <-> ";
            current = current->next;
        }
        cout << "]" << endl;
    }
    
    // 反向打印
    void printReverse() const {
        cout << "[";
        Node* current = tail;
        while (current != nullptr) {
            cout << current->data;
            if (current->prev != nullptr) cout << " <-> ";
            current = current->prev;
        }
        cout << "]" << endl;
    }
};
```

### 4. 跳跃链表（Skip List）

#### 4.1 基本概念

跳跃链表是一种概率性数据结构，通过维护多个层次的链表来提高查找效率。

**特点**：
- 平均查找时间复杂度为O(log n)
- 空间复杂度为O(n)
- 实现相对简单
- 支持并发操作

#### 4.2 跳跃链表实现

```cpp
template<typename T>
class SkipList {
private:
    struct Node {
        T data;
        vector<Node*> next;
        int level;
        
        Node(const T& value, int lvl) : data(value), level(lvl) {
            next.resize(lvl + 1, nullptr);
        }
    };
    
    Node* head;
    int maxLevel;
    int currentLevel;
    int length;
    
    // 随机生成层数
    int randomLevel() {
        int level = 0;
        while (rand() % 2 == 0 && level < maxLevel) {
            level++;
        }
        return level;
    }
    
public:
    SkipList(int maxLvl = 16) : maxLevel(maxLvl), currentLevel(0), length(0) {
        head = new Node(T(), maxLevel);
    }
    
    ~SkipList() {
        clear();
    }
    
    bool isEmpty() const {
        return length == 0;
    }
    
    int size() const {
        return length;
    }
    
    // 查找元素
    bool find(const T& value) const {
        Node* current = head;
        
        for (int i = currentLevel; i >= 0; i--) {
            while (current->next[i] != nullptr && current->next[i]->data < value) {
                current = current->next[i];
            }
        }
        
        current = current->next[0];
        return current != nullptr && current->data == value;
    }
    
    // 插入元素
    void insert(const T& value) {
        vector<Node*> update(maxLevel + 1);
        Node* current = head;
        
        for (int i = currentLevel; i >= 0; i--) {
            while (current->next[i] != nullptr && current->next[i]->data < value) {
                current = current->next[i];
            }
            update[i] = current;
        }
        
        current = current->next[0];
        
        if (current == nullptr || current->data != value) {
            int newLevel = randomLevel();
            
            if (newLevel > currentLevel) {
                for (int i = currentLevel + 1; i <= newLevel; i++) {
                    update[i] = head;
                }
                currentLevel = newLevel;
            }
            
            Node* newNode = new Node(value, newLevel);
            
            for (int i = 0; i <= newLevel; i++) {
                newNode->next[i] = update[i]->next[i];
                update[i]->next[i] = newNode;
            }
            
            length++;
        }
    }
    
    // 删除元素
    bool remove(const T& value) {
        vector<Node*> update(maxLevel + 1);
        Node* current = head;
        
        for (int i = currentLevel; i >= 0; i--) {
            while (current->next[i] != nullptr && current->next[i]->data < value) {
                current = current->next[i];
            }
            update[i] = current;
        }
        
        current = current->next[0];
        
        if (current != nullptr && current->data == value) {
            for (int i = 0; i <= currentLevel; i++) {
                if (update[i]->next[i] != current) {
                    break;
                }
                update[i]->next[i] = current->next[i];
            }
            
            delete current;
            
            while (currentLevel > 0 && head->next[currentLevel] == nullptr) {
                currentLevel--;
            }
            
            length--;
            return true;
        }
        
        return false;
    }
    
    // 清空链表
    void clear() {
        Node* current = head->next[0];
        while (current != nullptr) {
            Node* toDelete = current;
            current = current->next[0];
            delete toDelete;
        }
        
        for (int i = 0; i <= maxLevel; i++) {
            head->next[i] = nullptr;
        }
        currentLevel = 0;
        length = 0;
    }
    
    // 打印链表
    void print() const {
        cout << "跳跃链表 (层数: " << currentLevel + 1 << "):" << endl;
        
        for (int i = currentLevel; i >= 0; i--) {
            cout << "第" << i << "层: ";
            Node* current = head->next[i];
            while (current != nullptr) {
                cout << current->data << " ";
                current = current->next[i];
            }
            cout << endl;
        }
    }
};
```

### 5. 变种对比分析

| 变种类型 | 优点 | 缺点 | 适用场景 |
|----------|------|------|----------|
| **循环链表** | 无头尾概念，适合循环访问 | 遍历需要特殊处理 | 约瑟夫问题、循环缓冲区 |
| **静态链表** | 不需要指针，内存连续 | 容量固定，操作复杂 | 不支持指针的语言 |
| **双向链表** | 双向遍历，删除效率高 | 内存开销大，操作复杂 | 需要双向遍历的场景 |
| **跳跃链表** | 查找效率高，支持并发 | 实现复杂，空间开销大 | 需要高效查找的场景 |

```cpp
class BrowserHistory {
private:
    DoublyLinkedList<string> history;
    int currentIndex;
    
public:
    BrowserHistory() : currentIndex(-1) {}
    
    void visit(const string& url) {
        // 删除当前位置之后的所有记录
        while (currentIndex < history.size() - 1) {
            history.removeTail();
        }
        
        history.insertTail(url);
        currentIndex = history.size() - 1;
        cout << "访问: " << url << endl;
    }
    
    string back() {
        if (currentIndex > 0) {
            currentIndex--;
            string url = history.get(currentIndex);
            cout << "后退到: " << url << endl;
            return url;
        }
        cout << "无法后退" << endl;
        return "";
    }
    
    string forward() {
        if (currentIndex < history.size() - 1) {
            currentIndex++;
            string url = history.get(currentIndex);
            cout << "前进到: " << url << endl;
            return url;
        }
        cout << "无法前进" << endl;
        return "";
    }
    
    void printHistory() {
        cout << "历史记录: ";
        history.print();
        cout << "当前位置: " << currentIndex << endl;
    }
};
```

### 7. 总结

线性表的变种在特定场景下具有独特的优势：

1. **循环链表**：适合需要循环访问的场景
2. **静态链表**：适用于不支持指针的语言
3. **双向链表**：适合需要双向遍历的场景
4. **跳跃链表**：适合需要高效查找的场景

选择哪种变种应该根据具体的应用场景和性能要求来决定。理解这些变种的特点和实现方式，有助于在实际开发中做出合适的选择。

## 总结

### 线性表的重要性

1. **基础数据结构**：是其他复杂数据结构的基础
2. **算法基础**：许多算法都基于线性表实现
3. **实际应用**：在编程中应用非常广泛

### 选择原则

#### 选择顺序表的情况
- 需要频繁随机访问元素
- 数据大小相对固定
- 对内存使用要求严格
- 需要良好的缓存性能

#### 选择链表的情况
- 需要频繁插入删除操作
- 数据大小经常变化
- 内存分配不连续
- 需要实现栈、队列等数据结构

### 学习要点

1. **理解基本概念**：线性结构、有序性、同质性
2. **掌握基本操作**：插入、删除、查找、遍历
3. **熟悉实现方式**：顺序存储和链式存储
4. **了解应用场景**：根据需求选择合适的实现
5. **掌握复杂度分析**：理解不同操作的性能特点

线性表是数据结构学习的基础，掌握好线性表的概念和实现，对于学习更复杂的数据结构和算法具有重要意义。
