## 排序算法概述

### 什么是排序？

排序（Sorting）是将一组数据按照特定规则重新排列的过程，使得数据按照升序或降序排列。

### 排序算法的分类

#### 按稳定性分类
- **稳定排序**：相同元素的相对位置在排序后保持不变
- **不稳定排序**：相同元素的相对位置可能改变

#### 按时间复杂度分类
- **O(n²)**：冒泡排序、选择排序、插入排序
- **O(n log n)**：快速排序、归并排序、堆排序
- **O(n)**：计数排序、桶排序、基数排序（线性时间）

#### 按空间复杂度分类
- **原地排序**：只需要O(1)额外空间
- **非原地排序**：需要O(n)或更多额外空间

#### 按排序方式分类
- **比较排序**：通过比较元素大小来排序
- **非比较排序**：不通过比较，利用元素特性来排序

## 插入排序

### 1. 直接插入排序（Insertion Sort）

#### 基本思想

将待排序序列分为已排序和未排序两部分，每次从未排序部分取出一个元素，插入到已排序部分的正确位置。

#### 算法步骤

1. 从第一个元素开始，该元素可以认为已经被排序
2. 取出下一个元素，在已排序的元素序列中从后向前扫描
3. 如果已排序元素大于新元素，将该元素移到下一位置
4. 重复步骤3，直到找到已排序元素小于或等于新元素的位置
5. 将新元素插入到该位置
6. 重复步骤2-5，直到所有元素排序完成

#### 算法演示

```
初始序列：[5, 2, 8, 1, 9]

第1轮：已排序[5]，未排序[2, 8, 1, 9]
        [5, 2, 8, 1, 9] → [2, 5, 8, 1, 9]

第2轮：已排序[2, 5]，未排序[8, 1, 9]
        [2, 5, 8, 1, 9] → [2, 5, 8, 1, 9] (8已在正确位置)

第3轮：已排序[2, 5, 8]，未排序[1, 9]
        [2, 5, 8, 1, 9] → [1, 2, 5, 8, 9]

第4轮：已排序[1, 2, 5, 8]，未排序[9]
        [1, 2, 5, 8, 9] → [1, 2, 5, 8, 9] (9已在正确位置)

最终结果：[1, 2, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 直接插入排序
void insertionSort(int arr[], int n) {
    int i, j, key;
    
    for (i = 1; i < n; i++) {
        key = arr[i];  // 待插入的元素
        j = i - 1;     // 已排序部分的最后一个索引
        
        // 将大于key的元素向后移动
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        arr[j + 1] = key;  // 插入key到正确位置
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    insertionSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n) - 数组已经有序
  - 最坏情况：O(n²) - 数组逆序
  - 平均情况：O(n²)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：稳定排序

#### 特点

- ✅ 实现简单，代码量少
- ✅ 对于小规模数据或基本有序的数据效率高
- ✅ 稳定排序
- ✅ 原地排序
- ❌ 对于大规模乱序数据效率低

### 2. 希尔排序（Shell Sort）

#### 基本思想

希尔排序是插入排序的改进版本，通过将数组分成多个子序列，对每个子序列进行插入排序，然后逐步缩小间隔，最终完成排序。

#### 算法步骤

1. 选择一个增量序列（gap），通常为 n/2, n/4, ..., 1
2. 对每个增量值，将数组分成多个子序列
3. 对每个子序列进行插入排序
4. 减小增量，重复步骤2-3
5. 当增量为1时，进行最后一次插入排序

#### 算法演示

```
初始序列：[8, 3, 1, 6, 5, 2, 7, 4]，n=8

第1轮（gap=4）：
  子序列1：[8, 5] → [5, 8]
  子序列2：[3, 2] → [2, 3]
  子序列3：[1, 7] → [1, 7]
  子序列4：[6, 4] → [4, 6]
  结果：[5, 2, 1, 4, 8, 3, 7, 6]

第2轮（gap=2）：
  子序列1：[5, 1, 8, 7] → [1, 5, 7, 8]
  子序列2：[2, 4, 3, 6] → [2, 3, 4, 6]
  结果：[1, 2, 5, 3, 7, 4, 8, 6]

第3轮（gap=1）：
  对整个数组进行插入排序
  结果：[1, 2, 3, 4, 5, 6, 7, 8]
```

#### C语言实现

```c
#include <stdio.h>

// 希尔排序
void shellSort(int arr[], int n) {
    int gap, i, j, temp;
    
    // 初始gap为n/2，逐步缩小
    for (gap = n / 2; gap > 0; gap /= 2) {
        // 对每个子序列进行插入排序
        for (i = gap; i < n; i++) {
            temp = arr[i];
            j = i;
            
            // 在子序列中插入排序
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            
            arr[j] = temp;
        }
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {8, 3, 1, 6, 5, 2, 7, 4};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    shellSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n log n)
  - 最坏情况：O(n²) - 取决于增量序列
  - 平均情况：O(n^1.3) - 使用Hibbard增量序列
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：不稳定排序

#### 特点

- ✅ 比直接插入排序效率高
- ✅ 原地排序
- ✅ 对于中等规模数据表现良好
- ❌ 不稳定排序
- ❌ 复杂度分析复杂，取决于增量序列

## 交换排序

### 1. 冒泡排序（Bubble Sort）

#### 基本思想

重复遍历待排序序列，比较相邻元素，如果顺序错误就交换它们，直到没有需要交换的元素为止。

#### 算法步骤

1. 比较相邻的两个元素，如果前一个比后一个大，就交换它们
2. 对每一对相邻元素做同样的工作，从开始第一对到结尾的最后一对
3. 这样一轮下来，最大的元素会"冒泡"到末尾
4. 重复步骤1-3，每次比较范围减1（因为末尾已经有序）
5. 直到没有需要交换的元素

#### 算法演示

```
初始序列：[5, 2, 8, 1, 9]

第1轮：
  [5, 2, 8, 1, 9] → [2, 5, 8, 1, 9] (5>2，交换)
  [2, 5, 8, 1, 9] → [2, 5, 8, 1, 9] (5<8，不交换)
  [2, 5, 8, 1, 9] → [2, 5, 1, 8, 9] (8>1，交换)
  [2, 5, 1, 8, 9] → [2, 5, 1, 8, 9] (8<9，不交换)
  结果：[2, 5, 1, 8, 9] (9已到正确位置)

第2轮：
  [2, 5, 1, 8, 9] → [2, 5, 1, 8, 9] (2<5，不交换)
  [2, 5, 1, 8, 9] → [2, 1, 5, 8, 9] (5>1，交换)
  [2, 1, 5, 8, 9] → [2, 1, 5, 8, 9] (5<8，不交换)
  结果：[2, 1, 5, 8, 9] (8已到正确位置)

第3轮：
  [2, 1, 5, 8, 9] → [1, 2, 5, 8, 9] (2>1，交换)
  [1, 2, 5, 8, 9] → [1, 2, 5, 8, 9] (2<5，不交换)
  结果：[1, 2, 5, 8, 9] (5已到正确位置)

第4轮：
  [1, 2, 5, 8, 9] → [1, 2, 5, 8, 9] (1<2，不交换)
  结果：[1, 2, 5, 8, 9] (2已到正确位置)

最终结果：[1, 2, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 冒泡排序（基础版本）
void bubbleSort(int arr[], int n) {
    int i, j, temp;
    
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换元素
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// 冒泡排序（优化版本 - 提前终止）
void bubbleSortOptimized(int arr[], int n) {
    int i, j, temp;
    int swapped;  // 标记是否发生交换
    
    for (i = 0; i < n - 1; i++) {
        swapped = 0;
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        // 如果这一轮没有发生交换，说明已经有序
        if (swapped == 0) {
            break;
        }
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    bubbleSortOptimized(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n) - 数组已经有序（优化版本）
  - 最坏情况：O(n²) - 数组逆序
  - 平均情况：O(n²)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：稳定排序

#### 特点

- ✅ 实现简单，易于理解
- ✅ 稳定排序
- ✅ 原地排序
- ✅ 可以检测数组是否已经有序（优化版本）
- ❌ 效率低，不适合大规模数据

### 2. 快速排序（Quick Sort）

#### 基本思想

采用分治法（Divide and Conquer）策略，选择一个基准元素（pivot），将数组分成两部分，使得左边部分的所有元素都小于基准，右边部分的所有元素都大于基准，然后递归地对两部分进行排序。

#### 算法步骤

1. 选择一个基准元素（pivot）
2. 分区（Partition）：重新排列数组，使得所有小于基准的元素在基准左边，所有大于基准的元素在基准右边
3. 递归地对基准左边和右边的子数组进行快速排序
4. 当子数组长度为1或0时，递归结束

#### 算法演示

```
初始序列：[5, 2, 8, 1, 9, 3]

第1次分区（pivot=5）：
  [5, 2, 8, 1, 9, 3]
  → [2, 1, 3, 5, 8, 9]
  左子数组：[2, 1, 3]，右子数组：[8, 9]

第2次分区（左子数组，pivot=2）：
  [2, 1, 3] → [1, 2, 3]
  左子数组：[1]，右子数组：[3]

第3次分区（右子数组，pivot=8）：
  [8, 9] → [8, 9]
  左子数组：[]，右子数组：[9]

最终结果：[1, 2, 3, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 交换两个元素
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 分区函数 - 选择最后一个元素作为基准
int partition(int arr[], int low, int high) {
    int pivot = arr[high];  // 选择最后一个元素作为基准
    int i = low - 1;        // 小于基准的元素的索引
    
    for (int j = low; j < high; j++) {
        // 如果当前元素小于或等于基准
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}

// 快速排序主函数
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        // 获取分区点
        int pi = partition(arr, low, high);
        
        // 递归排序左子数组
        quickSort(arr, low, pi - 1);
        
        // 递归排序右子数组
        quickSort(arr, pi + 1, high);
    }
}

// 快速排序包装函数
void quickSortWrapper(int arr[], int n) {
    quickSort(arr, 0, n - 1);
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9, 3};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    quickSortWrapper(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 优化版本（三数取中法选择基准）

```c
// 选择三个数的中位数作为基准
int medianOfThree(int arr[], int low, int high) {
    int mid = low + (high - low) / 2;
    
    if (arr[low] > arr[mid]) {
        swap(&arr[low], &arr[mid]);
    }
    if (arr[low] > arr[high]) {
        swap(&arr[low], &arr[high]);
    }
    if (arr[mid] > arr[high]) {
        swap(&arr[mid], &arr[high]);
    }
    
    // 将中位数放到high位置
    swap(&arr[mid], &arr[high]);
    return arr[high];
}

// 优化的分区函数
int partitionOptimized(int arr[], int low, int high) {
    int pivot = medianOfThree(arr, low, high);
    int i = low - 1;
    
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n log n) - 每次分区都平衡
  - 最坏情况：O(n²) - 每次分区都不平衡（如已排序数组）
  - 平均情况：O(n log n)
- **空间复杂度**：
  - 最好情况：O(log n) - 递归栈深度
  - 最坏情况：O(n) - 递归栈深度
- **稳定性**：不稳定排序

#### 特点

- ✅ 平均情况下效率很高
- ✅ 原地排序（只需要O(log n)递归栈空间）
- ✅ 实际应用中表现优秀
- ❌ 最坏情况下退化为O(n²)
- ❌ 不稳定排序
- ❌ 对于小数组，插入排序可能更快

## 选择排序

### 1. 简单选择排序（Selection Sort）

#### 基本思想

每次从未排序部分选择最小（或最大）的元素，放到已排序部分的末尾。

#### 算法步骤

1. 在未排序序列中找到最小（大）元素，存放到排序序列的起始位置
2. 从剩余未排序元素中继续寻找最小（大）元素
3. 放到已排序序列的末尾
4. 重复步骤2-3，直到所有元素均排序完毕

#### 算法演示

```
初始序列：[5, 2, 8, 1, 9]

第1轮：未排序[5, 2, 8, 1, 9]，最小元素是1
        [5, 2, 8, 1, 9] → [1, 2, 8, 5, 9]
        已排序[1]，未排序[2, 8, 5, 9]

第2轮：未排序[2, 8, 5, 9]，最小元素是2
        [1, 2, 8, 5, 9] → [1, 2, 8, 5, 9] (已在正确位置)
        已排序[1, 2]，未排序[8, 5, 9]

第3轮：未排序[8, 5, 9]，最小元素是5
        [1, 2, 8, 5, 9] → [1, 2, 5, 8, 9]
        已排序[1, 2, 5]，未排序[8, 9]

第4轮：未排序[8, 9]，最小元素是8
        [1, 2, 5, 8, 9] → [1, 2, 5, 8, 9] (已在正确位置)
        已排序[1, 2, 5, 8]，未排序[9]

最终结果：[1, 2, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 简单选择排序
void selectionSort(int arr[], int n) {
    int i, j, minIndex, temp;
    
    for (i = 0; i < n - 1; i++) {
        // 找到未排序部分的最小元素
        minIndex = i;
        for (j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        
        // 将最小元素交换到已排序部分的末尾
        if (minIndex != i) {
            temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    selectionSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n²) - 仍需比较所有元素
  - 最坏情况：O(n²)
  - 平均情况：O(n²)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：不稳定排序（可能改变相同元素的相对位置）

#### 特点

- ✅ 实现简单
- ✅ 原地排序
- ✅ 交换次数少（最多n-1次）
- ❌ 时间复杂度始终为O(n²)
- ❌ 不稳定排序

### 2. 堆排序（Heap Sort）

#### 基本思想

利用堆（Heap）这种数据结构进行排序。堆是一个完全二叉树，满足堆性质：父节点的值总是大于（或小于）其子节点的值。

#### 算法步骤

1. 构建最大堆（Max Heap）：将数组转换为最大堆
2. 交换堆顶元素（最大值）和数组末尾元素
3. 减小堆的大小，对堆顶元素进行堆化（heapify）
4. 重复步骤2-3，直到堆的大小为1

#### 堆的性质

- **最大堆**：父节点 ≥ 子节点
- **最小堆**：父节点 ≤ 子节点
- **完全二叉树**：可以用数组表示
  - 父节点索引：`(i-1)/2`
  - 左子节点索引：`2*i+1`
  - 右子节点索引：`2*i+2`

#### 算法演示

```
初始序列：[5, 2, 8, 1, 9]

步骤1：构建最大堆
       5             9
      / \    →      / \
     2   8         8   5
    / \          / \
   1   9        1   2
   数组：[9, 8, 5, 1, 2]

步骤2：交换堆顶和末尾，堆化
   [9, 8, 5, 1, 2] → [2, 8, 5, 1, 9]
   堆化：[8, 2, 5, 1]

步骤3：重复步骤2
   [8, 2, 5, 1, 9] → [1, 2, 5, 8, 9]
   堆化：[5, 2, 1]

步骤4：继续
   [5, 2, 1, 8, 9] → [1, 2, 5, 8, 9]
   堆化：[2, 1]

步骤5：最后一步
   [2, 1, 5, 8, 9] → [1, 2, 5, 8, 9]

最终结果：[1, 2, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 交换两个元素
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 堆化函数 - 维护最大堆性质
void heapify(int arr[], int n, int i) {
    int largest = i;        // 初始化最大值为根节点
    int left = 2 * i + 1;  // 左子节点
    int right = 2 * i + 2; // 右子节点
    
    // 如果左子节点大于根节点
    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }
    
    // 如果右子节点大于当前最大值
    if (right < n && arr[right] > arr[largest]) {
        largest = right;
    }
    
    // 如果最大值不是根节点，交换并继续堆化
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}

// 堆排序主函数
void heapSort(int arr[], int n) {
    // 构建最大堆（从最后一个非叶子节点开始）
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    
    // 逐个从堆中取出元素
    for (int i = n - 1; i > 0; i--) {
        // 将堆顶（最大值）移到末尾
        swap(&arr[0], &arr[i]);
        
        // 对剩余部分重新堆化
        heapify(arr, i, 0);
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    heapSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

- **时间复杂度**：
  - 最好情况：O(n log n)
  - 最坏情况：O(n log n)
  - 平均情况：O(n log n)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：不稳定排序

#### 特点

- ✅ 时间复杂度稳定为O(n log n)
- ✅ 原地排序
- ✅ 不需要额外的辅助空间
- ✅ 适合大规模数据
- ❌ 不稳定排序
- ❌ 对于小规模数据，常数因子较大

## 归并排序

### 基本思想

采用分治法（Divide and Conquer）策略，将数组分成两半，分别对两半进行排序，然后将两个有序的子数组合并成一个有序数组。

### 算法步骤

1. 将数组分成两半
2. 递归地对左半部分进行归并排序
3. 递归地对右半部分进行归并排序
4. 合并两个有序子数组

### 合并过程

合并两个有序数组的过程：
- 使用两个指针分别指向两个子数组的起始位置
- 比较两个指针指向的元素，将较小的元素放入结果数组
- 移动指针，重复比较，直到其中一个子数组遍历完
- 将剩余元素复制到结果数组

### 算法演示

```
初始序列：[5, 2, 8, 1, 9, 3]

分解过程：
  [5, 2, 8, 1, 9, 3]
       ↓
  [5, 2, 8]  [1, 9, 3]
       ↓
  [5, 2] [8]  [1, 9] [3]
       ↓
  [5] [2] [8]  [1] [9] [3]

合并过程：
  [5] [2] → [2, 5]
  [2, 5] [8] → [2, 5, 8]
  
  [1] [9] → [1, 9]
  [1, 9] [3] → [1, 3, 9]
  
  [2, 5, 8] [1, 3, 9] → [1, 2, 3, 5, 8, 9]

最终结果：[1, 2, 3, 5, 8, 9]
```

### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 合并两个有序子数组
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1;  // 左子数组大小
    int n2 = right - mid;      // 右子数组大小
    
    // 创建临时数组
    int* L = (int*)malloc(n1 * sizeof(int));
    int* R = (int*)malloc(n2 * sizeof(int));
    
    // 复制数据到临时数组
    for (i = 0; i < n1; i++) {
        L[i] = arr[left + i];
    }
    for (j = 0; j < n2; j++) {
        R[j] = arr[mid + 1 + j];
    }
    
    // 合并临时数组回原数组
    i = 0;      // 左子数组索引
    j = 0;      // 右子数组索引
    k = left;   // 合并后数组索引
    
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }
    
    // 复制剩余元素
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }
    
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
    
    // 释放临时数组
    free(L);
    free(R);
}

// 归并排序主函数
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        
        // 递归排序左半部分
        mergeSort(arr, left, mid);
        
        // 递归排序右半部分
        mergeSort(arr, mid + 1, right);
        
        // 合并两个有序子数组
        merge(arr, left, mid, right);
    }
}

// 归并排序包装函数
void mergeSortWrapper(int arr[], int n) {
    mergeSort(arr, 0, n - 1);
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9, 3};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    mergeSortWrapper(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

- **时间复杂度**：
  - 最好情况：O(n log n)
  - 最坏情况：O(n log n)
  - 平均情况：O(n log n)
- **空间复杂度**：O(n) - 需要临时数组存储合并结果
- **稳定性**：稳定排序

### 特点

- ✅ 时间复杂度稳定为O(n log n)
- ✅ 稳定排序
- ✅ 适合链表排序
- ✅ 适合外部排序（处理大文件）
- ❌ 需要O(n)额外空间
- ❌ 对于小数组，常数因子较大

## 分配排序

分配排序是一类非比较排序算法，通过利用数据的特性（如数字的位数、值的范围等）来进行排序，可以达到线性时间复杂度。

### 1. 计数排序（Counting Sort）

#### 基本思想

统计每个元素出现的次数，然后根据统计结果将元素放回正确位置。适用于数据范围较小的整数排序。

#### 算法步骤

1. 找出数组中的最大值和最小值
2. 创建一个计数数组，大小为（最大值-最小值+1）
3. 统计每个元素出现的次数
4. 根据计数数组，将元素放回原数组的正确位置

#### 算法演示

```
初始序列：[4, 2, 2, 8, 3, 3, 1]
范围：1-8

步骤1：统计每个元素出现次数
  计数数组：[1:1, 2:2, 3:2, 4:1, 5:0, 6:0, 7:0, 8:1]

步骤2：计算累积计数（每个位置表示小于等于该值的元素个数）
  累积数组：[1:1, 2:3, 3:5, 4:6, 5:6, 6:6, 7:6, 8:7]

步骤3：根据累积数组放置元素
  从后往前遍历原数组：
    arr[6]=1 → 位置0 → [1, _, _, _, _, _, _]
    arr[5]=3 → 位置4 → [1, _, _, _, 3, _, _]
    arr[4]=3 → 位置3 → [1, _, _, 3, 3, _, _]
    arr[3]=8 → 位置6 → [1, _, _, 3, 3, _, 8]
    arr[2]=2 → 位置1 → [1, 2, _, 3, 3, _, 8]
    arr[1]=2 → 位置2 → [1, 2, 2, 3, 3, _, 8]
    arr[0]=4 → 位置5 → [1, 2, 2, 3, 3, 4, 8]

最终结果：[1, 2, 2, 3, 3, 4, 8]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 计数排序
void countingSort(int arr[], int n) {
    // 找出最大值和最小值
    int max = arr[0], min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }
    
    int range = max - min + 1;
    
    // 创建计数数组并初始化为0
    int* count = (int*)calloc(range, sizeof(int));
    
    // 统计每个元素出现次数
    for (int i = 0; i < n; i++) {
        count[arr[i] - min]++;
    }
    
    // 计算累积计数
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }
    
    // 创建输出数组
    int* output = (int*)malloc(n * sizeof(int));
    
    // 从后往前遍历，保证稳定性
    for (int i = n - 1; i >= 0; i--) {
        output[count[arr[i] - min] - 1] = arr[i];
        count[arr[i] - min]--;
    }
    
    // 将结果复制回原数组
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    // 释放内存
    free(count);
    free(output);
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {4, 2, 2, 8, 3, 3, 1};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    countingSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：O(n + k)，其中k是数据范围
- **空间复杂度**：O(k) - 需要计数数组
- **稳定性**：稳定排序（如果实现正确）

#### 特点

- ✅ 线性时间复杂度
- ✅ 稳定排序
- ✅ 适合数据范围较小的整数排序
- ❌ 需要知道数据的范围
- ❌ 数据范围很大时，空间开销大

### 2. 桶排序（Bucket Sort）

#### 基本思想

将数组分到有限数量的桶里，每个桶再分别排序（可以使用其他排序算法或递归使用桶排序），最后将各个桶中的数据合并。

#### 算法步骤

1. 确定桶的数量和范围
2. 将元素分配到对应的桶中
3. 对每个桶内的元素进行排序
4. 按顺序将各个桶中的元素合并

#### 算法演示

```
初始序列：[0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
范围：0-1，桶数：10

步骤1：分配到桶中
  桶0：[]
  桶1：[]
  桶2：[]
  桶3：[0.32, 0.33, 0.37]
  桶4：[0.42, 0.47]
  桶5：[0.52, 0.51]
  桶6-9：[]

步骤2：对每个桶排序
  桶3：[0.32, 0.33, 0.37]
  桶4：[0.42, 0.47]
  桶5：[0.51, 0.52]

步骤3：合并
  结果：[0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 使用插入排序对桶内元素排序
void insertionSort(float arr[], int n) {
    int i, j;
    float key;
    
    for (i = 1; i < n; i++) {
        key = arr[i];
        j = i - 1;
        
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 桶排序
void bucketSort(float arr[], int n) {
    // 创建n个桶
    float** buckets = (float**)malloc(n * sizeof(float*));
    int* bucketSizes = (int*)calloc(n, sizeof(int));
    int* bucketCounts = (int*)calloc(n, sizeof(int));
    
    // 初始化桶
    for (int i = 0; i < n; i++) {
        buckets[i] = (float*)malloc(n * sizeof(float));
        bucketCounts[i] = 0;
    }
    
    // 将元素分配到桶中
    for (int i = 0; i < n; i++) {
        int bucketIndex = (int)(n * arr[i]);
        buckets[bucketIndex][bucketCounts[bucketIndex]++] = arr[i];
    }
    
    // 对每个桶排序
    for (int i = 0; i < n; i++) {
        if (bucketCounts[i] > 0) {
            insertionSort(buckets[i], bucketCounts[i]);
        }
    }
    
    // 合并桶
    int index = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < bucketCounts[i]; j++) {
            arr[index++] = buckets[i][j];
        }
    }
    
    // 释放内存
    for (int i = 0; i < n; i++) {
        free(buckets[i]);
    }
    free(buckets);
    free(bucketSizes);
    free(bucketCounts);
}

// 打印数组
void printArray(float arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%.2f ", arr[i]);
    }
    printf("\n");
}

int main() {
    float arr[] = {0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    bucketSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n) - 元素均匀分布
  - 最坏情况：O(n²) - 所有元素在一个桶中
  - 平均情况：O(n + k)，k为桶内排序的时间复杂度
- **空间复杂度**：O(n + k) - 需要桶的存储空间
- **稳定性**：稳定排序（如果桶内排序是稳定的）

#### 特点

- ✅ 平均情况下效率高
- ✅ 稳定排序
- ✅ 适合数据分布均匀的情况
- ❌ 需要知道数据的分布情况
- ❌ 最坏情况下效率低

### 3. 基数排序（Radix Sort）

#### 基本思想

按照低位先排序，然后收集；再按照高位排序，然后再收集；依次类推，直到最高位。有时候有些属性是有优先级顺序的，先按低优先级排序，再按高优先级排序。

#### 算法步骤

1. 找到数组中的最大值，确定最大位数
2. 从最低位开始，对每一位进行计数排序（或桶排序）
3. 重复步骤2，直到最高位

#### 算法演示

```
初始序列：[170, 45, 75, 90, 2, 802, 24, 66]
最大位数：3位

第1轮（按个位排序）：
  0: [170, 90]
  2: [2, 802]
  4: [24]
  5: [45, 75]
  6: [66]
  结果：[170, 90, 2, 802, 24, 45, 75, 66]

第2轮（按十位排序）：
  0: [2, 802]
  2: [24]
  4: [45]
  6: [66]
  7: [170, 75]
  9: [90]
  结果：[2, 802, 24, 45, 66, 170, 75, 90]

第3轮（按百位排序）：
  0: [2, 24, 45, 66, 75, 90]
  1: [170]
  8: [802]
  结果：[2, 24, 45, 66, 75, 90, 170, 802]

最终结果：[2, 24, 45, 66, 75, 90, 170, 802]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 获取数组中最大值
int getMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// 对指定位数进行计数排序
void countSortByDigit(int arr[], int n, int exp) {
    int* output = (int*)malloc(n * sizeof(int));
    int count[10] = {0};
    
    // 统计每个数字出现的次数
    for (int i = 0; i < n; i++) {
        count[(arr[i] / exp) % 10]++;
    }
    
    // 计算累积计数
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }
    
    // 从后往前遍历，保证稳定性
    for (int i = n - 1; i >= 0; i--) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }
    
    // 将结果复制回原数组
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    free(output);
}

// 基数排序
void radixSort(int arr[], int n) {
    // 找到最大值，确定位数
    int max = getMax(arr, n);
    
    // 从个位开始，对每一位进行计数排序
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countSortByDigit(arr, n, exp);
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {170, 45, 75, 90, 2, 802, 24, 66};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    radixSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}

- **时间复杂度**：O(d × (n + k))，其中d是位数，k是基数（通常为10）
- **空间复杂度**：O(n + k) - 需要临时数组和计数数组
- **稳定性**：稳定排序

#### 特点

- ✅ 线性时间复杂度（当位数d较小时）
- ✅ 稳定排序
- ✅ 适合整数排序
- ✅ 适合位数较少的整数
- ❌ 需要知道数据的位数
- ❌ 不适合浮点数排序（需要特殊处理）

| 基数排序 | O(d × n) | O(d × n) | O(d × n) | O(n + k) | 稳定 |

注：k表示数据范围或桶的数量，d表示位数

### 算法选择建议

#### 小规模数据（n < 50）
- **推荐**：直接插入排序
- **原因**：实现简单，常数因子小，对于小数据效率高

#### 中等规模数据（50 < n < 1000）
- **推荐**：快速排序、归并排序
- **原因**：平均时间复杂度为O(n log n)，效率高

#### 大规模数据（n > 1000）
- **推荐**：快速排序、堆排序、归并排序
- **原因**：时间复杂度为O(n log n)，适合大规模数据

#### 数据基本有序
- **推荐**：直接插入排序、冒泡排序（优化版）
- **原因**：接近O(n)时间复杂度

#### 需要稳定排序
- **推荐**：直接插入排序、冒泡排序、归并排序、计数排序、桶排序、基数排序
- **原因**：这些算法都是稳定排序

#### 整数排序，范围较小
- **推荐**：计数排序、基数排序
- **原因**：可以达到线性时间复杂度

#### 数据分布均匀
- **推荐**：桶排序
- **原因**：
步骤4：继续
   [5, 2, 1, 8, 9] → [1, 2, 5, 8, 9]
   堆化：[2, 1]

步骤5：最后一步
   [2, 1, 5, 8, 9] → [1, 2, 5, 8, 9]

最终结果：[1, 2, 5, 8, 9]
```

#### C语言实现

```c
#include <stdio.h>

// 交换两个元素
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 堆化函数 - 维护最大堆性质
void heapify(int arr[], int n, int i) {
    int largest = i;        // 初始化最大值为根节点
    int left = 2 * i + 1;  // 左子节点
    int right = 2 * i + 2; // 右子节点
    
    // 如果左子节点大于根节点
    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }
    
    // 如果右子节点大于当前最大值
    if (right < n && arr[right] > arr[largest]) {
        largest = right;
    }
    
    // 如果最大值不是根节点，交换并继续堆化
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}

// 堆排序主函数
void heapSort(int arr[], int n) {
    // 构建最大堆（从最后一个非叶子节点开始）
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    
    // 逐个从堆中取出元素
    for (int i = n - 1; i > 0; i--) {
        // 将堆顶（最大值）移到末尾
        swap(&arr[0], &arr[i]);
        
        // 对剩余部分重新堆化
        heapify(arr, i, 0);
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    heapSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

  - 最好情况：O(n log n)
  - 最坏情况：O(n log n)
  - 平均情况：O(n log n)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：不稳定排序

#### 特点

- ✅ 时间复杂度稳定为O(n log n)
- ✅ 原地排序
- ✅ 不需要额外的辅助空间
- ✅ 适合大规模数据
- ❌ 不稳定排序
- ❌ 对于小规模数据，常数因子较大

## 归并排序

### 基本思想

采用分治法（Divide and Conquer）策略，将数组分成两半，分别对两半进行排序，然后将两个有序的子数组合并成一个有序数组。

### 算法步骤

1. 将数组分成两半
2. 递归地对左半部分进行归并排序
3. 递归地对右半部分进行归并排序
4. 合并两个有序子数组

### 合并过程

合并两个有序数组的过程：
- 使用两个指针分别指向两个子数组的起始位置
- 比较两个指针指向的元素，将较小的元素放入结果数组
- 移动指针，重复比较，直到其中一个子数组遍历完
- 将剩余元素复制到结果数组

### 算法演示

```
初始序列：[5, 2, 8, 1, 9, 3]

分解过程：
  [5, 2, 8, 1, 9, 3]
       ↓
  [5, 2, 8]  [1, 9, 3]
       ↓
  [5, 2] [8]  [1, 9] [3]
       ↓
  [5] [2] [8]  [1] [9] [3]

合并过程：
  [5] [2] → [2, 5]
  [2, 5] [8] → [2, 5, 8]
  
  [1] [9] → [1, 9]
  [1, 9] [3] → [1, 3, 9]
  
  [2, 5, 8] [1, 3, 9] → [1, 2, 3, 5, 8, 9]

最终结果：[1, 2, 3, 5, 8, 9]
```

### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 合并两个有序子数组
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1;  // 左子数组大小
    int n2 = right - mid;      // 右子数组大小
    
    // 创建临时数组
    int* L = (int*)malloc(n1 * sizeof(int));
    int* R = (int*)malloc(n2 * sizeof(int));
    
    // 复制数据到临时数组
    for (i = 0; i < n1; i++) {
        L[i] = arr[left + i];
    }
    for (j = 0; j < n2; j++) {
        R[j] = arr[mid + 1 + j];
    }
    
    // 合并临时数组回原数组
    i = 0;      // 左子数组索引
    j = 0;      // 右子数组索引
    k = left;   // 合并后数组索引
    
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }
    
    // 复制剩余元素
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }
    
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
    
    // 释放临时数组
    free(L);
    free(R);
}

// 归并排序主函数
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        
        // 递归排序左半部分
        mergeSort(arr, left, mid);
        
        // 递归排序右半部分
        mergeSort(arr, mid + 1, right);
        
        // 合并两个有序子数组
        merge(arr, left, mid, right);
    }
}

// 归并排序包装函数
void mergeSortWrapper(int arr[], int n) {
    mergeSort(arr, 0, n - 1);
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {5, 2, 8, 1, 9, 3};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    mergeSortWrapper(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

- **时间复杂度**：
  - 最好情况：O(n log n)
  - 最坏情况：O(n log n)
  - 平均情况：O(n log n)
- **空间复杂度**：O(n) - 需要临时数组存储合并结果
- **稳定性**：稳定排序

### 特点

- ✅ 时间复杂度稳定为O(n log n)
- ✅ 稳定排序
- ✅ 适合链表排序
- ✅ 适合外部排序（处理大文件）
- ❌ 需要O(n)额外空间
- ❌ 对于小数组，常数因子较大

## 分配排序

分配排序是一类非比较排序算法，通过利用数据的特性（如数字的位数、值的范围等）来进行排序，可以达到线性时间复杂度。

### 1. 计数排序（Counting Sort）

#### 基本思想

统计每个元素出现的次数，然后根据统计结果将元素放回正确位置。适用于数据范围较小的整数排序。

#### 算法步骤

1. 找出数组中的最大值和最小值
2. 创建一个计数数组，大小为（最大值-最小值+1）
3. 统计每个元素出现的次数
4. 根据计数数组，将元素放回原数组的正确位置

#### 算法演示

```
初始序列：[4, 2, 2, 8, 3, 3, 1]
范围：1-8

步骤1：统计每个元素出现次数
  计数数组：[1:1, 2:2, 3:2, 4:1, 5:0, 6:0, 7:0, 8:1]

步骤2：计算累积计数（每个位置表示小于等于该值的元素个数）
  累积数组：[1:1, 2:3, 3:5, 4:6, 5:6, 6:6, 7:6, 8:7]

步骤3：根据累积数组放置元素
  从后往前遍历原数组：
    arr[6]=1 → 位置0 → [1, _, _, _, _, _, _]
    arr[5]=3 → 位置4 → [1, _, _, _, 3, _, _]
    arr[4]=3 → 位置3 → [1, _, _, 3, 3, _, _]
    arr[3]=8 → 位置6 → [1, _, _, 3, 3, _, 8]
    arr[2]=2 → 位置1 → [1, 2, _, 3, 3, _, 8]
    arr[1]=2 → 位置2 → [1, 2, 2, 3, 3, _, 8]
    arr[0]=4 → 位置5 → [1, 2, 2, 3, 3, 4, 8]

最终结果：[1, 2, 2, 3, 3, 4, 8]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 计数排序
void countingSort(int arr[], int n) {
    // 找出最大值和最小值
    int max = arr[0], min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }
    
    int range = max - min + 1;
    
    // 创建计数数组并初始化为0
    int* count = (int*)calloc(range, sizeof(int));
    
    // 统计每个元素出现次数
    for (int i = 0; i < n; i++) {
        count[arr[i] - min]++;
    }
    
    // 计算累积计数
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }
    
    // 创建输出数组
    int* output = (int*)malloc(n * sizeof(int));
    
    // 从后往前遍历，保证稳定性
    for (int i = n - 1; i >= 0; i--) {
        output[count[arr[i] - min] - 1] = arr[i];
        count[arr[i] - min]--;
    }
    
    // 将结果复制回原数组
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    // 释放内存
    free(count);
    free(output);
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {4, 2, 2, 8, 3, 3, 1};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    countingSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：O(n + k)，其中k是数据范围
- **空间复杂度**：O(k) - 需要计数数组
- **稳定性**：稳定排序（如果实现正确）

#### 特点

- ✅ 线性时间复杂度
- ✅ 稳定排序
- ✅ 适合数据范围较小的整数排序
- ❌ 需要知道数据的范围
- ❌ 数据范围很大时，空间开销大

### 2. 桶排序（Bucket Sort）

#### 基本思想

将数组分到有限数量的桶里，每个桶再分别排序（可以使用其他排序算法或递归使用桶排序），最后将各个桶中的数据合并。

#### 算法步骤

1. 确定桶的数量和范围
2. 将元素分配到对应的桶中
3. 对每个桶内的元素进行排序
4. 按顺序将各个桶中的元素合并

#### 算法演示

```
初始序列：[0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
范围：0-1，桶数：10

步骤1：分配到桶中
  桶0：[]
  桶1：[]
  桶2：[]
  桶3：[0.32, 0.33, 0.37]
  桶4：[0.42, 0.47]
  桶5：[0.52, 0.51]
  桶6-9：[]

步骤2：对每个桶排序
  桶3：[0.32, 0.33, 0.37]
  桶4：[0.42, 0.47]
  桶5：[0.51, 0.52]

步骤3：合并
  结果：[0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 使用插入排序对桶内元素排序
void insertionSort(float arr[], int n) {
    int i, j;
    float key;
    
    for (i = 1; i < n; i++) {
        key = arr[i];
        j = i - 1;
        
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 桶排序
void bucketSort(float arr[], int n) {
    // 创建n个桶
    float** buckets = (float**)malloc(n * sizeof(float*));
    int* bucketSizes = (int*)calloc(n, sizeof(int));
    int* bucketCounts = (int*)calloc(n, sizeof(int));
    
    // 初始化桶
    for (int i = 0; i < n; i++) {
        buckets[i] = (float*)malloc(n * sizeof(float));
        bucketCounts[i] = 0;
    }
    
    // 将元素分配到桶中
    for (int i = 0; i < n; i++) {
        int bucketIndex = (int)(n * arr[i]);
        buckets[bucketIndex][bucketCounts[bucketIndex]++] = arr[i];
    }
    
    // 对每个桶排序
    for (int i = 0; i < n; i++) {
        if (bucketCounts[i] > 0) {
            insertionSort(buckets[i], bucketCounts[i]);
        }
    }
    
    // 合并桶
    int index = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < bucketCounts[i]; j++) {
            arr[index++] = buckets[i][j];
        }
    }
    
    // 释放内存
    for (int i = 0; i < n; i++) {
        free(buckets[i]);
    }
    free(buckets);
    free(bucketSizes);
    free(bucketCounts);
}

// 打印数组
void printArray(float arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%.2f ", arr[i]);
    }
    printf("\n");
}

int main() {
    float arr[] = {0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    bucketSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}
```

#### 复杂度分析

- **时间复杂度**：
  - 最好情况：O(n) - 元素均匀分布
  - 最坏情况：O(n²) - 所有元素在一个桶中
  - 平均情况：O(n + k)，k为桶内排序的时间复杂度
- **空间复杂度**：O(n + k) - 需要桶的存储空间
- **稳定性**：稳定排序（如果桶内排序是稳定的）

#### 特点

- ✅ 平均情况下效率高
- ✅ 稳定排序
- ✅ 适合数据分布均匀的情况
- ❌ 需要知道数据的分布情况
- ❌ 最坏情况下效率低

### 3. 基数排序（Radix Sort）

#### 基本思想

按照低位先排序，然后收集；再按照高位排序，然后再收集；依次类推，直到最高位。有时候有些属性是有优先级顺序的，先按低优先级排序，再按高优先级排序。

#### 算法步骤

1. 找到数组中的最大值，确定最大位数
2. 从最低位开始，对每一位进行计数排序（或桶排序）
3. 重复步骤2，直到最高位

#### 算法演示

```
初始序列：[170, 45, 75, 90, 2, 802, 24, 66]
最大位数：3位

第1轮（按个位排序）：
  0: [170, 90]
  2: [2, 802]
  4: [24]
  5: [45, 75]
  6: [66]
  结果：[170, 90, 2, 802, 24, 45, 75, 66]

第2轮（按十位排序）：
  0: [2, 802]
  2: [24]
  4: [45]
  6: [66]
  7: [170, 75]
  9: [90]
  结果：[2, 802, 24, 45, 66, 170, 75, 90]

第3轮（按百位排序）：
  0: [2, 24, 45, 66, 75, 90]
  1: [170]
  8: [802]
  结果：[2, 24, 45, 66, 75, 90, 170, 802]

最终结果：[2, 24, 45, 66, 75, 90, 170, 802]
```

#### C语言实现

```c
#include <stdio.h>
#include <stdlib.h>

// 获取数组中最大值
int getMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// 对指定位数进行计数排序
void countSortByDigit(int arr[], int n, int exp) {
    int* output = (int*)malloc(n * sizeof(int));
    int count[10] = {0};
    
    // 统计每个数字出现的次数
    for (int i = 0; i < n; i++) {
        count[(arr[i] / exp) % 10]++;
    }
    
    // 计算累积计数
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }
    
    // 从后往前遍历，保证稳定性
    for (int i = n - 1; i >= 0; i--) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }
    
    // 将结果复制回原数组
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    free(output);
}

// 基数排序
void radixSort(int arr[], int n) {
    // 找到最大值，确定位数
    int max = getMax(arr, n);
    
    // 从个位开始，对每一位进行计数排序
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countSortByDigit(arr, n, exp);
    }
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {170, 45, 75, 90, 2, 802, 24, 66};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("排序前: ");
    printArray(arr, n);
    
    radixSort(arr, n);
    
    printf("排序后: ");
    printArray(arr, n);
    
    return 0;
}

- **时间复杂度**：O(d × (n + k))，其中d是位数，k是基数（通常为10）
- **空间复杂度**：O(n + k) - 需要临时数组和计数数组
- **稳定性**：稳定排序

#### 特点

- ✅ 线性时间复杂度（当位数d较小时）
- ✅ 稳定排序
- ✅ 适合整数排序
- ✅ 适合位数较少的整数
- ❌ 需要知道数据的位数
- ❌ 不适合浮点数排序（需要特殊处理）

## 各种排序算法对比

### 时间复杂度对比表

| 排序算法 | 最好情况 | 平均情况 | 最坏情况 | 空间复杂度 | 稳定性 |
|---------|---------|---------|---------|-----------|--------|
| 直接插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n log n) | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 简单选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 计数排序 | O(n + k) | O(n + k) | O(n + k) | O(k) | 稳定 |
| 桶排序 | O(n) | O(n + k) | O(n²) | O(n + k) | 稳定 |
| 基数排序 | O(d × n) | O(d × n) | O(d × n) | O(n + k) | 稳定 |

注：k表示数据范围或桶的数量，d表示位数

### 算法选择建议

#### 小规模数据（n < 50）
- **推荐**：直接插入排序
- **原因**：实现简单，常数因子小，对于小数据效率高

#### 中等规模数据（50 < n < 1000）
- **推荐**：快速排序、归并排序
- **原因**：平均时间复杂度为O(n log n)，效率高

#### 大规模数据（n > 1000）
- **推荐**：快速排序、堆排序、归并排序
- **原因**：时间复杂度为O(n log n)，适合大规模数据

#### 数据基本有序
- **推荐**：直接插入排序、冒泡排序（优化版）
- **原因**：接近O(n)时间复杂度

#### 需要稳定排序
- **推荐**：直接插入排序、冒泡排序、归并排序、计数排序、桶排序、基数排序
- **原因**：这些算法都是稳定排序

#### 整数排序，范围较小
- **推荐**：计数排序、基数排序
- **原因**：可以达到线性时间复杂度

#### 数据分布均匀
- **推荐**：桶排序
- **原因**：平均情况下可以达到线性时间复杂度

#### 需要原地排序（空间受限）
- **推荐**：快速排序、堆排序、希尔排序
- **原因**：只需要O(1)或O(log n)额外空间

## 实际应用场景

### 1. 直接插入排序

#### 适用场景
- **小规模数据**：数据量小于50时效率高
- **基本有序的数据**：接近O(n)时间复杂度
- **稳定排序需求**：需要保持相同元素的相对顺序
- **在线排序**：数据流式输入，边输入边排序

#### 实际应用
- 扑克牌排序
- 小型数据库的排序
- 实时数据流的排序
- 作为其他排序算法的子程序（如快速排序的优化）

### 2. 希尔排序

#### 适用场景
- **中等规模数据**：比直接插入排序效率高
- **需要原地排序**：空间受限的情况
- **对稳定性要求不高**：可以接受不稳定排序

#### 实际应用
- 嵌入式系统中的排序
- 中等规模数组的排序
- 作为其他算法的优化手段

### 3. 冒泡排序

#### 适用场景
- **教学演示**：算法简单，易于理解
- **小规模数据**：数据量很小时可以使用
- **检测数据是否有序**：优化版本可以提前终止

#### 实际应用
- 算法教学
- 简单的排序需求
- 数据基本有序时的快速检测

### 4. 快速排序

#### 适用场景
- **大规模数据**：平均情况下效率很高
- **通用排序**：大多数情况下的首选
- **随机数据**：对随机数据表现优秀

#### 实际应用
- **C标准库的qsort**：使用快速排序
- **数据库系统**：用于排序查询结果
- **操作系统**：文件系统排序
- **编程语言标准库**：Java的Arrays.sort()（对小数组使用插入排序，大数组使用快速排序）

### 5. 简单选择排序

#### 适用场景
- **交换成本高**：交换操作代价大时
- **小规模数据**：数据量很小时
- **简单实现**：需要快速实现排序功能

#### 实际应用
- 交换操作成本高的场景
- 简单的排序需求

### 6. 堆排序

#### 适用场景
- **需要保证最坏情况O(n log n)**：不能接受快速排序的最坏情况
- **原地排序**：空间受限的情况
- **大规模数据**：适合处理大量数据

#### 实际应用
- **优先级队列**：堆数据结构的应用
- **实时系统**：需要保证时间复杂度上界
- **大规模数据排序**：需要稳定性能的场景

### 7. 归并排序

#### 适用场景
- **需要稳定排序**：必须保持相同元素的相对顺序
- **链表排序**：适合链表数据结构
- **外部排序**：处理大文件，无法全部加载到内存
- **并行排序**：容易实现并行化

#### 实际应用
- **数据库系统**：需要稳定排序的查询
- **外部排序**：处理大文件的排序
- **链表排序**：对链表进行排序
- **分布式系统**：可以并行处理
- **Python的sorted()函数**：使用Timsort（归并排序的变种）

### 8. 计数排序

#### 适用场景
- **整数排序**：只能用于整数
- **数据范围小**：数据范围远小于数据量
- **需要稳定排序**：保持相同元素的相对顺序

#### 实际应用
- **年龄排序**：人的年龄范围有限（0-150）
- **成绩排序**：分数范围有限（0-100）
- **字符频率统计**：ASCII字符范围有限（0-255）
- **作为基数排序的子程序**：用于基数排序的每一位排序

### 9. 桶排序

#### 适用场景
- **数据分布均匀**：元素均匀分布在某个范围内
- **浮点数排序**：适合0-1之间的浮点数
- **需要稳定排序**：保持相同元素的相对顺序

#### 实际应用
- **浮点数排序**：0-1之间的均匀分布浮点数
- **数据分布已知**：知道数据的大致分布情况
- **外部排序的优化**：作为外部排序的一部分

### 10. 基数排序

#### 适用场景
- **整数排序**：只能用于整数
- **位数较少**：位数d远小于数据量n
- **需要稳定排序**：保持相同元素的相对顺序

#### 实际应用
- **字符串排序**：按字典序排序
- **多关键字排序**：如日期排序（年、月、日）
- **IP地址排序**：IP地址可以看作4个字节的整数
- **电话号码排序**：固定长度的数字串

### 综合排序算法库

以下是一个完整的C语言实现，包含所有主要排序算法：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>

// ==================== 工具函数 ====================

// 交换两个元素
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// 打印数组
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// 复制数组
void copyArray(int src[], int dst[], int n) {
    for (int i = 0; i < n; i++) {
        dst[i] = src[i];
    }
}

// 检查数组是否有序
int isSorted(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        if (arr[i] < arr[i - 1]) {
            return 0;
        }
    }
    return 1;
}

// ==================== 插入排序 ====================

// 直接插入排序
void insertionSort(int arr[], int n) {
    int i, j, key;
    
    for (i = 1; i < n; i++) {
        key = arr[i];
        j = i - 1;
        
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        arr[j + 1] = key;
    }
}

// 希尔排序
void shellSort(int arr[], int n) {
    int gap, i, j, temp;
    
    for (gap = n / 2; gap > 0; gap /= 2) {
        for (i = gap; i < n; i++) {
            temp = arr[i];
            j = i;
            
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            
            arr[j] = temp;
        }
    }
}

// ==================== 交换排序 ====================

// 冒泡排序
void bubbleSort(int arr[], int n) {
    int i, j, temp;
    int swapped;
    
    for (i = 0; i < n - 1; i++) {
        swapped = 0;
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (swapped == 0) {
            break;
        }
    }
}

// 快速排序分区函数
int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}

// 快速排序
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

// 快速排序包装函数
void quickSortWrapper(int arr[], int n) {
    quickSort(arr, 0, n - 1);
}

// ==================== 选择排序 ====================

// 简单选择排序
void selectionSort(int arr[], int n) {
    int i, j, minIndex, temp;
    
    for (i = 0; i < n - 1; i++) {
        minIndex = i;
        for (j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        
        if (minIndex != i) {
            temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}

// 堆化函数
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    
    if (left < n && arr[left] > arr[largest]) {
        largest = left;
    }
    
    if (right < n && arr[right] > arr[largest]) {
        largest = right;
    }
    
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}

// 堆排序
void heapSort(int arr[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        heapify(arr, i, 0);
    }
}

// ==================== 归并排序 ====================

// 合并两个有序子数组
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1;
    int n2 = right - mid;
    
    int* L = (int*)malloc(n1 * sizeof(int));
    int* R = (int*)malloc(n2 * sizeof(int));
    
    for (i = 0; i < n1; i++) {
        L[i] = arr[left + i];
    }
    for (j = 0; j < n2; j++) {
        R[j] = arr[mid + 1 + j];
    }
    
    i = 0;
    j = 0;
    k = left;
    
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }
    
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }
    
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
    
    free(L);
    free(R);
}

// 归并排序
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}

// 归并排序包装函数
void mergeSortWrapper(int arr[], int n) {
    mergeSort(arr, 0, n - 1);
}

// ==================== 分配排序 ====================

// 计数排序
void countingSort(int arr[], int n) {
    int max = arr[0], min = arr[0];
    
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
        if (arr[i] < min) min = arr[i];
    }
    
    int range = max - min + 1;
    int* count = (int*)calloc(range, sizeof(int));
    
    for (int i = 0; i < n; i++) {
        count[arr[i] - min]++;
    }
    
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }
    
    int* output = (int*)malloc(n * sizeof(int));
    
    for (int i = n - 1; i >= 0; i--) {
        output[count[arr[i] - min] - 1] = arr[i];
        count[arr[i] - min]--;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    free(count);
    free(output);
}

// 获取最大值
int getMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

// 按指定位数进行计数排序
void countSortByDigit(int arr[], int n, int exp) {
    int* output = (int*)malloc(n * sizeof(int));
    int count[10] = {0};
    
    for (int i = 0; i < n; i++) {
        count[(arr[i] / exp) % 10]++;
    }
    
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }
    
    for (int i = n - 1; i >= 0; i--) {
        output[count[(arr[i] / exp) % 10] - 1] = arr[i];
        count[(arr[i] / exp) % 10]--;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = output[i];
    }
    
    free(output);
}

// 基数排序
void radixSort(int arr[], int n) {
    int max = getMax(arr, n);
    
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countSortByDigit(arr, n, exp);
    }
}

## 总结

排序算法是计算机科学的基础，不同的算法适用于不同的场景：

- **简单算法**（插入、选择、冒泡）：适合小规模数据，实现简单
- **高效算法**（快速、归并、堆）：适合大规模数据，时间复杂度O(n log n)
- **线性算法**（计数、桶、基数）：适合特定条件，可以达到O(n)时间复杂度

选择合适的排序算法需要考虑：
- 数据规模
- 数据特性（是否有序、分布情况）
- 稳定性要求
- 空间限制
- 实现复杂度

在实际应用中，大多数编程语言的标准库都使用了混合排序策略，结合多种算法的优点，以达到最佳性能。
