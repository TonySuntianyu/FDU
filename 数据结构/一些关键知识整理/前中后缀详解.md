## 前缀、中缀、后缀表达式基础

### 1.1 表达式表示法

在计算机科学中，数学表达式有三种主要的表示方法：

| 表示法 | 特点 | 示例 | 运算符位置 |
|--------|------|------|------------|
| **前缀表达式（波兰式）** | 运算符在操作数之前 | `+ 3 4` | 左→右 |
| **中缀表达式** | 运算符在操作数之间 | `3 + 4` | 左→右 |
| **后缀表达式（逆波兰式）** | 运算符在操作数之后 | `3 4 +` | 左→右 |

### 1.2 表达式特点对比

#### 前缀表达式（Polish Notation）
**特点**：
- 运算符在操作数之前
- 不需要括号
- 从右到左扫描
- 适合递归处理

**示例**：
```
中缀：a + b * c
前缀：+ a * b c

中缀：(a + b) * c
前缀：* + a b c

中缀：a + b * c - d
前缀：- + a * b c d
```

#### 中缀表达式（Infix Notation）
**特点**：
- 运算符在操作数之间
- 需要括号表示优先级
- 符合人类阅读习惯
- 需要处理运算符优先级

**示例**：
```
简单：3 + 4
复杂：3 + 4 * 5 - 6 / 2
带括号：(3 + 4) * (5 - 2)
```

#### 后缀表达式（Reverse Polish Notation）
**特点**：
- 运算符在操作数之后
- 不需要括号
- 从左到右扫描
- 适合栈处理

**示例**：
```
中缀：a + b * c
后缀：a b c * +

中缀：(a + b) * c
后缀：a b + c *

中缀：a + b * c - d
后缀：a b c * + d -
```

### 1.3 运算符优先级

| 运算符 | 优先级 | 结合性 | 说明 |
|--------|--------|--------|------|
| `^` | 4 | 右结合 | 幂运算 |
| `*`, `/` | 3 | 左结合 | 乘除运算 |
| `+`, `-` | 2 | 左结合 | 加减运算 |
| `(` | 1 | - | 左括号 |
| `)` | 1 | - | 右括号 |

## 表达式转换算法

### 2.1 中缀转后缀算法（Shunting Yard算法）

#### 算法思想
使用栈来存储运算符，根据运算符优先级和结合性决定何时将运算符弹出栈。

#### 算法步骤
1. 初始化一个空栈和一个空输出队列
2. 从左到右扫描中缀表达式
3. 如果遇到操作数，直接输出
4. 如果遇到左括号，压入栈
5. 如果遇到右括号，弹出栈中元素直到遇到左括号
6. 如果遇到运算符：
   - 弹出栈中优先级大于等于当前运算符的元素
   - 将当前运算符压入栈
7. 扫描完毕后，弹出栈中所有元素

#### 算法实现

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <queue>
#include <map>
#include <cctype>
using namespace std;

class ExpressionConverter {
private:
    // 运算符优先级
    map<char, int> precedence = {
        {'^', 4},
        {'*', 3}, {'/', 3},
        {'+', 2}, {'-', 2},
        {'(', 1}
    };
    
    // 判断是否为运算符
    bool isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/' || c == '^';
    }
    
    // 判断是否为左括号
    bool isLeftParenthesis(char c) {
        return c == '(';
    }
    
    // 判断是否为右括号
    bool isRightParenthesis(char c) {
        return c == ')';
    }
    
    // 获取运算符优先级
    int getPrecedence(char op) {
        return precedence[op];
    }
    
    // 判断运算符结合性（^为右结合，其他为左结合）
    bool isRightAssociative(char op) {
        return op == '^';
    }
    
public:
    // 中缀转后缀
    string infixToPostfix(const string& infix) {
        stack<char> operatorStack;
        queue<string> outputQueue;
        string result = "";
        
        for (int i = 0; i < infix.length(); i++) {
            char c = infix[i];
            
            // 跳过空格
            if (c == ' ') continue;
            
            // 处理操作数（包括多位数）
            if (isdigit(c) || c == '.') {
                string operand = "";
                while (i < infix.length() && (isdigit(infix[i]) || infix[i] == '.')) {
                    operand += infix[i];
                    i++;
                }
                i--; // 回退一位
                outputQueue.push(operand);
            }
            // 处理左括号
            else if (isLeftParenthesis(c)) {
                operatorStack.push(c);
            }
            // 处理右括号
            else if (isRightParenthesis(c)) {
                while (!operatorStack.empty() && !isLeftParenthesis(operatorStack.top())) {
                    outputQueue.push(string(1, operatorStack.top()));
                    operatorStack.pop();
                }
                if (!operatorStack.empty()) {
                    operatorStack.pop(); // 弹出左括号
                }
            }
            // 处理运算符
            else if (isOperator(c)) {
                while (!operatorStack.empty() && 
                       !isLeftParenthesis(operatorStack.top()) &&
                       ((isRightAssociative(c) && getPrecedence(operatorStack.top()) > getPrecedence(c)) ||
                        (!isRightAssociative(c) && getPrecedence(operatorStack.top()) >= getPrecedence(c)))) {
                    outputQueue.push(string(1, operatorStack.top()));
                    operatorStack.pop();
                }
                operatorStack.push(c);
            }
        }
        
        // 弹出栈中剩余运算符
        while (!operatorStack.empty()) {
            outputQueue.push(string(1, operatorStack.top()));
            operatorStack.pop();
        }
        
        // 构建结果字符串
        while (!outputQueue.empty()) {
            result += outputQueue.front();
            outputQueue.pop();
            if (!outputQueue.empty()) {
                result += " ";
            }
        }
        
        return result;
    }
    
    // 中缀转前缀
    string infixToPrefix(const string& infix) {
        // 反转中缀表达式
        string reversed = reverseString(infix);
        
        // 反转括号
        for (char& c : reversed) {
            if (c == '(') c = ')';
            else if (c == ')') c = '(';
        }
        
        // 转换为后缀
        string postfix = infixToPostfix(reversed);
        
        // 反转后缀表达式得到前缀
        return reverseString(postfix);
    }
    
    // 后缀转中缀
    string postfixToInfix(const string& postfix) {
        stack<string> operandStack;
        stringstream ss(postfix);
        string token;
        
        while (ss >> token) {
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                operandStack.push(token);
            } else if (isOperator(token[0])) {
                if (operandStack.size() < 2) {
                    throw runtime_error("无效的后缀表达式");
                }
                
                string b = operandStack.top();
                operandStack.pop();
                string a = operandStack.top();
                operandStack.pop();
                
                string result = "(" + a + " " + token + " " + b + ")";
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("无效的后缀表达式");
        }
        
        return operandStack.top();
    }
    
    // 前缀转中缀
    string prefixToInfix(const string& prefix) {
        stack<string> operandStack;
        stringstream ss(prefix);
        string token;
        vector<string> tokens;
        
        // 收集所有token
        while (ss >> token) {
            tokens.push_back(token);
        }
        
        // 从右到左处理
        for (int i = tokens.size() - 1; i >= 0; i--) {
            token = tokens[i];
            
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                operandStack.push(token);
            } else if (isOperator(token[0])) {
                if (operandStack.size() < 2) {
                    throw runtime_error("无效的前缀表达式");
                }
                
                string a = operandStack.top();
                operandStack.pop();
                string b = operandStack.top();
                operandStack.pop();
                
                string result = "(" + a + " " + token + " " + b + ")";
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("无效的前缀表达式");
        }
        
        return operandStack.top();
    }
    
    // 显示转换过程
    void showConversionProcess(const string& infix) {
        cout << "中缀表达式: " << infix << endl;
        
        stack<char> operatorStack;
        queue<string> outputQueue;
        string result = "";
        
        cout << "转换过程:" << endl;
        cout << "步骤\t输入\t栈\t\t输出" << endl;
        cout << "----\t----\t----\t\t----" << endl;
        
        int step = 0;
        for (int i = 0; i < infix.length(); i++) {
            char c = infix[i];
            
            if (c == ' ') continue;
            
            step++;
            cout << step << "\t" << c << "\t";
            
            if (isdigit(c) || c == '.') {
                string operand = "";
                while (i < infix.length() && (isdigit(infix[i]) || infix[i] == '.')) {
                    operand += infix[i];
                    i++;
                }
                i--;
                outputQueue.push(operand);
                cout << stackToString(operatorStack) << "\t\t" << operand << endl;
            }
            else if (isLeftParenthesis(c)) {
                operatorStack.push(c);
                cout << stackToString(operatorStack) << "\t\t" << endl;
            }
            else if (isRightParenthesis(c)) {
                while (!operatorStack.empty() && !isLeftParenthesis(operatorStack.top())) {
                    outputQueue.push(string(1, operatorStack.top()));
                    operatorStack.pop();
                }
                if (!operatorStack.empty()) {
                    operatorStack.pop();
                }
                cout << stackToString(operatorStack) << "\t\t" << endl;
            }
            else if (isOperator(c)) {
                while (!operatorStack.empty() && 
                       !isLeftParenthesis(operatorStack.top()) &&
                       ((isRightAssociative(c) && getPrecedence(operatorStack.top()) > getPrecedence(c)) ||
                        (!isRightAssociative(c) && getPrecedence(operatorStack.top()) >= getPrecedence(c)))) {
                    outputQueue.push(string(1, operatorStack.top()));
                    operatorStack.pop();
                }
                operatorStack.push(c);
                cout << stackToString(operatorStack) << "\t\t" << endl;
            }
        }
        
        while (!operatorStack.empty()) {
            outputQueue.push(string(1, operatorStack.top()));
            operatorStack.pop();
        }
        
        while (!outputQueue.empty()) {
            result += outputQueue.front();
            outputQueue.pop();
            if (!outputQueue.empty()) {
                result += " ";
            }
        }
        
        cout << "最终结果: " << result << endl;
    }
    
private:
    string reverseString(const string& str) {
        string result = "";
        for (int i = str.length() - 1; i >= 0; i--) {
            result += str[i];
        }
        return result;
    }
    
    string stackToString(const stack<char>& s) {
        stack<char> temp = s;
        string result = "";
        while (!temp.empty()) {
            result = temp.top() + result;
            temp.pop();
        }
        return result;
    }
};
```

### 2.2 递归转换算法

```cpp
class RecursiveConverter {
public:
    // 递归中缀转后缀
    string infixToPostfixRecursive(const string& infix) {
        return convertRecursive(infix, 0, infix.length() - 1);
    }
    
private:
    string convertRecursive(const string& expr, int start, int end) {
        if (start > end) return "";
        
        // 查找最低优先级的运算符
        int lowestPriority = INT_MAX;
        int lowestPos = -1;
        int parenCount = 0;
        
        for (int i = start; i <= end; i++) {
            char c = expr[i];
            
            if (c == '(') parenCount++;
            else if (c == ')') parenCount--;
            else if (parenCount == 0 && isOperator(c)) {
                int priority = getOperatorPriority(c);
                if (priority <= lowestPriority) {
                    lowestPriority = priority;
                    lowestPos = i;
                }
            }
        }
        
        // 如果没有找到运算符，返回操作数
        if (lowestPos == -1) {
            string result = "";
            for (int i = start; i <= end; i++) {
                if (expr[i] != ' ' && expr[i] != '(' && expr[i] != ')') {
                    result += expr[i];
                }
            }
            return result;
        }
        
        // 递归处理左右两部分
        string left = convertRecursive(expr, start, lowestPos - 1);
        string right = convertRecursive(expr, lowestPos + 1, end);
        
        return left + " " + right + " " + expr[lowestPos];
    }
    
    bool isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/' || c == '^';
    }
    
    int getOperatorPriority(char op) {
        switch (op) {
            case '+': case '-': return 1;
            case '*': case '/': return 2;
            case '^': return 3;
            default: return 0;
        }
    }
};
```

## 表达式求值算法

### 3.1 后缀表达式求值

#### 算法思想
使用栈存储操作数，遇到运算符时弹出相应数量的操作数进行计算。

#### 算法实现

```cpp
class PostfixEvaluator {
public:
    // 后缀表达式求值
    double evaluatePostfix(const string& postfix) {
        stack<double> operandStack;
        stringstream ss(postfix);
        string token;
        
        while (ss >> token) {
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                // 操作数
                operandStack.push(stod(token));
            } else if (isOperator(token[0])) {
                // 运算符
                if (operandStack.size() < 2) {
                    throw runtime_error("无效的后缀表达式");
                }
                
                double b = operandStack.top();
                operandStack.pop();
                double a = operandStack.top();
                operandStack.pop();
                
                double result = calculate(a, b, token[0]);
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("无效的后缀表达式");
        }
        
        return operandStack.top();
    }
    
    // 显示求值过程
    void showEvaluationProcess(const string& postfix) {
        cout << "后缀表达式: " << postfix << endl;
        cout << "求值过程:" << endl;
        cout << "步骤\t输入\t操作\t\t栈" << endl;
        cout << "----\t----\t----\t\t----" << endl;
        
        stack<double> operandStack;
        stringstream ss(postfix);
        string token;
        int step = 0;
        
        while (ss >> token) {
            step++;
            cout << step << "\t" << token << "\t";
            
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                operandStack.push(stod(token));
                cout << "压入操作数\t" << stackToString(operandStack) << endl;
            } else if (isOperator(token[0])) {
                if (operandStack.size() < 2) {
                    cout << "错误：操作数不足" << endl;
                    return;
                }
                
                double b = operandStack.top();
                operandStack.pop();
                double a = operandStack.top();
                operandStack.pop();
                
                double result = calculate(a, b, token[0]);
                operandStack.push(result);
                cout << "计算 " << a << " " << token[0] << " " << b << " = " << result << "\t" << stackToString(operandStack) << endl;
            }
        }
        
        if (operandStack.size() == 1) {
            cout << "最终结果: " << operandStack.top() << endl;
        } else {
            cout << "错误：表达式无效" << endl;
        }
    }
    
private:
    bool isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/' || c == '^';
    }
    
    double calculate(double a, double b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': 
                if (b == 0) throw runtime_error("除零错误");
                return a / b;
            case '^': return pow(a, b);
            default: throw runtime_error("未知运算符");
        }
    }
    
    string stackToString(const stack<double>& s) {
        stack<double> temp = s;
        string result = "";
        while (!temp.empty()) {
            if (!result.empty()) result = " " + result;
            result = to_string(temp.top()) + result;
            temp.pop();
        }
        return "[" + result + "]";
    }
};
```

```cpp
class InfixEvaluator {
public:
    // 中缀表达式直接求值
    double evaluateInfix(const string& infix) {
        stack<double> operandStack;
        stack<char> operatorStack;
        
        for (int i = 0; i < infix.length(); i++) {
            char c = infix[i];
            
            if (c == ' ') continue;
            
            if (isdigit(c) || c == '.') {
                // 读取完整数字
                string num = "";
                while (i < infix.length() && (isdigit(infix[i]) || infix[i] == '.')) {
                    num += infix[i];
                    i++;
                }
                i--; // 回退一位
                operandStack.push(stod(num));
            }
            else if (c == '(') {
                operatorStack.push(c);
            }
            else if (c == ')') {
                while (!operatorStack.empty() && operatorStack.top() != '(') {
                    processOperator(operandStack, operatorStack);
                }
                if (!operatorStack.empty()) {
                    operatorStack.pop(); // 弹出左括号
                }
            }
            else if (isOperator(c)) {
                while (!operatorStack.empty() && 
                       operatorStack.top() != '(' &&
                       getPrecedence(operatorStack.top()) >= getPrecedence(c)) {
                    processOperator(operandStack, operatorStack);
                }
                operatorStack.push(c);
            }
        }
        
        while (!operatorStack.empty()) {
            processOperator(operandStack, operatorStack);
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("无效的中缀表达式");
        }
        
        return operandStack.top();
    }
    
private:
    bool isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/' || c == '^';
    }
    
    int getPrecedence(char op) {
        switch (op) {
            case '+': case '-': return 1;
            case '*': case '/': return 2;
            case '^': return 3;
            default: return 0;
        }
    }
    
    void processOperator(stack<double>& operandStack, stack<char>& operatorStack) {
        if (operandStack.size() < 2) {
            throw runtime_error("操作数不足");
        }
        
        double b = operandStack.top();
        operandStack.pop();
        double a = operandStack.top();
        operandStack.pop();
        
        char op = operatorStack.top();
        operatorStack.pop();
        
        double result = calculate(a, b, op);
        operandStack.push(result);
    }
    
    double calculate(double a, double b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': 
                if (b == 0) throw runtime_error("除零错误");
                return a / b;
            case '^': return pow(a, b);
            default: throw runtime_error("未知运算符");
        }
    }
};
```

## 栈在表达式处理中的应用

### 4.1 栈的基本操作

```cpp
template<typename T>
class Stack {
private:
    vector<T> data;
    
public:
    // 入栈
    void push(const T& item) {
        data.push_back(item);
    }
    
    // 出栈
    T pop() {
        if (isEmpty()) {
            throw runtime_error("栈为空");
        }
        T item = data.back();
        data.pop_back();
        return item;
    }
    
    // 查看栈顶
    T peek() const {
        if (isEmpty()) {
            throw runtime_error("栈为空");
        }
        return data.back();
    }
    
    // 判断是否为空
    bool isEmpty() const {
        return data.empty();
    }
    
    // 获取大小
    size_t size() const {
```

### 4.2 表达式处理中的栈应用

```cpp
class ExpressionProcessor {
private:
    Stack<char> operatorStack;
    Stack<double> operandStack;
    
public:
    // 处理中缀表达式
    double processInfix(const string& infix) {
        operatorStack.clear();
        operandStack.clear();
        
        for (int i = 0; i < infix.length(); i++) {
            char c = infix[i];
            
            if (c == ' ') continue;
            
            if (isdigit(c) || c == '.') {
                // 读取数字
                string num = "";
                while (i < infix.length() && (isdigit(infix[i]) || infix[i] == '.')) {
                    num += infix[i];
                    i++;
                }
                i--;
                operandStack.push(stod(num));
            }
            else if (c == '(') {
                operatorStack.push(c);
            }
            else if (c == ')') {
                while (!operatorStack.isEmpty() && operatorStack.peek() != '(') {
                    processOperator();
                }
                if (!operatorStack.isEmpty()) {
                    operatorStack.pop();
                }
            }
            else if (isOperator(c)) {
                while (!operatorStack.isEmpty() && 
                       operatorStack.peek() != '(' &&
                       getPrecedence(operatorStack.peek()) >= getPrecedence(c)) {
                    processOperator();
                }
                operatorStack.push(c);
            }
        }
        
        while (!operatorStack.isEmpty()) {
            processOperator();
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("表达式无效");
        }
        
        return operandStack.pop();
    }
    
    // 处理后缀表达式
    double processPostfix(const string& postfix) {
        operandStack.clear();
        stringstream ss(postfix);
        string token;
        
        while (ss >> token) {
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                operandStack.push(stod(token));
            } else if (isOperator(token[0])) {
                if (operandStack.size() < 2) {
                    throw runtime_error("操作数不足");
                }
                
                double b = operandStack.pop();
                double a = operandStack.pop();
                double result = calculate(a, b, token[0]);
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("表达式无效");
        }
        
        return operandStack.pop();
    }
    
    // 处理前缀表达式
    double processPrefix(const string& prefix) {
        operandStack.clear();
        stringstream ss(prefix);
        string token;
        vector<string> tokens;
        
        while (ss >> token) {
            tokens.push_back(token);
        }
        
        for (int i = tokens.size() - 1; i >= 0; i--) {
            token = tokens[i];
            
            if (isdigit(token[0]) || (token[0] == '-' && token.length() > 1)) {
                operandStack.push(stod(token));
            } else if (isOperator(token[0])) {
                if (operandStack.size() < 2) {
                    throw runtime_error("操作数不足");
                }
                
                double a = operandStack.pop();
                double b = operandStack.pop();
                double result = calculate(a, b, token[0]);
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw runtime_error("表达式无效");
        }
        
        return operandStack.pop();
    }
    
private:
    bool isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/' || c == '^';
    }
    
    int getPrecedence(char op) {
        switch (op) {
            case '+': case '-': return 1;
            case '*': case '/': return 2;
            case '^': return 3;
            default: return 0;
        }
    }
    
    void processOperator() {
        if (operandStack.size() < 2) {
            throw runtime_error("操作数不足");
        }
        
        double b = operandStack.pop();
        double a = operandStack.pop();
        char op = operatorStack.pop();
        
        double result = calculate(a, b, op);
        operandStack.push(result);
    }
    
    double calculate(double a, double b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': 
                if (b == 0) throw runtime_error("除零错误");
                return a / b;
            case '^': return pow(a, b);
            default: throw runtime_error("未知运算符");
        }
    }
};
```

### 5.1 时间复杂度分析

| 算法 | 时间复杂度 | 说明 |
|------|------------|------|
| **中缀转后缀** | O(n) | n为表达式长度，每个字符处理一次 |
| **中缀转前缀** | O(n) | 需要反转字符串，但仍是线性时间 |
| **后缀求值** | O(n) | 每个token处理一次 |
| **前缀求值** | O(n) | 每个token处理一次 |
| **中缀直接求值** | O(n) | 使用双栈，每个字符处理一次 |

## 总结

### 前中后缀表达式的重要性

1. **前缀表达式**：
   - 适合递归处理
   - 无括号，结构清晰
   - 在编译器中应用广泛

2. **中缀表达式**：
   - 符合人类阅读习惯
   - 需要处理运算符优先级
   - 在用户界面中常用

3. **后缀表达式**：
   - 适合栈处理
   - 无括号，计算简单
   - 在计算器和虚拟机中应用

### 学习要点

1. **掌握转换算法**：中缀转前缀、后缀的算法
2. **理解求值过程**：栈在表达式求值中的应用
3. **熟悉优先级处理**：运算符优先级和结合性
4. **了解实际应用**：计算器、编译器、表达式解析

### 进阶学习

1. **表达式优化**：常数折叠、公共子表达式消除
2. **函数表达式**：支持数学函数的表达式处理
3. **变量表达式**：支持变量的表达式求值
4. **表达式树**：将表达式表示为树结构

前中后缀表达式是计算机科学中的基础概念，掌握它们对于理解编译器、计算器、表达式解析等应用具有重要意义。
