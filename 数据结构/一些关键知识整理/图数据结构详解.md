## 图的基本概念

### 什么是图？

图（Graph）是一种**非线性数据结构**，由**顶点（Vertex）**和**边（Edge）**组成的有序对集合。图可以表示为：

**G = (V, E)**

其中：
- **V**：顶点的有限集合，V = {v₁, v₂, ..., vₙ}
- **E**：边的有限集合，E = {e₁, e₂, ..., eₘ}

### 图的特点

1. **顶点集合**：图中的基本元素，可以表示任何实体
2. **边集合**：连接顶点的关系，可以表示顶点之间的关系
3. **无向图**：边没有方向，表示双向关系
4. **有向图**：边有方向，表示单向关系
5. **权值图**：边可以有权重，表示距离、成本等

### 图的形象比喻

图可以形象地理解：
- **顶点（节点）**：城市、人物、网页等实体
- **边**：道路、关系、链接等连接
- **权值**：距离、成本、权重等属性

### 图与其他数据结构的对比

为了更好地理解图，我们将其与常见的数据结构进行对比：

| 特性 | 线性表 | 树 | 图 |
|------|--------|----|----|
| **结构** | 一对一关系 | 一对多关系 | 多对多关系 |
| **连接性** | 顺序连接 | 层次连接 | 任意连接 |
| **顶点关系** | 前驱和后继唯一 | 一个父节点，多个子节点 | 任意多个相邻顶点 |
| **示例** | 数组、链表 | 二叉树、文件系统 | 社交网络、地图 |

**示例对比**：
```
线性表：A -> B -> C -> D（顺序关系）
树：     A
       / \
      B   C
     / \
    D   E（层次关系）
图：     A --- B
        | \   |
        |  \  |
        C--- D（网状关系）
```

### 图的基本示例

#### 示例1：简单的无向图
```
图G = (V, E)
V = {A, B, C, D}
E = {(A,B), (A,C), (B,C), (C,D)}

图示：
    A --- B
    |  \  |
    |   \ |
    C --- D
```

**解读**：
- 4个顶点：A、B、C、D
- 4条边：A-B、A-C、B-C、C-D
- 这是一个连通图（所有顶点都连通）
- 这是一个简单图（没有自环和多重边）

#### 示例2：简单的有向图
```
图G = (V, E)
V = {1, 2, 3, 4}
E = {<1,2>, <1,3>, <2,4>, <3,4>}

图示：
    1 --> 2
    |     |
    v     v
    3 --> 4
```

**解读**：
- 4个顶点：1、2、3、4
- 4条有向边：1→2、1→3、2→4、3→4
- 顶点1有出度2，无入度（源点）
- 顶点4有入度2，无出度（汇点）

#### 示例3：有权图（地图示例）
```
城市地图：
顶点：北京、上海、广州、深圳
边和权重：
北京--800km--上海
上海--1500km--广州
广州--100km--深圳
北京--2000km--广州

图示：
    北京 ----800---- 上海
     |                |
     |                |
   2000km         1500km
     |                |
     |                |
    广州 ----100---- 深圳
```

### 为什么需要图？

图数据结构解决了以下问题：

1. **复杂关系建模**：现实世界中许多关系不是简单的线性或层次结构
   - 社交网络：朋友关系是双向的、多对多的
   - 交通网络：城市之间有多种路径连接

2. **路径查找**：需要找到两点之间的最短路径或所有路径
   - GPS导航：寻找最佳行车路线
   - 网络路由：数据包传输路径选择

3. **连通性分析**：判断图中哪些部分是连通的
   - 网络故障检测：判断哪些服务器仍可通信
   - 社交网络分析：找到朋友圈

4. **依赖关系处理**：处理任务之间的依赖
   - 项目调度：确定任务执行顺序
   - 编译系统：确定模块编译顺序

### 图的数学表示

图可以用多种数学方式表示：

**1. 集合表示法**：
```
G = (V, E)
V = {v₁, v₂, ..., vₙ}  （顶点集）
E = {e₁, e₂, ..., eₘ}  （边集）
```

**2. 矩阵表示法**（邻接矩阵）：
```
对于图：
  A --- B
  |     |
  C --- D

邻接矩阵：
    A  B  C  D
A [ 0  1  1  0 ]
B [ 1  0  1  1 ]
C [ 1  1  0  1 ]
D [ 0  1  1  0 ]
```

**3. 列表表示法**（邻接表）：
```
A: [B, C]
B: [A, C, D]
C: [A, B, D]
D: [B, C]
```

## 图的术语和定义

### 基本术语

| 术语 | 定义 | 示例 |
|------|------|------|
| **顶点（Vertex）** | 图中的基本单位，也称为节点 | 节点A、B、C |
| **边（Edge）** | 连接两个顶点的线 | 边(A, B) |
| **无向边** | 没有方向的边，表示双向关系 | (A, B) = (B, A) |
| **有向边（弧）** | 有方向的边，用有序对表示 | <A, B> ≠ <B, A> |
| **邻接（Adjacent）** | 两个顶点之间有边连接 | A和B邻接 |
| **关联（Incident）** | 顶点与边的关系 | 边(A, B)与顶点A关联 |
| **度（Degree）** | 与顶点关联的边的数量 | 顶点A的度为3 |
| **入度（In-Degree）** | 指向顶点的边的数量（有向图） | 顶点B的入度为2 |
| **出度（Out-Degree）** | 从顶点出发的边的数量（有向图） | 顶点A的出度为1 |

### 图的属性

#### 1. 路径（Path）

**定义**：从顶点v到顶点w的顶点序列，序列中相邻顶点之间有边相连。

```
示例：
图：A -- B -- C -- D
路径：A -> B -> C -> D（长度为3）
```

**路径长度**：路径上边的数量

#### 2. 简单路径

**定义**：路径中所有顶点都不重复的路径。

#### 3. 回路（Cycle）

**定义**：起点和终点相同的路径，也称为环。

#### 4. 连通性

- **连通图**：无向图中任意两个顶点之间都存在路径
- **强连通图**：有向图中任意两个顶点之间都存在双向路径
- **连通分量**：极大连通子图

#### 5. 度数和边数的关系

**无向图**：
- 所有顶点的度数之和 = 2 × 边数
- Σdeg(v) = 2|E|

**证明**：
每条边连接两个顶点，在计算度数时每条边被计算了两次（分别从两个端点计算），所以所有度数之和等于边数的2倍。

**示例**：
```
图：
  A --- B
  |     |
  C --- D

度数：
deg(A) = 2
deg(B) = 2
deg(C) = 2
deg(D) = 2
总和 = 8

边数 = 4
2 × 边数 = 8 ✓
```

**有向图**：
- 所有顶点的入度之和 = 所有顶点的出度之和 = 边数
- Σindeg(v) = Σoutdeg(v) = |E|

**证明**：
每条有向边从一个顶点出发（计入该顶点的出度），指向另一个顶点（计入该顶点的入度），所以入度之和等于出度之和，都等于边数。

**示例**：
```
有向图：
  1 --> 2
  |     |
  v     v
  3 --> 4

入度：indeg(1)=0, indeg(2)=1, indeg(3)=1, indeg(4)=2
     总和 = 4
出度：outdeg(1)=2, outdeg(2)=1, outdeg(3)=1, outdeg(4)=0
     总和 = 4
边数 = 4 ✓
```

#### 6. 子图（Subgraph）

**定义**：图G' = (V', E')是图G = (V, E)的子图，当且仅当：
- V' ⊆ V（顶点集是子集）
- E' ⊆ E（边集是子集）
- E'中的边只在V'的顶点之间

**示例**：
```
原图G：
    A --- B
    |     |
    C --- D

子图G'：
    A --- B
    |
    C

顶点集：{A, B, C} ⊆ {A, B, C, D}
边集：{(A,B), (A,C)} ⊆ {(A,B), (A,C), (B,D), (C,D)}
```

#### 7. 生成子图（Spanning Subgraph）

**定义**：包含图G所有顶点的子图，即V' = V。

**示例**：
```
原图G（5个顶点）：
生成子图必须包含所有5个顶点，但边可以是原边的子集
```

#### 8. 生成树（Spanning Tree）

**定义**：连通图的生成子图，且是一棵树（n个顶点，n-1条边，无环）。

**特点**：
- 包含原图所有顶点
- 边数为顶点数-1
- 连通且无环

#### 9. 自环（Self-loop）和多重边（Multiple Edges）

**自环**：起点和终点相同的边。
```
示例：A --A-- 或 A --<--A（自己指向自己）
```

**多重边**：两个顶点之间有不止一条边。
```
示例：A ====== B（两条或多条边连接相同顶点）
```

**简单图**：没有自环和多重边的图。

#### 10. 完全图（Complete Graph）

**无向完全图Kₙ**：n个顶点，任意两个顶点之间都有边。

- 边数：n(n-1)/2
- 每个顶点度数为n-1

**示例**：
```
K₃（三角形）：
   A
  / \
 /   \
B-----C
边数 = 3(3-1)/2 = 3

K₄：
  A---B
  |\ /|
  | X |
  |/ \|
  C---D
边数 = 4(4-1)/2 = 6
```

#### 11. 正则图（Regular Graph）

**定义**：所有顶点度数相同的图。

**k-正则图**：每个顶点的度数都是k。

**示例**：
```
3-正则图（立方图）：
每个顶点度数都是3
```

## 图的分类

### 1. 按边的方向分类

#### 无向图（Undirected Graph）

**定义**：图中的边没有方向，边表示双向关系。

```
示例：
    A --- B
    |     |
    C --- D
```

**特点**：
- 边(A, B) = 边(B, A)
- 顶点A和B互相邻接
- 适用于表示对称关系

#### 有向图（Directed Graph）

**定义**：图中的边有方向，用箭头表示。

```
示例：
    A --> B
    ↓     ↑
    C --> D
```

**特点**：
- 弧<A, B> ≠ 弧<B, A>
- 顶点A指向B，但B不一定指向A
- 适用于表示非对称关系

### 2. 按边的权值分类

#### 无权图（Unweighted Graph）

**定义**：图中的边没有权重，只表示连接关系。

**应用**：社交网络、网页链接关系

#### 有权图（Weighted Graph）

**定义**：图中的边有权重值，表示距离、成本等。

```
示例：
    A --5-- B
    |       |
    3       2
    |       |
    C --4-- D
```

**应用**：地图导航、网络路由、成本计算

### 3. 按边的数量分类

#### 稀疏图（Sparse Graph）

**定义**：边的数量远少于完全图的边数（|E| << |V|²）

**特点**：
- 适合用邻接表存储
- 内存占用小
- 适合实际应用

#### 稠密图（Dense Graph）

**定义**：边的数量接近完全图的边数（|E| ≈ |V|²）

**特点**：
- 适合用邻接矩阵存储
- 查询速度快
- 内存占用大

### 4. 特殊类型的图

#### 完全图（Complete Graph）

**定义**：任意两个顶点之间都有边相连。

- **无向完全图**：边数 = n(n-1)/2
- **有向完全图**：边数 = n(n-1)

#### 二分图（Bipartite Graph）

**定义**：顶点可以分为两个集合，所有边连接不同集合的顶点。

```
示例：
集合1: {A, B, C}
集合2: {D, E, F}
边：(A, D), (B, E), (C, F)
```

#### 树和森林

- **树**：连通且无环的无向图（n个顶点，n-1条边）
- **森林**：多棵互不相交的树的集合

## 图的存储结构

### 1. 邻接矩阵（Adjacency Matrix）

**定义**：使用二维数组存储图的边关系。对于图G(V, E)，邻接矩阵是一个|V|×|V|的矩阵，其中：
- matrix[i][j] = 1（或权重）表示顶点i和j之间有边
- matrix[i][j] = 0（或INF）表示顶点i和j之间无边

#### 无向图的邻接矩阵

**构建步骤**：

1. **初始化**：创建一个n×n的矩阵，全部初始化为0
2. **添加边**：对于边(u, v)，设置matrix[u][v] = 1和matrix[v][u] = 1
3. **特点**：矩阵关于主对角线对称

**详细示例**：

对于无向图：
```
    A --- B
    |     |
    C --- D
```

**步骤1：初始化4×4矩阵**
```
     A  B  C  D
  A [ 0  0  0  0 ]
  B [ 0  0  0  0 ]
  C [ 0  0  0  0 ]
  D [ 0  0  0  0 ]
```

**步骤2：添加边A-B**
```
     A  B  C  D
  A [ 0  1  0  0 ]
  B [ 1  0  0  0 ]  <- 无向图，对称设置
  C [ 0  0  0  0 ]
  D [ 0  0  0  0 ]
```

**步骤3：添加边A-C**
```
     A  B  C  D
  A [ 0  1  1  0 ]
  B [ 1  0  0  0 ]
  C [ 1  0  0  0 ]  <- 对称设置
  D [ 0  0  0  0 ]
```

**步骤4：完成所有边**
```
     A  B  C  D
  A [ 0  1  1  0 ]
  B [ 1  0  1  1 ]
  C [ 1  1  0  1 ]
  D [ 0  1  1  0 ]
```

**代码实现**：

```cpp
#define MAX_VERTEX 100
int adjMatrix[MAX_VERTEX][MAX_VERTEX];
int vertexCount;

// 初始化
void initGraph(int n) {
    vertexCount = n;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            adjMatrix[i][j] = 0;  // 0表示无边，1表示有边
        }
    }
}

// 添加边
void addEdge(int u, int v) {
    adjMatrix[u][v] = 1;
    adjMatrix[v][u] = 1;  // 无向图需要对称
}
```

**特点**：
- 矩阵对称（无向图）
- 适合稠密图
- 查询边是否存在：O(1)
- 空间复杂度：O(V²)

#### 有权图的邻接矩阵

```cpp
// 使用INF表示无边，数字表示权重
#define INF 999999
int adjMatrix[MAX_VERTEX][MAX_VERTEX];

void addWeightedEdge(int u, int v, int weight) {
    adjMatrix[u][v] = weight;
    adjMatrix[v][u] = weight;  // 无向图
}

// 有向图只需一条
void addDirectedWeightedEdge(int u, int v, int weight) {
    adjMatrix[u][v] = weight;
}
```

**优点**：
- 查找边的时间复杂度：O(1)
- 实现简单，代码简洁
- 适合稠密图

**缺点**：
- 空间复杂度：O(V²)
- 不适合稀疏图
- 遍历所有邻接顶点需要O(V)时间

### 2. 邻接表（Adjacency List）

**定义**：使用链表数组存储每个顶点的邻接顶点。每个顶点对应一个链表，链表中存储该顶点的所有邻接顶点。

**构建步骤**：

1. **初始化**：创建n个链表，每个链表初始为空
2. **添加边**：对于边(u, v)，将v添加到u的链表中
3. **无向图**：同时将u添加到v的链表中（对称处理）

**详细示例**：

对于无向图：
```
    A --- B
    |     |
    C --- D
```

**步骤1：初始化空链表数组**
```
A: [空]
B: [空]
C: [空]
D: [空]
```

**步骤2：添加边A-B**
```
A: [B]
B: [A]  <- 无向图，对称添加
C: [空]
D: [空]
```

**步骤3：添加边A-C**
```
A: [C -> B]  <- 新边插入头部
B: [A]
C: [A]  <- 对称添加
D: [空]
```

**步骤4：完成所有边**
```
A: [C -> B]
B: [D -> C -> A]
C: [D -> A -> B]
D: [C -> B]
```

**内存结构示意图**：
```
数组索引    链表
  [0]  A -> [C] -> [B] -> NULL
  [1]  B -> [D] -> [C] -> [A] -> NULL
  [2]  C -> [D] -> [A] -> [B] -> NULL
  [3]  D -> [C] -> [B] -> NULL
```

**代码实现**：

```cpp
struct EdgeNode {
    int vertex;
    int weight;  // 有权图使用
    EdgeNode* next;
};

struct Graph {
    EdgeNode* adjList[MAX_VERTEX];
    int vertexCount;
    bool isDirected;
    bool isWeighted;
};

// 初始化图
void initGraph(Graph* g, int n, bool directed, bool weighted) {
    g->vertexCount = n;
    g->isDirected = directed;
    g->isWeighted = weighted;
    for (int i = 0; i < n; i++) {
        g->adjList[i] = nullptr;
    }
}

// 添加边
void addEdge(Graph* g, int u, int v, int weight = 1) {
    EdgeNode* edge = new EdgeNode;
    edge->vertex = v;
    edge->weight = weight;
    edge->next = g->adjList[u];
    g->adjList[u] = edge;
    
    // 无向图需要添加反向边
    if (!g->isDirected) {
        EdgeNode* reverseEdge = new EdgeNode;
        reverseEdge->vertex = u;
        reverseEdge->weight = weight;
        reverseEdge->next = g->adjList[v];
        g->adjList[v] = reverseEdge;
    }
}
```

**优点**：
- 空间复杂度：O(V + E)
- 适合稀疏图
- 遍历邻接顶点高效
- 动态添加边方便

**缺点**：
- 查询边是否存在需要O(度)
- 实现相对复杂
- 需要额外的指针空间

### 3. 边集数组（Edge List）

**定义**：使用数组存储所有边的信息。

```cpp
struct Edge {
    int u, v;      // 边的两个端点
    int weight;    // 边的权重
};

Edge edges[MAX_EDGES];
int edgeCount;

// 添加边
void addEdge(int u, int v, int w) {
    edges[edgeCount].u = u;
    edges[edgeCount].v = v;
    edges[edgeCount].weight = w;
    edgeCount++;
}
```

**特点**：
- 空间复杂度：O(E)
- 适合Kruskal算法等需要遍历所有边的算法
- 查找边效率低：O(E)

### 4. 十字链表（Orthogonal List）

**定义**：有向图的另一种存储方法，同时存储入边和出边。

```cpp
struct ArcNode {
    int tailvex, headvex;  // 弧尾和弧头
    int weight;
    ArcNode* hlink;  // 指向同弧头的下一条弧
    ArcNode* tlink;  // 指向同弧尾的下一条弧
};

struct VertexNode {
    int data;
    ArcNode* firstin;   // 指向以该顶点为弧头的第一条弧
    ArcNode* firstout;  // 指向以该顶点为弧尾的第一条弧
};

struct OrthogonalGraph {
    VertexNode vertices[MAX_VERTEX];
    int vertexCount;
};
```

**优点**：
- 同时记录入边和出边
- 适合有向图
- 便于求顶点的入度和出度

**缺点**：
- 实现复杂
- 空间开销较大

### 5. 邻接多重表（Adjacency Multilist）

**定义**：无向图的一种存储方法，每条边只存储一次。

```cpp
struct EdgeNode {
    int mark;        // 标记边是否被访问
    int ivex, jvex;  // 边的两个顶点
    EdgeNode* ilink; // 指向依附于ivex的下一条边
    EdgeNode* jlink; // 指向依附于jvex的下一条边
    int weight;
};

struct VertexNode {
    int data;
    EdgeNode* firstedge;  // 指向第一条依附于该顶点的边
};
```

**优点**：
- 每条边只存储一次
- 适合无向图
- 节省空间

**缺点**：
- 实现复杂
- 维护困难

### 存储结构比较

| 存储方法 | 空间复杂度 | 查询边 | 遍历邻接顶点 | 适用场景 |
|----------|------------|--------|--------------|----------|
| 邻接矩阵 | O(V²) | O(1) | O(V) | 稠密图、频繁查询 |

| 邻接多重表 | O(V + E) | O(度) | O(度) | 无向图 |

## 图的遍历

图的遍历是指按照某种规则访问图中的每个顶点，且每个顶点只访问一次。

### 1. 深度优先搜索（DFS - Depth First Search）

**定义**：类似于树的先序遍历，尽可能深地搜索图的分支。DFS采用"深入到底"的策略，先访问一个顶点，然后递归访问其未访问的邻接顶点。

**算法思想**：
1. 从起始顶点开始访问
2. 标记当前顶点为已访问
3. 递归访问当前顶点的所有未访问邻接顶点
4. 当一个顶点的所有邻接顶点都访问完，回溯到上一个顶点

**执行步骤演示**：

对于图：
```
    0 --- 1
    |  \  |
    |   \ |
    2 --- 3
```

**从顶点0开始DFS的详细步骤**：

```
步骤1：访问顶点0
  访问序列：[0]
  已访问：[0]
  当前深度：0

步骤2：访问0的邻接顶点1（选择第一个未访问的邻接顶点）
  访问序列：[0, 1]
  已访问：[0, 1]
  当前深度：1

步骤3：访问1的邻接顶点3
  访问序列：[0, 1, 3]
  已访问：[0, 1, 3]
  当前深度：2

步骤4：访问3的邻接顶点2
  访问序列：[0, 1, 3, 2]
  已访问：[0, 1, 3, 2]
  当前深度：3

步骤5：回溯（2的所有邻接顶点都已访问）
  回到顶点3
  当前深度：2

步骤6：回溯（3的所有邻接顶点都已访问）
  回到顶点1
  当前深度：1

步骤7：回溯（1的所有邻接顶点都已访问）
  回到顶点0
  当前深度：0

步骤8：回溯到初始状态
  访问完成！
  最终序列：[0, 1, 3, 2]
```

**递归调用栈演示**：
```
DFS(0)
  ├─ 访问0
  ├─ DFS(1)
  │   ├─ 访问1
  │   ├─ DFS(3)
  │   │   ├─ 访问3
  │   │   ├─ DFS(2)
  │   │   │   ├─ 访问2
  │   │   │   └─ 返回（2的邻接顶点都已访问）
  │   │   └─ 返回（3的邻接顶点都已访问）
  │   └─ 返回（1的邻接顶点都已访问）
  └─ 返回（0的邻接顶点都已访问）
```

**特点**：
- 使用栈（递归调用栈或显式栈）来实现
- 访问顺序取决于图的存储结构和邻接顶点的访问顺序
- 可能得到不同的访问序列，但都符合DFS的特性

#### 递归实现

```cpp
bool visited[MAX_VERTEX];

// 邻接矩阵实现
void DFS_Matrix(int adjMatrix[][MAX_VERTEX], int v, int n) {
    visited[v] = true;
    cout << v << " ";
    
    for (int i = 0; i < n; i++) {
        if (adjMatrix[v][i] == 1 && !visited[i]) {
            DFS_Matrix(adjMatrix, i, n);
        }
    }
}

// 邻接表实现
void DFS_List(Graph* g, int v) {
    visited[v] = true;
    cout << v << " ";
    
    EdgeNode* p = g->adjList[v];
    while (p != nullptr) {
        if (!visited[p->vertex]) {
            DFS_List(g, p->vertex);
        }
        p = p->next;
    }
}

// 遍历整个图（处理非连通图）
void DFSTraverse(Graph* g) {
    for (int i = 0; i < g->vertexCount; i++) {
        visited[i] = false;
    }
    
    for (int i = 0; i < g->vertexCount; i++) {
        if (!visited[i]) {
            DFS_List(g, i);
        }
    }
}
```

#### 非递归实现（使用栈）

```cpp
void DFS_NonRecursive(Graph* g, int start) {
```

**特点**：
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 适用于：查找路径、检测环、拓扑排序

### 2. 广度优先搜索（BFS - Breadth First Search）

**定义**：类似于树的层序遍历，先访问离起点最近的顶点。BFS采用"层层推进"的策略，先访问所有与起点距离为1的顶点，再访问距离为2的顶点，以此类推。

**算法思想**：
1. 将起始顶点加入队列并标记为已访问
2. 从队列中取出一个顶点访问
3. 将该顶点的所有未访问邻接顶点加入队列并标记
4. 重复步骤2-3直到队列为空

**执行步骤演示**：

对于图：
```
    0 --- 1
    |  \  |
    |   \ |
    2 --- 3
```

**从顶点0开始BFS的详细步骤**：

```
步骤1：访问顶点0，将其邻接顶点加入队列
  访问序列：[0]
  已访问：[0]
  队列：[1, 2, 3]（0的邻接顶点）
  当前层：0

步骤2：从队列取出1访问，将其未访问邻接顶点加入队列
  访问序列：[0, 1]
  已访问：[0, 1]
  队列：[2, 3]（1的邻接顶点3已访问，无需加入）
  当前层：1

步骤3：从队列取出2访问，将其未访问邻接顶点加入队列
  访问序列：[0, 1, 2]
  已访问：[0, 1, 2]
  队列：[3]（2的邻接顶点都已访问）
  当前层：2

步骤4：从队列取出3访问
  访问序列：[0, 1, 2, 3]
  已访问：[0, 1, 2, 3]
  队列：[]（空）
  当前层：3

步骤5：队列为空，遍历完成
  最终序列：[0, 1, 2, 3]
```

**队列状态变化**：
```
初始：[0]
  访问0后：[1, 2, 3]
  访问1后：[2, 3]
  访问2后：[3]
  访问3后：[]
```

**层次结构**：
```
第0层：0
第1层：1, 2, 3
```

**特点**：
- 使用队列实现
- 保证找到从起点到任意顶点的最短路径（无权图）
- 访问顺序是按距离起点由近到远

**代码实现**：

```cpp

                    p = p->next;
                }
            }
        }
    }

```

**特点**：
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 适用于：最短路径（无权图）、最小生成树

## 最短路径算法

### 1. 单源最短路径

#### Dijkstra算法

**适用条件**：有向图或无向图，边权非负

**算法思想**：贪心策略，每次选择距离起点最近的未访问顶点。Dijkstra算法基于贪心思想：一旦确定某个顶点到起点的最短距离，这个距离就不再改变。

**核心概念**：
- **dist[v]**：从起点到顶点v的当前最短距离
- **visited[v]**：顶点v是否已经确定最短距离
- **松弛操作（Relaxation）**：如果通过顶点u到v的距离比当前dist[v]更短，则更新dist[v]

**算法步骤详解**：

1. **初始化**：
   - 将所有顶点的距离初始化为无穷大（INF）
   - 起点距离设为0
   - 所有顶点标记为未访问

2. **主循环**（重复V-1次）：
   - 在未访问的顶点中，找到距离起点最近的顶点u
   - 将顶点u标记为已访问（确定最短距离）
   - 对u的所有未访问邻接顶点v进行松弛操作：
     - 如果 dist[u] + weight(u,v) < dist[v]，则更新 dist[v] = dist[u] + weight(u,v)

3. **结束**：所有顶点的最短距离已确定

**执行过程演示**：

对于图（从顶点0开始）：
```
        0
       / \
     4/   \2
     /     \
    1 ----- 2
     \     /
     1\   /3
       \ /
        3
```

**详细执行步骤**：

```
初始状态：
顶点  0   1   2   3
dist  0  INF INF INF
visit ×   ×   ×   ×

迭代1：选择顶点0（距离最近）
  顶点  0   1   2   3
  dist  0   4   2  INF
  visit ✓   ×   ×   ×
  更新：通过0到1的距离4 < INF，更新dist[1]=4
       通过0到2的距离2 < INF，更新dist[2]=2

迭代2：选择顶点2（距离最近，dist=2）
  顶点  0   1   2   3
  dist  0   4   2   5
  visit ✓   ×   ✓   ×
  更新：通过2到3的距离3，2+3=5 < INF，更新dist[3]=5
       通过2到1的距离1，2+1=3 < 4，更新dist[1]=3

迭代3：选择顶点1（距离最近，dist=3）
  顶点  0   1   2   3
  dist  0   3   2   4
  visit ✓   ✓   ✓   ×
  更新：通过1到3的距离1，3+1=4 < 5，更新dist[3]=4

迭代4：选择顶点3（最后一个未访问顶点）
  顶点  0   1   2   3
  dist  0   3   2   4
  visit ✓   ✓   ✓   ✓
  
最终结果：
从0到0的最短距离：0
从0到1的最短距离：3（路径：0→2→1）
从0到2的最短距离：2（路径：0→2）
从0到3的最短距离：4（路径：0→2→1→3）
```

**为什么Dijkstra算法是正确的？**

关键点：由于所有边权非负，一旦某个顶点u被标记为已访问（确定最短距离），就不可能有更短的路径到达u。

**证明思路**：
- 假设顶点u被标记为已访问时，存在一条更短路径P到达u
- 路径P必须经过某个未访问顶点v
- 但dist[v] ≥ dist[u]（因为u是当前距离最近的未访问顶点）
- 加上边权非负，路径P的长度 ≥ dist[u]
- 矛盾！因此u的最短距离已确定

**代码实现**：

```cpp
#define INF 999999

void Dijkstra(int graph[][MAX_VERTEX], int n, int start) {
    int dist[MAX_VERTEX];      // 最短距离
    bool visited[MAX_VERTEX];   // 访问标记
    int prev[MAX_VERTEX];       // 前驱节点（用于路径重建）
    
    // 初始化
    for (int i = 0; i < n; i++) {
        dist[i] = INF;
        visited[i] = false;
        prev[i] = -1;
    }
    dist[start] = 0;
    
    // 主循环
    for (int count = 0; count < n - 1; count++) {
        // 找到未访问的距离最小的顶点
        int u = -1;
        int minDist = INF;
        for (int v = 0; v < n; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                u = v;
            }
        }
        
        if (u == -1) break;
        visited[u] = true;
        
        // 更新邻接顶点的距离
        for (int v = 0; v < n; v++) {
            if (!visited[v] && graph[u][v] != INF && 
                dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
                prev[v] = u;
            }
        }
    }
    
    // 打印结果
    cout << "从顶点 " << start << " 到各顶点的最短距离：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}

// 使用优先队列优化的Dijkstra算法
#include <queue>
#include <vector>

struct Node {
    int vertex;
    int distance;
    bool operator<(const Node& other) const {
        return distance > other.distance;  // 最小堆
    }
};

void Dijkstra_Optimized(vector<vector<pair<int, int>>>& adjList, int start) {
    int n = adjList.size();
    vector<int> dist(n, INF);
    vector<bool> visited(n, false);
    priority_queue<Node> pq;
    
    dist[start] = 0;
    pq.push({start, 0});
    
    while (!pq.empty()) {
        Node current = pq.top();
        pq.pop();
        int u = current.vertex;
        
        if (visited[u]) continue;
        visited[u] = true;
        
        for (auto& edge : adjList[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({v, dist[v]});
            }
        }
    }
    
    // 打印结果
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}
```

**时间复杂度**：
- 基本实现：O(V²)
- 优先队列优化：O((V + E)log V)
- 斐波那契堆优化：O(E + V log V)

#### Bellman-Ford算法

**适用条件**：有向图，允许负权边，能检测负权环

**算法思想**：动态规划思想，通过对所有边进行V-1次松弛操作，逐步更新最短距离。Bellman-Ford算法不需要贪心策略，可以处理负权边。

**核心概念**：
- **松弛操作**：对于边(u, v)，如果 dist[u] + weight(u,v) < dist[v]，则更新 dist[v]
- **V-1次迭代**：在无负权环的情况下，最多V-1次松弛即可找到所有最短路径
- **负权环检测**：如果第V次迭代还能松弛，说明存在负权环

**算法步骤详解**：

1. **初始化**：
   - 将所有顶点的距离初始化为无穷大（INF）
   - 起点距离设为0

2. **松弛阶段**（重复V-1次）：
   - 对图中的每条边(u, v)进行松弛：
     - 如果 dist[u] + weight(u,v) < dist[v]，则更新 dist[v] = dist[u] + weight(u,v)

3. **负权环检测**：
   - 再进行一次完整的松弛操作
   - 如果还能更新任何距离，说明存在负权环

**为什么需要V-1次松弛？**

**理论依据**：在无负权环的情况下，从起点到任意顶点的最短路径最多包含V-1条边（否则会形成环）。

**证明思路**：
- 第1次松弛：可以找到经过最多1条边的最短路径
- 第2次松弛：可以找到经过最多2条边的最短路径
- ...
- 第V-1次松弛：可以找到经过最多V-1条边的最短路径

**执行过程演示**：

对于图（从顶点0开始，注意边0→2的权重为-1）：
```
    0 --4--> 1
    |        |
   -1|       2
    |        |
    v        v
    2 <--3-- 3
```

**详细执行步骤**：

```
初始状态：
顶点  0   1   2   3
dist  0  INF INF INF

第1次松弛（检查所有边）：
  边0→1：0+4=4 < INF，更新dist[1]=4
  边0→2：0+(-1)=-1 < INF，更新dist[2]=-1
  边1→3：4+2=6 < INF，更新dist[3]=6
  边3→2：6+3=9，不更新（9 > -1）
  
  顶点  0   1   2   3
  dist  0   4  -1   6

第2次松弛：
  边0→1：0+4=4，不更新（4 = 4）
  边0→2：0+(-1)=-1，不更新（-1 = -1）
  边1→3：4+2=6，不更新（6 = 6）
  边3→2：6+3=9，不更新（9 > -1）
  
  顶点  0   1   2   3
  dist  0   4  -1   6

第3次松弛（V-1=3）：
  所有距离不再变化
  
最终结果：
从0到0的最短距离：0
从0到1的最短距离：4
从0到2的最短距离：-1
从0到3的最短距离：6
```

**负权环检测示例**：

对于包含负权环的图：
```
    0 --1--> 1
    ^         |
    |         | -3
    |         v
    |--(-2)-- 2
```

**检测过程**：

```
初始：dist[0]=0, dist[1]=INF, dist[2]=INF

经过V-1=2次松弛后：
dist[0]=0, dist[1]=1, dist[2]=-2

第V次（第3次）松弛：
边2→0：dist[2]+weight(2,0)=-2+(-2)=-4 < dist[0]=0
还能更新！说明存在负权环
```

**与Dijkstra算法的对比**：

| 特性 | Dijkstra | Bellman-Ford |
|------|----------|--------------|
| 边权限制 | 非负 | 允许负权 |
| 时间复杂度 | O(V²)或O((V+E)log V) | O(V×E) |
| 负权环检测 | 不支持 | 支持 |
| 贪心策略 | 是 | 否 |
| 适用场景 | 非负权图 | 允许负权的图 |

**代码实现**：

```cpp
void BellmanFord(int graph[][MAX_VERTEX], int n, int start) {
    int dist[MAX_VERTEX];
    
    // 初始化
    for (int i = 0; i < n; i++) {
        dist[i] = INF;
    }
    dist[start] = 0;
    
    // 松弛操作：重复V-1次
    for (int i = 0; i < n - 1; i++) {
        for (int u = 0; u < n; u++) {
            for (int v = 0; v < n; v++) {
                if (graph[u][v] != INF && 
                    dist[u] != INF && 
                    dist[u] + graph[u][v] < dist[v]) {
                    dist[v] = dist[u] + graph[u][v];
                }
            }
        }
    }
    
    // 检测负权环
    for (int u = 0; u < n; u++) {
        for (int v = 0; v < n; v++) {
            if (graph[u][v] != INF && 
                dist[u] != INF && 
                dist[u] + graph[u][v] < dist[v]) {
                cout << "图中存在负权环！" << endl;
                return;
            }
        }
    }
    
    // 打印结果
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}
```

**时间复杂度**：O(V × E)

### 2. 全源最短路径

#### Floyd-Warshall算法

**适用条件**：有向图或无向图，允许负权边（但不能有负权环）

**算法思想**：动态规划，逐步考虑每个顶点作为中间节点。Floyd-Warshall算法通过逐步添加中间顶点来更新所有顶点对之间的最短距离。

**核心概念**：
- **dist[i][j]**：从顶点i到顶点j的当前最短距离
- **中间顶点k**：逐步考虑顶点0, 1, 2, ..., n-1作为中间顶点
- **状态转移方程**：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

**算法步骤详解**：

1. **初始化**：
   - dist[i][j] = 图的邻接矩阵（i和j之间的直接边权重）
   - dist[i][i] = 0（自己到自己的距离为0）
   - 如果i和j之间无边，dist[i][j] = INF

2. **动态规划阶段**（三重循环）：
   - 外层循环k：依次考虑顶点0, 1, 2, ..., n-1作为中间顶点
   - 对于每个k，遍历所有顶点对(i, j)
   - 如果 dist[i][k] + dist[k][j] < dist[i][j]，则更新 dist[i][j]

3. **结束**：dist矩阵存储了所有顶点对之间的最短距离

**为什么Floyd-Warshall算法是正确的？**

**动态规划思想**：
- 在考虑中间顶点k时，我们已经计算了使用顶点0到k-1作为中间顶点的最短路径
- 对于路径i→j，要么不经过k（保持原值），要么经过k（i→k→j）
- 取两种情况的最小值

**状态转移方程解释**：
```
dist[k][i][j] = 使用顶点0到k作为中间顶点，从i到j的最短距离

递推关系：
dist[k][i][j] = min(dist[k-1][i][j],          // 不使用k
                    dist[k-1][i][k] + dist[k-1][k][j])  // 使用k

简化实现（空间优化）：
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

1. **全源最短路径**：一次运行得到所有顶点对之间的最短距离
2. **实现简单**：核心代码只需3行嵌套循环
3. **空间优化**：可以在原矩阵上更新，空间复杂度O(V²)
4. **路径重建**：需要额外的path数组记录路径

**与Dijkstra和Bellman-Ford的对比**：

| 特性 | Dijkstra | Bellman-Ford | Floyd-Warshall |
|------|----------|--------------|----------------|
| 解决问题 | 单源最短路径 | 单源最短路径 | 全源最短路径 |
| 时间复杂度 | O(V²)或O((V+E)log V) | O(V×E) | O(V³) |
| 空间复杂度 | O(V) | O(V) | O(V²) |
| 边权限制 | 非负 | 允许负权 | 允许负权（无负权环） |
| 适用场景 | 单源问题，非负权 | 单源问题，允许负权 | 全源问题 |

**代码实现**：

```cpp
void FloydWarshall(int graph[][MAX_VERTEX], int n) {
    int dist[MAX_VERTEX][MAX_VERTEX];
    int path[MAX_VERTEX][MAX_VERTEX];  // 路径记录
    
    // 初始化
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            dist[i][j] = graph[i][j];
            if (i == j) {
                dist[i][j] = 0;
            }
            if (graph[i][j] != INF) {
                path[i][j] = i;
            } else {
                path[i][j] = -1;
            }
        }
    }
    
    // 动态规划：考虑每个顶点作为中间节点
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] != INF && dist[k][j] != INF &&
                    dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                    path[i][j] = path[k][j];
                }
            }
        }
    }
    
    // 打印最短距离矩阵
    cout << "最短距离矩阵：" << endl;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (dist[i][j] == INF) {
                cout << "INF ";
            } else {
                cout << dist[i][j] << " ";
            }
        }
        cout << endl;
    }
}

// 打印路径
void printPath(int path[][MAX_VERTEX], int u, int v) {
    if (path[u][v] == -1) {
        cout << "不存在路径" << endl;
        return;
    }
    
    if (u == v) {
        cout << u << " ";
    } else {
        printPath(path, u, path[u][v]);
        cout << v << " ";
    }
}
```

**时间复杂度**：O(V³)

**空间复杂度**：O(V²)

## 最小生成树

最小生成树（MST - Minimum Spanning Tree）是在连通无向图中，连接所有顶点且边权值之和最小的树。

### 最小生成树的性质

1. **边数**：最小生成树有且仅有 n-1 条边（n为顶点数）
2. **唯一性**：如果所有边权都不相同，最小生成树唯一；否则可能不唯一
3. **最优子结构**：最小生成树的任意子树也是相应子图的最小生成树

### 最小生成树的应用

- **网络设计**：设计成本最低的网络连接（如通信网络、电网）
- **聚类分析**：用于数据聚类
- **图像分割**：计算机视觉中的应用
- **路由算法**：网络路由中的最小成本路径

### 1. Kruskal算法

**算法思想**：贪心策略，按边权从小到大选择边，如果加入该边不会形成环，则加入最小生成树。

**核心概念**：
- **并查集（Union-Find）**：用于快速判断两个顶点是否在同一个连通分量中
- **环检测**：如果边的两个端点已经在同一个集合中，加入该边会形成环
- **贪心选择**：每次选择权重最小的边

**算法步骤详解**：

1. **初始化**：
   - 将所有边按权重从小到大排序
   - 初始化并查集，每个顶点自成一个集合
   - 初始化MST边集为空

2. **主循环**（遍历排序后的所有边）：
   - 取出当前权重最小的边(u, v)
   - 检查u和v是否在同一个集合中（使用并查集）
   - 如果不在同一集合：
     - 将边(u, v)加入MST
     - 合并u和v所在的集合
     - 累加总权重
   - 如果已在同一集合，跳过（会形成环）

3. **结束条件**：
   - MST中有n-1条边时，算法结束
   - 如果遍历完所有边后仍少于n-1条，说明图不连通

**为什么Kruskal算法是正确的？**

**贪心选择性质**：假设存在最优解，当算法选择权重最小的边时，如果这条边不会形成环，那么它一定在某个最小生成树中。

**证明思路**（反证法）：
1. 假设算法选择的边e不在某个最小生成树T中
2. 将e加入T会形成环，环中必有另一条边e'的权重≥e的权重
3. 移除e'，用e替换，得到新的生成树T'
4. T'的权重≤T的权重，因此T'也是最小生成树
5. 因此，e在某个最小生成树中，贪心选择是正确的

**并查集的作用**：

- **find操作**：快速查找顶点所属的集合（O(α(n))）
- **unite操作**：合并两个集合，标记连通分量
- **环检测**：如果两个顶点在同一集合，说明已连通，加入边会形成环

**示例：并查集状态变化**
```
初始：parent = [0,1,2,3,4]

加入(2,4)：
  parent = [0,1,2,3,2]  （4的父节点是2）

加入(0,2)：
  parent = [0,1,0,3,2]  （2的父节点是0）
  注意：find(4)会通过路径压缩找到0

加入(0,3)：
  parent = [0,1,0,0,2]  （3的父节点是0）

加入(1,3)：
  parent = [0,0,0,0,2]  （1的父节点是0）

检查(0,1)：
  find(0) = 0, find(1) = 0，在同一集合
```

**代码实现**：

```cpp
struct Edge {
    int u, v;
    int weight;
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

class UnionFind {
private:
    int parent[MAX_VERTEX];
    int rank[MAX_VERTEX];
    
public:
    UnionFind(int n) {
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            rank[i] = 0;
        }
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) return false;
        
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        return true;
    }
};

void Kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end());
    UnionFind uf(n);
    vector<Edge> mst;
    int totalWeight = 0;
    
    for (Edge& e : edges) {
        if (uf.unite(e.u, e.v)) {
            mst.push_back(e);
            totalWeight += e.weight;
            
            if (mst.size() == n - 1) {
                break;  // 已找到n-1条边
            }
        }
    }
    
    if (mst.size() != n - 1) {
        cout << "图不连通，无法生成最小生成树" << endl;
        return;
    }
    
    cout << "最小生成树的边：" << endl;
    for (Edge& e : mst) {
        cout << e.u << " - " << e.v << " : " << e.weight << endl;
    }
    cout << "总权重: " << totalWeight << endl;
}
```

**时间复杂度**：O(E log E)（主要来自排序）

**Kruskal算法的特点**：

| 优点 | 缺点 |
|------|------|
| 适合稀疏图 | 需要对所有边排序 |
| 实现相对简单 | 需要并查集支持 |
| 易于理解 | 不适合稠密图 |

### 2. Prim算法

**算法思想**：从任意顶点开始，逐步扩展最小生成树。每次选择连接已选顶点集合和未选顶点集合的权重最小的边，将对应的顶点加入MST。

**核心概念**：
- **key[v]**：顶点v到当前MST的最小边权重
- **inMST[v]**：顶点v是否已在MST中
- **parent[v]**：MST中顶点v的父节点
- **贪心选择**：每次选择key值最小的未访问顶点

**算法步骤详解**：

1. **初始化**：
   - 选择任意起始顶点（通常选0）
   - 将起始顶点的key设为0
   - 其他顶点的key设为无穷大（INF）
   - 所有顶点标记为不在MST中
   - 所有顶点的parent设为-1

2. **主循环**（重复n-1次）：
   - 在未加入MST的顶点中，找到key值最小的顶点u
   - 将u标记为已加入MST
   - 对于u的所有未加入MST的邻接顶点v：
     - 如果边(u,v)的权重 < key[v]，则更新：
       - key[v] = weight(u,v)
       - parent[v] = u

3. **结束**：所有顶点都已加入MST

**执行过程演示**：

**为什么Prim算法是正确的？**

**关键思想**：每次选择的顶点u，其key值就是连接已选集合和未选集合的最小边权重。

**证明思路**：
1. 假设算法在某一步选择的顶点u，其key值对应的边(u, parent[u])不在某个最小生成树T中
2. 由于u是通过最小key值选择的，边(u, parent[u])是连接已选集合和未选集合的最小边
3. 将边(u, parent[u])加入T会形成环，环中必有另一条连接已选和未选集合的边e'
4. 由于key[u]是最小的，e'的权重≥key[u]
5. 移除e'，用(u, parent[u])替换，得到新的生成树T'
6. T'的权重≤T的权重，因此T'也是最小生成树

**key值的更新规则**：

- key[v]表示：从已选顶点集合到顶点v的最小边权重
- 当新顶点u加入MST时：
  - 对于u的邻接顶点v（未在MST中）
  - 比较：当前key[v] vs 边(u,v)的权重
  - 取较小者更新key[v]

**示例：key值变化**
```
初始：key = [0, INF, INF, INF, INF]

顶点0加入后：
  key = [0, 7, 5, 7, INF]
  说明：从0到1、2、3的边权重分别是7、5、7

顶点2加入后：
  key = [0, 7, 5, 7, 6]
  说明：从2到4的边权重6 < INF，更新key[4]=6
        从2到3的边权重15 > 7，不更新key[3]

顶点4加入后：
  key = [0, 7, 5, 7, 6]
  说明：从4到3的边权重11 > 7，不更新key[3]

顶点1加入后：
  key = [0, 7, 5, 7, 6]
  说明：从1到3的边权重9 > 7，不更新key[3]

顶点3加入后：
  key = [0, 7, 5, 7, 6]
  所有顶点已加入
```

**Prim与Dijkstra的相似性**：

两者都是贪心算法，都使用类似的策略：
- **Dijkstra**：维护dist数组，选择距离起点最近的顶点
- **Prim**：维护key数组，选择连接MST的最小边对应的顶点

**区别**：
- **Dijkstra**：计算距离时是累加的（dist[u] + weight）
- **Prim**：key值是独立的边权重（只考虑单条边）

**Kruskal vs Prim对比**：

| 特性 | Kruskal | Prim |
|------|---------|------|
| 思想 | 按边排序，全局选择 | 从顶点开始，局部扩展 |
| 数据结构 | 并查集 | key数组 |
| 适合场景 | 稀疏图 | 稠密图 |
| 时间复杂度 | O(E log E) | O(V²)或O((V+E)log V) |
| 起始点 | 无要求 | 需要指定起始点 |
| 边处理 | 需要排序所有边 | 只需处理邻接边 |

**代码实现**：

```cpp
void Prim(int graph[][MAX_VERTEX], int n) {
    int parent[MAX_VERTEX];      // 最小生成树的父节点
    int key[MAX_VERTEX];         // 最小边权值
    bool inMST[MAX_VERTEX];      // 是否在MST中
    
    // 初始化
    for (int i = 0; i < n; i++) {
        key[i] = INF;
        inMST[i] = false;
        parent[i] = -1;
    }
    
    key[0] = 0;  // 从顶点0开始
    
    // 主循环
    for (int count = 0; count < n - 1; count++) {
        // 找到不在MST中的最小key值顶点
        int u = -1;
        int minKey = INF;
        for (int v = 0; v < n; v++) {
            if (!inMST[v] && key[v] < minKey) {
                minKey = key[v];
                u = v;
            }
        }
        
        inMST[u] = true;
        
        // 更新邻接顶点的key值
        for (int v = 0; v < n; v++) {
            if (graph[u][v] != INF && !inMST[v] && 
                graph[u][v] < key[v]) {
                key[v] = graph[u][v];
                parent[v] = u;
            }
        }
    }
    
    // 打印结果
    cout << "最小生成树的边：" << endl;
    int totalWeight = 0;
    for (int i = 1; i < n; i++) {
        cout << parent[i] << " - " << i << " : " << key[i] << endl;
        totalWeight += key[i];
    }
    cout << "总权重: " << totalWeight << endl;
}

// 使用优先队列优化的Prim算法
void Prim_Optimized(vector<vector<pair<int, int>>>& adjList, int n) {
    vector<int> parent(n, -1);
    vector<int> key(n, INF);
    vector<bool> inMST(n, false);
    priority_queue<Node> pq;
    
    key[0] = 0;
    pq.push({0, 0});
    
    while (!pq.empty()) {
        Node current = pq.top();
        pq.pop();
        int u = current.vertex;
        
        if (inMST[u]) continue;
        inMST[u] = true;
        
        for (auto& edge : adjList[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            if (!inMST[v] && weight < key[v]) {
                key[v] = weight;
                parent[v] = u;
                pq.push({v, key[v]});
            }
        }
    }
    
    // 打印结果
    int totalWeight = 0;
    for (int i = 1; i < n; i++) {
        cout << parent[i] << " - " << i << " : " << key[i] << endl;
        totalWeight += key[i];
    }
    cout << "总权重: " << totalWeight << endl;
}
```

**时间复杂度**：
- 基本实现：O(V²)
- 优先队列优化：O((V + E)log V)

**Prim算法的特点**：

| 优点 | 缺点 |
|------|------|
| 适合稠密图 | 基本实现需要O(V²)时间找最小值 |
| 与Dijkstra相似，易于理解 | 起始顶点不同可能得到不同MST |
| 不需要排序所有边 | 需要维护key数组 |
| 适合邻接矩阵存储 | 稀疏图效率较低 |

**优化版本说明**：

使用优先队列（最小堆）优化的Prim算法：
- 用优先队列存储(key值, 顶点)对
- 每次从队列中取出key最小的顶点
- 时间复杂度从O(V²)降低到O((V+E)log V)
- 适合稀疏图

**两种算法选择建议**：

1. **选择Kruskal**：
   - 稀疏图（边数远少于V²）
   - 图的边已经给定或易于获取
   - 不需要指定起始点
   - 实现相对简单（只需排序和并查集）

2. **选择Prim**：
   - 稠密图（边数接近V²）
   - 图以邻接矩阵形式存储
   - 需要从特定顶点开始构建
   - 可以边处理边构建（在线算法）

## 拓扑排序

拓扑排序（Topological Sort）是对有向无环图（DAG）的顶点进行线性排序，使得对于每条边(u, v)，u在排序中都出现在v之前。

### 拓扑排序的性质

1. **唯一性**：拓扑排序可能不唯一，一个DAG可能有多个拓扑排序
2. **必要条件**：图必须是有向无环图（DAG）
3. **应用价值**：解决依赖关系和任务调度问题

### 应用场景

- **任务调度**：安排有依赖关系的任务执行顺序
- **课程依赖关系**：确定课程的学习顺序
- **编译顺序**：确定源文件的编译顺序
- **项目依赖管理**：管理软件模块的依赖关系
- **事件排序**：确定事件的先后顺序

---

### 算法实现

#### 1. Kahn算法（基于入度）

**算法思想**：不断移除入度为0的顶点（没有前驱的顶点），直到所有顶点都被处理。移除顶点后，更新其邻接顶点的入度。

**核心概念**：
- **入度（In-degree）**：指向该顶点的边的数量
- **队列**：存储当前入度为0的顶点
- **贪心策略**：每次处理入度为0的顶点（可以任意顺序）

**算法步骤详解**：

1. **初始化**：
   - 计算每个顶点的入度
   - 将所有入度为0的顶点加入队列

2. **主循环**：
   - 从队列中取出一个顶点u
   - 将u加入结果序列
   - 遍历u的所有邻接顶点v：
     - 将v的入度减1
     - 如果v的入度变为0，将v加入队列

3. **结束判断**：
   - 如果结果序列的长度等于顶点数，拓扑排序成功
   - 否则，说明图中存在环

**为什么Kahn算法是正确的？**

**关键观察**：如果图是DAG，则至少存在一个入度为0的顶点（否则所有顶点都有前驱，可以沿边回溯形成环）。

**证明思路**：
1. 假设存在环，则环中的顶点永远无法入度变为0（每个顶点都有环内的前驱）
2. 因此，如果算法成功处理所有顶点，说明图无环
3. 每次选择的顶点都是"已准备好的"（没有未处理的前驱），满足拓扑排序的要求

```cpp
vector<int> topologicalSort_Kahn(vector<vector<int>>& adjList, int n) {
    vector<int> inDegree(n, 0);
    vector<int> result;
    queue<int> q;
    
    // 计算每个顶点的入度
    for (int u = 0; u < n; u++) {
        for (int v : adjList[u]) {
            inDegree[v]++;
        }
    }
    
    // 将所有入度为0的顶点加入队列
    for (int i = 0; i < n; i++) {
        if (inDegree[i] == 0) {
            q.push(i);
        }
    }
    
    // 主循环
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        result.push_back(u);
        
        // 移除该顶点的所有出边
        for (int v : adjList[u]) {
            inDegree[v]--;
            if (inDegree[v] == 0) {
                q.push(v);
            }
        }
    }
    
    // 检测是否存在环
    if (result.size() != n) {
        cout << "图中存在环，无法进行拓扑排序" << endl;
        return vector<int>();
    }
    
    return result;
}
```

#### 2. DFS算法

**算法思想**：利用DFS的递归特性，当递归返回到一个顶点时，该顶点的所有后继都已处理完毕。使用栈记录递归返回的顺序，得到拓扑排序。

**核心概念**：
- **递归栈**：DFS的自然递归特性
- **结果栈**：记录DFS完成顺序（后进先出）
- **访问标记**：visited数组标记已访问顶点
- **递归栈标记**：recStack数组检测环

**算法步骤详解**：

1. **初始化**：
   - 所有顶点标记为未访问
   - 创建结果栈

2. **DFS遍历**：
   - 对每个未访问的顶点进行DFS
   - DFS过程中：
     - 标记顶点为已访问
     - 递归访问所有未访问的邻接顶点
     - 当顶点的所有后继都处理完毕后，将顶点压入栈

3. **结果提取**：
   - 从栈中依次弹出顶点，得到拓扑排序

**为什么DFS算法是正确的？**

**关键思想**：当DFS从一个顶点返回时，该顶点的所有后继都已处理完毕。因此，先返回的顶点应该在拓扑排序中排在后面。

**证明思路**：
1. 假设存在边(u, v)，则DFS必须先访问u才能访问v
2. DFS返回时，v一定在u之前返回（因为v是u的后继）
3. 由于使用栈（后进先出），v会被先弹出，u后被弹出
4. 因此拓扑排序中u在v之前，满足要求

```

  ├─ DFS(1): 开始访问C2
  │    └─ DFS(3): 开始访问C4

  │         └─ 返回C5，压入栈
  │    └─ 返回C4，压入栈
  └─ DFS(2): 开始访问C3
       └─ DFS(3): C4已访问，跳过
       └─ 返回C3，压入栈
  └─ 返回C2，压入栈
  └─ 返回C1，压入栈

栈的状态变化（栈底在上）：
空栈
[4]       ← DFS(4)返回
[4, 3]    ← DFS(3)返回
[4, 3, 2] ← DFS(2)返回
[4, 3, 2, 1] ← DFS(1)返回
[4, 3, 2, 1, 0] ← DFS(0)返回

弹出顺序（从栈顶到栈底）：
0 → 1 → 2 → 3 → 4
对应：C1 → C2 → C3 → C4 → C5
```

**详细递归调用追踪**：

```
步骤1：DFS(0)开始
  visited[0] = true
  recStack[0] = true
  遍历邻接顶点：[1, 2]

步骤2：DFS(1)开始（从0递归）
  visited[1] = true
  recStack[1] = true
  遍历邻接顶点：[3]

步骤3：DFS(3)开始（从1递归）
  visited[3] = true
  recStack[3] = true
  遍历邻接顶点：[4]

步骤4：DFS(4)开始（从3递归）
  visited[4] = true
  recStack[4] = true
  遍历邻接顶点：[]（空）
  recStack[4] = false
  stack.push(4)  ← 栈：[4]
  返回

步骤5：回到DFS(3)
  recStack[3] = false
  stack.push(3)  ← 栈：[4, 3]
  返回

步骤6：回到DFS(1)
  recStack[1] = false
  stack.push(1)  ← 栈：[4, 3, 1]
  返回

步骤7：回到DFS(0)，继续遍历顶点2
  DFS(2)开始
    visited[2] = true
    recStack[2] = true
    遍历邻接顶点：[3]
    DFS(3)：已访问，跳过
    recStack[2] = false
    stack.push(2)  ← 栈：[4, 3, 1, 2]
    返回

步骤8：回到DFS(0)
  recStack[0] = false
  stack.push(0)  ← 栈：[4, 3, 1, 2, 0]
  返回

最终栈内容：[4, 3, 1, 2, 0]（栈底到栈顶）
弹出顺序：0, 1, 2, 3, 4
拓扑排序：[0, 1, 2, 3, 4]
```

**环检测机制**：

DFS算法通过recStack（递归栈标记）检测环：

```
对于包含环的图：
A → B
B → C
C → A

DFS过程：
DFS(A):
  visited[A] = true
  recStack[A] = true
  DFS(B):
    visited[B] = true
    recStack[B] = true
    DFS(C):
      visited[C] = true
      recStack[C] = true
      DFS(A): 已访问
        检查recStack[A] = true ← 在递归栈中！
        检测到环！返回
```

**Kahn vs DFS对比**：

| 特性 | Kahn算法 | DFS算法 |
|------|----------|---------|
| 思想 | 基于入度，迭代处理 | 基于递归，回溯处理 |
| 实现 | 队列+BFS思想 | 递归+栈 |
| 环检测 | 结果长度检查 | recStack检查 |
| 结果顺序 | 队列顺序 | DFS完成顺序 |
| 适用场景 | 明确需要队列顺序 | 递归实现更自然 |

**代码实现**：

```cpp
void DFS_Topological(int u, vector<vector<int>>& adjList, 
                     vector<bool>& visited, 
                     vector<bool>& recStack,
                     stack<int>& result) {
    visited[u] = true;
    recStack[u] = true;
    
    for (int v : adjList[u]) {
        if (!visited[v]) {
            DFS_Topological(v, adjList, visited, recStack, result);
        } else if (recStack[v]) {
            // 检测到环
            return;
        }
    }
    
    recStack[u] = false;
    result.push(u);
}

vector<int> topologicalSort_DFS(vector<vector<int>>& adjList, int n) {
    vector<bool> visited(n, false);
    vector<bool> recStack(n, false);
    stack<int> s;
    
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            DFS_Topological(i, adjList, visited, recStack, s);
        }
    }
    
    vector<int> result;
    while (!s.empty()) {
        result.push_back(s.top());
        s.pop();
    }
    
    return result;
}
```

**时间复杂度**：O(V + E)

## 关键路径

关键路径（Critical Path）是在AOE（Activity On Edge）网络中，从源点到汇点的最长路径，决定了整个工程的最短完成时间。

### AOE网络

**定义**：用边表示活动（Activity），用顶点表示事件（Event）的有向无环图。

**重要概念**：
- **源点（Source）**：入度为0的顶点（工程开始事件）
- **汇点（Sink）**：出度为0的顶点（工程结束事件）
- **边权**：活动持续时间
- **事件**：某个活动的开始或结束时刻
- **活动**：需要时间完成的任务

**AOE vs AON（Activity On Node）**：
- **AOE**：边表示活动，顶点表示事件
- **AON**：顶点表示活动，边表示依赖关系

### 关键路径中的关键概念

**1. 事件的最早发生时间（ve - earliest time）**
- ve[i]：事件i能够发生的最早时间
- 计算：从源点开始，沿拓扑顺序计算
- 公式：ve[v] = max{ve[u] + duration(u→v)}，u是v的所有前驱

**2. 事件的最晚发生时间（vl - latest time）**
- vl[i]：事件i在不推迟整个工程完成时间的前提下，最晚必须发生的时间
- 计算：从汇点开始，逆拓扑顺序计算
- 公式：vl[u] = min{vl[v] - duration(u→v)}，v是u的所有后继

**3. 活动的最早开始时间（e - earliest start）**
- e[i]：活动i能够开始的最早时间
- e[i] = ve[u]，其中u是活动i的起点

**4. 活动的最晚开始时间（l - latest start）**
- l[i]：活动i在不推迟整个工程完成时间的前提下，最晚必须开始的时间
- l[i] = vl[v] - duration，其中v是活动i的终点

**5. 活动的时间余量（slack）**
- slack = l[i] - e[i]
- 关键活动：slack = 0的活动（没有时间余量）

### 关键路径算法步骤

**算法流程**：
1. 计算事件的最早发生时间（ve）
2. 计算事件的最晚发生时间（vl）
3. 计算活动的最早和最晚开始时间
4. 找出关键活动（e = l）
5. 关键活动组成的路径就是关键路径

关键路径由关键活动组成：
```
路径1：0 --a1(6)--> 1 --a4(1)--> 4 --a7(9)--> 5 --a9(2)--> 7
      总时间：6 + 1 + 9 + 2 = 18

路径2：0 --a3(5)--> 3 --a6(2)--> 4 --a7(9)--> 5 --a9(2)--> 7
      总时间：5 + 2 + 9 + 2 = 18

      总时间：6 + 1 + 7 + 4 = 18

路径4：0 --a3(5)--> 3 --a6(2)--> 4 --a8(7)--> 6 --a10(4)--> 7
      总时间：5 + 2 + 7 + 4 = 18

关键路径长度：18（工程最短完成时间）
```

**关键路径的性质**：

1. **唯一性**：关键路径可能不唯一（如上面的4条路径）
2. **决定工期**：关键路径的长度决定整个工程的最短完成时间
3. **关键活动**：关键活动延迟会导致整个工程延期
4. **非关键活动**：非关键活动有一定的时间余量

**时间余量的应用**：

- **a2**（0→2，持续时间4）：
  - 最早开始：0
  - 最晚开始：2
  - 时间余量：2
  - 说明：可以延迟2个单位时间开始，不影响工期

- **a5**（2→4，持续时间1）：
  - 最早开始：4（当ve[2]=4时）
  - 最晚开始：6（当vl[4]=7，最晚完成时间）
  - 时间余量：2
  - 说明：活动可以延迟到时间6开始

### 关键路径算法

**代码实现**：

```cpp
struct Activity {
    int u, v;      // 活动的起点和终点
    int duration;  // 活动持续时间
};

// 计算事件的最早发生时间（ve）
vector<int> computeVE(vector<Activity>& activities, int n, int source) {
    vector<int> ve(n, 0);
    vector<vector<int>> adjList(n);
    vector<int> inDegree(n, 0);
    
    // 构建邻接表和计算入度
    for (Activity& act : activities) {
        adjList[act.u].push_back(act.v);
        inDegree[act.v]++;
    }
    
    queue<int> q;
    q.push(source);
    
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        
        for (int v : adjList[u]) {
            // 更新ve[v]为所有前驱事件的最早完成时间
            for (Activity& act : activities) {
                if (act.u == u && act.v == v) {
                    ve[v] = max(ve[v], ve[u] + act.duration);
                    break;
                }
            }
            
            inDegree[v]--;
            if (inDegree[v] == 0) {
                q.push(v);
            }
        }
    }
    
    return ve;
}

// 计算事件的最晚发生时间（vl）
vector<int> computeVL(vector<Activity>& activities, int n, int sink, int ve_sink) {
    vector<int> vl(n, ve_sink);
    vector<vector<int>> reverseAdjList(n);
    vector<int> outDegree(n, 0);
    
    // 构建反向邻接表
    for (Activity& act : activities) {
        reverseAdjList[act.v].push_back(act.u);
        outDegree[act.u]++;
    }
    
    queue<int> q;
    q.push(sink);
    
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        
        for (int u : reverseAdjList[v]) {
            for (Activity& act : activities) {
                if (act.u == u && act.v == v) {
                    vl[u] = min(vl[u], vl[v] - act.duration);
                    break;
                }
            }
            
            outDegree[u]--;
            if (outDegree[u] == 0) {
                q.push(u);
            }
        }
    }
    
    return vl;
}

// 计算关键路径
void findCriticalPath(vector<Activity>& activities, int n, int source, int sink) {
    vector<int> ve = computeVE(activities, n, source);
    vector<int> vl = computeVL(activities, n, sink, ve[sink]);
    
    cout << "关键活动：" << endl;
    for (Activity& act : activities) {
        int e = ve[act.u];              // 活动最早开始时间
        int l = vl[act.v] - act.duration; // 活动最晚开始时间
        
        if (e == l) {
            cout << act.u << " -> " << act.v << " (持续时间: " 
                 << act.duration << ")" << endl;
        }
    }
    
    cout << "关键路径长度（最短完成时间）: " << ve[sink] << endl;
}
```

**关键路径算法的复杂度分析**：

- **时间复杂度**：O(V + E)
  - 计算ve：拓扑排序O(V + E) + 遍历边O(E) = O(V + E)
  - 计算vl：逆拓扑排序O(V + E) + 遍历边O(E) = O(V + E)
  - 总复杂度：O(V + E)

- **空间复杂度**：O(V + E)
  - ve数组：O(V)
  - vl数组：O(V)
  - 邻接表：O(V + E)

**关键路径的应用场景**：

1. **项目管理**：确定项目的关键任务和最短工期
2. **工程调度**：优化工程进度，识别瓶颈活动
3. **资源分配**：重点投入资源到关键活动
4. **风险管理**：识别可能导致工期延期的关键活动

**算法的优化建议**：

1. **并行计算**：多个前驱的事件可以并行计算
2. **增量更新**：如果某个活动时间改变，只需要更新相关路径
3. **可视化**：使用甘特图等工具可视化关键路径

```cpp
class Graph {

        adjList.resize(n, nullptr);
    }
    
    ~Graph() {
        for (int i = 0; i < vertexCount; i++) {
            EdgeNode* p = adjList[i];
            while (p != nullptr) {
                EdgeNode* temp = p;
                p = p->next;
                delete temp;
            }
        }
    }
    
    // 添加边
    void addEdge(int u, int v, int weight = 1) {
        EdgeNode* edge = new EdgeNode(v, weight);
        edge->next = adjList[u];
        adjList[u] = edge;
        
        if (!isDirected) {
            EdgeNode* reverseEdge = new EdgeNode(u, weight);
            reverseEdge->next = adjList[v];
            adjList[v] = reverseEdge;
        }
    }
    
    // 打印图
    void printGraph() {
        for (int i = 0; i < vertexCount; i++) {
            cout << "顶点 " << i << ": ";
            EdgeNode* p = adjList[i];
            while (p != nullptr) {
                if (isWeighted) {
                    cout << "(" << p->vertex << "," << p->weight << ") ";
                } else {
                    cout << p->vertex << " ";
                }
                p = p->next;
            }
            cout << endl;
        }
    }
    
    // DFS遍历
    void DFS(int start) {
        vector<bool> visited(vertexCount, false);
        DFSHelper(start, visited);
    }
    
    void DFSHelper(int v, vector<bool>& visited) {
        visited[v] = true;
        cout << v << " ";
        
        EdgeNode* p = adjList[v];
        while (p != nullptr) {
            if (!visited[p->vertex]) {
                DFSHelper(p->vertex, visited);
            }
            p = p->next;
        }
    }
    
    // BFS遍历
    void BFS(int start) {
        vector<bool> visited(vertexCount, false);
        queue<int> q;
        
        visited[start] = true;
        q.push(start);
        
        while (!q.empty()) {
            int v = q.front();
            q.pop();
            cout << v << " ";
            
            EdgeNode* p = adjList[v];
            while (p != nullptr) {
                if (!visited[p->vertex]) {
                    visited[p->vertex] = true;
                    q.push(p->vertex);
                }
                p = p->next;
            }
        }
    }
    
    // Dijkstra算法
    void Dijkstra(int start) {
        vector<int> dist(vertexCount, INT_MAX);
        vector<bool> visited(vertexCount, false);
        vector<int> parent(vertexCount, -1);
        
        dist[start] = 0;
        
        for (int count = 0; count < vertexCount - 1; count++) {
            int u = -1;
            int minDist = INT_MAX;
            
            for (int v = 0; v < vertexCount; v++) {
                if (!visited[v] && dist[v] < minDist) {
                    minDist = dist[v];
                    u = v;
                }
            }
            
            if (u == -1) break;
            visited[u] = true;
            
            EdgeNode* p = adjList[u];
            while (p != nullptr) {
                int v = p->vertex;
                int weight = p->weight;
                
                if (!visited[v] && dist[u] != INT_MAX && 
                    dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    parent[v] = u;
                }
                p = p->next;
            }
        }
        
        // 打印结果
        cout << "从顶点 " << start << " 到各顶点的最短距离：" << endl;
        for (int i = 0; i < vertexCount; i++) {
            if (dist[i] == INT_MAX) {
                cout << "到 " << i << " : 不可达" << endl;
            } else {
                cout << "到 " << i << " : " << dist[i] << endl;
            }
        }
    }
    
    // 计算顶点的度
    int getDegree(int v) {
        int degree = 0;
        EdgeNode* p = adjList[v];
        while (p != nullptr) {
            degree++;
            p = p->next;
        }
        return degree;
    }
    
    // 检查是否存在边
    bool hasEdge(int u, int v) {
        EdgeNode* p = adjList[u];
        while (p != nullptr) {
            if (p->vertex == v) {
                return true;
            }
            p = p->next;
        }
        return false;
    }
};

// 使用示例
int main() {
```

## 常见问题解答（FAQ）

### Q1：什么时候用邻接矩阵，什么时候用邻接表？

**A**：
- **邻接矩阵**：适合稠密图、需要频繁查询边、顶点数不太大（通常<1000）
- **邻接表**：适合稀疏图、需要遍历邻接顶点、动态图、顶点数很大

### Q2：DFS和BFS有什么区别？

**A**：
- **DFS**：深度优先，使用栈，适合路径查找、环检测、回溯问题
- **BFS**：广度优先，使用队列，适合最短路径（无权图）、层序遍历

### Q3：如何判断图是否连通？

**A**：
- 从任意顶点开始DFS或BFS
- 如果能访问到所有顶点，则图连通
- 否则需要多次遍历找到所有连通分量

### Q4：有向图和无向图的主要区别？

**A**：
- **存储**：无向图邻接矩阵对称，有向图不对称
- **度数**：无向图只有度数，有向图有入度和出度
- **连通性**：无向图只需一个连通分量，有向图有强连通分量

### Q5：如何选择最短路径算法？

**A**：
- **Dijkstra**：非负权，单源最短路径
- **Bellman-Ford**：允许负权，单源最短路径，能检测负权环
- **Floyd-Warshall**：全源最短路径
