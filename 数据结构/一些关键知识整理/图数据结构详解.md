## 图的基本概念

### 什么是图？

图（Graph）是一种**非线性数据结构**，由**顶点（Vertex）**和**边（Edge）**组成的有序对集合。图可以表示为：

**G = (V, E)**

其中：
- **V**：顶点的有限集合，V = {v₁, v₂, ..., vₙ}
- **E**：边的有限集合，E = {e₁, e₂, ..., eₘ}

### 图的特点

1. **顶点集合**：图中的基本元素，可以表示任何实体
2. **边集合**：连接顶点的关系，可以表示顶点之间的关系
3. **无向图**：边没有方向，表示双向关系
4. **有向图**：边有方向，表示单向关系
5. **权值图**：边可以有权重，表示距离、成本等

### 图的形象比喻

图可以形象地理解：
- **顶点（节点）**：城市、人物、网页等实体
- **边**：道路、关系、链接等连接
- **权值**：距离、成本、权重等属性

## 图的术语和定义

### 基本术语

| 术语 | 定义 | 示例 |
|------|------|------|
| **顶点（Vertex）** | 图中的基本单位，也称为节点 | 节点A、B、C |
| **边（Edge）** | 连接两个顶点的线 | 边(A, B) |
| **无向边** | 没有方向的边，表示双向关系 | (A, B) = (B, A) |
| **有向边（弧）** | 有方向的边，用有序对表示 | <A, B> ≠ <B, A> |
| **邻接（Adjacent）** | 两个顶点之间有边连接 | A和B邻接 |
| **关联（Incident）** | 顶点与边的关系 | 边(A, B)与顶点A关联 |
| **度（Degree）** | 与顶点关联的边的数量 | 顶点A的度为3 |
| **入度（In-Degree）** | 指向顶点的边的数量（有向图） | 顶点B的入度为2 |
| **出度（Out-Degree）** | 从顶点出发的边的数量（有向图） | 顶点A的出度为1 |

### 图的属性

#### 1. 路径（Path）

**定义**：从顶点v到顶点w的顶点序列，序列中相邻顶点之间有边相连。

```
示例：
图：A -- B -- C -- D
路径：A -> B -> C -> D（长度为3）
```

**路径长度**：路径上边的数量

#### 2. 简单路径

**定义**：路径中所有顶点都不重复的路径。

#### 3. 回路（Cycle）

**定义**：起点和终点相同的路径，也称为环。

#### 4. 连通性

- **连通图**：无向图中任意两个顶点之间都存在路径
- **强连通图**：有向图中任意两个顶点之间都存在双向路径
- **连通分量**：极大连通子图

#### 5. 度数和边数的关系

**无向图**：
- 所有顶点的度数之和 = 2 × 边数
- Σdeg(v) = 2|E|

**有向图**：
- 所有顶点的入度之和 = 所有顶点的出度之和 = 边数
- Σindeg(v) = Σoutdeg(v) = |E|

## 图的分类

### 1. 按边的方向分类

#### 无向图（Undirected Graph）

**定义**：图中的边没有方向，边表示双向关系。

```
示例：
    A --- B
    |     |
    C --- D
```

**特点**：
- 边(A, B) = 边(B, A)
- 顶点A和B互相邻接
- 适用于表示对称关系

#### 有向图（Directed Graph）

**定义**：图中的边有方向，用箭头表示。

```
示例：
    A --> B
    ↓     ↑
    C --> D
```

**特点**：
- 弧<A, B> ≠ 弧<B, A>
- 顶点A指向B，但B不一定指向A
- 适用于表示非对称关系

### 2. 按边的权值分类

#### 无权图（Unweighted Graph）

**定义**：图中的边没有权重，只表示连接关系。

**应用**：社交网络、网页链接关系

#### 有权图（Weighted Graph）

**定义**：图中的边有权重值，表示距离、成本等。

```
示例：
    A --5-- B
    |       |
    3       2
    |       |
    C --4-- D
```

**应用**：地图导航、网络路由、成本计算

### 3. 按边的数量分类

#### 稀疏图（Sparse Graph）

**定义**：边的数量远少于完全图的边数（|E| << |V|²）

**特点**：
- 适合用邻接表存储
- 内存占用小
- 适合实际应用

#### 稠密图（Dense Graph）

**定义**：边的数量接近完全图的边数（|E| ≈ |V|²）

**特点**：
- 适合用邻接矩阵存储
- 查询速度快
- 内存占用大

### 4. 特殊类型的图

#### 完全图（Complete Graph）

**定义**：任意两个顶点之间都有边相连。

- **无向完全图**：边数 = n(n-1)/2
- **有向完全图**：边数 = n(n-1)

#### 二分图（Bipartite Graph）

**定义**：顶点可以分为两个集合，所有边连接不同集合的顶点。

```
示例：
集合1: {A, B, C}
集合2: {D, E, F}
边：(A, D), (B, E), (C, F)
```

#### 树和森林

- **树**：连通且无环的无向图（n个顶点，n-1条边）
- **森林**：多棵互不相交的树的集合

## 图的存储结构

### 1. 邻接矩阵（Adjacency Matrix）

**定义**：使用二维数组存储图的边关系。

#### 无向图的邻接矩阵

```cpp
#define MAX_VERTEX 100
int adjMatrix[MAX_VERTEX][MAX_VERTEX];
int vertexCount;

// 初始化
void initGraph(int n) {
    vertexCount = n;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            adjMatrix[i][j] = 0;  // 0表示无边，1表示有边
        }
    }
}

// 添加边
void addEdge(int u, int v) {
    adjMatrix[u][v] = 1;
    adjMatrix[v][u] = 1;  // 无向图需要对称
}
```

**特点**：
- 矩阵对称（无向图）
- 适合稠密图
- 查询边是否存在：O(1)
- 空间复杂度：O(V²)

#### 有权图的邻接矩阵

```cpp
// 使用INF表示无边，数字表示权重
#define INF 999999
int adjMatrix[MAX_VERTEX][MAX_VERTEX];

void addWeightedEdge(int u, int v, int weight) {
    adjMatrix[u][v] = weight;
    adjMatrix[v][u] = weight;  // 无向图
}

// 有向图只需一条
void addDirectedWeightedEdge(int u, int v, int weight) {
    adjMatrix[u][v] = weight;
}
```

**优点**：
- 查找边的时间复杂度：O(1)
- 实现简单，代码简洁
- 适合稠密图

**缺点**：
- 空间复杂度：O(V²)
- 不适合稀疏图
- 遍历所有邻接顶点需要O(V)时间

### 2. 邻接表（Adjacency List）

**定义**：使用链表数组存储每个顶点的邻接顶点。

```cpp
struct EdgeNode {
    int vertex;
    int weight;  // 有权图使用
    EdgeNode* next;
};

struct Graph {
    EdgeNode* adjList[MAX_VERTEX];
    int vertexCount;
    bool isDirected;
    bool isWeighted;
};

// 初始化图
void initGraph(Graph* g, int n, bool directed, bool weighted) {
    g->vertexCount = n;
    g->isDirected = directed;
    g->isWeighted = weighted;
    for (int i = 0; i < n; i++) {
        g->adjList[i] = nullptr;
    }
}

// 添加边
void addEdge(Graph* g, int u, int v, int weight = 1) {
    EdgeNode* edge = new EdgeNode;
    edge->vertex = v;
    edge->weight = weight;
    edge->next = g->adjList[u];
    g->adjList[u] = edge;
    
    // 无向图需要添加反向边
    if (!g->isDirected) {
        EdgeNode* reverseEdge = new EdgeNode;
        reverseEdge->vertex = u;
        reverseEdge->weight = weight;
        reverseEdge->next = g->adjList[v];
        g->adjList[v] = reverseEdge;
    }
}
```

**优点**：
- 空间复杂度：O(V + E)
- 适合稀疏图
- 遍历邻接顶点高效
- 动态添加边方便

**缺点**：
- 查询边是否存在需要O(度)
- 实现相对复杂
- 需要额外的指针空间

### 3. 边集数组（Edge List）

**定义**：使用数组存储所有边的信息。

```cpp
struct Edge {
    int u, v;      // 边的两个端点
    int weight;    // 边的权重
};

Edge edges[MAX_EDGES];
int edgeCount;

// 添加边
void addEdge(int u, int v, int w) {
    edges[edgeCount].u = u;
    edges[edgeCount].v = v;
    edges[edgeCount].weight = w;
    edgeCount++;
}
```

**特点**：
- 空间复杂度：O(E)
- 适合Kruskal算法等需要遍历所有边的算法
- 查找边效率低：O(E)

### 4. 十字链表（Orthogonal List）

**定义**：有向图的另一种存储方法，同时存储入边和出边。

```cpp
struct ArcNode {
    int tailvex, headvex;  // 弧尾和弧头
    int weight;
    ArcNode* hlink;  // 指向同弧头的下一条弧
    ArcNode* tlink;  // 指向同弧尾的下一条弧
};

struct VertexNode {
    int data;
    ArcNode* firstin;   // 指向以该顶点为弧头的第一条弧
    ArcNode* firstout;  // 指向以该顶点为弧尾的第一条弧
};

struct OrthogonalGraph {
    VertexNode vertices[MAX_VERTEX];
    int vertexCount;
};
```

**优点**：
- 同时记录入边和出边
- 适合有向图
- 便于求顶点的入度和出度

**缺点**：
- 实现复杂
- 空间开销较大

### 5. 邻接多重表（Adjacency Multilist）

**定义**：无向图的一种存储方法，每条边只存储一次。

```cpp
struct EdgeNode {
    int mark;        // 标记边是否被访问
    int ivex, jvex;  // 边的两个顶点
    EdgeNode* ilink; // 指向依附于ivex的下一条边
    EdgeNode* jlink; // 指向依附于jvex的下一条边
    int weight;
};

struct VertexNode {
    int data;
    EdgeNode* firstedge;  // 指向第一条依附于该顶点的边
};
```

**优点**：
- 每条边只存储一次
- 适合无向图
- 节省空间

**缺点**：
- 实现复杂
- 维护困难

### 存储结构比较

| 存储方法 | 空间复杂度 | 查询边 | 遍历邻接顶点 | 适用场景 |
|----------|------------|--------|--------------|----------|
| 邻接矩阵 | O(V²) | O(1) | O(V) | 稠密图、频繁查询 |
| 邻接表 | O(V + E) | O(度) | O(度) | 稀疏图、动态图 |
| 边集数组 | O(E) | O(E) | - | 遍历所有边 |
| 十字链表 | O(V + E) | O(度) | O(度) | 有向图 |
| 邻接多重表 | O(V + E) | O(度) | O(度) | 无向图 |

## 图的遍历

图的遍历是指按照某种规则访问图中的每个顶点，且每个顶点只访问一次。

### 1. 深度优先搜索（DFS - Depth First Search）

**定义**：类似于树的先序遍历，尽可能深地搜索图的分支。

#### 递归实现

```cpp
bool visited[MAX_VERTEX];

// 邻接矩阵实现
void DFS_Matrix(int adjMatrix[][MAX_VERTEX], int v, int n) {
    visited[v] = true;
    cout << v << " ";
    
    for (int i = 0; i < n; i++) {
        if (adjMatrix[v][i] == 1 && !visited[i]) {
            DFS_Matrix(adjMatrix, i, n);
        }
    }
}

// 邻接表实现
void DFS_List(Graph* g, int v) {
    visited[v] = true;
    cout << v << " ";
    
    EdgeNode* p = g->adjList[v];
    while (p != nullptr) {
        if (!visited[p->vertex]) {
            DFS_List(g, p->vertex);
        }
        p = p->next;
    }
}

// 遍历整个图（处理非连通图）
void DFSTraverse(Graph* g) {
    for (int i = 0; i < g->vertexCount; i++) {
        visited[i] = false;
    }
    
    for (int i = 0; i < g->vertexCount; i++) {
        if (!visited[i]) {
            DFS_List(g, i);
        }
    }
}
```

#### 非递归实现（使用栈）

```cpp
void DFS_NonRecursive(Graph* g, int start) {
    stack<int> s;
    bool visited[MAX_VERTEX] = {false};
    
    s.push(start);
    visited[start] = true;
    
    while (!s.empty()) {
        int v = s.top();
        s.pop();
        cout << v << " ";
        
        EdgeNode* p = g->adjList[v];
        while (p != nullptr) {
            if (!visited[p->vertex]) {
                visited[p->vertex] = true;
                s.push(p->vertex);
            }
            p = p->next;
        }
    }
}
```

**特点**：
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 适用于：查找路径、检测环、拓扑排序

### 2. 广度优先搜索（BFS - Breadth First Search）

**定义**：类似于树的层序遍历，先访问离起点最近的顶点。

```cpp
void BFS(Graph* g, int start) {
    queue<int> q;
    bool visited[MAX_VERTEX] = {false};
    
    visited[start] = true;
    q.push(start);
    
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        cout << v << " ";
        
        EdgeNode* p = g->adjList[v];
        while (p != nullptr) {
            if (!visited[p->vertex]) {
                visited[p->vertex] = true;
                q.push(p->vertex);
            }
            p = p->next;
        }
    }
}

// 遍历整个图
void BFSTraverse(Graph* g) {
    bool visited[MAX_VERTEX] = {false};
    
    for (int i = 0; i < g->vertexCount; i++) {
        if (!visited[i]) {
            queue<int> q;
            visited[i] = true;
            q.push(i);
            
            while (!q.empty()) {
                int v = q.front();
                q.pop();
                cout << v << " ";
                
                EdgeNode* p = g->adjList[v];
                while (p != nullptr) {
                    if (!visited[p->vertex]) {
                        visited[p->vertex] = true;
                        q.push(p->vertex);
                    }
                    p = p->next;
                }
            }
        }
    }
}
```

**特点**：
- 时间复杂度：O(V + E)
- 空间复杂度：O(V)
- 适用于：最短路径（无权图）、最小生成树

### 3. DFS和BFS的应用场景

#### DFS适用场景
- 检测图中是否有环
- 拓扑排序
- 强连通分量
- 回溯算法
- 路径查找

#### BFS适用场景
- 无权图的最短路径
- 最小生成树（Prim算法）
- 连通性检测
- 社交网络中的"六度分隔"问题

## 最短路径算法

### 1. 单源最短路径

#### Dijkstra算法

**适用条件**：有向图或无向图，边权非负

**算法思想**：贪心策略，每次选择距离起点最近的未访问顶点。

```cpp
#define INF 999999

void Dijkstra(int graph[][MAX_VERTEX], int n, int start) {
    int dist[MAX_VERTEX];      // 最短距离
    bool visited[MAX_VERTEX];   // 访问标记
    int prev[MAX_VERTEX];       // 前驱节点（用于路径重建）
    
    // 初始化
    for (int i = 0; i < n; i++) {
        dist[i] = INF;
        visited[i] = false;
        prev[i] = -1;
    }
    dist[start] = 0;
    
    // 主循环
    for (int count = 0; count < n - 1; count++) {
        // 找到未访问的距离最小的顶点
        int u = -1;
        int minDist = INF;
        for (int v = 0; v < n; v++) {
            if (!visited[v] && dist[v] < minDist) {
                minDist = dist[v];
                u = v;
            }
        }
        
        if (u == -1) break;
        visited[u] = true;
        
        // 更新邻接顶点的距离
        for (int v = 0; v < n; v++) {
            if (!visited[v] && graph[u][v] != INF && 
                dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
                prev[v] = u;
            }
        }
    }
    
    // 打印结果
    cout << "从顶点 " << start << " 到各顶点的最短距离：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}

// 使用优先队列优化的Dijkstra算法
#include <queue>
#include <vector>

struct Node {
    int vertex;
    int distance;
    bool operator<(const Node& other) const {
        return distance > other.distance;  // 最小堆
    }
};

void Dijkstra_Optimized(vector<vector<pair<int, int>>>& adjList, int start) {
    int n = adjList.size();
    vector<int> dist(n, INF);
    vector<bool> visited(n, false);
    priority_queue<Node> pq;
    
    dist[start] = 0;
    pq.push({start, 0});
    
    while (!pq.empty()) {
        Node current = pq.top();
        pq.pop();
        int u = current.vertex;
        
        if (visited[u]) continue;
        visited[u] = true;
        
        for (auto& edge : adjList[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({v, dist[v]});
            }
        }
    }
    
    // 打印结果
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}
```

**时间复杂度**：
- 基本实现：O(V²)
- 优先队列优化：O((V + E)log V)
- 斐波那契堆优化：O(E + V log V)

#### Bellman-Ford算法

**适用条件**：有向图，允许负权边，能检测负权环

```cpp
void BellmanFord(int graph[][MAX_VERTEX], int n, int start) {
    int dist[MAX_VERTEX];
    
    // 初始化
    for (int i = 0; i < n; i++) {
        dist[i] = INF;
    }
    dist[start] = 0;
    
    // 松弛操作：重复V-1次
    for (int i = 0; i < n - 1; i++) {
        for (int u = 0; u < n; u++) {
            for (int v = 0; v < n; v++) {
                if (graph[u][v] != INF && 
                    dist[u] != INF && 
                    dist[u] + graph[u][v] < dist[v]) {
                    dist[v] = dist[u] + graph[u][v];
                }
            }
        }
    }
    
    // 检测负权环
    for (int u = 0; u < n; u++) {
        for (int v = 0; v < n; v++) {
            if (graph[u][v] != INF && 
                dist[u] != INF && 
                dist[u] + graph[u][v] < dist[v]) {
                cout << "图中存在负权环！" << endl;
                return;
            }
        }
    }
    
    // 打印结果
    for (int i = 0; i < n; i++) {
        cout << "到 " << i << " 的距离: " << dist[i] << endl;
    }
}
```

**时间复杂度**：O(V × E)

### 2. 全源最短路径

#### Floyd-Warshall算法

**适用条件**：有向图或无向图，允许负权边（但不能有负权环）

**算法思想**：动态规划，逐步考虑每个顶点作为中间节点。

```cpp
void FloydWarshall(int graph[][MAX_VERTEX], int n) {
    int dist[MAX_VERTEX][MAX_VERTEX];
    int path[MAX_VERTEX][MAX_VERTEX];  // 路径记录
    
    // 初始化
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            dist[i][j] = graph[i][j];
            if (i == j) {
                dist[i][j] = 0;
            }
            if (graph[i][j] != INF) {
                path[i][j] = i;
            } else {
                path[i][j] = -1;
            }
        }
    }
    
    // 动态规划：考虑每个顶点作为中间节点
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][k] != INF && dist[k][j] != INF &&
                    dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                    path[i][j] = path[k][j];
                }
            }
        }
    }
    
    // 打印最短距离矩阵
    cout << "最短距离矩阵：" << endl;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (dist[i][j] == INF) {
                cout << "INF ";
            } else {
                cout << dist[i][j] << " ";
            }
        }
        cout << endl;
    }
}

// 打印路径
void printPath(int path[][MAX_VERTEX], int u, int v) {
    if (path[u][v] == -1) {
        cout << "不存在路径" << endl;
        return;
    }
    
    if (u == v) {
        cout << u << " ";
    } else {
        printPath(path, u, path[u][v]);
        cout << v << " ";
    }
}
```

## 最小生成树

最小生成树（MST - Minimum Spanning Tree）是在连通无向图中，连接所有顶点且边权值之和最小的树。

### 1. Kruskal算法

**算法思想**：贪心策略，按边权从小到大选择，不形成环。

```cpp
struct Edge {
    int u, v;
    int weight;
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

class UnionFind {
private:
    int parent[MAX_VERTEX];
    int rank[MAX_VERTEX];
    
public:
    UnionFind(int n) {
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            rank[i] = 0;
        }
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) return false;
        
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        return true;
    }
};

void Kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end());
    UnionFind uf(n);
    vector<Edge> mst;
    int totalWeight = 0;
    
    for (Edge& e : edges) {
        if (uf.unite(e.u, e.v)) {
            mst.push_back(e);
            totalWeight += e.weight;
            
            if (mst.size() == n - 1) {
                break;  // 已找到n-1条边
            }
        }
    }
    
    if (mst.size() != n - 1) {
        cout << "图不连通，无法生成最小生成树" << endl;
        return;
    }
    
    cout << "最小生成树的边：" << endl;
    for (Edge& e : mst) {
        cout << e.u << " - " << e.v << " : " << e.weight << endl;
    }
    cout << "总权重: " << totalWeight << endl;
}
```

**时间复杂度**：O(E log E)（主要来自排序）

### 2. Prim算法

**算法思想**：从任意顶点开始，每次选择连接已选顶点集合和未选顶点集合的最小边。

```cpp
void Prim(int graph[][MAX_VERTEX], int n) {
    int parent[MAX_VERTEX];      // 最小生成树的父节点
    int key[MAX_VERTEX];         // 最小边权值
    bool inMST[MAX_VERTEX];      // 是否在MST中
    
    // 初始化
    for (int i = 0; i < n; i++) {
        key[i] = INF;
        inMST[i] = false;
        parent[i] = -1;
    }
    
    key[0] = 0;  // 从顶点0开始
    
    // 主循环
    for (int count = 0; count < n - 1; count++) {
        // 找到不在MST中的最小key值顶点
        int u = -1;
        int minKey = INF;
        for (int v = 0; v < n; v++) {
            if (!inMST[v] && key[v] < minKey) {
                minKey = key[v];
                u = v;
            }
        }
        
        inMST[u] = true;
        
        // 更新邻接顶点的key值
        for (int v = 0; v < n; v++) {
            if (graph[u][v] != INF && !inMST[v] && 
                graph[u][v] < key[v]) {
                key[v] = graph[u][v];
                parent[v] = u;
            }
        }
    }
    
    // 打印结果
    cout << "最小生成树的边：" << endl;
    int totalWeight = 0;
    for (int i = 1; i < n; i++) {
        cout << parent[i] << " - " << i << " : " << key[i] << endl;
        totalWeight += key[i];
    }
    cout << "总权重: " << totalWeight << endl;
}

// 使用优先队列优化的Prim算法
void Prim_Optimized(vector<vector<pair<int, int>>>& adjList, int n) {
    vector<int> parent(n, -1);
    vector<int> key(n, INF);
    vector<bool> inMST(n, false);
    priority_queue<Node> pq;
    
    key[0] = 0;
    pq.push({0, 0});
    
    while (!pq.empty()) {
        Node current = pq.top();
        pq.pop();
        int u = current.vertex;
        
        if (inMST[u]) continue;
        inMST[u] = true;
        
        for (auto& edge : adjList[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            if (!inMST[v] && weight < key[v]) {
                key[v] = weight;
                parent[v] = u;
                pq.push({v, key[v]});
            }
        }
    }
    
    // 打印结果
    int totalWeight = 0;
    for (int i = 1; i < n; i++) {
        cout << parent[i] << " - " << i << " : " << key[i] << endl;
        totalWeight += key[i];
    }
    cout << "总权重: " << totalWeight << endl;
}
```

**时间复杂度**：
- 基本实现：O(V²)
- 优先队列优化：O((V + E)log V)

## 拓扑排序

拓扑排序（Topological Sort）是对有向无环图（DAG）的顶点进行线性排序，使得对于每条边(u, v)，u在排序中都出现在v之前。

### 应用场景

- 任务调度
- 课程依赖关系
- 编译顺序
- 项目依赖管理

### 算法实现

#### 1. Kahn算法（基于入度）

```cpp
vector<int> topologicalSort_Kahn(vector<vector<int>>& adjList, int n) {
    vector<int> inDegree(n, 0);
    vector<int> result;
    queue<int> q;
    
    // 计算每个顶点的入度
    for (int u = 0; u < n; u++) {
        for (int v : adjList[u]) {
            inDegree[v]++;
        }
    }
    
    // 将所有入度为0的顶点加入队列
    for (int i = 0; i < n; i++) {
        if (inDegree[i] == 0) {
            q.push(i);
        }
    }
    
    // 主循环
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        result.push_back(u);
        
        // 移除该顶点的所有出边
        for (int v : adjList[u]) {
            inDegree[v]--;
            if (inDegree[v] == 0) {
                q.push(v);
            }
        }
    }
    
    // 检测是否存在环
    if (result.size() != n) {
        cout << "图中存在环，无法进行拓扑排序" << endl;
        return vector<int>();
    }
    
    return result;
}
```

**时间复杂度**：O(V + E)

#### 2. DFS算法

```cpp
void DFS_Topological(int u, vector<vector<int>>& adjList, 
                     vector<bool>& visited, 
                     vector<bool>& recStack,
                     stack<int>& result) {
    visited[u] = true;
    recStack[u] = true;
    
    for (int v : adjList[u]) {
        if (!visited[v]) {
            DFS_Topological(v, adjList, visited, recStack, result);
        } else if (recStack[v]) {
            // 检测到环
            return;
        }
    }
    
    recStack[u] = false;
    result.push(u);
}

vector<int> topologicalSort_DFS(vector<vector<int>>& adjList, int n) {
    vector<bool> visited(n, false);
    vector<bool> recStack(n, false);
    stack<int> s;
    
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            DFS_Topological(i, adjList, visited, recStack, s);
        }
    }
    
    vector<int> result;
    while (!s.empty()) {
        result.push_back(s.top());
        s.pop();
    }
    
    return result;
}
```

**时间复杂度**：O(V + E)

## 关键路径

关键路径（Critical Path）是在AOE（Activity On Edge）网络中，从源点到汇点的最长路径，决定了整个工程的最短完成时间。

### AOE网络

**定义**：用边表示活动，用顶点表示事件的有向无环图。

**特点**：
- 源点：入度为0的顶点（开始事件）
- 汇点：出度为0的顶点（结束事件）
- 边权：活动持续时间

### 关键路径算法

```cpp
struct Activity {
    int u, v;      // 活动的起点和终点
    int duration;  // 活动持续时间
};

// 计算事件的最早发生时间（ve）
vector<int> computeVE(vector<Activity>& activities, int n, int source) {
    vector<int> ve(n, 0);
    vector<vector<int>> adjList(n);
    vector<int> inDegree(n, 0);
    
    // 构建邻接表和计算入度
    for (Activity& act : activities) {
        adjList[act.u].push_back(act.v);
        inDegree[act.v]++;
    }
    
    queue<int> q;
    q.push(source);
    
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        
        for (int v : adjList[u]) {
            // 更新ve[v]为所有前驱事件的最早完成时间
            for (Activity& act : activities) {
                if (act.u == u && act.v == v) {
                    ve[v] = max(ve[v], ve[u] + act.duration);
                    break;
                }
            }
            
            inDegree[v]--;
            if (inDegree[v] == 0) {
                q.push(v);
            }
        }
    }
    
    return ve;
}

// 计算事件的最晚发生时间（vl）
vector<int> computeVL(vector<Activity>& activities, int n, int sink, int ve_sink) {
    vector<int> vl(n, ve_sink);
    vector<vector<int>> reverseAdjList(n);
    vector<int> outDegree(n, 0);
    
    // 构建反向邻接表
    for (Activity& act : activities) {
        reverseAdjList[act.v].push_back(act.u);
        outDegree[act.u]++;
    }
    
    queue<int> q;
    q.push(sink);
    
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        
        for (int u : reverseAdjList[v]) {
            for (Activity& act : activities) {
                if (act.u == u && act.v == v) {
                    vl[u] = min(vl[u], vl[v] - act.duration);
                    break;
                }
            }
            
            outDegree[u]--;
            if (outDegree[u] == 0) {
                q.push(u);
            }
        }
    }
    
    return vl;
}

// 计算关键路径
void findCriticalPath(vector<Activity>& activities, int n, int source, int sink) {
    vector<int> ve = computeVE(activities, n, source);
    vector<int> vl = computeVL(activities, n, sink, ve[sink]);
    
    cout << "关键活动：" << endl;
    for (Activity& act : activities) {
        int e = ve[act.u];              // 活动最早开始时间
        int l = vl[act.v] - act.duration; // 活动最晚开始时间
        
        if (e == l) {
            cout << act.u << " -> " << act.v << " (持续时间: " 
                 << act.duration << ")" << endl;
        }
    }
    
    cout << "关键路径长度（最短完成时间）: " << ve[sink] << endl;
}
```

## 实现示例

### 完整的图类实现（邻接表）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <stack>
#include <algorithm>
#include <climits>
using namespace std;

class Graph {
private:
    struct EdgeNode {
        int vertex;
        int weight;
        EdgeNode* next;
        
        EdgeNode(int v, int w = 1) : vertex(v), weight(w), next(nullptr) {}
    };
    
    vector<EdgeNode*> adjList;
    int vertexCount;
    bool isDirected;
    bool isWeighted;
    
public:
    Graph(int n, bool directed = false, bool weighted = false) {
        vertexCount = n;
        isDirected = directed;
        isWeighted = weighted;
        adjList.resize(n, nullptr);
    }
    
    ~Graph() {
        for (int i = 0; i < vertexCount; i++) {
            EdgeNode* p = adjList[i];
            while (p != nullptr) {
                EdgeNode* temp = p;
                p = p->next;
                delete temp;
            }
        }
    }
    
    // 添加边
    void addEdge(int u, int v, int weight = 1) {
        EdgeNode* edge = new EdgeNode(v, weight);
        edge->next = adjList[u];
        adjList[u] = edge;
        
        if (!isDirected) {
            EdgeNode* reverseEdge = new EdgeNode(u, weight);
            reverseEdge->next = adjList[v];
            adjList[v] = reverseEdge;
        }
    }
    
    // 打印图
    void printGraph() {
        for (int i = 0; i < vertexCount; i++) {
            cout << "顶点 " << i << ": ";
            EdgeNode* p = adjList[i];
            while (p != nullptr) {
                if (isWeighted) {
                    cout << "(" << p->vertex << "," << p->weight << ") ";
                } else {
                    cout << p->vertex << " ";
                }
                p = p->next;
            }
            cout << endl;
        }
    }
    
    // DFS遍历
    void DFS(int start) {
        vector<bool> visited(vertexCount, false);
        DFSHelper(start, visited);
    }
    
    void DFSHelper(int v, vector<bool>& visited) {
        visited[v] = true;
        cout << v << " ";
        
        EdgeNode* p = adjList[v];
        while (p != nullptr) {
            if (!visited[p->vertex]) {
                DFSHelper(p->vertex, visited);
            }
            p = p->next;
        }
    }
    
    // BFS遍历
    void BFS(int start) {
        vector<bool> visited(vertexCount, false);
        queue<int> q;
        
        visited[start] = true;
        q.push(start);
        
        while (!q.empty()) {
            int v = q.front();
            q.pop();
            cout << v << " ";
            
            EdgeNode* p = adjList[v];
            while (p != nullptr) {
                if (!visited[p->vertex]) {
                    visited[p->vertex] = true;
                    q.push(p->vertex);
                }
                p = p->next;
            }
        }
    }
    
    // Dijkstra算法
    void Dijkstra(int start) {
        vector<int> dist(vertexCount, INT_MAX);
        vector<bool> visited(vertexCount, false);
        vector<int> parent(vertexCount, -1);
        
        dist[start] = 0;
        
        for (int count = 0; count < vertexCount - 1; count++) {
            int u = -1;
            int minDist = INT_MAX;
            
            for (int v = 0; v < vertexCount; v++) {
                if (!visited[v] && dist[v] < minDist) {
                    minDist = dist[v];
                    u = v;
                }
            }
            
            if (u == -1) break;
            visited[u] = true;
            
            EdgeNode* p = adjList[u];
            while (p != nullptr) {
                int v = p->vertex;
                int weight = p->weight;
                
                if (!visited[v] && dist[u] != INT_MAX && 
                    dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    parent[v] = u;
                }
                p = p->next;
            }
        }
        
        // 打印结果
        cout << "从顶点 " << start << " 到各顶点的最短距离：" << endl;
        for (int i = 0; i < vertexCount; i++) {
            if (dist[i] == INT_MAX) {
                cout << "到 " << i << " : 不可达" << endl;
            } else {
                cout << "到 " << i << " : " << dist[i] << endl;
            }
        }
    }
    
    // 计算顶点的度
    int getDegree(int v) {
        int degree = 0;
        EdgeNode* p = adjList[v];
        while (p != nullptr) {
            degree++;
            p = p->next;
        }
        return degree;
    }
    
    // 检查是否存在边
    bool hasEdge(int u, int v) {
        EdgeNode* p = adjList[u];
        while (p != nullptr) {
            if (p->vertex == v) {
                return true;
            }
            p = p->next;
        }
        return false;
    }
};

// 使用示例
int main() {
    // 创建无向无权图
    Graph g(5, false, false);
    
    g.addEdge(0, 1);
    g.addEdge(0, 2);
    g.addEdge(1, 3);
    g.addEdge(2, 3);
    g.addEdge(3, 4);
    
    cout << "图的邻接表表示：" << endl;
    g.printGraph();
    cout << endl;
    
    cout << "DFS遍历（从顶点0开始）：";
    g.DFS(0);
    cout << endl;
    
    cout << "BFS遍历（从顶点0开始）：";
    g.BFS(0);
    cout << endl;
    
    // 创建有向有权图
    Graph weightedGraph(4, true, true);
    weightedGraph.addEdge(0, 1, 4);
    weightedGraph.addEdge(0, 2, 2);
    weightedGraph.addEdge(1, 2, 1);
    weightedGraph.addEdge(1, 3, 5);
    weightedGraph.addEdge(2, 3, 8);
    
    cout << "\n有权图的邻接表表示：" << endl;
    weightedGraph.printGraph();
    cout << endl;
```

1. **理解基本概念**：顶点、边、路径、连通性等
2. **掌握存储结构**：邻接矩阵、邻接表的优缺点
3. **熟练遍历算法**：DFS和BFS的实现和应用
4. **经典算法**：Dijkstra、Floyd、Kruskal、Prim等
5. **应用场景**：理解图在现实问题中的应用

图数据结构是计算机科学的重要组成部分，掌握图的存储和算法，对于解决复杂的实际问题具有重要意义。
