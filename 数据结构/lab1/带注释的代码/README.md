# 数据结构实验1 - 带详细注释的代码

本文件夹包含了数据结构实验1的两个程序的详细注释版本。

## 文件说明

### 1. josephus_problem_详细注释.cpp
**约瑟夫问题求解程序**

- **问题描述**：n个人围成一圈，从第1个人开始报数，数到第k个人就将其淘汰，求最后剩下的人的编号
- **数据结构**：循环单链表
- **算法思路**：通过删除节点模拟淘汰过程
- **时间复杂度**：O(n*k)
- **空间复杂度**：O(n)

**主要功能**：
- 创建包含n个节点的循环链表
- 模拟报数和淘汰过程
- 返回最后剩下的人的编号

### 2. single_linked_list_详细注释.cpp
**单链表操作程序**

- **功能描述**：实现支持多种操作的单链表
- **数据结构**：单链表 + 哈希表（用于优化查找）
- **时间复杂度**：大部分操作O(1)，删除操作O(n)
- **空间复杂度**：O(n)

**支持的操作**：
1. **插入节点**：在指定值为x的节点后插入新节点y
2. **查询节点**：查询指定值为x的节点的后继节点值
3. **删除节点**：删除指定值为x的节点（初始节点永远不被删除）
4. **修改节点**：将指定值为x的节点的数据修改为y
5. **打印链表**：按顺序输出所有节点的值

## 注释特点

### 详细程度
- **文件头注释**：包含问题描述、算法思路、复杂度分析
- **类注释**：说明类的用途和设计思路
- **函数注释**：详细说明参数、返回值、功能实现
- **行内注释**：解释关键代码逻辑和算法步骤

### 注释内容
- **算法分析**：时间复杂度和空间复杂度分析
- **优化建议**：提供可能的优化思路

- **边界条件处理**：说明特殊情况的处理方式

## 编译和运行

### 约瑟夫问题程序
```bash
g++ -o josephus josephus_problem_详细注释.cpp
./josephus
```

**输入格式**：
```
n k
```
- n：总人数
- k：报数间隔

**输出**：最后剩下的人的编号

### 单链表操作程序
```bash
g++ -o linkedlist single_linked_list_详细注释.cpp
./linkedlist
```

**输入格式**：
```
q
operation1
operation2
...
operationq
```

**操作类型**：
- `1 x y`：在值为x的节点后插入值为y的新节点
- `2 x`：查询值为x的节点的后继节点值
- `3 x`：删除值为x的节点
- `4 x y`：将值为x的节点修改为y
- `5`：打印所有节点
