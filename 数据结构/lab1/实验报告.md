### 2.2 题目2：约瑟夫问题

使用循环单链表解决约瑟夫问题：
- 有n个人围成圆圈，从第1个人开始报数
- 每次数到k的人出列，从下一个人继续报数
- 求最后剩下的人的编号

## 三、算法设计与实现

### 3.1 单链表设计

#### 3.1.1 数据结构设计

```cpp
// 链表节点类
class ListNode {
public:
    unsigned long long data;        // 数据域，存储正整数
    ListNode* next;                 // 指针域，指向下一个节点
    
    ListNode(unsigned long long val) : data(val), next(nullptr) {}
    ~ListNode() {}
};

// 单链表类
class LinkedList {
private:
    ListNode* head;  // 头节点指针
    unordered_map<unsigned long long, ListNode*> nodeMap;  // 快速查找映射表
};
```

#### 3.1.2 关键设计决策

1. **数据类型选择**：使用`unsigned long long`支持最大2^32-1的整数范围
2. **查找优化**：使用`unordered_map`实现O(1)时间复杂度的节点查找
3. **内存管理**：实现完整的构造函数和析构函数，避免内存泄漏

#### 3.1.3 核心算法实现

**插入操作**：
```cpp
void insertNode(unsigned long long x, unsigned long long y) {
    if (nodeMap.find(x) == nodeMap.end()) return;  // 节点不存在则忽略
    
    ListNode* targetNode = nodeMap[x];
    ListNode* newNode = new ListNode(y);
    
    newNode->next = targetNode->next;
    targetNode->next = newNode;
    nodeMap[y] = newNode;  // 更新映射表
}
```

**删除操作**：
```cpp
void deleteNode(unsigned long long x) {
    if (nodeMap.find(x) == nodeMap.end()) return;  // 节点不存在则忽略
    if (head->data == x) return;  // 保护初始节点不被删除
    
    // 找到前驱节点
    ListNode* prev = nullptr;
    ListNode* current = head;
    while (current != nullptr && current->data != x) {
        prev = current;
        current = current->next;
    }
    
    if (current != nullptr) {
        prev->next = current->next;
        nodeMap.erase(x);
        delete current;
    }
}
```

### 3.2 循环单链表设计

#### 3.2.1 数据结构设计

```cpp
class CircularListNode {

    ~CircularListNode() {}
};

class CircularLinkedList {
private:
    CircularListNode* head;      // 头节点指针
    CircularListNode* current;   // 当前节点指针
    int size;                   // 链表大小
};
```

#### 3.2.2 约瑟夫问题算法

**核心思想**：
1. 创建包含n个节点的循环链表
2. 从第1个人开始，数k-1个人后删除第k个人
3. 重复步骤2直到只剩1个人

**算法实现**：
```cpp
int solveJosephus(int k) {
    current = head;  // 从第1个人开始
    
    while (!isLastOne()) {
        // 数k-1个人（因为要删除第k个人）
        for (int i = 1; i < k; i++) {
            moveNext();
        }
        
        // 删除当前节点（第k个人）
        deleteCurrent();
    }
    
    return getCurrentData();  // 返回最后剩下的人的编号
}
```

## 四、实验过程与问题解决

### 4.1 开发过程

1. **需求分析**：仔细阅读题目要求，理解各种操作的输入输出格式
2. **数据结构设计**：设计合适的节点类和链表类结构
3. **功能实现**：逐步实现各种操作函数
4. **测试验证**：使用题目提供的测试用例验证程序正确性

### 4.2 遇到的问题与解决方案

#### 问题1：大整数处理
**问题描述**：题目要求支持最大2^32-1的整数，但初始使用`long long`类型
**解决方案**：改用`unsigned long long`类型，确保能正确处理所有测试用例

#### 问题2：查找效率
**问题描述**：如果使用线性查找，时间复杂度为O(n)，效率较低
**解决方案**：使用`unordered_map`建立值到节点的映射，实现O(1)查找

#### 问题3：内存管理
**问题描述**：需要确保所有动态分配的内存都被正确释放
**解决方案**：实现完整的析构函数，在链表销毁时释放所有节点内存
