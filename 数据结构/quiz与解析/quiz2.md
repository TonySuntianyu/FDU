## 1. 对称矩阵存储问题

### 题目
设有一个12×12的对称矩阵M，将其上三角部分的元素mi,j（1<=i<=j<=12）按行优先存入C语言的一维数组N中，元素m6,6在N中的下标是（）。

### 解答

#### 问题分析
对于12×12的对称矩阵，上三角部分按行优先存储：

- 第1行：m₁,₁, m₁,₂, m₁,₃, ..., m₁,₁₂ (12个元素)
- 第2行：m₂,₂, m₂,₃, ..., m₂,₁₂ (11个元素)
- 第3行：m₃,₃, m₃,₄, ..., m₃,₁₂ (10个元素)
- ...
- 第5行：m₅,₅, m₅,₆, ..., m₅,₁₂ (8个元素)
- 第6行：m₆,₆, m₆,₇, ..., m₆,₁₂ (7个元素)

#### 计算过程
元素m₆,₆位于第6行第6列，是第6行的第一个元素。

在按行优先存储的数组中，m₆,₆的下标等于前面所有行的元素个数之和：

```
下标 = 第1行元素数 + 第2行元素数 + ... + 第5行元素数
     = 12 + 11 + 10 + 9 + 8
     = 50
```

#### 答案
**元素m₆,₆在数组N中的下标是50。**

## 2. 三对角矩阵存储问题

### 题目
设有一个10×10的对称矩阵M，将其上三角部分的元素mi,j（1<=i<=j<=10）按列优先存入C语言的一维数组N中，元素m7,2在N中的下标是（）。

### 解答

#### 问题分析
对于10×10的对称矩阵，上三角部分按列优先存储：

- 第1列：m₁,₁, m₂,₁, m₃,₁, ..., m₁₀,₁ (10个元素)
- 第2列：m₂,₂, m₃,₂, m₄,₂, ..., m₁₀,₂ (9个元素)
- 第3列：m₃,₃, m₄,₃, m₅,₃, ..., m₁₀,₃ (8个元素)
- ...
- 第6列：m₆,₆, m₇,₆, m₈,₆, m₉,₆, m₁₀,₆ (5个元素)
- 第7列：m₇,₇, m₈,₇, m₉,₇, m₁₀,₇ (4个元素)

#### 计算过程
元素m₇,₂位于第7行第2列。

**修正分析：**

对于10×10的对称矩阵，上三角部分（i ≤ j）按列优先存储时：

- **第1列**：m₁,₁ (1个元素，索引0)
- **第2列**：m₁,₂, m₂,₂ (2个元素，索引1-2)
- **第3列**：m₁,₃, m₂,₃, m₃,₃ (3个元素，索引3-5)
- **第4列**：m₁,₄, m₂,₄, m₃,₄, m₄,₄ (4个元素，索引6-9)
- **第5列**：m₁,₅, m₂,₅, m₃,₅, m₄,₅, m₅,₅ (5个元素，索引10-14)
- **第6列**：m₁,₆, m₂,₆, m₃,₆, m₄,₆, m₅,₆, m₆,₆ (6个元素，索引15-20)
- **第7列**：m₁,₇, m₂,₇, m₃,₇, m₄,₇, m₅,₇, m₆,₇, m₇,₇ (7个元素，索引21-27)

在第7列中，m₇,₂不在第7列，因为7 > 2，不满足i ≤ j。

**重新理解：** m₇,₂应该存储为m₂,₇（对称矩阵中m₇,₂ = m₂,₇）。

在第7列中找m₂,₇：
- 前6列元素总数：1 + 2 + 3 + 4 + 5 + 6 = 21
- 第7列中m₂,₇是第2个元素（m₁,₇, m₂,₇）
- 索引 = 21 + 1 = 22

```
下标 = 21 + 1 = 22
```

#### 答案
**元素m₇,₂在数组N中的下标是22。**

## 3. 稀疏矩阵三元组表存储问题

### 题目
若采用三元组表存储结构存储稀疏矩阵M，则除三元组表外，下列数据中还需要保存的是（）。

M的行数 II. M中包含非零元素的行数
M的列数 IV. M中包含非零元素的列数

答案选项组：
- 仅I, III
- 仅I, IV
- 仅II, IV
- I, II, III, IV

### 解答

#### 三元组表存储结构
三元组表是存储稀疏矩阵的一种压缩存储方式，每个非零元素用三元组(i, j, value)表示，其中：
- i：行号
- j：列号  
- value：元素值

#### 分析各选项

**I. M的行数** - **需要保存**
- 三元组表中只存储了非零元素的行号，但没有存储矩阵的总行数
- 为了知道矩阵的完整维度，必须保存总行数

**II. M中包含非零元素的行数** - **不需要单独保存**
- 这个信息可以从三元组表中统计得出，通过扫描所有三元组的行号即可得到

**III. M的列数** - **需要保存**
- 三元组表中只存储了非零元素的列号，但没有存储矩阵的总列数
- 为了知道矩阵的完整维度，必须保存总列数

**IV. M中包含非零元素的列数** - **不需要单独保存**
- 这个信息可以从三元组表中统计得出，通过扫描所有三元组的列号即可得到

#### 为什么需要保存行数和列数？
1. **矩阵运算需要**：进行矩阵加法、乘法等运算时，需要知道矩阵的维度
2. **边界检查需要**：访问矩阵元素时需要检查行号和列号是否在有效范围内
3. **内存分配需要**：将三元组表转换回二维数组时需要知道矩阵大小
4. **显示输出需要**：打印矩阵时需要知道完整的行列数

#### 答案
**仅I, III**

需要保存的是：
- I. M的行数
- III. M的列数

## 4. KMP算法字符比较次数问题

### 题目
已知字符串S为"abaabaabcabaabc"，模式串t为"abaabc"。采用KMP算法进行匹配，到匹配成功时为止，在匹配过程中进行的单个字符间比较次数是（）。

### 解答

#### 问题分析
- 文本串S：`"abaabaabcabaabc"`
- 模式串T：`"abaabc"`
- 需要计算匹配成功时为止的字符比较次数

#### 构建Next数组
首先为模式串T = "abaabc"构建next数组：

```
模式串: a b a a b c
索引:   0 1 2 3 4 5

next[0] = 0
next[1] = 0  (b != a)
next[2] = 1  (a == a)
next[3] = 1  (a == a)
next[4] = 2  (b == b)
next[5] = 0  (c != a)

next数组: [0, 0, 1, 1, 2, 0]
```

#### 匹配过程
**文本串S：** `a b a a b a a b c a b a a b c`
**模式串T：** `a b a a b c`

**第1轮匹配：**
- S[0]='a' vs T[0]='a' ✓ (比较1次)
- S[1]='b' vs T[1]='b' ✓ (比较2次)
- S[2]='a' vs T[2]='a' ✓ (比较3次)
- S[3]='a' vs T[3]='a' ✓ (比较4次)
- S[4]='b' vs T[4]='b' ✓ (比较5次)
- S[5]='a' vs T[5]='c' ✗ (比较6次)

**第2轮匹配（利用next数组回退）：**
- j = next[4] = 2，从T[2]开始匹配
- S[5]='a' vs T[2]='a' ✓ (比较7次)
- S[6]='a' vs T[3]='a' ✓ (比较8次)
- S[7]='b' vs T[4]='b' ✓ (比较9次)
- S[8]='c' vs T[5]='c' ✓ (比较10次)

**匹配成功！**

#### 答案
**在匹配过程中进行的单个字符间比较次数是10次。**

## 5. KMP算法失配处理问题

### 题目
已知字符串S为"abaabaabacacaabaabcc"，模式串t为"abaabc"。采用KMP算法进行匹配，第一次出现失配（s[i]≠t[j]）时，i=j=5，则下次开始匹配时i和j的值分别是（）。

### 解答

#### 问题分析
- 文本串S：`"abaabaabacacaabaabcc"`
- 模式串T：`"abaabc"`
- 第一次失配时：i = j = 5
- 需要确定下次开始匹配时的i和j值

#### 构建Next数组
为模式串T = "abaabc"构建next数组：

```
模式串: a b a a b c
索引:   0 1 2 3 4 5

next数组: [0, 0, 1, 1, 2, 0]
```

#### 失配处理规则
当S[i] ≠ T[j]时：
- **i保持不变**：文本串指针不移动
- **j回退到next[j-1]**：模式串指针回退

#### 计算下次匹配位置
- 当前j = 5
- j回退到next[5-1] = next[4] = 2
- 所以下次匹配时：i = 5, j = 2

#### 答案
**下次开始匹配时：**
- **i = 5**（文本串指针保持不变）
- **j = 2**（模式串指针回退到next[4] = 2）

## 6. 中缀表达式转后缀表达式问题

### 题目
假设栈初始为空，将中缀表达式a/b+(c*d-e*f)/g转化为等价的后缀表达式的过程中，当扫描到f时，栈中的元素依次是（）。

### 解答

#### 问题分析
- 中缀表达式：`a/b+(c*d-e*f)/g`
- 需要确定扫描到字符'f'时，栈中的元素

#### 中缀转后缀的算法规则
1. **操作数**：直接输出
2. **左括号'('**：入栈
3. **右括号')'**：弹出栈中元素直到遇到左括号
4. **运算符**：
   - 如果栈空或栈顶是'('，直接入栈
   - 如果当前运算符优先级 > 栈顶运算符优先级，入栈
   - 如果当前运算符优先级 ≤ 栈顶运算符优先级，弹出栈顶元素，继续比较
5. **扫描完毕**：弹出栈中所有元素

#### 运算符优先级
- `*`, `/`：优先级高
- `+`, `-`：优先级低
- `(`：优先级最低

#### 逐步分析
扫描表达式 `a/b+(c*d-e*f)/g` 到字符'f'：

| 字符 | 类型 | 操作 | 栈状态 | 输出 |
|------|------|------|--------|------|
| a | 操作数 | 输出 | `[]` | `a` |
| / | 运算符 | 入栈 | `[/]` | `a` |
| b | 操作数 | 输出 | `[/]` | `a b` |
| + | 运算符 | 弹出/，入栈+ | `[+]` | `a b /` |
| ( | 左括号 | 入栈 | `[+, (]` | `a b /` |
| c | 操作数 | 输出 | `[+, (]` | `a b / c` |
| * | 运算符 | 入栈 | `[+, (, *]` | `a b / c` |
| d | 操作数 | 输出 | `[+, (, *]` | `a b / c d` |
| - | 运算符 | 弹出*，入栈- | `[+, (, -]` | `a b / c d *` |
| e | 操作数 | 输出 | `[+, (, -]` | `a b / c d * e` |
| * | 运算符 | 入栈 | `[+, (, -, *]` | `a b / c d * e` |
| **f** | 操作数 | 输出 | `[+, (, -, *]` | `a b / c d * e f` |

#### 答案
**当扫描到'f'时，栈中的元素依次是：`+, (, -, *`**

## 7. 循环队列判断条件问题

### 题目
循环队列放在一维数组A[0…M-1]中，end1指向队头元素，end2指向队尾元素后一个位置。假设队列两端均可进行出队和入队操作，队列中最多能容纳M-1个元素。初始时为空。下列判断队空和队满条件中，正确的是（）。

答案选项组：
- 队空：end1 == end2；队满：end1==(end2+1) mod M
- 队空：end1 == end2；队满：end2==(end1+1) mod (M-1)
- 队空：end2==(end1+1) mod M；队满：end1==(end2+1) mod M
- 队空：end1==(end2+1) mod M；队满：end2==(end1+1) mod (M-1)

### 解答

#### 问题分析
- 循环队列存储在一维数组A[0…M-1]中
- end1指向队头元素
- end2指向队尾元素后一个位置
- 队列两端均可进行出队和入队操作
- 队列中最多能容纳M-1个元素
- 初始时为空

#### 循环队列的基本原理

**指针含义：**
- **end1**：指向队头元素的位置
- **end2**：指向队尾元素后一个位置（即下一个入队位置）

**队列状态判断：**

**队空条件：**
当队列为空时，end1和end2指向同一个位置，即：
```
队空：end1 == end2
```

**队满条件：**
当队列满时，end2的下一个位置就是end1，即：
```
队满：end1 == (end2 + 1) % M
```

#### 验证各选项

**选项1：队空：end1 == end2；队满：end1==(end2+1) mod M**
- 队空：✓ 正确
- 队满：✓ 正确

**选项2：队空：end1 == end2；队满：end2==(end1+1) mod (M-1)**
- 队空：✓ 正确
- 队满：✗ 错误，应该是end1 == (end2+1) % M

**选项3：队空：end2==(end1+1) mod M；队满：end1==(end2+1) mod M**
- 队空：✗ 错误，队空应该是end1 == end2
- 队满：✓ 正确

**选项4：队空：end1==(end2+1) mod M；队满：end2==(end1+1) mod (M-1)**
- 队空：✗ 错误，队空应该是end1 == end2
- 队满：✗ 错误，队满应该是end1 == (end2+1) % M

#### 答案
**选项1：队空：end1 == end2；队满：end1==(end2+1) mod M**

## 8. 栈和队列操作问题

### 题目
设栈S和队列Q的初始状态均为空，元素abcdefg依次入栈S。若每个元素出栈后立刻入队列Q，且7个元素出队的顺序是bdcfeag，则栈的容量至少是（）。

### 解答

#### 问题分析
- 栈S和队列Q初始为空
- 元素abcdefg依次入栈S
- 每个元素出栈后立刻入队列Q
- 7个元素出队的顺序是bdcfeag
- 需要求栈的容量至少是多少

#### 解题思路
由于每个元素出栈后立刻入队列Q，所以队列Q中元素的顺序就是栈S中元素出栈的顺序。

因此，栈S中元素出栈的顺序是：`b d c f e a g`

#### 模拟栈操作过程

**入栈顺序：** `a b c d e f g`
**出栈顺序：** `b d c f e a g`

#### 逐步分析：

| 步骤 | 操作 | 栈状态 | 栈深度 | 队列Q |
|------|------|--------|--------|-------|
| 1 | a入栈 | [a] | 1 | [] |
| 2 | b入栈 | [a,b] | 2 | [] |
| 3 | b出栈 | [a] | 1 | [b] |
| 4 | c入栈 | [a,c] | 2 | [b] |
| 5 | d入栈 | [a,c,d] | 3 | [b] |
| 6 | d出栈 | [a,c] | 2 | [b,d] |
| 7 | c出栈 | [a] | 1 | [b,d,c] |
| 8 | e入栈 | [a,e] | 2 | [b,d,c] |
| 9 | f入栈 | [a,e,f] | 3 | [b,d,c] |
| 10 | f出栈 | [a,e] | 2 | [b,d,c,f] |
| 11 | e出栈 | [a] | 1 | [b,d,c,f,e] |
| 12 | a出栈 | [] | 0 | [b,d,c,f,e,a] |
| 13 | g入栈 | [g] | 1 | [b,d,c,f,e,a] |
| 14 | g出栈 | [] | 0 | [b,d,c,f,e,a,g] |

#### 最大栈深度
从上面的分析可以看出，栈的最大深度是3，出现在：
- 步骤5：栈中有[a,c,d]，深度为3
- 步骤9：栈中有[a,e,f]，深度为3

#### 答案
**栈的容量至少是3。**
