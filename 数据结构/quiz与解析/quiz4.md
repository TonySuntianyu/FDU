## 核心知识点总结

### 1. 无向图的基本性质

**节点数与边数的关系：**
- 对于有n个顶点的无向图，最多有 n(n-1)/2 条边（完全图）
- 对于有n个顶点的连通无向图，至少需要 n-1 条边（树）
- 对于有n个顶点的无向图，如果有m条边，则 m ≤ n(n-1)/2

**连通性判断：**
- 连通图：任意两个顶点之间都存在路径
- 非连通图：存在至少两个顶点之间没有路径
- 连通图至少需要 n-1 条边（n个顶点）
- 如果边数 < n-1，则图一定不连通

### 2. 图的度与边数的关系

**握手定理（Handshaking Lemma）：**
- 对于无向图，所有顶点的度数之和 = 2 × 边数
- 即：Σ(deg(v)) = 2|E|
- 这个定理是图论中的基本定理，用于解决顶点度数相关的问题

**度的性质：**
- 每个顶点的度数至少为0（孤立顶点）
- 在简单图中，每个顶点的度数最多为 n-1（与其他所有顶点都相邻）

### 3. 图的遍历算法

**广度优先搜索（BFS）：**
- 使用队列（Queue）数据结构
- 从起始顶点开始，逐层访问所有相邻顶点
- 类似于树的层序遍历
- 当所有边权值相等时，BFS可以找到单源最短路径
- 当边权值不相等时，BFS不能保证找到最短路径（需要使用Dijkstra算法）

**深度优先搜索（DFS）：**
- 使用栈（Stack）数据结构（递归实现时使用系统栈）
- 从起始顶点开始，尽可能深地访问路径，直到无法继续，然后回溯
- 类似于树的前序遍历
- **核心原则**：尽可能深地访问，遇到已访问顶点或没有未访问邻居时回溯
- **特点**：访问顺序取决于邻接关系和访问顺序的选择

**BFS与树遍历的对应关系：**
- BFS ≈ 树的层序遍历（Level-order Traversal）
- DFS ≈ 树的前序遍历（Pre-order Traversal）
- BFS ≠ 树的后序遍历（Post-order Traversal）

### 4. 最小生成树（MST）

**最小生成树的定义：**
- 对于连通无向图，最小生成树是包含所有顶点且边权值之和最小的树
- 最小生成树的边数 = 顶点数 - 1

**最小生成树的性质：**
- **代价唯一性**：虽然最小生成树的结构可能不唯一，但所有最小生成树的总权值（代价）是唯一的
- **最小边不一定都在MST中**：所有权值最小的边不一定都出现在所有MST中（如果这些边形成环，则不能全部选择）
- **算法结果**：Prim算法和Kruskal算法都能找到最小生成树，但结果可能不同（如果存在多个MST）

**Prim算法：**
- 从任意顶点开始，逐步扩展最小生成树
- 每次选择连接已选顶点和未选顶点且权值最小的边
- 从不同顶点开始可能得到不同的MST（如果存在多个MST）

**Kruskal算法：**
- 按边权值从小到大排序，依次选择不形成环的边
- 使用并查集判断是否形成环
- 结果可能不同于Prim算法（如果存在多个MST）

- |V| + 1 > |E|

## 2. 无向图顶点个数计算

### 题目

无向图G有16条边，其中度为4的顶点个数为3，度为3的顶点个数是4，其他顶点的度均小于3。图G所含顶点个数至少是()

A. 11

B. 10

C. 13

D. 15

### 答案

**A. 11**

### 详细解析

#### 知识点回顾

**握手定理（Handshaking Lemma）：**
对于无向图，所有顶点的度数之和等于边数的2倍：
Σ(deg(v)) = 2|E|

#### 解题步骤

**已知条件：**
- 边数：|E| = 16
- 度为4的顶点：3个
- 度为3的顶点：4个
- 其他顶点的度均 < 3

**第一步：计算已知顶点的度数之和**

度为4的顶点贡献的度数：3 × 4 = 12
度为3的顶点贡献的度数：4 × 3 = 12
已知顶点度数之和：12 + 12 = 24

**第二步：应用握手定理**

所有顶点度数之和 = 2 × |E| = 2 × 16 = 32

**第三步：计算其他顶点需要贡献的度数**

其他顶点需要贡献的度数 = 32 - 24 = 8

**第四步：确定其他顶点的最小个数**

其他顶点的度均 < 3，即每个顶点的度 ≤ 2。

为了使顶点总数最小，我们应该让其他顶点的度尽可能大（即度为2）。

如果其他顶点都是度为2：
- 需要的顶点数 = 8 ÷ 2 = 4个

**第五步：计算最小顶点总数**

最小顶点总数 = 度为4的顶点数 + 度为3的顶点数 + 其他顶点数
= 3 + 4 + 4
= 11

**验证：**
- 度为4的顶点：3个，度数之和 = 12
- 度为3的顶点：4个，度数之和 = 12
- 度为2的顶点：4个，度数之和 = 8
- 总度数 = 12 + 12 + 8 = 32 = 2 × 16 ✓

**结论：**
图G所含顶点个数至少是11个。

#### 其他选项分析

**选项B（10）：**
如果只有10个顶点：
- 已知顶点：3 + 4 = 7个
- 其他顶点：10 - 7 = 3个
- 其他顶点最大度数之和 = 3 × 2 = 6
- 总度数 = 24 + 6 = 30 < 32
- 不满足握手定理，错误

**选项C（13）和D（15）：**
这些值都大于11，虽然满足条件，但不是最小值。

## 3. 无向连通图性质判断

### 题目

下列关于无向连通图的叙述中，正确的是()

I. 所有顶点的度之和为偶数

II. 边数大于顶点个数减1

III. 至少有一个顶点的度为1

A. 仅I

B. 仅II

C. 仅I和II

D. 仅I和III

### 答案

**A. 仅I**

### 详细解析

#### 知识点回顾

**握手定理（Handshaking Lemma）：**
对于无向图，所有顶点的度数之和等于边数的2倍：
Σ(deg(v)) = 2|E|

**连通图的性质：**
- n个顶点的连通无向图至少需要 n-1 条边（此时图是一棵树）
- 边数可以等于 n-1（树），也可以大于 n-1（有环的连通图）

#### 逐项分析

**陈述I：所有顶点的度之和为偶数**

**分析：**
根据握手定理，对于无向图G=(V,E)：
Σ(deg(v)) = 2|E|

由于边数 |E| 是正整数，所以 2|E| 一定是偶数。

**结论：** 陈述I是正确的。✓

**陈述II：边数大于顶点个数减1**

**分析：**
对于n个顶点的连通无向图：
- **最小边数**：n-1（此时图是一棵树）
- **边数可以等于 n-1**：例如，3个顶点用2条边连接成一条路径，图是连通的
- **边数可以大于 n-1**：例如，4个顶点形成完全图K₄，有6条边，图是连通的

**关键点：**
陈述II说"边数**大于**顶点个数减1"，使用了严格大于（>）符号。

**反例：**
- 设 |V| = 3，|E| = 2
- 检查：|E| = 2，|V| - 1 = 2
- 所以 |E| = |V| - 1，不满足 |E| > |V| - 1
- 但3个顶点、2条边可以形成连通的路径图（如1-2-3）

因此，连通图的边数可以**等于** n-1，不一定**大于** n-1。

**结论：** 陈述II是错误的。✗

**陈述III：至少有一个顶点的度为1**

**分析：**
这个陈述说连通图至少有一个度为1的顶点（即至少有一个叶子节点）。

**反例1：完全图**
- 完全图Kₙ（n ≥ 3）中，每个顶点的度都是 n-1 ≥ 2
- 例如，K₃（三角形）中，每个顶点度都是2
- 例如，K₄中，每个顶点度都是3
- 完全图是连通的，但所有顶点度都大于1

**反例2：环图**
- n个顶点（n ≥ 3）形成一个环，每个顶点度都是2
- 环图是连通的，但所有顶点度都等于2，没有度为1的顶点

**反例3：更一般的例子**
- 考虑一个4个顶点的连通图：顶点1-2-3-4形成一个环（每个度都是2），再加一条边1-3
- 此时所有顶点度都大于1，图是连通的

**关键点：**
虽然树（n个顶点、n-1条边的连通图）确实至少有两个度为1的顶点，但并不是所有连通图都满足这个性质。

**结论：** 陈述III是错误的。✗

#### 综合判断

- **陈述I**：正确 ✓
- **陈述II**：错误 ✗
- **陈述III**：错误 ✗

因此，只有陈述I是正确的，答案为**A. 仅I**。

#### 深入理解

**为什么陈述I总是成立？**

握手定理是图论的基本定理，适用于所有无向图（无论是否连通）：
- 每条边连接两个顶点，在度数统计中被计算两次
- 因此总度数 = 2 × 边数，一定是偶数
- 这个性质与图的连通性无关

**为什么陈述II不成立？**

连通图的最小边数是 n-1（树），而不是严格大于 n-1：
- 当边数 = n-1 时，图是树，仍然是连通的
- 只有当边数 < n-1 时，图才一定不连通
- 因此"边数大于顶点个数减1"不是连通图的必要条件

**为什么陈述III不成立？**

连通图不一定有度为1的顶点：
- 树（n-1条边）确实至少有两个度为1的顶点
- 但有环的连通图可能所有顶点度都 ≥ 2
- 完全图、环图等都是反例

## 4. 广度优先搜索算法性质判断

### 题目

下列关于广度优先算法的说法中，正确的是()

I. 当各边的权值相等时，广度优先算法可以解决单源最短路径问题

II. 当各边的权值不相等时，广度优先算法可以解决单源最短路径问题

III. 广度优先遍历算法类似于树中的后序遍历算法

IV. 实现图的广度优先算法时，使用的数据结构是队列

A. I, IV

B. II, III, IV

C. II, IV

D. I, III, IV

### 答案

**A. I, IV**

### 详细解析

#### 知识点回顾

**广度优先搜索（BFS）算法：**
- **数据结构**：使用队列（Queue）实现
- **遍历方式**：从起始顶点开始，逐层访问所有相邻顶点
- **与树遍历的对应**：BFS类似于树的层序遍历（Level-order Traversal），而不是后序遍历

**BFS与最短路径：**
- **边权值相等时**：BFS可以找到单源最短路径
  - 因为BFS按层访问，先访问到的顶点距离起始顶点更近
  - 当所有边权值相等时，路径长度 = 经过的边数 = BFS的层数
- **边权值不相等时**：BFS不能保证找到最短路径
  - 需要使用Dijkstra算法或Bellman-Ford算法
  - 反例：如果存在一条权值很大的边，BFS可能先访问到该边，但这不是最短路径

#### 逐项分析

**陈述I：当各边的权值相等时，广度优先算法可以解决单源最短路径问题**

**分析：**
当所有边的权值相等时（通常假设为1），BFS可以找到从起始顶点到所有其他顶点的最短路径。

**原理：**
- BFS按层访问顶点，第k层包含距离起始顶点恰好k条边的所有顶点
- 当所有边权值相等时，最短路径长度 = 经过的边数 = BFS的层数
- BFS保证先访问到的路径就是最短路径

**示例：**
考虑一个无向图，所有边权值为1：
```
    A
   / \
  B---C
  |   |
  D---E
```
从A开始BFS：
- 第0层：A（距离0）
- 第1层：B, C（距离1）
- 第2层：D, E（距离2）

BFS找到的路径就是最短路径。

**结论：** 陈述I是正确的。✓

**陈述II：当各边的权值不相等时，广度优先算法可以解决单源最短路径问题**

**分析：**
当边权值不相等时，BFS不能保证找到最短路径。

**反例：**
考虑以下有向图，边权值不相等：
```
    A
   / \
  1   3
 /     \
B       C
|       |
2       1
|       |
D       E
```
从A到E：
- BFS路径：A → C → E（总权值 = 3 + 1 = 4）
- 最短路径：A → B → D → E（总权值 = 1 + 2 + 1 = 4，但假设D到E的边权值更小）

更清晰的反例：
```
    A
   / \
  1   100
 /     \
B       C
|       |
1       1
|       |
D       E
```
从A到E：
- BFS会先访问C（因为BFS按层访问，不考虑边权值），然后访问E
- 路径：A → C → E（总权值 = 100 + 1 = 101）
- 但最短路径是：A → B → D → E（总权值 = 1 + 1 + 1 = 3）

**关键点：**
BFS只考虑经过的边数，不考虑边权值。当边权值不相等时，边数少的路径不一定权值最小。

**结论：** 陈述II是错误的。✗

**陈述III：广度优先遍历算法类似于树中的后序遍历算法**

**分析：**
这个陈述是错误的。BFS与树的后序遍历完全不同。

**BFS（广度优先搜索）：**
- 按层访问：先访问根节点，再访问所有子节点，再访问所有孙节点...
- 类似于树的**层序遍历**（Level-order Traversal）
- 访问顺序：A → B → C → D → E → F → G（假设是满二叉树）

**后序遍历（Post-order Traversal）：**
- 先访问左子树，再访问右子树，最后访问根节点
- 访问顺序：D → E → B → F → G → C → A（假设是满二叉树）

**对比示例：**
对于以下树：
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```

- **BFS（层序遍历）**：A → B → C → D → E → F → G
- **后序遍历**：D → E → B → F → G → C → A

两者完全不同。

**结论：** 陈述III是错误的。✗

**陈述IV：实现图的广度优先算法时，使用的数据结构是队列**

**分析：**
这是BFS算法的基本实现细节。

**BFS算法实现：**
1. 将起始顶点入队
2. 当队列非空时：
   - 出队一个顶点
   - 访问该顶点
   - 将该顶点的所有未访问的相邻顶点入队
3. 重复步骤2直到队列为空

**为什么使用队列？**
- 队列是FIFO（先进先出）数据结构
- BFS需要先访问先发现的顶点（按层访问）
- 队列保证了先入队的顶点先被访问，符合BFS的层序遍历要求

**对比DFS：**
- DFS使用栈（Stack），LIFO（后进先出）
- 因为DFS需要尽可能深地访问路径，后发现的顶点先访问

**结论：** 陈述IV是正确的。✓

#### 综合判断

- **陈述I**：正确 ✓
- **陈述II**：错误 ✗
- **陈述III**：错误 ✗
- **陈述IV**：正确 ✓

因此，只有陈述I和IV是正确的，答案为**A. I, IV**。

#### 深入理解

**为什么BFS在边权值相等时可以找最短路径？**

BFS的核心思想是按层访问：
- 第0层：起始顶点（距离0）
- 第1层：与起始顶点直接相邻的顶点（距离1）
- 第2层：与第1层顶点相邻但未访问的顶点（距离2）
- ...

当所有边权值相等时：
- 路径长度 = 经过的边数 = BFS的层数
- BFS保证先访问到的顶点距离更近
- 因此BFS找到的路径就是最短路径

**为什么BFS在边权值不相等时不能找最短路径？**

BFS只考虑经过的边数，不考虑边权值：
- 可能先访问到一条边数少但总权值大的路径
- 而实际最短路径可能边数多但总权值小
- 因此需要使用考虑边权值的算法（如Dijkstra算法）

**BFS与树遍历的对应关系：**

| 图的遍历 | 树的遍历 | 数据结构 |
|---------|---------|---------|
| BFS | 层序遍历 | 队列 |
| DFS | 前序遍历 | 栈（递归） |

**记忆技巧：**
- BFS = Breadth First = 广度优先 = 横向扩展 = 层序遍历 = 队列
- DFS = Depth First = 深度优先 = 纵向深入 = 前序遍历 = 栈

## 5. 广度优先遍历序列判断

### 题目

若对如下无向图进行遍历，则下列选项中，不是广度优先遍历序列的是()

**图的结构：**
- 顶点：a, b, c, d, e, f, g, h
- 边：(a,b), (a,e), (a,h), (b,c), (b,d), (c,d), (c,h), (e,f), (e,g)
![alt text](2.png)

A. a, b, c, d, h, e, f, g

B. h, c, a, b, d, e, g, f

C. e, a, f, g, b, h, c, d

D. d, b, c, a, h, e, f, g

### 答案

**A. a, b, c, d, h, e, f, g**

### 详细解析

#### 知识点回顾

**广度优先搜索（BFS）的核心原则：**
- BFS按层访问顶点，先访问完一层的所有顶点，再访问下一层
- 对于起始顶点v，访问顺序为：
  - 第0层：v（起始顶点）
  - 第1层：v的所有未访问的邻居
  - 第2层：第1层顶点的所有未访问的邻居
  - 以此类推
- **关键约束**：同一层的顶点必须在下一层顶点之前全部访问完

#### 图的邻接关系

首先明确图的邻接关系：

```
顶点a的邻居：b, e, h
顶点b的邻居：a, c, d
顶点c的邻居：b, d, h
顶点d的邻居：b, c
顶点e的邻居：a, f, g
顶点f的邻居：e
顶点g的邻居：e
顶点h的邻居：a, c
```

#### 逐项分析

**选项A：a, b, c, d, h, e, f, g**

**分析：**
假设从顶点a开始BFS遍历。

**第0层：** a（起始顶点）

**第1层：** a的邻居是 b, e, h
- 按照BFS原则，应该先访问完a的所有邻居（b, e, h）后，再访问它们的邻居
- 但序列中：访问了b后，立即访问了c和d（b的邻居）
- 然后才访问h（a的邻居）
- 最后才访问e（a的邻居）

**问题所在：**
- 序列：a → b → c → d → h → e → f → g
- 在访问完b后，立即访问了c和d（b的邻居，属于第2层）
- 但此时h和e（a的邻居，属于第1层）还没有被访问
- 这违反了BFS的层序原则：必须先访问完第1层的所有顶点（b, e, h），才能访问第2层的顶点（c, d, f, g）

**正确的BFS序列应该是：**
- 从a开始：a → b, e, h（第1层，顺序可以任意）→ c, d, f, g（第2层）

**结论：** 选项A不是BFS遍历序列。✗

**选项B：h, c, a, b, d, e, g, f**

**分析：**
假设从顶点h开始BFS遍历。

**第0层：** h（起始顶点）

**第1层：** h的邻居是 a, c
- 序列访问了c和a，符合BFS原则 ✓

**第2层：**
- c的未访问邻居：b, d
- a的未访问邻居：b, e（h已访问）
- 序列访问了b, d, e，符合BFS原则 ✓

**第3层：**
- e的未访问邻居：f, g（a已访问）

4. 如果序列中相邻顶点之间没有边，且不能通过回溯解释，则不是DFS序列

**DFS与BFS的区别：**

| 特性 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列 | 栈 |
| 访问方式 | 按层访问 | 深入优先 |
| 序列特点 | 层序性 | 深入-回溯 |
| 与树遍历对应 | 层序遍历 | 前序遍历 |

## 8. 最小生成树性质判断

### 题目

下列关于最小生成树的叙述中，正确的是()

I. 最小生成树的代价唯一

II. 所有权值最小的边一定会出现在所有的最小生成树中

III. 使用Prim算法从不同顶点开始的最小生成树一定相同

IV. 使用Prim和Kruskal算法得到的最小生成树总不相同

A. 仅I

B. 仅II

C. 仅I, III

D. 仅II, IV

### 答案

**A. 仅I**

### 详细解析

#### 知识点回顾

**最小生成树（MST）的性质：**
- 对于连通无向图，最小生成树是包含所有顶点且边权值之和最小的树
- 最小生成树的边数 = 顶点数 - 1
- **代价唯一性**：虽然MST的结构可能不唯一，但所有MST的总权值（代价）是唯一的
- **边的不确定性**：最小权值的边不一定都出现在所有MST中（如果这些边形成环）

#### 逐项分析

**陈述I：最小生成树的代价唯一**

**分析：**
最小生成树的代价（总权值）是唯一的，这是最小生成树的基本性质。

**证明：**
假设存在两个不同的最小生成树T1和T2，它们的总权值不同。
- 设T1的总权值为W1，T2的总权值为W2
- 如果W1 < W2，则T2不是最小生成树（矛盾）
- 如果W1 > W2，则T1不是最小生成树（矛盾）
- 因此W1 = W2

**结论：** 陈述I是正确的。✓

**陈述II：所有权值最小的边一定会出现在所有的最小生成树中**

**分析：**
这个陈述是错误的。最小权值的边不一定都出现在所有MST中。

**反例：**
考虑以下图：
```
    A
   / \
  1   1
 /     \
B-------C
    1
```

所有边的权值都是1（都是最小权值）。
- MST1：A-B, A-C（总权值=2）
- MST2：A-B, B-C（总权值=2）
- MST3：A-C, B-C（总权值=2）

在MST1中，边B-C没有出现；在MST2中，边A-C没有出现；在MST3中，边A-B没有出现。

因此，不是所有最小权值的边都出现在所有MST中。

**更清晰的例子：**
考虑一个三角形，三条边权值都是1：
```
    A
   / \
  1   1
 /     \
B---1---C
```

可能的MST：
- MST1：A-B, A-C（不包含B-C）
- MST2：A-B, B-C（不包含A-C）
- MST3：A-C, B-C（不包含A-B）

**结论：** 陈述II是错误的。✗

**陈述III：使用Prim算法从不同顶点开始的最小生成树一定相同**

**分析：**
这个陈述是错误的。Prim算法从不同顶点开始可能得到不同的MST。

**原因：**
Prim算法是贪心算法，每一步选择连接已选顶点和未选顶点且权值最小的边。当存在多条权值相同的边时，选择顺序可能不同，导致结果不同。

**反例：**
考虑以下图：
```
    A
   / \
  1   1
 /     \
B---1---C
```

从A开始Prim算法：
- 选择A，连接A-B（权值1）或A-C（权值1），假设选择A-B
- 选择B，连接B-C（权值1）
- 得到MST：A-B, B-C

从B开始Prim算法：
- 选择B，连接B-A（权值1）或B-C（权值1），假设选择B-A
- 选择A，连接A-C（权值1）
- 得到MST：B-A, A-C

两个MST不同。

**结论：** 陈述III是错误的。✗

**陈述IV：使用Prim和Kruskal算法得到的最小生成树总不相同**

**分析：**
这个陈述是错误的。Prim算法和Kruskal算法可能得到相同的MST。

**原因：**
虽然Prim和Kruskal算法的实现方式不同，但它们都是寻找最小生成树的算法。当图只有唯一的最小生成树时，两种算法会得到相同的结果。

**反例：**
考虑一个图，所有边的权值都不同：
```
    A
   / \
  1   3
 /     \
B---2---C
```

- Prim算法（从A开始）：A-B(1), B-C(2)，总权值=3
- Kruskal算法：按权值排序，选择A-B(1), B-C(2)，总权值=3

两种算法得到相同的MST。

**结论：** 陈述IV是错误的。✗

#### 综合判断

- **陈述I**：正确 ✓
- **陈述II**：错误 ✗
- **陈述III**：错误 ✗
- **陈述IV**：错误 ✗

因此，只有陈述I是正确的，答案为**A. 仅I**。

#### 深入理解

**最小生成树的唯一性：**

1. **代价唯一性**：所有MST的总权值（代价）是唯一的
2. **结构不唯一性**：MST的结构（边的选择）可能不唯一
3. **唯一MST的条件**：当图中所有边的权值都不同时，MST是唯一的

**最小权值边的性质：**

- 最小权值的边不一定都出现在所有MST中
- 只有当最小权值的边不形成环时，它们才会全部出现在MST中
- 如果最小权值的边形成环，则只能选择其中的一部分

**Prim算法与Kruskal算法的比较：**

| 特性 | Prim算法 | Kruskal算法 |
|------|---------|------------|
| 起始点 | 从任意顶点开始 | 不需要起始点 |
| 选择策略 | 连接已选和未选顶点的最小边 | 全局最小边（不形成环） |
| 结果 | 可能因起始点不同而不同 | 结果唯一（如果MST唯一） |
| 时间复杂度 | O(V²)或O(E log V) | O(E log E) |

**关键点：**
- 两种算法都是正确的，都能找到最小生成树
- 当存在多个MST时，两种算法可能得到不同的结果
- 当MST唯一时，两种算法得到相同的结果

## 9. 最小生成树算法选择差异

### 题目

求下图的最小生成树时，可能是Kruskal算法第2次选中但不是Prim算法（从V4开始）第2次选中的边是（）。

**图的结构（无向图）：**
- 顶点：V1, V2, V3, V4
- 边及权值：
  - (V1,V4) 权值5
  - (V1,V3) 权值8
  - (V2,V3) 权值8
  - (V3,V4) 权值8
  - (V1,V2) 权值10
  - (V2,V4) 权值11

A. (V2,V3)

B. (V1,V3)

C. (V1,V4)

D. (V3,V4)

### 答案

**A. (V2,V3)**

### 详细解析

#### 知识点回顾

**Kruskal算法：**
- 按边权值从小到大排序
- 依次选择不形成环的边
- **关键特点**：选择边时只考虑全局最小权值和是否形成环，不要求边与已选边相邻

**Prim算法：**
- 从起始顶点开始，逐步扩展最小生成树
- 每次选择连接**已选顶点**和**未选顶点**且权值最小的边
- **关键特点**：选择边时要求边的一端在已选顶点集合中，另一端在未选顶点集合中

#### Kruskal算法第2次可能选择的边

**步骤1：按权值排序所有边**
- (V1,V4) 权值5
- (V1,V3) 权值8
- (V2,V3) 权值8
- (V3,V4) 权值8
- (V1,V2) 权值10
- (V2,V4) 权值11

**步骤2：第1次选择**
- 选择权值最小的边：(V1,V4) 权值5
- 当前生成树：包含顶点 {V1, V4}，边 {(V1,V4)}

**步骤3：第2次选择**
- 从剩余边中选择权值最小的边，且不形成环
- 权值为8的边有3条：(V1,V3), (V2,V3), (V3,V4)

**分析每条权值为8的边：**

1. **(V1,V3) 权值8**
   - 连接V1（已在树中）和V3（不在树中）
   - 不形成环 ✓
   - **可能被Kruskal第2次选中**

2. **(V2,V3) 权值8**
   - 连接V2（不在树中）和V3（不在树中）
   - 不形成环（因为V2和V3都不在树中，这条边会形成一个新的连通分量）
   - **可能被Kruskal第2次选中**

3. **(V3,V4) 权值8**
   - 连接V3（不在树中）和V4（已在树中）
   - 不形成环 ✓
   - **可能被Kruskal第2次选中**

**结论：** Kruskal算法第2次可能选择的边有：(V1,V3), (V2,V3), (V3,V4)

#### Prim算法（从V4开始）第2次可能选择的边

**步骤1：初始化**
- 起始顶点：V4
- 已选顶点集合：{V4}
- 未选顶点集合：{V1, V2, V3}

**步骤2：第1次选择**
- 从连接V4和未选顶点的边中选择权值最小的边
- 候选边：
  - (V1,V4) 权值5
  - (V3,V4) 权值8
  - (V2,V4) 权值11
- 选择 (V1,V4) 权值5
- 当前生成树：包含顶点 {V4, V1}，边 {(V1,V4)}

**步骤3：第2次选择**
- 已选顶点集合：{V4, V1}
- 未选顶点集合：{V2, V3}
- 从连接已选顶点{V4, V1}和未选顶点{V2, V3}的边中选择权值最小的边

**候选边分析：**

1. **(V1,V3) 权值8**
   - 连接V1（已选）和V3（未选）✓
   - **可能被Prim第2次选中**

2. **(V3,V4) 权值8**
   - 连接V4（已选）和V3（未选）✓
   - **可能被Prim第2次选中**

3. **(V1,V2) 权值10**
   - 连接V1（已选）和V2（未选）✓
   - 但权值大于8，不会被选择

4. **(V2,V4) 权值11**
   - 连接V4（已选）和V2（未选）✓
   - 但权值大于8，不会被选择

5. **(V2,V3) 权值8**
   - 连接V2（未选）和V3（未选）✗
   - **问题**：V2和V3都不在已选顶点集合中
   - Prim算法要求边的一端在已选集合，另一端在未选集合
   - **不可能被Prim第2次选中**

**结论：** Prim算法（从V4开始）第2次可能选择的边有：(V1,V3) 或 (V3,V4)，但**不可能**选择 (V2,V3)

#### 综合判断

**满足条件的边：**
- 可能是Kruskal算法第2次选中 ✓
- 但不是Prim算法（从V4开始）第2次选中 ✓

**检查各选项：**

- **选项A：(V2,V3)**
  - Kruskal第2次可能选中 ✓
  - Prim第2次不可能选中 ✓
  - **满足条件** ✓

- **选项B：(V1,V3)**
  - Kruskal第2次可能选中 ✓
  - Prim第2次也可能选中 ✗
  - 不满足条件

- **选项C：(V1,V4)**
  - Kruskal第1次选中（不是第2次）✗
  - Prim第1次选中（不是第2次）✗
  - 不满足条件

- **选项D：(V3,V4)**
  - Kruskal第2次可能选中 ✓
  - Prim第2次也可能选中 ✗
  - 不满足条件

因此，答案为**A. (V2,V3)**。

#### 深入理解

**Kruskal与Prim算法的关键区别：**

| 特性 | Kruskal算法 | Prim算法 |
|------|------------|---------|
| **选择范围** | 全局所有边 | 连接已选和未选顶点的边 |
| **约束条件** | 不形成环 | 一端在已选集合，另一端在未选集合 |
| **独立性** | 边可以独立选择（只要不成环） | 边必须与当前生成树相邻 |

**为什么(V2,V3)可能被Kruskal第2次选中？**

- Kruskal算法按全局权值排序选择边
- (V2,V3)权值为8，是最小的未选边之一
- 虽然V2和V3都不在已选集合中，但Kruskal允许选择这样的边（只要不形成环）
- 选择(V2,V3)后，会形成一个新的连通分量，不会与已有的{V1,V4}形成环

**为什么(V2,V3)不可能被Prim第2次选中？**

- Prim算法要求边必须连接已选顶点和未选顶点
- 第2次选择时，已选集合是{V4, V1}，未选集合是{V2, V3}
- (V2,V3)的两端都在未选集合中，不符合Prim算法的选择条件
- Prim算法只能选择(V1,V3)或(V3,V4)这样的边

**解题技巧：**

1. **对于Kruskal算法**：关注全局最小权值边，只要不形成环即可选择
2. **对于Prim算法**：关注连接已选和未选顶点的边，选择其中权值最小的
3. **对比两种算法**：找出满足"可能被Kruskal选中但不可能被Prim选中"的边

## 10. Kruskal算法边选取顺序

### 题目

已知无向图G如下所示，使用Kruskal算法求图G的最小生成树，加到最小生成树中的边依次是()。

**图的信息概述：**
- 顶点：a, b, c, d, e, f
- 边及权值：
  - (b,f)=5, (b,d)=6, (d,f)=7
  - (a,e)=9, (c,e)=10, (b,e)=11
  - (a,c)=12, (e,d)=14, (c,d)=18
  - (a,b)=20

选项（以边加入次序表示）：

A. bf, bd, ae, ce, be  
B. bf, bd, be, ae, ce  
C. ae, be, ce, bd, bf  
D. ae, ce, be, bf, bd

### 答案

**A. bf, bd, ae, ce, be**

### 详细解析

#### Kruskal算法回顾
- 按照边的权值从小到大排序
- 依次扫描每条边：若加入后不会在当前森林中形成环，则选用该边
- 当选用的边数达到顶点数-1时得到最小生成树

#### 具体步骤

1. **排序边权**：5, 6, 7, 9, 10, 11, 12, 14, 18, 20

2. **依次判断**  
   - **(b,f)=5**：必选，MST边集 = {bf}  
   - **(b,d)=6**：连接d，MST边集 = {bf, bd}  
   - **(d,f)=7**：d和f已在同一连通块，形成环，跳过  
   - **(a,e)=9**：新连通块 {a,e}，加入 → {bf, bd, ae}  
   - **(c,e)=10**：连接c到{a,e}，加入 → {bf, bd, ae, ce}  
   - **(b,e)=11**：把{b,d,f}与{a,c,e}连接起来，加入 → {bf, bd, ae, ce, be}  
   - 其余边即使继续检查也会形成环或不需要

3. **终止条件**  
   - 图有6个顶点，MST需要5条边  
   - 当前边集恰好5条，算法结束

#### 选项比较
- A 顺序：bf → bd → ae → ce → be，与上述过程一致 ✓
- B 顺序把 be 提前于 ae，违反权值排序 ✗
- C、D 以较大权值的边开头，与Kruskal流程不符 ✗

#### 总结
按照权值排序并逐条判断是否成环，可以唯一确定加入顺序为 **bf, bd, ae, ce, be**。

## 总结

### 题目1的关键点
- 理解无向图连通性与边数的关系
- 掌握"n个顶点的连通图至少需要n-1条边"这一基本定理
- 能够通过反例排除错误选项

### 题目2的关键点
- 熟练掌握握手定理：Σ(deg(v)) = 2|E|
- 在约束条件下（其他顶点度 < 3），通过最大化其他顶点的度来最小化顶点总数
- 理解"至少"的含义，需要找到满足条件的最小值

### 题目3的关键点
- 握手定理的应用：所有顶点度数之和 = 2|E|，一定是偶数
- 区分"至少"和"大于"：连通图至少需要n-1条边，可以等于n-1
- 理解连通图不一定有度为1的顶点：完全图、环图等都是反例
- 掌握通过反例证明陈述错误的方法

### 题目4的关键点
- BFS使用队列数据结构实现
- BFS在边权值相等时可以找单源最短路径，在边权值不相等时不能
- BFS类似于树的层序遍历，而不是后序遍历
- 理解BFS与DFS的区别：BFS用队列（层序），DFS用栈（前序）

### 题目5的关键点
- BFS的核心原则：按层访问，同一层的顶点必须在下一层之前全部访问完
- 判断BFS序列的方法：验证层序性，检查是否违反"先访问完一层再访问下一层"的原则
- 理解BFS序列的特点：层序性、同层顺序可任意、起始顶点可任意
- 掌握通过逐层分析验证BFS序列正确性的方法

### 题目6的关键点
- DFS的核心原则：尽可能深地访问路径，然后回溯
- 判断DFS序列的方法：验证相邻顶点之间是否有边（直接或通过回溯），检查是否符合深入-回溯模式
- 理解DFS序列的特点：深入优先、回溯机制、访问序列中相邻顶点要么有直接边要么通过回溯连接
- 掌握通过模拟DFS过程验证序列正确性的方法

### 题目7的关键点
- DFS序列个数取决于选择未访问邻居的顺序
- 当从一个顶点有多个未访问邻居时，不同的选择顺序会产生不同的序列
- 需要系统枚举所有可能的选择顺序
- 掌握通过树形结构枚举所有可能DFS序列的方法

### 题目8的关键点
- 最小生成树的代价（总权值）是唯一的，但结构可能不唯一
- 最小权值的边不一定都出现在所有MST中（如果形成环）
- Prim算法从不同顶点开始可能得到不同的MST
- Prim和Kruskal算法可能得到相同的MST（当MST唯一时）

### 题目9的关键点
- Kruskal算法按全局权值排序选边，只要不成环即可，不要求与现有生成树相邻
- Prim算法只能在"已选顶点→未选顶点"的边中挑选最小权值边
- 对比两种算法的候选边范围可以快速判断某条边能否在特定步骤被选中
- 理解两种算法的选择约束差异是解题关键

### 题目10的关键点
- Kruskal算法严格按照权值从小到大扫描，每条边都要做“是否成环”判断
- 同权边可能有多条，若其中一条导致成环就跳过，继续检查下一条
- 记录边被接受的次序时，要把被跳过的边也列入判断过程
- 终止条件是“已选边数 = 顶点数 - 1”，无需继续检查后续大权值的边

### 解题技巧
1. **对于连通性问题**：牢记"n个顶点至少需要n-1条边才能连通"
2. **对于度数问题**：使用握手定理建立方程
3. **对于最值问题**：在约束条件下，通过极值分析（最大化或最小化）来求解
4. **对于性质判断**：通过构造反例来证明陈述错误
5. **注意数学符号**：区分"≥"（至少）和">"（大于）的含义
6. **对于算法问题**：理解算法的适用条件和数据结构选择
7. **记忆遍历对应关系**：BFS=层序=队列，DFS=前序=栈
8. **对于BFS序列判断**：明确图的邻接关系，逐层验证访问顺序是否符合层序原则
9. **对于DFS序列判断**：明确图的邻接关系，模拟DFS过程，验证相邻顶点是否有边或通过回溯连接
10. **理解回溯机制**：DFS序列中相邻顶点可能没有直接边，但可以通过回溯解释
11. **对于DFS序列个数计算**：系统枚举所有可能的选择顺序，使用树形结构组织枚举过程
12. **对于MST性质**：牢记代价唯一性，理解结构可能不唯一，掌握通过反例证明的方法
13. **Prim vs Kruskal的步骤判断**：Prim受当前生成树限制，Kruskal只受不成环限制，比较候选边集合可以快速定位答案
14. **Kruskal边序推断**：列出全部边的升序列表，逐条分析是否成环并记录被接纳的先后顺序
