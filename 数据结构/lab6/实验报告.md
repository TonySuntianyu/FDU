## 二、题目一：岛屿的周长总和

### 2.1 问题分析

给定一个 m×n 的网格，其中 1 表示陆地，0 表示海洋。需要计算所有岛屿的周长总和。每个岛屿的周长定义为该岛屿所有陆地格子中，与海洋（或网格边界）相邻的边的总数。

### 2.2 算法设计思路

**核心思想**：对于每个陆地格子，检查其上下左右四个方向，如果相邻位置是海洋或超出边界，则该边计入周长。

**算法步骤**：
1. 遍历网格中的每个格子
2. 如果当前格子是陆地（值为1），检查其四个方向（上、下、左、右）
3. 对于每个方向，如果相邻位置超出边界或是海洋（值为0），则周长加1
4. 累加所有陆地格子的周长贡献

### 2.3 关键代码实现

**Java版本**：
```java
// 定义四个方向：上、下、左、右
int[] dx = {-1, 1, 0, 0};
int[] dy = {0, 0, -1, 1};

// 遍历网格中的每个格子
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (grid[i][j] == 1) {
            // 检查四个方向
            for (int k = 0; k < 4; k++) {
                int newX = i + dx[k];
                int newY = j + dy[k];
                
                // 如果相邻位置超出边界或是海洋，则该边计入周长
                if (newX < 0 || newX >= m || newY < 0 || newY >= n || grid[newX][newY] == 0) {
                    totalPerimeter++;
                }
            }
        }
    }
}
```

### 2.4 复杂度分析

- **时间复杂度**：O(m×n)，需要遍历网格中的每个格子，每个格子检查4个方向，总操作数为 4×m×n，因此时间复杂度为 O(m×n)
- **空间复杂度**：O(m×n)，用于存储网格数据

### 2.5 涉及的知识点

1. **二维数组遍历**：使用双重循环遍历网格
2. **方向数组**：使用方向数组（dx, dy）来简化四个方向的遍历
3. **边界检查**：判断坐标是否超出网格边界
4. **网格问题**：典型的网格遍历问题，不需要使用DFS/BFS，直接遍历即可

## 三、题目二：消防局选址问题

### 3.1 问题分析

给定 n 个街区，通过双向道路连接，每条道路有确定的长度。需要找到消防局所在的街区，使得该街区到其他所有街区的最长距离（即该街区到所有其他街区的最短路径中的最大值）尽可能小。这是一个图论中的**图的中心**问题。如果图不连通（存在任意一对街区无法互达），则无法满足要求，输出 `-1`。

**关键概念**：
- **偏心率（Eccentricity）**：从节点 v 到其他所有节点的最短路径的最大值
- **图的中心（Center）**：偏心率最小的节点

### 3.2 算法设计思路

**核心思想**：使用Floyd-Warshall算法计算所有点对之间的最短路径，然后对于每个节点计算其偏心率，选择偏心率最小的节点。

**算法步骤**：
1. 使用Floyd-Warshall算法计算所有点对之间的最短路径
2. 对于每个节点 i，计算其偏心率：`eccentricity[i] = max(dist[i][j])`，其中 j ≠ i
3. 选择偏心率最小的节点，如果有多个，选择编号最小的

### 3.3 Floyd-Warshall算法详解

Floyd-Warshall算法是动态规划算法，用于计算所有点对之间的最短路径。

**算法原理**：
- 设 `dist[i][j]` 表示从节点 i 到节点 j 的最短路径长度
- 对于每个中间节点 k，尝试通过 k 来缩短 i 到 j 的距离
- 状态转移方程：`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

**算法步骤**：
1. 初始化距离矩阵：如果存在直接边，距离为边权；否则为无穷大；节点到自身为0
2. 三重循环：对于每个中间节点 k，更新所有点对 (i, j) 的最短距离

### 3.4 关键代码实现

**Java版本**：
```java
// Floyd-Warshall算法的核心：三重循环
for (int k = 0; k < n; k++) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            // 如果通过节点k可以缩短i到j的距离
            if (dist[i][k] != Integer.MAX_VALUE && 
                dist[k][j] != Integer.MAX_VALUE &&
                dist[i][k] + dist[k][j] < dist[i][j]) {
                dist[i][j] = dist[i][k] + dist[k][j];
            }
        }
    }
}

// 计算每个节点的偏心率
for (int i = 0; i < n; i++) {
    int eccentricity = 0;
    for (int j = 0; j < n; j++) {
        if (i != j && dist[i][j] > eccentricity) {
            eccentricity = dist[i][j];
        }
    }
    // 选择偏心率最小的节点
    if (eccentricity < minEccentricity) {
        minEccentricity = eccentricity;
        optimalNode = i;
    }
}
```

- 节点1的偏心率最小，因此选择节点1

## 四、题目三：连接所有城市的最低成本

### 4.1 问题分析

给定 n 个城市，一些城市之间可以修建双向公路，每条公路有修建成本。需要通过修建公路使所有城市连通，且总费用最低。这是一个经典的**最小生成树（MST）**问题。

**关键点**：
- 如果图不连通，无法使所有城市连通，输出 -1
- 需要找到连接所有节点的最小成本边集

### 4.2 算法设计思路

**核心思想**：使用Kruskal算法求解最小生成树，结合并查集（Union-Find）来判断是否形成环。

**Kruskal算法步骤**：
1. 将所有边按权重（成本）从小到大排序
2. 依次选择权重最小的边，如果该边的两个端点不在同一个连通分量中，则加入MST
3. 使用并查集来高效判断两个节点是否在同一个连通分量中
4. 如果最终MST包含 n-1 条边，则所有城市连通，输出总成本；否则输出 -1

### 4.3 并查集（Union-Find）详解

并查集是一种树型数据结构，用于处理一些不交集的合并及查询问题。

**核心操作**：
1. **Find(x)**：查找节点 x 的根节点（带路径压缩优化）
2. **Union(x, y)**：合并节点 x 和 y 所在的集合（按秩合并优化）

**优化技术**：
- **路径压缩**：在查找根节点时，将路径上的所有节点直接指向根节点，降低树的高度
- **按秩合并**：总是将秩小的树合并到秩大的树下，保持树的平衡

### 4.4 关键代码实现

**Java版本**：
```java
// 并查集类
static class UnionFind {
    private int[] parent;
    private int[] rank;
    
    // 查找根节点（带路径压缩）
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }
    
    // 合并两个集合（按秩合并）
    boolean union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) {
            return false; // 已在同一集合中
        }
        
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        
        return true;
    }
}

// Kruskal算法主流程
private static int kruskalMST(List<Edge> edges, int n) {
    // 按边的权重排序
    edges.sort((e1, e2) -> Integer.compare(e1.cost, e2.cost));
    
    UnionFind uf = new UnionFind(n);
    int totalCost = 0;
    int edgeCount = 0;
    
    for (Edge edge : edges) {
        // 如果两个端点不在同一连通分量中
        if (uf.union(edge.from, edge.to)) {
            totalCost += edge.cost;
            edgeCount++;
            
            // 已加入n-1条边，所有节点连通
            if (edgeCount == n - 1) {
                break;
            }
        }
    }
    
    // 如果边数少于n-1，图不连通
    if (edgeCount < n - 1) {
        return -1;
    }
    
    return totalCost;
}
```

**C++版本**：
```cpp
// 边结构体
struct Edge {
    int from, to, cost;
    Edge(int f, int t, int c) : from(f), to(t), cost(c) {}
    bool operator<(const Edge& other) const {
        return cost < other.cost;
    }
};

// 并查集类
class UnionFind {
private:
    vector<int> parent;
    vector<int> rank;
    
public:
    UnionFind(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return false;
        
        // 按秩合并
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        return true;
    }
};

// Kruskal算法主流程
int kruskalMST(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end()); // 排序
    UnionFind uf(n);
    int totalCost = 0, edgeCount = 0;
    
    for (const Edge& edge : edges) {
        if (uf.unite(edge.from, edge.to)) {
            totalCost += edge.cost;
            edgeCount++;
            if (edgeCount == n - 1) break;
        }
    }
    
    return (edgeCount < n - 1) ? -1 : totalCost;
}
```

**C++版本关键差异**：
- 使用 `struct` 定义边，重载 `<` 运算符用于排序
- 使用 `vector<Edge>` 代替 `List<Edge>`
- 使用 `sort(edges.begin(), edges.end())` 代替 `edges.sort()`
- 并查集的合并方法命名为 `unite`（C++常用命名）
- 需要包含 `<algorithm>` 头文件用于排序

### 4.5 复杂度分析

- **时间复杂度**：O(m×log m)，其中 m 是边的数量。主要时间消耗在排序上（O(m×log m)），Kruskal算法本身的时间复杂度为 O(m×α(n))，其中 α 是阿克曼函数的反函数，在实际应用中可视为常数
- **空间复杂度**：O(n)，用于并查集的 parent 和 rank 数组

### 4.6 涉及的知识点

1. **最小生成树（MST）**：连接所有节点的最小权重边集
2. **Kruskal算法**：贪心算法，按边权重从小到大选择边
3. **并查集（Union-Find）**：高效的数据结构，用于判断图的连通性
4. **路径压缩**：并查集的优化技术，降低查找时间复杂度
5. **按秩合并**：并查集的优化技术，保持树的平衡
6. **贪心算法**：Kruskal算法是贪心算法的典型应用
