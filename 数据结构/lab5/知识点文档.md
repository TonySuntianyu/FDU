# Lab5 知识点文档

## 一、二叉树（Binary Tree）

### 1.1 基本概念

**二叉树**是一种重要的树形数据结构，每个节点最多有两个子节点，分别称为**左子节点**和**右子节点**。

```
       A          ← 根节点
      / \
     B   C        ← A的子节点
    / \   \
   D   E   F      ← 叶子节点
```

**术语定义：**
- **节点（Node）**：树中的基本元素，包含数据和指向子节点的指针
- **根节点（Root）**：树的顶层节点，没有父节点
- **叶子节点（Leaf）**：没有子节点的节点
- **内部节点（Internal Node）**：有至少一个子节点的节点
- **深度（Depth）**：从根节点到该节点的路径长度
- **高度（Height）**：从该节点到最深叶子节点的路径长度

### 1.2 二叉树的性质

1. **第 i 层最多有 2^i 个节点**
2. **深度为 h 的二叉树最多有 2^h - 1 个节点**
3. **具有 n 个节点的完全二叉树，高度为 ⌊log₂n⌋ + 1**
4. **对于任意二叉树，叶子节点数 = 度为2的节点数 + 1**

## 二、二叉树的遍历（Tree Traversal）

### 2.1 三种基本遍历方式

二叉树的遍历是指按照某种规则访问树中的每个节点，且每个节点只访问一次。

#### 前序遍历（Preorder Traversal）：根 → 左 → 右

**遍历规则：**
1. 访问根节点
2. 前序遍历左子树
3. 前序遍历右子树

**示例：**
```
       A
      / \
     B   C
    / \   \
   D   E   F
```
前序遍历结果：`A B D E C F`

**应用场景：** 复制二叉树、计算前缀表达式

#### 中序遍历（Inorder Traversal）：左 → 根 → 右

**遍历规则：**
1. 中序遍历左子树
2. 访问根节点
3. 中序遍历右子树

**示例：**
```
       A
      / \
     B   C
    / \   \
   D   E   F
```
中序遍历结果：`D B E A C F`

**应用场景：** 二叉搜索树的有序输出

#### 后序遍历（Postorder Traversal）：左 → 右 → 根

**遍历规则：**
1. 后序遍历左子树
2. 后序遍历右子树
3. 访问根节点

**示例：**
```
       A
      / \
     B   C
    / \   \
   D   E   F
```
后序遍历结果：`D E B F C A`

**应用场景：** 删除二叉树、计算后缀表达式

### 2.2 遍历的递归实现

```cpp
// 前序遍历
void preorder(TreeNode* root) {
    if (root == nullptr) return;
    visit(root);              // 访问根节点
    preorder(root->left);     // 遍历左子树
    preorder(root->right);    // 遍历右子树
}

// 中序遍历
void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);      // 遍历左子树
    visit(root);              // 访问根节点
    inorder(root->right);     // 遍历右子树
}

// 后序遍历
void postorder(TreeNode* root) {
    if (root == nullptr) return;
    postorder(root->left);    // 遍历左子树
    postorder(root->right);   // 遍历右子树
    visit(root);              // 访问根节点
}
```

### 2.3 遍历的非递归实现（迭代法）

可以使用栈（Stack）来实现非递归遍历：

```cpp
// 前序遍历（迭代）
void preorderIterative(TreeNode* root) {
    stack<TreeNode*> stk;
    if (root) stk.push(root);
    
    while (!stk.empty()) {
        TreeNode* node = stk.top();
        stk.pop();
        visit(node);
        
        // 注意：先压入右子树，再压入左子树
        // 这样出栈时是左子树先出
        if (node->right) stk.push(node->right);
        if (node->left) stk.push(node->left);
    }
}
```

## 三、根据遍历序列重建二叉树

### 3.1 理论基础

**重要结论：**
- **中序遍历 + 前序遍历** 可以唯一确定一棵二叉树
- **中序遍历 + 后序遍历** 可以唯一确定一棵二叉树
- **前序遍历 + 后序遍历** **不能**唯一确定一棵二叉树（除非是满二叉树）

**原因分析：**
- 中序遍历能够区分左右子树（根节点在中间）
- 前序/后序遍历能够确定根节点（前序的第一个，后序的最后一个）

### 3.2 重建算法

#### 方法：递归分割

**给定前序遍历和中序遍历：**

```
前序：C B A D E F C H G
中序：A B E D F C H G C

步骤：
1. 前序第一个字符 C 是根节点
2. 在中序中找到 C 的位置（索引8）
3. 左子树中序：A B E D F C H G（索引0-7）
4. 右子树中序：（索引9之后为空，所以无右子树）
5. 左子树前序：B A D E F C H G（从位置1开始，长度8）
6. 递归处理左右子树
```

**算法模板：**
```cpp
TreeNode* buildTree(string preorder, string inorder) {
    if (preorder.empty()) return nullptr;
    
    // 1. 确定根节点
    char rootVal = preorder[0];
    
    // 2. 在中序中找到根节点位置
    int rootIndex = inorder.find(rootVal);
    
    // 3. 分割左右子树
    string leftInorder = inorder.substr(0, rootIndex);
    string rightInorder = inorder.substr(rootIndex + 1);
    string leftPreorder = preorder.substr(1, leftInorder.length());
    string rightPreorder = preorder.substr(1 + leftInorder.length());
    
    // 4. 递归构建
    TreeNode* root = new TreeNode(rootVal);
    root->left = buildTree(leftPreorder, leftInorder);
    root->right = buildTree(rightPreorder, rightInorder);
    
    return root;
}
```

**时间复杂度：** O(n²)
- 每次递归需要 O(n) 时间在中序序列中查找根节点
- 可以使用哈希表优化到 O(n)

## 四、最近公共祖先（LCA - Lowest Common Ancestor）

### 4.1 定义

**最近公共祖先（LCA）**是指在一棵树中，两个节点 `x` 和 `y` 的最近公共祖先是指：
- 同时是 `x` 与 `y` 的祖先的所有节点中
- **距离它们最近**（深度最大）的那个节点

**直观理解：**
- 从节点 `x` 和 `y` 分别向上走到根节点
- 第一个相交的祖先节点就是它们的 LCA

```
        A
       / \
      B   C
     / \ / \
    D  E F  G

节点 D 和 E 的 LCA：B
节点 D 和 F 的 LCA：A
节点 F 和 G 的 LCA：C
```

### 4.2 LCA 查询算法

#### 方法1：向上遍历法（本实验使用）

**适用场景：** 每个节点都有指向父节点的指针

**算法步骤：**
1. 从节点 `x` 向上遍历到根节点，记录所有祖先节点到集合中
2. 从节点 `y` 向上遍历，找到第一个出现在集合中的节点，即为 LCA

**时间复杂度：** O(h)，其中 h 是树的高度

```cpp
char findLCA(TreeNode* root, char x, char y) {
    TreeNode* nodeX = findNode(root, x);
    TreeNode* nodeY = findNode(root, y);
    
    // 记录 x 的所有祖先
    set<TreeNode*> ancestors;
    TreeNode* curr = nodeX;
    while (curr != nullptr) {
        ancestors.insert(curr);
        curr = curr->parent;
    }
    
    // 从 y 向上找第一个公共祖先
    curr = nodeY;
    while (curr != nullptr) {
        if (ancestors.find(curr) != ancestors.end()) {
            return curr->val;  // 找到 LCA
        }
        curr = curr->parent;
    }
    
    return '\0';  // 不存在
}
```

#### 方法2：递归法（无父节点指针）

**适用场景：** 没有父节点指针，需要从根节点开始查找

```cpp
TreeNode* findLCA(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (root == nullptr || root == p || root == q) {
        return root;
    }
    
    TreeNode* left = findLCA(root->left, p, q);
    TreeNode* right = findLCA(root->right, p, q);
    
    if (left != nullptr && right != nullptr) {
        return root;  // p 和 q 分别在左右子树，当前节点是 LCA
    }
    
    return left != nullptr ? left : right;  // 返回非空的那个
}
```

**时间复杂度：** O(n)

#### 方法3：Tarjan 算法（离线查询）

**适用场景：** 需要查询多对节点的 LCA

**时间复杂度：** O(n + q)，其中 q 是查询次数

#### 方法4：倍增法（在线查询）

**适用场景：** 需要快速在线查询多对节点的 LCA

**预处理时间复杂度：** O(n log n)
**单次查询时间复杂度：** O(log n)

**核心思想：** 预处理每个节点的 2^i 级祖先，然后使用二进制跳跃

## 五、递归（Recursion）

### 5.1 递归的基本概念

**递归**是一种函数直接或间接调用自身的方法。

**递归三要素：**
1. **递归终止条件**（Base Case）：防止无限递归
2. **递归关系**（Recurrence Relation）：将问题分解为更小的子问题
3. **递归调用**（Recursive Call）：调用自身处理子问题

### 5.2 递归在二叉树中的应用

**递归天然适合处理树结构：**
- 树的定义本身就是递归的（树由子树组成）
- 树的遍历、构建、查找都可以用递归实现

**示例：计算树的高度**
```cpp
int height(TreeNode* root) {
    if (root == nullptr) return 0;  // 终止条件
    return 1 + max(height(root->left), height(root->right));  // 递归关系
}
```

### 5.3 递归的优缺点

**优点：**
- 代码简洁、易于理解
- 适合处理递归定义的数据结构（如树、图）

**缺点：**
- 函数调用开销大
- 可能导致栈溢出（递归深度过大）
- 可能存在重复计算（如斐波那契数列的朴素递归）

**优化方法：**
- 尾递归优化
- 记忆化（Memoization）
- 迭代实现

## 六、字符串处理

### 6.1 C++ 字符串常用操作

**substr：提取子字符串**
```cpp
string str = "Hello World";
string sub1 = str.substr(0, 5);    // "Hello"（从位置0开始，长度5）
string sub2 = str.substr(6);       // "World"（从位置6到结尾）
```

**find：查找字符或子字符串**
```cpp
string str = "Hello World";
int pos1 = str.find('o');           // 返回4（第一个'o'的位置）
int pos2 = str.find("World");       // 返回6（"World"的开始位置）
int pos3 = str.find('x');           // 返回string::npos（未找到）
```

**length / size：获取字符串长度**
```cpp
string str = "Hello";
int len = str.length();             // 返回5
```

### 6.2 字符串在树重建中的应用

在根据遍历序列重建二叉树时，字符串操作用于：
- 提取根节点字符
- 分割左右子树的遍历序列
- 查找根节点在中序序列中的位置

## 七、时间复杂度和空间复杂度分析

### 7.1 题目1的复杂度分析

**时间复杂度：O(n²)**
- 递归深度：O(log n) 到 O(n)（取决于树的平衡度）
- 每次递归需要 O(n) 时间在中序序列中查找根节点
- 总时间复杂度：O(n²)

**空间复杂度：O(n)**
- 递归调用栈深度：O(log n) 到 O(n)
- 字符串操作的空间开销：O(n)

**优化方法：**
- 使用哈希表预存中序序列位置：时间复杂度降为 O(n)

### 7.2 题目2的复杂度分析

**时间复杂度：O(n²)**
- 构建树：O(n²)（每个节点需要在中序序列中查找）
- 查找节点：O(n)（最坏情况）
- 查找LCA：O(h)（h为树高）
- 总体：O(n²)

**空间复杂度：O(n)**
- 存储整个二叉树：O(n)
- 递归栈：O(h)
- ancestors 集合：O(h)

## 八、内存管理

### 8.1 动态内存分配

**使用 new 分配：**
```cpp
TreeNode* node = new TreeNode('A');
```

**使用 delete 释放：**
```cpp
delete node;
```

### 8.2 二叉树的内存释放

**递归释放整个树：**
```cpp
void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);   // 先释放左子树
    deleteTree(root->right);  // 再释放右子树
    delete root;              // 最后释放根节点
}
```

**注意：** 必须使用后序遍历顺序释放，确保子节点先于父节点被释放。

### 8.3 内存泄漏预防

**常见错误：**
- 只删除根节点，不删除子树
- 忘记删除动态分配的内存

**最佳实践：**
- 使用智能指针（如 `shared_ptr`、`unique_ptr`）
- 成对使用 new/delete
- 在析构函数中释放资源
