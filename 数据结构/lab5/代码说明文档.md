# Lab5 代码说明文档

## 题目1：奶牛的家谱Ⅰ - 代码说明

### 功能描述
给定二叉树的中序遍历和前序遍历序列，输出该二叉树的后序遍历序列。

### 核心算法：递归构建二叉树

#### 函数：`buildPostOrder`
```cpp
void buildPostOrder(string preorder, string inorder, string& postorder)
```

**参数说明：**
- `preorder`: 前序遍历序列
- `inorder`: 中序遍历序列
- `postorder`: 用于存储后序遍历结果的字符串（引用传递）

**算法步骤：**

1. **确定根节点**
   - 前序遍历的第一个元素就是二叉树的根节点
   - 例如：前序 `CBADEFGH` 中，`C` 是根节点

2. **在中序序列中定位根节点**
   - 在中序遍历中找到根节点的位置
   - 根节点将中序序列分为左子树和右子树两部分
   - 例如：中序 `ABEDFCHG`，找到 `C` 后，左子树为 `ABEDF`，右子树为 `HG`

3. **分割左右子树**
   - **左子树**：
     - 中序遍历：从开始到根节点位置之前
     - 前序遍历：从第二个字符开始，长度为左子树节点数
   - **右子树**：
     - 中序遍历：从根节点位置之后到结束
     - 前序遍历：左子树之后的剩余部分

4. **递归处理**
   - 递归处理左子树，得到左子树的后序遍历
   - 递归处理右子树，得到右子树的后序遍历
   - 最后将根节点添加到结果中（后序遍历：左-右-根）

**示例分析（样例1）：**
```
中序：ABEDFCHG
前序：CBADEFGH

步骤：
1. 根节点：C
2. 中序中C的位置：5，左子树中序：ABEDF，右子树中序：HG
3. 左子树前序：BADEF（从位置1开始，长度5）
4. 右子树前序：GH（剩余部分）

递归处理左子树（前序：BADEF，中序：ABEDF）：
  - 根节点：B
  - 左子树：A（前序：A，中序：A）
  - 右子树：EDF（前序：DEF，中序：EDF）
  - 继续递归...

最终后序遍历：AEFDBHGC
```

### 时间复杂度
- **O(n²)**：其中 n 是节点数
  - 每次递归需要在中序序列中查找根节点，最坏情况 O(n)
  - 递归深度为 O(log n) 到 O(n)（取决于树的平衡度）
  - 总时间复杂度：O(n²)

### 空间复杂度
- **O(n)**：递归调用栈的深度最多为树的高度

## 题目2：奶牛的家谱Ⅱ - 代码说明

### 功能描述
给定二叉树的前序遍历和中序遍历序列，以及两个节点名称，找出这两个节点的最近公共祖先（LCA）。

### 数据结构

#### TreeNode 结构体
```cpp
struct TreeNode {
    char val;           // 节点值（奶牛名称）
    TreeNode* left;     // 左子节点指针
    TreeNode* right;    // 右子节点指针
    TreeNode* parent;   // 父节点指针（用于向上遍历）
};
```

### 核心函数说明

#### 1. `buildTree` - 构建二叉树
```cpp
TreeNode* buildTree(string preorder, string inorder, TreeNode* parent)
```

**功能：** 根据前序遍历和中序遍历序列递归构建完整的二叉树结构。

**算法步骤：**
1. 从前序遍历序列的第一个字符获取根节点值
2. 在中序遍历序列中找到根节点的位置
3. 根据根节点位置分割左右子树的中序遍历序列
4. 分割左右子树的前序遍历序列
5. 递归构建左右子树，并设置父节点指针

**关键点：**
- 每个节点都保存了指向父节点的指针，便于向上遍历查找祖先

#### 2. `findNode` - 查找节点
```cpp
TreeNode* findNode(TreeNode* root, char val)
```

**功能：** 在二叉树中查找值为 `val` 的节点。

**算法：** 使用深度优先搜索（DFS）：
- 如果当前节点为空，返回 `nullptr`
- 如果当前节点的值匹配，返回当前节点
- 否则递归在左子树和右子树中查找

#### 3. `findLCA` - 查找最近公共祖先
```cpp
char findLCA(TreeNode* root, char node1, char node2)
```

**功能：** 查找两个节点的最近公共祖先。

**算法步骤（向上遍历法）：**

1. **查找两个节点**
   - 使用 `findNode` 函数在树中查找 `node1` 和 `node2`
   - 如果任一节点不存在，返回 `'\0'`（表示不存在，输出 "NA"）

2. **记录第一个节点的所有祖先**
   - 从 `node1` 开始，沿着 `parent` 指针向上遍历到根节点
   - 将所有经过的节点存入集合 `ancestors` 中

3. **查找第一个公共祖先**
   - 从 `node2` 开始，沿着 `parent` 指针向上遍历
   - 第一个出现在 `ancestors` 集合中的节点就是最近公共祖先
   - 返回该节点的值

**示例分析（样例1）：**
```
前序：ABDECFGH
中序：DBEAFCGH
查询：E 和 H

构建的树结构：
        A
       / \
      B   C
     /   / \
    D   F   G
     \       \
      E       H

查找过程：
1. 找到节点 E 和 H
2. E 的祖先路径：E -> D -> B -> A -> (root)
3. H 的祖先路径：H -> G -> C -> A -> (root)
4. 第一个公共祖先：A
5. 输出：A
```

#### 4. `deleteTree` - 释放内存
```cpp
void deleteTree(TreeNode* root)
```

**功能：** 递归释放整个二叉树的内存，防止内存泄漏。

**算法：** 后序遍历释放节点：
- 先释放左子树
- 再释放右子树
- 最后释放根节点

### 时间复杂度
- **构建树：** O(n²) - 每个节点需要在中序序列中查找位置
- **查找节点：** O(n) - 最坏情况需要遍历整个树
- **查找LCA：** O(h) - h 为树的高度，最多需要向上遍历两次
- **总体：** O(n²)

### 空间复杂度
- **O(n)** - 存储整个二叉树，递归栈深度为 O(h)

## 两个题目的对比

| 特性 | 题目1 | 题目2 |
|------|-------|-------|
| **需要构建完整树结构** | ❌ 否（只需输出序列） | ✅ 是（需要树结构查询） |
| **使用父节点指针** | ❌ 否 | ✅ 是 |
| **需要内存管理** | ❌ 否 | ✅ 是（需要释放） |
| **复杂度** | O(n²) | O(n²) |
| **主要算法** | 递归构建后序序列 | 递归构建树 + LCA查询 |

---

## 代码优化建议

1. **题目1优化：** 可以使用哈希表预存中序序列中每个字符的位置，将查找时间从 O(n) 降为 O(1)，总时间复杂度降为 O(n)

2. **题目2优化：** 同样可以使用哈希表优化中序序列查找，并且可以使用 Tarjan 算法或倍增法进一步优化 LCA 查询

3. **内存优化：** 对于固定大小的字符（只有26个大写字母），可以考虑使用数组代替动态分配
