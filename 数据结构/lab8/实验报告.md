# Lab8 实验报告：计算项目的关键路径

## 一、实验目的

1. 理解关键路径法（CPM, Critical Path Method）的基本原理
2. 掌握在带权有向无环图（DAG）中计算事件最早发生时间（TE）和最迟发生时间（TL）的方法
3. 实现关键路径的查找算法，确定项目的最短总工期
4. 熟练运用拓扑排序、动态规划等算法解决实际问题

## 二、问题描述

给定一个带权有向无环图（DAG），用于表示项目的事件-活动网络：
- **顶点**：代表事件，其中顶点 0 是项目的唯一起点事件，顶点 n-1 是项目的唯一终点事件
- **有向边**：代表活动，边的权重表示该活动的持续时间（正整数）
- **约束条件**：活动需遵循事件的先后关系，只有边的起点事件完成后，对应的活动才能开始，边的终点事件才能触发

### 任务要求

1. 计算每个事件的最早发生时间（TE）：从起点事件出发，该事件最早能完成的时间
2. 计算每个事件的最迟发生时间（TL）：在不延误项目总工期的前提下，该事件最晚能开始的时间
3. 输出唯一的关键路径（按事件先后顺序描述）及项目的最短总工期（即关键路径的总权重）

### 输入输出格式

**输入格式：**
- 第一行：两个整数 n 和 m，分别表示事件数（顶点数）和活动数（边数）
- 接下来 m 行：每行三个整数 u、v、t，表示一条从事件 u 到事件 v 的活动，其持续时间为 t

**输出格式：**
1. 第一行：TE₀ TE₁ ... TEₙ₋₁，其中 TEᵢ 表示事件 i 的最早发生时间
2. 第二行：TL₀ TL₁ ... TLₙ₋₁，其中 TLᵢ 表示事件 i 的最迟发生时间
3. 第三行：v₀ v₁ ... vₙ₋₁，其中 v₀, v₁, ..., vₙ₋₁ 是关键路径上的事件，按先后顺序排列
4. 第四行：X，其中 X 是项目的最短总工期

## 三、算法设计

### 3.1 算法思路

关键路径算法（CPM）的核心思想是：
1. **拓扑排序**：确定事件的处理顺序，确保在计算某个事件的时间时，其所有前驱事件的时间已经计算完成
2. **计算TE（最早发生时间）**：从起点开始，按照拓扑顺序，对于每个事件，其最早发生时间等于所有前驱事件的最早发生时间加上对应活动持续时间的最大值
3. **计算TL（最迟发生时间）**：从终点开始，按照逆拓扑顺序，对于每个事件，其最迟发生时间等于所有后继事件的最迟发生时间减去对应活动持续时间的最小值
4. **找出关键路径**：关键路径上的事件满足 TE[i] == TL[i]，即最早发生时间等于最迟发生时间的事件

### 3.2 算法步骤

```
1. 构建图结构（邻接表和反向图）
2. 计算每个顶点的入度
3. 执行拓扑排序，得到事件的处理顺序
4. 按照拓扑顺序计算TE：
   - TE[0] = 0（起点）
   - 对于每个事件u：TE[u] = max(TE[prev] + weight)，其中prev是u的所有前驱事件
5. 按照逆拓扑顺序计算TL：
   - TL[n-1] = TE[n-1]（终点）
   - 对于每个事件u：TL[u] = min(TL[next] - weight)，其中next是u的所有后继事件
6. 找出关键路径：遍历拓扑序列，找出所有满足TE[i] == TL[i]的事件
7. 输出结果
```

### 3.3 时间复杂度分析

- **拓扑排序**：O(n + m)，其中 n 是顶点数，m 是边数
- **计算TE**：O(n + m)，需要遍历所有顶点和边
- **计算TL**：O(n + m)，需要遍历所有顶点和边
- **找出关键路径**：O(n)，遍历所有顶点
- **总体时间复杂度**：O(n + m)

### 3.4 空间复杂度分析

- **图存储**：O(n + m)，邻接表和反向图
- **辅助数组**：O(n)，入度数组、TE数组、TL数组
- **拓扑序列**：O(n)
- **总体空间复杂度**：O(n + m)

## 四、数据结构设计

### 4.1 Edge 结构体

```cpp
struct Edge {
    int to;        // 目标顶点
    int weight;    // 边的权重（活动持续时间）
    
    Edge(int to, int weight) : to(to), weight(weight) {}
};
```

用于存储图中的边信息，包含目标顶点和边的权重。

### 4.2 主要数据结构

1. **graph**：`vector<vector<Edge>>`，正向邻接表，用于存储从每个顶点出发的边
2. **reverseGraph**：`vector<vector<Edge>>`，反向邻接表，用于快速查找指向某个顶点的所有边
3. **inDegree**：`vector<int>`，存储每个顶点的入度，用于拓扑排序
4. **topoOrder**：`vector<int>`，存储拓扑排序的结果
5. **TE**：`vector<int>`，存储每个事件的最早发生时间
6. **TL**：`vector<int>`，存储每个事件的最迟发生时间
7. **criticalPath**：`vector<int>`，存储关键路径上的事件

## 五、代码实现详解

### 5.1 图的构建

```cpp
// 构建图：邻接表存储边
vector<vector<Edge>> graph(n);
// 反向图：用于计算TE（最早发生时间）
vector<vector<Edge>> reverseGraph(n);
// 入度数组
vector<int> inDegree(n, 0);

// 读取边并构建图
for (int i = 0; i < m; i++) {
    int u, v, t;
    cin >> u >> v >> t;
    
    graph[u].push_back(Edge(v, t));
    reverseGraph[v].push_back(Edge(u, t));
    inDegree[v]++;
}
```

**说明**：
- 同时构建正向图和反向图，正向图用于计算TL和拓扑排序，反向图用于快速查找前驱事件以计算TE
- 在构建图的同时统计每个顶点的入度

### 5.2 拓扑排序

```cpp
// 1. 拓扑排序
vector<int> topoOrder;
queue<int> q;

// 找到所有入度为0的顶点（起点）
for (int i = 0; i < n; i++) {
    if (inDegree[i] == 0) {
        q.push(i);
    }
}

// 执行拓扑排序
while (!q.empty()) {
    int u = q.front();
    q.pop();
    topoOrder.push_back(u);
    
    for (const Edge& edge : graph[u]) {
        int v = edge.to;
        inDegree[v]--;
        if (inDegree[v] == 0) {
            q.push(v);
        }
    }
}
```

**说明**：
- 使用队列实现拓扑排序
- 将所有入度为0的顶点入队，然后依次处理，每处理一个顶点，将其所有邻接顶点的入度减1
- 当某个顶点的入度变为0时，将其入队
- 最终得到拓扑排序序列

### 5.3 计算最早发生时间（TE）

```cpp
// 2. 计算TE（最早发生时间）
vector<int> TE(n, 0);
// 起点事件的最早发生时间为0
TE[0] = 0;

// 按照拓扑顺序计算每个事件的最早发生时间
for (int u : topoOrder) {
    // 遍历所有指向u的边（在反向图中）
    for (const Edge& edge : reverseGraph[u]) {
        int prev = edge.to; // 前驱事件
        int weight = edge.weight; // 活动持续时间
        // TE[u] = max(所有前驱的TE + 对应边的权重)
        TE[u] = max(TE[u], TE[prev] + weight);
    }
}
```

**说明**：
- 起点事件的最早发生时间为0
- 按照拓扑顺序处理每个事件，确保在处理某个事件时，其所有前驱事件的最早发生时间已经计算完成
- 使用反向图快速找到所有指向当前事件的前驱事件
- 对于每个事件，其最早发生时间等于所有前驱事件的最早发生时间加上对应活动持续时间的最大值

### 5.4 计算最迟发生时间（TL）

```cpp
// 3. 计算TL（最迟发生时间）
vector<int> TL(n);
// 终点事件的最迟发生时间等于最早发生时间（项目总工期）
int totalDuration = TE[n - 1];
fill(TL.begin(), TL.end(), totalDuration);
TL[n - 1] = totalDuration;

// 按照逆拓扑顺序计算每个事件的最迟发生时间
for (int i = topoOrder.size() - 1; i >= 0; i--) {
    int u = topoOrder[i];
    // 遍历所有从u出发的边
    for (const Edge& edge : graph[u]) {
        int v = edge.to; // 后继事件
        int weight = edge.weight; // 活动持续时间
        // TL[u] = min(所有后继的TL - 对应边的权重)
        TL[u] = min(TL[u], TL[v] - weight);
    }
}
```

**说明**：
- 终点事件的最迟发生时间等于其最早发生时间（即项目总工期）
- 按照逆拓扑顺序处理每个事件，确保在处理某个事件时，其所有后继事件的最迟发生时间已经计算完成
- 对于每个事件，其最迟发生时间等于所有后继事件的最迟发生时间减去对应活动持续时间的最小值

### 5.5 找出关键路径

```cpp
// 4. 找出关键路径
vector<int> criticalPath;
// 关键路径上的事件满足：TE[i] == TL[i]
for (int u : topoOrder) {
    if (TE[u] == TL[u]) {
        criticalPath.push_back(u);
    }
}
```

**说明**：
- 关键路径上的事件满足：最早发生时间等于最迟发生时间
- 按照拓扑顺序遍历，确保关键路径上的事件按先后顺序排列

## 六、测试结果

### 6.1 测试用例

**输入：**
```
5 6
0 1 3
0 2 2
1 3 4
2 3 5
1 4 6
3 4 2
```

**输出：**
```
0 3 2 7 9
0 3 2 7 9

```

### 6.2 结果分析

1. **TE值**：`0 3 2 7 9`
   - 事件0（起点）：TE = 0
   - 事件1：TE = max(0+3) = 3
   - 事件2：TE = max(0+2) = 2
   - 事件3：TE = max(3+4, 2+5) = max(7, 7) = 7
   - 事件4（终点）：TE = max(3+6, 7+2) = max(9, 9) = 9

2. **TL值**：`0 3 2 7 9`
   - 事件4（终点）：TL = 9
   - 事件3：TL = min(9-2) = 7
   - 事件2：TL = min(7-5) = 2
   - 事件1：TL = min(7-4, 9-6) = min(3, 3) = 3
   - 事件0（起点）：TL = min(3-3, 2-2) = min(0, 0) = 0

3. **关键路径**：`0 1 3 4`
   - 所有满足 TE[i] == TL[i] 的事件：0, 1, 3, 4
   - 关键路径：0 → 1 → 3 → 4
   - 总工期：9
