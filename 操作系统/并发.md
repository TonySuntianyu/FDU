## 9. 并发（Concurrency）

### 9.1 并发基础

#### 并发的核心问题（基于Three Easy Pieces）
- **如何实现并发执行**：在单个进程中创建多个执行线程
- **如何协调线程访问**：使用同步机制协调线程访问共享资源
- **如何避免竞态条件**：防止多个线程同时修改共享数据
- **如何避免死锁**：防止多个线程相互等待造成的死锁
- **如何优化性能**：在安全性和性能之间找到平衡

#### 线程概念详解

##### 线程定义与特点
- **线程定义**：进程内的独立执行单元，拥有独立的栈和寄存器
- **线程组成**：线程ID、程序计数器、寄存器集合、栈
- **线程状态**：新建、就绪、运行、阻塞、终止
- **线程优势**：共享地址空间，创建开销小，切换速度快

##### 线程 vs 进程
- **资源开销**：线程创建和切换开销远小于进程
- **地址空间**：线程共享进程的地址空间，进程有独立地址空间
- **通信方式**：线程间通信简单，进程间通信复杂
- **安全性**：线程间相互影响，进程间相互隔离

##### 线程实现模型

###### 用户级线程（User-Level Threads）
- **实现方式**：在用户空间实现线程管理
- **优势**：切换速度快，不涉及内核态切换
- **劣势**：一个线程阻塞会导致整个进程阻塞
- **应用场景**：I/O密集型应用，需要大量线程的场景

###### 内核级线程（Kernel-Level Threads）
- **实现方式**：由操作系统内核管理线程
- **优势**：一个线程阻塞不影响其他线程
- **劣势**：切换开销大，需要系统调用
- **应用场景**：CPU密集型应用，需要真正并行执行

###### 混合模型（Hybrid Model）
- **多对多模型**：多个用户线程映射到多个内核线程
- **多对一模型**：多个用户线程映射到一个内核线程
- **一对一模型**：一个用户线程映射到一个内核线程

#### 线程创建和管理

##### 线程创建
```c
// POSIX线程创建示例
#include <pthread.h>

void* thread_function(void* arg) {
    printf("Thread ID: %lu\n", pthread_self());
    return NULL;
}

int main() {
    pthread_t thread;
    int result = pthread_create(&thread, NULL, thread_function, NULL);
    if (result != 0) {
        perror("pthread_create");
        return 1;
    }
    
    pthread_join(thread, NULL);  // 等待线程结束
    return 0;
}
```

##### 线程同步
- **线程等待**：pthread_join()等待线程结束
- **线程分离**：pthread_detach()分离线程
- **线程取消**：pthread_cancel()取消线程
- **线程退出**：pthread_exit()线程退出

### 9.2 同步机制

#### 锁（Locks）

##### 互斥锁（Mutex）
- **定义**：确保同一时间只有一个线程访问临界区
- **实现**：硬件原子操作或软件算法
- **使用场景**：保护共享数据，防止竞态条件
- **性能考虑**：锁竞争、锁粒度、锁开销

##### 读写锁（Reader-Writer Lock）
- **定义**：允许多个读者或一个写者
- **读者锁**：多个线程可以同时持有读者锁
- **写者锁**：只有一个线程可以持有写者锁
- **使用场景**：读多写少的场景

##### 自旋锁（Spinlock）
- **定义**：忙等待的锁，适用于短时间持有
- **实现**：CPU自旋等待锁释放
- **优势**：避免上下文切换开销
- **劣势**：浪费CPU时间

##### 条件变量（Condition Variables）
- **定义**：用于线程间的条件同步
- **操作**：wait、signal、broadcast
- **使用场景**：生产者-消费者问题
- **实现**：与互斥锁配合使用

##### 条件变量详细实现
```c
// 条件变量使用示例
#include <pthread.h>

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t condition = PTHREAD_COND_INITIALIZER;
int shared_data = 0;
int data_ready = 0;

// 生产者线程
void* producer(void* arg) {
    for (int i = 0; i < 10; i++) {
        pthread_mutex_lock(&mutex);
        shared_data = i;
        data_ready = 1;
        pthread_cond_signal(&condition);  // 通知消费者
        pthread_mutex_unlock(&mutex);
        sleep(1);
    }
    return NULL;
}

// 消费者线程
void* consumer(void* arg) {
    for (int i = 0; i < 10; i++) {
        pthread_mutex_lock(&mutex);
        while (!data_ready) {
            pthread_cond_wait(&condition, &mutex);  // 等待条件
        }
        printf("Consumed: %d\n", shared_data);
        data_ready = 0;
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}
```

##### 条件变量原理
- **等待队列**：条件变量维护一个等待队列
- **原子操作**：wait操作原子地释放锁并阻塞线程
- **唤醒机制**：signal唤醒一个等待线程，broadcast唤醒所有等待线程
- **虚假唤醒**：使用while循环检查条件，避免虚假唤醒

#### 信号量（Semaphores）

##### 信号量概念
- **计数信号量**：控制对有限资源的访问
- **二进制信号量**：类似互斥锁的二元信号量
- **信号量操作**：P操作（等待）和V操作（释放）
- **信号量应用**：生产者-消费者问题

##### 信号量实现
```c
// 信号量实现示例
#include <semaphore.h>

sem_t empty_slots;    // 空缓冲区数量
sem_t full_slots;     // 满缓冲区数量
sem_t mutex;          // 互斥信号量
int buffer[BUFFER_SIZE];
int in = 0, out = 0;

// 生产者
void* producer(void* arg) {
    for (int i = 0; i < 10; i++) {
        sem_wait(&empty_slots);  // P操作：等待空缓冲区
        sem_wait(&mutex);        // P操作：进入临界区
        buffer[in] = i;
        in = (in + 1) % BUFFER_SIZE;
        sem_post(&mutex);        // V操作：离开临界区
        sem_post(&full_slots);   // V操作：增加满缓冲区
    }
    return NULL;
}

// 消费者
void* consumer(void* arg) {
    for (int i = 0; i < 10; i++) {
        sem_wait(&full_slots);   // P操作：等待满缓冲区
        sem_wait(&mutex);        // P操作：进入临界区
        int item = buffer[out];
        out = (out + 1) % BUFFER_SIZE;
        sem_post(&mutex);        // V操作：离开临界区
        sem_post(&empty_slots);  // V操作：增加空缓冲区
        printf("Consumed: %d\n", item);
    }
    return NULL;
}
```

##### 信号量原理
- **原子操作**：P和V操作都是原子操作
- **阻塞机制**：P操作时如果资源不足则阻塞
- **唤醒机制**：V操作时唤醒等待的线程
- **计数机制**：信号量维护一个计数器

#### 管程（Monitors）

##### 管程概念
- **管程定义**：高级同步原语，封装共享数据
- **管程操作**：进入和退出管程的原子操作
- **条件变量**：管程内的条件同步机制
- **管程优势**：简化并发编程

##### 管程实现
```c
// 管程实现示例（Java风格）
class BoundedBuffer {
    private int[] buffer;
    private int count = 0;
    private int in = 0, out = 0;
    private final int size;
    
    public BoundedBuffer(int size) {
        this.size = size;
        this.buffer = new int[size];
    }
    
    public synchronized void put(int item) {
        while (count == size) {
            try {
                wait();  // 等待缓冲区有空间
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        buffer[in] = item;
        in = (in + 1) % size;
        count++;
        notifyAll();  // 通知等待的消费者
    }
    
    public synchronized int get() {
        while (count == 0) {
            try {
                wait();  // 等待缓冲区有数据
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        int item = buffer[out];
        out = (out + 1) % size;
        count--;
        notifyAll();  // 通知等待的生产者
        return item;
    }
}
```

##### 管程特性
- **互斥访问**：同一时间只有一个线程可以进入管程
- **条件等待**：线程可以在管程内等待条件
- **自动唤醒**：条件满足时自动唤醒等待的线程
- **封装性**：将共享数据和操作封装在一起

### 9.3 死锁问题

#### 死锁条件
- **互斥条件**：资源不能被多个线程同时使用
- **持有和等待**：线程持有资源并等待其他资源
- **不可抢占**：资源不能被强制释放
- **循环等待**：存在线程的循环等待链

#### 死锁预防
- **破坏互斥条件**：允许资源共享
- **破坏持有和等待**：一次性获取所有资源
- **破坏不可抢占**：允许资源抢占
- **破坏循环等待**：资源排序

#### 死锁检测和恢复

##### 死锁检测算法
```c
// 死锁检测算法实现
typedef struct {
    int process_id;
    int allocated[MAX_RESOURCES];
    int max_need[MAX_RESOURCES];
    int request[MAX_RESOURCES];
} process_info_t;

// 银行家算法检测死锁
bool is_safe_state(process_info_t processes[], int available[], int num_processes, int num_resources) {
    int work[MAX_RESOURCES];
    bool finish[MAX_PROCESSES];
    
    // 初始化
    for (int i = 0; i < num_resources; i++) {
        work[i] = available[i];
    }
    for (int i = 0; i < num_processes; i++) {
        finish[i] = false;
    }
    
    // 寻找安全序列
    int count = 0;
    while (count < num_processes) {
        bool found = false;
        for (int i = 0; i < num_processes; i++) {
            if (!finish[i]) {
                bool can_allocate = true;
                for (int j = 0; j < num_resources; j++) {
                    if (processes[i].request[j] > work[j]) {
                        can_allocate = false;
                        break;
                    }
                }
                if (can_allocate) {
                    // 分配资源
                    for (int j = 0; j < num_resources; j++) {
                        work[j] += processes[i].allocated[j];
                    }
                    finish[i] = true;
                    found = true;
                    count++;
                }
            }
        }
        if (!found) {
            return false;  // 死锁
        }
    }
    return true;  // 安全状态
}
```

##### 死锁恢复策略
- **进程终止**：终止一个或多个死锁进程
- **资源抢占**：从某些进程抢占资源
- **回滚机制**：将进程回滚到安全状态
- **优先级策略**：基于优先级选择终止进程

##### 死锁避免
- **银行家算法**：避免死锁的资源分配算法
- **资源排序**：对资源进行排序，避免循环等待
- **超时机制**：设置资源请求超时
- **死锁预防**：破坏死锁的四个必要条件

### 9.4 经典并发问题

#### 生产者-消费者问题
- **问题描述**：生产者生产数据，消费者消费数据
- **同步需求**：缓冲区满时生产者等待，缓冲区空时消费者等待
- **解决方案**：使用信号量或条件变量
- **代码示例**：
```c
// 使用信号量解决生产者-消费者问题
semaphore mutex = 1;      // 互斥信号量
semaphore empty = N;      // 空缓冲区数量
semaphore full = 0;       // 满缓冲区数量

// 生产者
while(true) {
    produce_item();
    P(empty);             // 等待空缓冲区
    P(mutex);             // 进入临界区
    insert_item();
    V(mutex);             // 离开临界区
    V(full);              // 增加满缓冲区
}

// 消费者
while(true) {
    P(full);              // 等待满缓冲区
    P(mutex);             // 进入临界区
    remove_item();
    V(mutex);             // 离开临界区
    V(empty);             // 增加空缓冲区
    consume_item();
}
```

#### 读者-写者问题
- **问题描述**：多个读者可以同时读，但写者需要独占访问
- **同步需求**：读者之间不互斥，读者与写者互斥
- **解决方案**：使用读写锁或信号量
- **变种**：读者优先、写者优先、公平调度

#### 哲学家就餐问题
- **问题描述**：5个哲学家围坐，需要两把叉子才能就餐
- **死锁问题**：所有哲学家同时拿起左叉子，导致死锁
- **解决方案**：限制同时就餐人数、资源排序、超时机制

### 9.6 事件驱动并发（Event-based Concurrency）

#### 事件驱动模型
- **事件循环**：单线程处理所有事件
- **非阻塞I/O**：避免线程阻塞
- **回调机制**：事件发生时调用回调函数
- **状态管理**：维护事件处理状态

#### 事件驱动实现
```c
// 事件循环结构
struct event_loop {
    int epoll_fd;
    struct epoll_event* events;
    int max_events;
    struct event_handler* handlers;
};

// 事件处理器
struct event_handler {
    int fd;
    int event_type;
    void (*callback)(int fd, int events, void* arg);
    void* arg;
};

// 事件循环主函数
int event_loop_run(struct event_loop* loop) {
    while (1) {
        // 1. 等待事件
        int nfds = epoll_wait(loop->epoll_fd, loop->events, 
                            loop->max_events, -1);
        
        // 2. 处理事件
        for (int i = 0; i < nfds; i++) {
            int fd = loop->events[i].data.fd;
            int events = loop->events[i].events;
            
            // 查找事件处理器
            struct event_handler* handler = find_handler(loop, fd);
            if (handler) {
                handler->callback(fd, events, handler->arg);
            }
        }
    }
    
    return 0;
}

// 添加事件监听
int event_loop_add_fd(struct event_loop* loop, int fd, int events,
                      void (*callback)(int, int, void*), void* arg) {
    struct event_handler* handler = malloc(sizeof(struct event_handler));
    handler->fd = fd;
    handler->event_type = events;
    handler->callback = callback;
    handler->arg = arg;
    
    // 添加到epoll
    struct epoll_event ev;
    ev.events = events;
    ev.data.fd = fd;
    epoll_ctl(loop->epoll_fd, EPOLL_CTL_ADD, fd, &ev);
    
    // 添加到处理器列表
    add_handler(loop, handler);
    
    return 0;
}
```

#### 异步I/O
```c
// 异步I/O操作
struct async_io {
    int fd;
    void* buffer;
    size_t size;
    off_t offset;
    void (*callback)(struct async_io*);
    void* user_data;
};

// 异步读取
int async_read(struct async_io* aio) {
    // 使用aio_read进行异步读取
    struct aiocb cb;
    cb.aio_fildes = aio->fd;
    cb.aio_buf = aio->buffer;
    cb.aio_nbytes = aio->size;
    cb.aio_offset = aio->offset;
    cb.aio_sigevent.sigev_notify = SIGEV_THREAD;
    cb.aio_sigevent.sigev_notify_function = aio_completion_handler;
    cb.aio_sigevent.sigev_value.sival_ptr = aio;
    
    return aio_read(&cb);
}

// 异步I/O完成处理
void aio_completion_handler(sigval_t sigval) {
    struct async_io* aio = (struct async_io*)sigval.sival_ptr;
    
    // 检查I/O状态
    int result = aio_return(&aio->aiocb);
    if (result > 0) {
        // I/O成功，调用回调
        aio->callback(aio);
    } else {
        // I/O失败，处理错误
        handle_io_error(aio, result);
    }
}
```

#### 事件驱动优势
- **高并发**：单线程处理大量连接
- **低开销**：避免线程创建和切换开销
- **简单模型**：无需复杂的同步机制
- **可扩展性**：支持大量并发连接

#### 事件驱动挑战
- **阻塞操作**：避免使用阻塞系统调用
- **状态管理**：复杂的状态机管理
- **错误处理**：异步错误处理复杂
- **调试困难**：异步执行难以调试

### 9.7 基于锁的并发数据结构

#### 并发计数器
```c
// 并发计数器实现
struct concurrent_counter {
    int value;
    pthread_mutex_t mutex;
};

// 初始化计数器
int counter_init(struct concurrent_counter* counter) {
    counter->value = 0;
    return pthread_mutex_init(&counter->mutex, NULL);
}

// 增加计数
int counter_increment(struct concurrent_counter* counter) {
    pthread_mutex_lock(&counter->mutex);
    counter->value++;
    int result = counter->value;
    pthread_mutex_unlock(&counter->mutex);
    return result;
}

// 减少计数
int counter_decrement(struct concurrent_counter* counter) {
    pthread_mutex_lock(&counter->mutex);
    counter->value--;
    int result = counter->value;
    pthread_mutex_unlock(&counter->mutex);
    return result;
}

// 获取计数值
int counter_get(struct concurrent_counter* counter) {
    pthread_mutex_lock(&counter->mutex);
    int result = counter->value;
    pthread_mutex_unlock(&counter->mutex);
    return result;
}
```

#### 并发链表
```c
// 并发链表节点
struct concurrent_list_node {
    void* data;
    struct concurrent_list_node* next;
    pthread_mutex_t mutex;
};

// 并发链表
struct concurrent_list {
    struct concurrent_list_node* head;
    pthread_mutex_t head_mutex;
    int size;
};

// 初始化链表
int concurrent_list_init(struct concurrent_list* list) {
    list->head = NULL;
    list->size = 0;
    return pthread_mutex_init(&list->head_mutex, NULL);
}

// 插入节点
int concurrent_list_insert(struct concurrent_list* list, void* data) {
    struct concurrent_list_node* new_node = malloc(sizeof(struct concurrent_list_node));
    new_node->data = data;
    new_node->next = NULL;
    pthread_mutex_init(&new_node->mutex, NULL);
    
    pthread_mutex_lock(&list->head_mutex);
    new_node->next = list->head;
    list->head = new_node;
    list->size++;
    pthread_mutex_unlock(&list->head_mutex);
    
    return 0;
}

// 查找节点
struct concurrent_list_node* concurrent_list_find(struct concurrent_list* list, 
                                                void* target_data) {
    pthread_mutex_lock(&list->head_mutex);
    struct concurrent_list_node* current = list->head;
    
    while (current) {
        pthread_mutex_lock(&current->mutex);
        if (current->data == target_data) {
            pthread_mutex_unlock(&current->mutex);
            pthread_mutex_unlock(&list->head_mutex);
            return current;
        }
        struct concurrent_list_node* next = current->next;
        pthread_mutex_unlock(&current->mutex);
        current = next;
    }
    
    pthread_mutex_unlock(&list->head_mutex);
    return NULL;
}
```

```c
struct concurrent_queue_node {

// 并发队列
struct concurrent_queue {

// 初始化队列
int concurrent_queue_init(struct concurrent_queue* queue) {
    queue->head = NULL;
    queue->tail = NULL;
    queue->size = 0;
    pthread_mutex_init(&queue->head_mutex, NULL);
    pthread_mutex_init(&queue->tail_mutex, NULL);
    pthread_cond_init(&queue->not_empty, NULL);
    return 0;
}

// 入队
int concurrent_queue_enqueue(struct concurrent_queue* queue, void* data) {
    struct concurrent_queue_node* new_node = malloc(sizeof(struct concurrent_queue_node));
    new_node->data = data;
    new_node->next = NULL;
    
    pthread_mutex_lock(&queue->tail_mutex);
    if (queue->tail) {
        queue->tail->next = new_node;
    } else {
        queue->head = new_node;
    }
    queue->tail = new_node;
    queue->size++;
    pthread_cond_signal(&queue->not_empty);
    pthread_mutex_unlock(&queue->tail_mutex);
    
    return 0;
}

// 出队
void* concurrent_queue_dequeue(struct concurrent_queue* queue) {
    pthread_mutex_lock(&queue->head_mutex);
    
    while (queue->head == NULL) {
        pthread_cond_wait(&queue->not_empty, &queue->head_mutex);
    }
    
    struct concurrent_queue_node* node = queue->head;
    void* data = node->data;
    queue->head = node->next;
    if (queue->head == NULL) {
        queue->tail = NULL;
    }
    queue->size--;
    
    pthread_mutex_unlock(&queue->head_mutex);
    free(node);
    
    return data;
}
```

#### 并发哈希表
```c
// 哈希表桶
struct hash_bucket {
    struct concurrent_list* list;
    pthread_mutex_t mutex;
};

// 并发哈希表
struct concurrent_hash_table {
    struct hash_bucket* buckets;
    int bucket_count;
    int (*hash_function)(void*);
    int (*compare_function)(void*, void*);
};

// 初始化哈希表
int concurrent_hash_table_init(struct concurrent_hash_table* table, 
                               int bucket_count,
                               int (*hash_func)(void*),
                               int (*compare_func)(void*, void*)) {
    table->buckets = malloc(bucket_count * sizeof(struct hash_bucket));
    table->bucket_count = bucket_count;
    table->hash_function = hash_func;
    table->compare_function = compare_func;
    
    for (int i = 0; i < bucket_count; i++) {
        concurrent_list_init(&table->buckets[i].list);
        pthread_mutex_init(&table->buckets[i].mutex, NULL);
    }
    
    return 0;
}

// 插入键值对
int concurrent_hash_table_put(struct concurrent_hash_table* table, 
                             void* key, void* value) {
    int bucket_index = table->hash_function(key) % table->bucket_count;
    struct hash_bucket* bucket = &table->buckets[bucket_index];
    
    pthread_mutex_lock(&bucket->mutex);
    
    // 检查键是否已存在
    struct concurrent_list_node* existing = concurrent_list_find(bucket->list, key);
    if (existing) {
        // 更新现有值
        existing->data = value;
    } else {
        // 插入新键值对
        concurrent_list_insert(bucket->list, key);
    }
    
    pthread_mutex_unlock(&bucket->mutex);
    return 0;
}

// 获取值
void* concurrent_hash_table_get(struct concurrent_hash_table* table, void* key) {
    int bucket_index = table->hash_function(key) % table->bucket_count;
    struct hash_bucket* bucket = &table->buckets[bucket_index];
    
    pthread_mutex_lock(&bucket->mutex);
    struct concurrent_list_node* node = concurrent_list_find(bucket->list, key);
    void* result = node ? node->data : NULL;
    pthread_mutex_unlock(&bucket->mutex);
    
    return result;
}
```

#### 性能优化策略
- **细粒度锁**：使用多个锁减少锁竞争
- **无锁数据结构**：使用原子操作避免锁
- **读写锁**：允许多个读者同时访问
- **锁分段**：将数据结构分段，每段独立加锁
