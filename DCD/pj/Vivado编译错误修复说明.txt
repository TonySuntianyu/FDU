问题1: integer变量声明位置
───────────────────────────────────────────────────────────────────
❌ 错误代码（在initial块内声明）：
    initial begin
        integer i;  // ← 这会导致Vivado编译错误
        for (i = 0; i < 256; i = i + 1) begin
            ...
        end
    end

✅ 修复后（在模块级声明）：
    integer i;  // ← 移到模块级
    
    initial begin
        for (i = 0; i < 256; i = i + 1) begin
            ...
        end
    end

已修复的文件：
  ✓ ProgramMemory.v
  ✓ DataMemory.v
  ✓ RegisterFile.v

步骤1: 清理旧项目（如果有）
───────────────────────────────────────────────────────────────────
1. 关闭当前Vivado项目
2. 删除生成的文件夹（如果存在）：
   - vivado_project/
   - .Xil/
   - *.jou, *.log

步骤2: 在Vivado中创建新项目
───────────────────────────────────────────────────────────────────
1. File → Project → New
2. 项目名称：CPU_Project
3. 项目类型：RTL Project
4. 点击 Next

步骤3: 添加设计源文件
───────────────────────────────────────────────────────────────────
点击 "Add Files"，添加以下文件作为 Design Sources：

  ✓ ALU.v
  ✓ RegisterFile.v
  ✓ ProgramMemory.v
  ✓ DataMemory.v
  ✓ ControlUnit.v
  ✓ ImmGen.v
  ✓ CPU.v

注意：不要添加任何 *_tb.v 文件到这里！

步骤4: 添加仿真源文件
───────────────────────────────────────────────────────────────────
1. 在"Add Sources"界面，切换到：
   "Add or create simulation sources"
   
2. 点击 "Add Files"，添加：
   ✓ CPU_tb_vivado.v  ← 注意：是vivado版本！

3. 点击 Finish

步骤5: 运行仿真
───────────────────────────────────────────────────────────────────
1. Flow Navigator → SIMULATION
2. 点击 "Run Behavioral Simulation"
3. 等待编译完成（应该不会有错误了）
4. 仿真启动，查看波形

步骤6: 添加观察信号
───────────────────────────────────────────────────────────────────
在Scope窗口：CPU_tb → cpu

从Objects窗口拖动以下信号到波形窗口：
  ✓ clk
  ✓ rst
  ✓ PC
  ✓ Instruction
  ✓ ALU_Result
  ✓ RegWrite, MemWrite, MemRead

展开 RF → registers：
  ✓ registers[1] 到 registers[8]

展开 DM → memory：
  ✓ memory[4]
  ✓ memory[12]

步骤7: 设置显示格式
───────────────────────────────────────────────────────────────────
右键信号 → Radix → Hexadecimal

步骤8: 运行仿真
───────────────────────────────────────────────────────────────────
点击工具栏的 ▶ 按钮，运行仿真到结束

问题A: 仍然有编译错误
───────────────────────────────────────────────────────────────────
解决方法：
1. 确认使用的是修复后的文件（有"循环变量"注释）
2. 检查文件是否完整复制到Vivado项目中
3. 尝试：Flow → Reset Simulation，然后重新运行

问题B: 找不到CPU_tb_vivado模块
───────────────────────────────────────────────────────────────────
解决方法：
1. Sources窗口 → Simulation Sources
2. 右键 → Add or Create Simulation Sources
3. Add Files → 选择 CPU_tb_vivado.v
4. 设置为顶层仿真文件

问题C: 波形显示不正常
───────────────────────────────────────────────────────────────────
解决方法：
1. 检查复位信号（rst应该在开始时为高）
2. 确认时钟信号正常（20ns周期）
3. 手动添加需要观察的信号

问题D: Tcl Console没有输出
───────────────────────────────────────────────────────────────────
解决方法：
1. Window → Tcl Console（打开窗口）
2. 检查仿真是否运行到结束（看到$finish）
3. 查看日志文件中的输出
