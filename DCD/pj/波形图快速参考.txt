左侧SST窗口: CPU_tb → cpu

必须添加的信号：
  ☑ clk                          时钟
  ☑ rst                          复位
  ☑ PC                           程序计数器 [Hex]
  ☑ Instruction                  当前指令 [Hex]
  ☑ ALU_Result                   ALU结果 [Hex]
  ☑ RegWrite                     寄存器写使能
  ☑ MemWrite                     存储器写使能
  ☑ MemRead                      存储器读使能
  
展开 RF 模块添加:
  ☑ registers[1] ~ registers[8]  寄存器X1-X8 [Hex]

展开 DM 模块添加:
  ☑ memory[4]                    数据存储器地址4
  ☑ memory[12]                   数据存储器地址12

提示：右键信号 → Data Format → Hex 设置为十六进制显示

│ 📌 第六步：编写波形说明                                               │
└──────────────────────────────────────────────────────────────────────┘

每张波形图的说明应包括：

1. 图号和标题
   例：图3-1 addi指令执行波形图

2. 基本信息
   - PC地址
   - 指令机器码
   - 指令功能

3. 执行过程（6个要点）
   ① 取指：PC值，读取的指令码
   ② 译码：识别的指令类型，控制信号状态
   ③ 读寄存器：源操作数的值
   ④ 执行：ALU操作类型和结果
   ⑤ 访存：如有存储器访问，说明地址和数据
   ⑥ 写回：目标寄存器/存储器的最终值

4. 关键信号变化
   - 标注时钟上升沿
   - 说明控制信号的作用
   - 指出数据变化的时刻

5. 结果验证
   - 与预期结果对比
   - 确认执行正确

┌──────────────────────────────────────────────────────────────────────┐
│ 📌 各指令的关键观察点                                                 │
└──────────────────────────────────────────────────────────────────────┘

指令1 - addi X1,X0,8:
  ✓ Immediate = 0x00000008
  ✓ ALUSrc = 1 (选择立即数)
  ✓ X1: 0x00 → 0x08

指令2 - lw X2,4(X1):
  ✓ 地址计算: X1(8) + 4 = 12
  ✓ MemRead = 1
  ✓ 从DM[12]读取 → X2 = 0x04

指令3 - add X3,X1,X2:
  ✓ ALUSrc = 0 (选择寄存器)
  ✓ 8 + 4 = 12
  ✓ X3 = 0x0C

指令4 - sub X4,X3,X1:
  ✓ ALUOp = SUB
  ✓ 12 - 8 = 4
  ✓ X4 = 0x04

指令5 - or X5,X1,X4:
  ✓ ALUOp = OR
  ✓ 0x08 | 0x04 = 0x0C
  ✓ X5 = 0x0C

指令6 - ori X6,X5,1:
  ✓ 0x0C | 0x01 = 0x0D
  ✓ X6 = 0x0D

指令7 - sw X6,0(X2):
  ✓ MemWrite = 1
  ✓ 向DM[4]写入0x0D
  ✓ 观察DM.memory[4]变化

指令8 - slt X7,X2,X4:
  ✓ 比较: 4 < 4 ?
  ✓ 结果: 假
  ✓ X7 = 0x00

指令9 - slti X8,X2,8:
  ✓ 比较: 4 < 8 ?
  ✓ 结果: 真
  ✓ X8 = 0x01

指令10 - beq X3,X5,-12:
  ✓ X3(12) == X5(12) → 相等
  ✓ Zero = 1, Branch = 1
  ✓ PC: 0x24 → 0x1C (跳转)

│ 📌 常见问题快速解决                                                   │
└──────────────────────────────────────────────────────────────────────┘

Q: 波形全是X态？
A: 检查复位信号，确保rst在开始时为高

Q: 看不到寄存器值？
A: 需要展开RF模块，手动添加registers[n]

Q: 时间轴怎么定位？
A: 点击波形窗口下方的时间数字，或Time → Go To Time

Q: 波形太密集？
A: View → Zoom In (或鼠标滚轮)

Q: 如何改变信号颜色？
A: 右键信号 → Highlight → 选择颜色

Q: 导出图片不清晰？
A: 调整窗口大小，或在导出设置中提高分辨率
