## 1. 运行仿真

### 方法A：使用自动脚本（推荐）

**Windows系统：**
```bash
# 双击运行或命令行执行
run_sim.bat
```

**Linux/Mac系统：**
```bash
chmod +x run_sim.sh
./run_sim.sh
```

运行后会生成 `cpu_wave.vcd` 波形文件。

### 方法B：手动编译运行

```bash
# 编译所有Verilog文件
iverilog -o cpu_sim.vvp ALU.v RegisterFile.v ProgramMemory.v DataMemory.v ControlUnit.v ImmGen.v CPU.v CPU_tb.v

# 运行仿真
vvp cpu_sim.vvp

# 生成 cpu_wave.vcd 文件
```

## 2. 使用GTKWave查看波形

### 2.1 安装GTKWave

**Windows:**
- 下载地址：http://gtkwave.sourceforge.net/
- 安装后添加到系统PATH

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install gtkwave
```

**Mac:**
```bash
brew install --cask gtkwave
```

### 2.2 打开波形文件

```bash
gtkwave cpu_wave.vcd
```

### 2.3 添加需要观察的信号

**步骤：**
1. 左侧"SST"窗口选择 `CPU_tb` → `cpu`
2. 在"Signals"窗口中找到需要的信号
3. 选中信号后点击"Append"或直接拖拽到波形窗口

**必须观察的关键信号：**

```
✓ clk                    # 时钟信号
✓ rst                    # 复位信号
✓ PC                     # 程序计数器（32位，显示为十六进制）
✓ Instruction            # 当前指令（32位，显示为十六进制）
✓ ALU_Result             # ALU运算结果（32位，显示为十六进制）
✓ RegWrite               # 寄存器写使能
✓ MemWrite               # 存储器写使能
✓ MemRead                # 存储器读使能
```

**寄存器信号（展开RF模块）：**
```
✓ RF → registers[1]      # X1寄存器
✓ RF → registers[2]      # X2寄存器
✓ RF → registers[3]      # X3寄存器
✓ RF → registers[4]      # X4寄存器
✓ RF → registers[5]      # X5寄存器
✓ RF → registers[6]      # X6寄存器
✓ RF → registers[7]      # X7寄存器
✓ RF → registers[8]      # X8寄存器
```

**数据存储器（展开DM模块）：**
```
✓ DM → memory[4]         # DM地址4
✓ DM → memory[12]        # DM地址12
```

### 2.4 设置信号显示格式

右键点击信号 → Data Format：
- **十六进制**: Hex
- **十进制**: Decimal
- **二进制**: Binary
- **ASCII**: ASCII

**推荐设置：**
- PC, Instruction, ALU_Result, 寄存器值 → **Hex**
- 控制信号（RegWrite, MemWrite等）→ **Binary**

### 2.5 定位到特定指令

1. 使用时间标尺：每条指令执行时间为20ns（一个时钟周期）
2. 点击波形窗口底部的时间轴
3. 或者使用 Search → Go To Time

**各指令的时间点：**
```
指令1 (addi): 25ns - 45ns
指令2 (lw):   45ns - 65ns
指令3 (add):  65ns - 85ns
指令4 (sub):  85ns - 105ns
指令5 (or):   105ns - 125ns
指令6 (ori):  125ns - 145ns
指令7 (sw):   145ns - 165ns
指令8 (slt):  165ns - 185ns
指令9 (slti): 185ns - 205ns
指令10 (beq): 205ns - 225ns
```

## 3. 使用ModelSim查看波形

### 3.1 启动ModelSim仿真

```tcl
# 创建工作库
vlib work

# 编译所有模块
vlog ALU.v RegisterFile.v ProgramMemory.v DataMemory.v ControlUnit.v ImmGen.v CPU.v CPU_tb.v

# 开始仿真
vsim -gui CPU_tb

# 添加波形
add wave -radix hexadecimal sim:/CPU_tb/cpu/clk
add wave -radix hexadecimal sim:/CPU_tb/cpu/rst
add wave -radix hexadecimal sim:/CPU_tb/cpu/PC
add wave -radix hexadecimal sim:/CPU_tb/cpu/Instruction
add wave -radix hexadecimal sim:/CPU_tb/cpu/ALU_Result

# 添加寄存器
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[1]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[2]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[3]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[4]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[5]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[6]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[7]
add wave -radix hexadecimal sim:/CPU_tb/cpu/RF/registers[8]

# 添加控制信号
add wave sim:/CPU_tb/cpu/RegWrite
add wave sim:/CPU_tb/cpu/MemWrite
add wave sim:/CPU_tb/cpu/MemRead

# 运行仿真
run 400ns
```

### 3.2 截取波形图

1. **缩放到合适的时间范围**：View → Zoom → Zoom Range
2. **截图**：File → Export → Image
3. 选择PNG或JPG格式
4. 设置分辨率（推荐1920x1080）

## 4. 使用Vivado查看波形

### 4.1 创建项目并运行仿真

1. **创建RTL项目**
2. **添加源文件**：Add Sources → 添加所有.v文件（除CPU_tb.v）
3. **添加仿真文件**：Add Sources → Add or create simulation sources → 添加CPU_tb.v
4. **运行仿真**：Flow Navigator → Simulation → Run Behavioral Simulation

### 4.2 查看波形

Vivado会自动显示部分信号，可以手动添加更多：

1. 在Scope窗口选择 `CPU_tb` → `cpu`
2. 在Objects窗口找到需要的信号
3. 右键 → Add to Wave Window

### 4.3 设置显示格式

1. 右键信号 → Radix → Hexadecimal（或其他格式）
2. 右键信号 → Wave Color → 设置颜色方便区分

### 4.4 导出波形图

1. File → Export → Export Waveform
2. 或直接截图：File → Print Screen

## 5. 波形图截取方法

### 5.1 单条指令波形图（10张）

**截取范围：** 每条指令执行的一个完整时钟周期

**必须包含的信号：**
```
时钟 (clk)
复位 (rst)
PC值
当前指令 (Instruction)
相关寄存器值（输入/输出）
ALU结果 (ALU_Result)
相关控制信号（RegWrite/MemWrite/MemRead）
```

**截图步骤：**
1. 缩放到该指令的时间范围（20ns）
2. 确保所有关键信号可见
3. 截图并保存为 `waveform_指令名.png`

**文件命名：**
```
waveform_01_addi.png    # 指令1: addi
waveform_02_lw.png      # 指令2: lw
waveform_03_add.png     # 指令3: add
waveform_04_sub.png     # 指令4: sub
waveform_05_or.png      # 指令5: or
waveform_06_ori.png     # 指令6: ori
waveform_07_sw.png      # 指令7: sw
waveform_08_slt.png     # 指令8: slt
waveform_09_slti.png    # 指令9: slti
waveform_10_beq.png     # 指令10: beq
```

### 5.2 完整流程波形图（1张）

**截取范围：** 所有指令执行的完整过程

**必须包含：**
```
PC的变化过程
所有寄存器的最终值
关键时间点标注
```

**文件命名：**
```
waveform_complete.png   # 完整流程
```

## 6. 每条指令的波形分析

### 指令1: addi X1, X0, 8

**时间：** 25ns - 45ns  
**地址：** PC = 0x00  
**机器码：** 0x00800093

**关键观察点：**
```
✓ Instruction = 0x00800093
✓ ReadData1 (X0的值) = 0x00000000
✓ Immediate = 0x00000008
✓ ALUSrc = 1 (选择立即数)
✓ ALU_Result = 0 + 8 = 0x00000008
✓ RegWrite = 1
✓ 时钟上升沿后 X1 = 0x00000008
```

**波形说明模板：**
```
图X-1 addi指令执行波形图

说明：
1. PC = 0x00，从程序存储器读取指令 0x00800093
2. 译码识别为addi指令，立即数为8
3. ALU执行加法：X0(0) + 8 = 8
4. RegWrite=1，在时钟上升沿将结果8写入X1寄存器
5. 执行后 X1 = 0x08，PC更新为0x04
```

---

### 指令2: lw X2, 4(X1)

**时间：** 45ns - 65ns  
**地址：** PC = 0x04  
**机器码：** 0x0040a103

**关键观察点：**
```
✓ Instruction = 0x0040a103
✓ ReadData1 (X1的值) = 0x00000008
✓ Immediate = 0x00000004
✓ ALUSrc = 1
✓ ALU_Result = 8 + 4 = 0x0000000C (存储器地址)
✓ MemRead = 1
✓ MemReadData = 0x00000004 (从DM[12]读取)
✓ MemtoReg = 1 (选择存储器数据)
✓ RegWrite = 1
✓ 时钟上升沿后 X2 = 0x00000004
```

**波形说明模板：**
```
图X-2 lw指令执行波形图

说明：
1. PC = 0x04，读取lw指令 0x0040a103
2. 计算存储器地址：X1(8) + offset(4) = 12 (0x0C)
3. MemRead=1，从数据存储器DM[12]读取数据
4. 读取到的数据为 0x04
5. MemtoReg=1，选择存储器数据写回
6. RegWrite=1，将数据4写入X2寄存器
7. 执行后 X2 = 0x04，PC更新为0x08
```

### 指令10: beq X3, X5, -12

**时间：** 205ns - 225ns（以及循环后的执行）  
**地址：** PC = 0x24  
**机器码：** 0xfe518ae3

**关键观察点：**
```
✓ Instruction = 0xfe518ae3
✓ ReadData1 (X3的值) = 0x0000000C
✓ ReadData2 (X5的值) = 0x0000000C
✓ Immediate = 0xFFFFFFF4 (-12的补码)
✓ ALUSrc = 0
✓ ALUOp = SUB
✓ ALU_Result = 12 - 12 = 0x00000000
✓ Zero = 1 (两数相等)
✓ Branch = 1
✓ PCSrc = Branch & Zero = 1
✓ PC_Next = 0x24 + (-12) = 0x1C
✓ 下一时钟周期 PC = 0x0000001C
```

**波形说明模板：**
```
图X-10 beq指令执行波形图

说明：
1. PC = 0x24，读取beq指令 0xfe518ae3
2. 读取要比较的寄存器：X3=12, X5=12
3. ALU执行减法：12 - 12 = 0
4. Zero=1表示两数相等，Branch=1表示是分支指令
5. PCSrc = Branch & Zero = 1，触发分支跳转
6. 计算跳转目标：PC(0x24) + offset(-12) = 0x1C
7. 下一时钟周期PC跳转到0x1C，形成循环
8. 观察波形可见PC从0x24跳转到0x1C，然后继续执行slt指令
```

## 10. 常见问题

### Q1: 波形显示都是X态？
**A:** 检查复位信号是否正确，确保rst信号在开始时为高电平并持续一段时间。

### Q2: 看不到寄存器的值？
**A:** 需要展开RF模块，手动添加registers[1]到registers[8]到波形窗口。

### Q3: 时间定位不准确？
**A:** 每条指令执行时间为20ns（时钟周期），复位解除后第一条指令从25ns开始。

### Q4: 波形太密集看不清？
**A:** 使用缩放功能（Zoom In/Out），或者调整窗口大小和信号高度。

### Q5: 如何导出高质量图片？
**A:** 
- GTKWave: File → Print To File → 选择PNG格式
- ModelSim: File → Export → Image → 设置高分辨率
- 或使用截图工具（推荐Snipaste）

## 11. 提示和技巧

### 技巧1：使用书签标记关键时间点
在GTKWave中：
- Time → Insert Blank Marker
- 在重要时间点添加标记

### 技巧2：保存波形配置
```bash
# GTKWave保存配置
File → Write Save File → 保存为 cpu_wave.gtkw
# 下次打开时自动加载信号
gtkwave cpu_wave.vcd cpu_wave.gtkw
```

### 技巧3：添加注释
在波形图上添加文字注释，标明：
- 指令名称
- 关键信号变化
- 时间点

### 技巧4：批量导出
可以编写脚本自动截取所有指令的波形图。
