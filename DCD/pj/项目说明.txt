项目概述
───────────────────────────────────────────────────────────────
本项目实现了一个完整的32位RISC-V单周期CPU，支持10条指令：
✓ add, sub, or, slt (R型指令)
✓ addi, ori, slti, lw (I型指令)
✓ sw (S型指令)
✓ beq (B型指令，可选+10分)

快速开始
═══════════════════════════════════════════════════════════════

方法1：使用脚本自动运行（推荐）
───────────────────────────────────────────────────────────────
Windows用户：
    1. 双击运行 run_sim.bat
    2. 等待编译和仿真完成
    3. 查看输出结果和波形文件

Linux/Mac用户：
    1. 打开终端，进入项目目录
    2. chmod +x run_sim.sh
    3. ./run_sim.sh
    4. 查看输出结果和波形文件

方法2：手动编译运行
───────────────────────────────────────────────────────────────
使用iverilog：
    iverilog -o cpu_sim.vvp ALU.v RegisterFile.v ProgramMemory.v DataMemory.v ControlUnit.v ImmGen.v CPU.v CPU_tb.v
    vvp cpu_sim.vvp
    gtkwave cpu_wave.vcd

使用ModelSim：
    vlib work
    vlog *.v
    vsim -gui CPU_tb
    add wave -radix hexadecimal sim:/CPU_tb/cpu/*
    run -all

使用Vivado：
    1. 创建新项目
    2. 添加所有.v文件
    3. 设置CPU_tb为顶层仿真文件
    4. 运行行为仿真

文件说明
═══════════════════════════════════════════════════════════════

核心模块（8个.v文件）
───────────────────────────────────────────────────────────────
ALU.v              - 算术逻辑单元（ADD/SUB/OR/SLT）
RegisterFile.v     - 32个32位寄存器，X0恒为0
ProgramMemory.v    - 256字节程序存储器（包含测试程序）
DataMemory.v       - 256字节数据存储器
ControlUnit.v      - 控制单元（生成控制信号）
ImmGen.v          - 立即数生成器（I/S/B型）
CPU.v             - CPU顶层模块（整合所有部件）
CPU_tb.v          - 测试平台（自动化测试）

测试程序说明
═══════════════════════════════════════════════════════════════

程序存储器中预置的测试程序：

地址    指令              功能                    预期结果
────────────────────────────────────────────────────────────
0x00    addi X1,X0,8      X1 = 0 + 8             X1 = 8
0x04    lw X2,4(X1)       X2 = MEM[12]           X2 = 4
0x08    add X3,X1,X2      X3 = 8 + 4             X3 = 12
0x0C    sub X4,X3,X1      X4 = 12 - 8            X4 = 4
0x10    or X5,X1,X4       X5 = 8 | 4             X5 = 12
0x14    ori X6,X5,1       X6 = 12 | 1            X6 = 13
0x18    sw X6,0(X2)       MEM[4] = 13            DM[4] = 13
0x1C    slt X7,X2,X4      X7 = (4 < 4) ? 1:0     X7 = 0
0x20    slti X8,X2,8      X8 = (4 < 8) ? 1:0     X8 = 1
0x24    beq X3,X5,-12     if(12==12) 跳转        PC = 0x1C

常见问题解决
═══════════════════════════════════════════════════════════════

Q1: 找不到iverilog命令
A1: 需要安装Icarus Verilog
    Windows: http://bleyer.org/icarus/
    Linux: sudo apt-get install iverilog
    Mac: brew install icarus-verilog

Q2: 仿真输出有X或Z态
A2: 检查复位信号是否正确，确保所有存储器已初始化

Q3: 寄存器值不对
A3: 检查：
    - X0是否始终为0
    - RegWrite信号是否正确
    - 时钟上升沿触发是否正常

Q4: beq不跳转
A4: 检查：
    - Zero标志位计算是否正确
    - 立即数符号扩展是否正确
    - PC更新逻辑是否正确
