## 一、实验目的

1. 理解单周期CPU的工作原理和数据通路设计
2. 掌握RISC-V指令集的基本指令格式和编码方式
3. 学习使用Verilog HDL进行数字电路设计
4. 掌握功能仿真和波形分析的方法
5. 培养系统级硬件设计能力

## 二、实验要求

### 2.1 基本要求

实现一个32位RISC-V单周期CPU，支持以下9条指令：

| 指令类型 | 指令 | 功能描述 |
|---------|------|---------|
| R型 | add | 寄存器加法 |
| R型 | sub | 寄存器减法 |
| R型 | or | 寄存器逻辑或 |
| R型 | slt | 有符号数小于比较 |
| I型 | addi | 立即数加法 |
| I型 | ori | 立即数逻辑或 |
| I型 | slti | 立即数小于比较 |
| I型 | lw | 加载字 |
| S型 | sw | 存储字 |

### 2.2 附加要求（可选，+10分）

实现B型分支指令：
- **beq**：相等跳转

### 2.3 硬件资源要求

- **寄存器**：32个32位通用寄存器（X0-X31），X0恒为0
- **特殊寄存器**：PC（程序计数器）
- **程序存储器**：256字节（地址0-255）
- **数据存储器**：256字节（地址0-255）
- **存储方式**：小端模式（Little Endian）

#### 3.3.1 R型指令（以add为例）

3. **读寄存器**：读取rs1和rs2的值
4. **执行**：ALU执行加法操作
5. **写回**：在时钟上升沿将结果写入rd
