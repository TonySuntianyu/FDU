# RISC-V 单周期CPU设计项目

## 项目概述

本项目实现了一个简单的32位RISC-V单周期CPU，支持9条基本指令和1条可选的分支指令。

### 支持的指令

#### 必需指令（9条）
1. **add** - 寄存器加法（R型）
2. **sub** - 寄存器减法（R型）
3. **or** - 寄存器逻辑或（R型）
4. **slt** - 小于则置位（R型）
5. **addi** - 立即数加法（I型）
6. **ori** - 立即数逻辑或（I型）
7. **slti** - 立即数小于则置位（I型）
8. **lw** - 加载字（I型）
9. **sw** - 存储字（S型）

#### 可选指令（附加10分）
10. **beq** - 相等跳转（B型）

### 2. 各模块功能说明

#### 2.1 ALU（算术逻辑单元）
- **功能**：执行算术和逻辑运算
- **支持操作**：
  - ADD：加法运算
  - SUB：减法运算
  - OR：逻辑或运算
  - SLT：有符号数比较（小于则置1）
- **输出**：32位运算结果和零标志位（用于分支判断）

#### 2.2 RegisterFile（寄存器堆）
- **规格**：32个32位通用寄存器（X0-X31）
- **特性**：
  - X0寄存器恒为0，不可写入
  - 支持同时读取两个寄存器
  - 在时钟上升沿写入数据
  - 支持复位清零

#### 2.3 ProgramMemory（程序存储器）
- **容量**：256字节（地址0-255）
- **特性**：
  - 只读存储器，存储指令代码
  - 采用小端模式存储
  - 按字节寻址，每次读取32位指令
  - 使用initial块初始化测试程序

#### 2.4 DataMemory（数据存储器）
- **容量**：256字节（地址0-255）
- **特性**：
  - 可读可写存储器
  - 采用小端模式存储
  - 按字节寻址，支持32位数据读写
  - 写操作在时钟上升沿进行

#### 2.5 ControlUnit（控制单元）
- **功能**：根据指令的opcode、funct3、funct7生成控制信号
- **输出信号**：
  - RegWrite：寄存器写使能
  - MemWrite：存储器写使能
  - MemRead：存储器读使能
  - MemtoReg：存储器数据写回寄存器选择
  - ALUSrc：ALU第二操作数来源选择
  - Branch：分支指令标志
  - ALUOp[3:0]：ALU操作码

#### 2.6 ImmGen（立即数生成器）
- **功能**：根据指令类型提取并符号扩展立即数
- **支持类型**：
  - I型：12位立即数扩展为32位
  - S型：拼接分散的立即数字段
  - B型：拼接分支偏移量

#### 2.7 CPU（顶层模块）
- **功能**：整合所有子模块，实现完整的CPU功能
- **关键逻辑**：
  - PC更新：正常+4或分支跳转
  - 数据通路：指令获取→解码→执行→访存→写回
  - 信号连接：协调各部件协同工作

## 指令执行流程

### 单周期执行过程

每条指令在一个时钟周期内完成以下步骤：

1. **取指（IF - Instruction Fetch）**
   - 用PC值作为地址从程序存储器读取指令

2. **译码（ID - Instruction Decode）**
   - 控制单元解析opcode、funct3、funct7，生成控制信号
   - 从寄存器堆读取源操作数
   - 立即数生成器提取立即数

3. **执行（EX - Execute）**
   - ALU根据ALUOp执行相应运算
   - 分支判断（如果是beq指令）

4. **访存（MEM - Memory Access）**
   - lw指令：从数据存储器读取数据
   - sw指令：向数据存储器写入数据

5. **写回（WB - Write Back）**
   - 在时钟上升沿将结果写入目标寄存器
   - 同时更新PC值

## 测试程序说明

程序存储器中预置了以下测试程序：

```assembly
# 地址  指令          说明
0x00:  addi X1,X0,8   # X1 = 0 + 8 = 8
0x04:  lw X2,4(X1)    # X2 = MEM[8+4] = MEM[12] = 4
0x08:  add X3,X1,X2   # X3 = 8 + 4 = 12
0x0C:  sub X4,X3,X1   # X4 = 12 - 8 = 4
0x10:  or X5,X1,X4    # X5 = 8 | 4 = 12
0x14:  ori X6,X5,1    # X6 = 12 | 1 = 13
0x18:  sw X6,0(X2)    # MEM[4+0] = 13
0x1C:  slt X7,X2,X4   # X7 = (4 < 4) ? 1 : 0 = 0
0x20:  slti X8,X2,8   # X8 = (4 < 8) ? 1 : 0 = 1
0x24:  beq X3,X5,-12  # if(X3==X5) PC=PC-12 (跳转到0x1C)
```

## 波形分析要点

### 关键信号观察

1. **PC变化**：观察程序计数器是否正确递增和跳转
2. **指令执行**：确认每个时钟周期执行的指令正确
3. **寄存器更新**：验证寄存器在时钟上升沿正确更新
4. **ALU结果**：检查ALU运算结果是否正确
5. **存储器访问**：确认lw/sw指令正确读写存储器
6. **控制信号**：验证控制单元产生的信号符合预期

### 各指令验证要点

#### 1. addi指令（0x00处）
- 观察X1寄存器从0变为8
- ALUSrc信号为1（选择立即数）
- RegWrite信号为1（写寄存器）

#### 2. lw指令（0x04处）
- ALU计算地址：8+4=12
- MemRead信号为1
- X2寄存器获得值4

#### 3. add指令（0x08处）
- ALU执行：8+4=12
- ALUSrc信号为0（选择寄存器）
- X3寄存器获得值12

#### 4. sub指令（0x0C处）
- ALU执行：12-8=4
- X4寄存器获得值4

#### 5. or指令（0x10处）
- ALU执行：8|4=12
- X5寄存器获得值12

#### 6. ori指令（0x14处）
- ALU执行：12|1=13
- X6寄存器获得值13

#### 7. sw指令（0x18处）
- MemWrite信号为1
- 数据存储器地址4处写入13

#### 8. slt指令（0x1C处）
- ALU执行：4<4=0
- X7寄存器获得值0

#### 9. slti指令（0x20处）
- ALU执行：4<8=1
- X8寄存器获得值1

#### 10. beq指令（0x24处）
- Zero信号为1（X3==X5）
- PC跳转到0x1C
- 形成循环执行

## 性能分析

### 时钟周期计算

- **CPI（Cycles Per Instruction）**：1.0（单周期设计）
- **时钟周期**：由最慢的指令路径决定

### 关键路径分析

最长路径为lw指令：
```
PC → PM → Control → RF → ALU → DM → WriteData → RF
```

路径延迟估算：
- PC寄存器输出：1ns
- 程序存储器读取：5ns
- 控制单元译码：2ns
- 寄存器堆读取：3ns
- ALU运算：5ns
- 数据存储器读取：5ns
- 写回数据选择：1ns
- 寄存器堆建立时间：2ns

**总延迟约24ns**，因此最高工作频率约为40MHz。

### 设计改进建议

1. **流水线化**
   - 将单周期设计改为5级流水线
   - 可提升吞吐量约5倍
   - 需要处理数据冒险和控制冒险

2. **存储器优化**
   - 使用faster SRAM替代当前存储器
   - 添加Cache降低存储器访问延迟

3. **控制逻辑优化**
   - 使用查找表（LUT）加速控制信号生成
   - 简化关键路径上的组合逻辑

4. **增加指令**
   - 支持更多RISC-V指令（jal、jalr、lui等）
   - 实现完整的RV32I指令集

## 常见问题

### Q1: 仿真时寄存器值不对？
A: 检查以下几点：
- X0寄存器是否始终为0
- 控制信号RegWrite是否正确
- 时钟上升沿是否正确触发
- 写回数据选择是否正确

### Q2: 存储器读写不正确？
A: 检查以下几点：
- 地址计算是否正确
- 小端模式是否正确实现
- MemRead/MemWrite信号是否正确
- 时钟同步是否正确

### Q3: beq指令不跳转？
A: 检查以下几点：
- 比较的两个寄存器值是否相等
- Zero标志位是否正确
- 立即数生成是否正确（注意符号扩展）
- PC更新逻辑是否正确

### Q4: 波形显示乱码或X态？
A: 检查以下几点：
- 所有寄存器是否正确复位
- 存储器是否正确初始化
- 是否存在未驱动的信号
- 组合逻辑是否有环路

## 项目总结

本项目实现了一个功能完整的RISC-V单周期CPU，具有以下特点：

### 优点
1. **结构清晰**：模块化设计，易于理解和维护
2. **功能完整**：支持所有要求的指令，包括可选的beq

4. **可扩展性**：便于添加新指令和功能

### 局限性
1. **性能较低**：单周期设计导致时钟频率受限
2. **资源利用率低**：许多部件在某些指令中闲置
3. **功能有限**：仅支持部分RISC-V指令
