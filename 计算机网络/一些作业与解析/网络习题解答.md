# 网络习题解答

## P2-1 网络吞吐量分析

### 题目描述
考虑与图2.1(b)对应的吞吐量示例。现在假设有M个客户端-服务器对，而不是10个。将Rs、Rc和R分别表示服务器链路、客户端链路和网络链路的速率。假设所有其他链路都具有充足的容量，并且网络中除了M个客户端-服务器对产生的流量之外没有其他流量。推导一个关于Rs、Rc、R和M的吞吐量通用表达式。

### 解答
对于有M个客户端-服务器对的网络拓扑，系统的总吞吐量T的通用表达式为：

**T = min(M × Rs, M × Rc, R)**

其中：
- **Rs**: 每个服务器链路的速率
- **Rc**: 每个客户端链路的速率
- **R**: 中央瓶颈链路的总容量
- **M**: 客户端-服务器对的数量

**解释：**
系统的总吞吐量受到三个约束的限制：
1. 所有服务器链路的总容量：M × Rs
2. 所有客户端链路的总容量：M × Rc
3. 中央瓶颈链路的总容量：R

由于所有流量都必须通过中央瓶颈链路，系统的实际吞吐量等于这三个值中的最小值。这个表达式体现了网络性能受最弱环节限制的基本原理。

## P2-2 多路径网络吞吐量

### 题目描述
考虑图2.2(b)。假设服务器和客户端之间有M条路径，且没有两条路径共享任何链路。每条路径k（k=1到M）由N条链路组成，传输速率分别为R₁ᵏ, R₂ᵏ, ..., Rₙᵏ。

1. 如果服务器只能使用一条路径发送数据，服务器能达到的最大吞吐量是多少？
2. 如果服务器可以使用所有M条路径发送数据，服务器能达到的最大吞吐量是多少？

### 解答

**1. 服务器只能使用一条路径时：**
对于任意一条路径k，它由N个串联的链路组成。在串联链路中，整个路径的吞吐量由其中最慢的链路决定（即瓶颈链路）。

因此，路径k的最大吞吐量为：
Throughput_k = min(R₁ᵏ, R₂ᵏ, ..., Rₙᵏ)

如果服务器只能选择一条路径来发送数据，它会选择在所有M条路径中吞吐量最大的那一条。

**T_one_path = max_{k=1,...,M} (min_{i=1,...,N} R_i^k)**

**2. 服务器可以使用所有M条路径时：**
题目说明"没有两条路径共享任何链路"，这意味着这M条路径是相互独立的。当多条独立路径同时用于数据传输时，它们的吞吐量可以简单地叠加。

每条路径k的最大吞吐量仍然是其瓶颈链路的速率：
Throughput_k = min(R₁ᵏ, R₂ᵏ, ..., Rₙᵏ)

由于服务器可以同时利用所有M条路径，并且它们互不干扰，总的最大吞吐量将是所有路径各自最大吞吐量之和：

**T_all_paths = Σ_{k=1}^{M} (min_{i=1,...,N} R_i^k)**

## P2-3 分组传输时延分析

### 题目描述
考虑图2.2(a)。假设从服务器到客户端路径上的瓶颈链路是第一条链路，速率为Rs bits/sec。一对分组从服务器背靠背发送到客户端，路径上没有其他流量。每个分组大小为L bits，两条链路具有相同的传播时延d_prop。

a) 目的地的分组到达间隔是多少？即从第一个分组的最后一位到达直到第二个分组的最后一位到达经过了多少时间？

b) 现在假设第二条链路是瓶颈链路（即Rc < Rs）。第二个分组是否可能在第二条链路的输入队列中排队？解释。现在假设服务器在发送第一个分组T秒后发送第二个分组。T必须多大才能确保在第二条链路前没有排队？解释。

### 解答

**a) 第一条链路为瓶颈的情况：**
- 分组大小：L bits
- 瓶颈链路速率：Rs bits/sec
- 两分组背靠背发送，间隔保持为瓶颈的发送时间

**T_dest = L / Rs**

**b) 第二条链路为瓶颈的情况：**
- 第二条链路速率：Rc < Rs
- 第二条链路传输时间：L / Rc

**排队分析：**
若仍背靠背发送（T=0），到达第二条链路输入的两分组间隔为0 < L/Rc，第一分组尚未发完第二条链路，第二分组必排队，故会产生排队。

**避免排队的条件：**
若第二个分组在第一个分组之后延迟T秒再发送，则到达第二条链路输入的两分组间隔为T。为避免在第二链路前排队，需要第二链路在第二个分组到达前已发完第一个分组：

**T ≥ L / Rc**

**结论：**
- a) T_dest = L/Rs
- b) 会排队；避免排队的充要条件：T ≥ L/Rc

## P2-4 数据传输方式选择

### 题目描述
假设您需要紧急将50TB数据从北京传送到上海。您有一条100Mbps的专用链路可用于数据传输。您会选择通过这条链路传输数据，还是使用顺丰次晨达？解释。

### 解答

**计算分析：**

**数据量：** 50 TB = 50 × 10¹² bytes = 4 × 10¹⁴ bits

**专用链路传输时间：**
- 链路速率：100 Mbps = 1 × 10⁸ bits/s
- 传输时间：T = 4 × 10¹⁴ / 1 × 10⁸ = 4 × 10⁶ s ≈ 46 天

**24小时内传输所需速率：**
- 所需速率：4 × 10¹⁴ / 86400 ≈ 4.6 Gbps
- 100 Mbps远低于所需速率

**结论：**
选择顺丰次晨达更快。100 Mbps的专用链路需要约46天才能传输完50TB数据，而顺丰次晨达可以在24小时内完成物理传输，因此使用顺丰隔夜寄送硬盘是更优选择。

## P2-5 消息分段传输分析

### 题目描述
考虑图2.3所示的端到端消息传输。假设要发送的消息长度为10⁶ bits，图中每条链路的速率为5Mbps。忽略传播、排队和处理时延。

a) 无消息分段：将整个消息从源主机移动到第一个分组交换机需要多长时间？假设每个交换机使用存储转发分组交换，将消息从源主机移动到目的主机需要多长时间？

b) 有消息分段：消息被分段为100个分组，每个分组长度为10,000 bits。将第一个分组从源主机移动到第一个交换机需要多长时间？当第一个分组从第一个交换机发送到第二个交换机时，第二个分组正从源主机发送到第一个交换机。第二个分组何时完全到达第一个交换机？

c) 使用消息分段时，将整个文件从源主机移动到目的主机需要多长时间？将此结果与(a)部分的答案进行比较并给出评论。

### 解答

**给定条件：**
- 消息大小：10⁶ bits
- 链路速率：5 Mbps = 5 × 10⁶ bits/s
- 网络拓扑：源 → 交换机1 → 交换机2 → 目的

**a) 无消息分段：**
- 从源到第一个交换机：T₁ = 10⁶ / (5 × 10⁶) = 0.2 s
- 总时间（存储转发）：T_total = 3 × 0.2 = 0.6 s

**b) 有消息分段（100个分组，每个10,000 bits）：**
- 第一个分组到第一个交换机：T_first = 10,000 / (5 × 10⁶) = 0.002 s
- 第二个分组完全到达第一个交换机的时间：T_second = 2 × 0.002 = 0.004 s

**c) 分段传输总时间：**
- 最后一个分组开始传输时间：99 × 0.002 = 0.198 s
- 最后一个分组传输时间：0.002 s
- 总时间：T_segmented = 0.198 + 0.002 = 0.2 s

**比较：**
- 无分段：0.6 s
- 有分段：0.2 s
- 分段传输比无分段快3倍

**结论：** 消息分段通过流水线传输显著提高了端到端传输效率，减少了总传输时间。

## P2-6 最优分段大小

### 题目描述
假设您要通过网络从主机A向主机B发送一个大的F bits文件。主机A和主机B之间有三条链路和两个交换机。假设链路不拥塞（即没有排队时延）。主机A将文件分段为S bits的段，每个段添加80 bits的头部。每个生成的分组大小为L = 80 + S bits。三条链路中的每一条都有R bits/sec的传输速率。忽略传播时延。找到使整个文件从主机A移动到主机B的总时延最小的S值。

### 解答

**给定条件：**
- 文件大小：F bits
- 分段大小：S bits
- 包头：80 bits
- 分组大小：L = 80 + S bits
- 链路数：3条
- 链路速率：R bps
- 忽略传播时延

**分析：**
- 分段数：n = F/S
- 每个分组传输时间：t = L/R = (80 + S)/R
- 总传输时间（流水线）：T = (n-1) × t + 3 × t = (n+2) × t

**总时延表达式：**
T = (F/S + 2) × (80 + S)/R

**求最优S：**
对T关于S求导并令导数为0：

dT/dS = (1/R) × [-(F/S²) × (80 + S) + (F/S + 2) × 1] = 0

化简得：
-F(80 + S)/S² + F/S + 2 = 0
-F(80 + S) + FS + 2S² = 0
-80F - FS + FS + 2S² = 0
2S² = 80F
S² = 40F
S = √(40F)

**结论：**
最优分段大小为 **S = √(40F) bits**，此时总传输时延最小。

## P2-7 Skype服务实现

### 题目描述
Skype提供一项服务，允许您从PC拨打普通电话。这意味着语音通话必须通过互联网和电话网络。讨论这是如何实现的。

### 解答

**Skype PC到普通电话的实现方式：**

**1. 网络架构：**
- PC端：通过互联网连接到Skype服务器
- 电话端：通过传统PSTN（公共交换电话网）连接

**2. 关键技术组件：**

**a) 网关（Gateway）：**
- 互联网与PSTN之间的桥梁
- 负责协议转换和数据格式转换

**b) 信令处理：**
- SIP（会话发起协议）用于建立连接
- 处理呼叫建立、保持、释放等信令

**c) 媒体处理：**
- 语音编码/解码（如G.711、G.729）
- 实时传输协议（RTP）用于语音数据传输

**3. 呼叫流程：**
1. PC发起呼叫请求到Skype服务器
2. 服务器通过网关连接到PSTN
3. 网关将互联网协议转换为电话网协议
4. 建立双向语音通道
5. 实时传输语音数据

**4. 技术挑战：**
- 延迟控制（QoS保证）
- 语音质量优化
- 网络地址转换（NAT）穿透
- 安全性和加密

**总结：** 通过网关技术实现互联网与PSTN的互联，实现跨网络语音通信。
